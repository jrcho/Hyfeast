    1 Overview

    2D Modeling and Section Tools는 두 가지 작업을 다룬다.

    1. 단면 도구 — 임의 형상 보 단면의 단면 상수 계산과 비선형 단면해석
    2. 2차원 유한요소 모델링 — 2차원 형상·메쉬를 만들어 hfAnalyzer/hfStudio 모델의 입력으로 활용하는 전처리
    프로그램 역할
    hf2DStudio 두 작업 모두를 수행하는 GUI 작업 환경. 형상 모델링, 메쉬 생성, 단면해석 실행, 결과 검토(chart, contour)
    hfSectAnalyzer 이 중 **단면 도구**에 대응하는 CLI solver. .hf2d 입력 파일을 읽어 단면 상수 계산과 비선형 단면해석을 수행

    1.1 임의 형상 단면의 단면 상수 계산

    • 단면적, 단면이차모멘트, 도심, 비틀림상수, 전단면적 등 단면 상수를 계산한다.
    • 비틀림상수(torsional constant)와 전단면적(shear area)은 2차원 포텐셜 문제의 유한요소해석으로 계산한다.
    • hf2DStudio에서 형상을 모델링하고 유한요소 메쉬를 생성한 뒤 단면 상수를 계산한다.

    Fig. 1. Computation of Sectional Constants

    1.2 임의 형상 단면의 비선형 단면해석

    • 철근콘크리트, 프리스트레스트 콘크리트, FRP 보강 보·기둥 등 다양한 단면의 비선형 단면해석이 가능하다.
    • 재료 모델은 선형탄성, 탄소성, 콘크리트 등을 지원한다. 탄소성·콘크리트 모델의 파괴포락선은 미리 정의된 함수 또는 값 테이블(다중선형)로 지정할 수 있다.

    • 비선형 단면해석의 유형은 다음과 같다.

      • 축력과 모멘트가 주어질 때 축변형과 곡률을 구하는 해석(NM 해석)
      • 축력과 곡률이 주어질 때 축변형과 모멘트를 구하는 해석(NK 해석)
      • 축변형과 모멘트가 주어질 때 축력과 곡률을 구하는 해석(EM 해석)
      • 축변형과 곡률이 주어질 때 축력과 모멘트를 구하는 해석(EK 해석)

    • 위 해석들은 이어서 수행할 수 있으며, 프리텐션과 포스트텐션을 가력할 수 있다.

    Fig. 2는 축력을 0으로 유지한 채 NK 해석으로 모멘트-곡률 곡선을 구하는 개념도다. 단면 설계에 필요한 PM 다이어그램은 여러 축력 수준에 대해 모멘트-곡률 곡선을 계산한 뒤 파괴 시 모멘트(최대 모멘트)를 모아 구한다(Fig. 3).

    1.3 2차원 유한요소 모델링과 hfAnalyzer 활용

    hf2DStudio의 형상·메쉬 작성 기능은 단면 전용이 아니다. 2차원 영역을 그리고 메쉬를 만든 뒤, 그 결과를 클립보드로 내보내 hfStudio/hfAnalyzer 모델의 입력으로 쓸 수 있다.

    1. 임의 2차원 영역을 curve로 그리고 face를 만들어 삼각형/사각형 메쉬를 생성한다 (TFI·Netgen, Mesh Generation).
    2. Model Tree에서 해당 항목을 우클릭해 Export 메뉴로 입력 텍스트를 클립보드에 복사한다.
    3. hfStudio의 File > Import from Clipboard 로 붙여 넣거나, .inp 파일에 직접 붙여 넣는다.
    Model Tree 우클릭 추출 내용
    Section > Export Domain Mesh to Clipboard 2차원 영역 메쉬 (CPS3/CPS4 또는 CPS6/CPS8 요소 입력)
    Section > Export Section to Clipboard 보 단면 입력(*Section, TYPE=Beam) — hfAnalyzer 보 요소의 단면으로 사용
    Geometry > Export Guide to Clipboard *Geometry, TYPE=Guide 형상 입력
    Geometry > Export Curve Mesh to Clipboard 곡선을 따라 나눈 1차원 절점·요소 입력

    같은 추출을 원격 제어 명령(export-domain-mesh, export-section, export-guide-geometry, export-curve-mesh)으로도 할 수 있다 (Operation and Analysis 2.6.9).
