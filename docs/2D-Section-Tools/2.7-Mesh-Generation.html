    2.7 Mesh Generation

    2.7.1 배경

    • hf2DStudio의 domain meshing은 built-in TFI와 외부 Netgen 모듈을 함께 사용한다.
    • TFI(Transfinite Interpolation)는 4-side patch를 대상으로 동작한다. face 경계가 4개의 side chain으로 정리되어야 하고, 서로 마주보는 side chain의 seed/sample 개수가 같아야 한다. 이 조건이 맞으면 TFI는 현재 mesh order에 따라 Q4 또는 Q8 요소를 직접 생성한다.
    • Netgen은 외부 2D mesher이다. 기본적으로 triangular meshing을 만들고, mesh option에 따라 생성된 triangle을 quad-dominated mesh로 합치는 후처리를 할 수 있다.
    • 따라서 자동 메슁의 기본 목표는 "가능하면 TFI로 깔끔한 Q4를 만들고, 그렇지 않으면 Netgen으로 안전하게 메슁한다"이다.

    2.7.2 Use TFI if possible

    Settings > Mesh Generation Option > Use TFI if possible (Generate Q4 elements if possible)를 켜면 Auto Mesh는 face마다 먼저 TFI boundary plan을 만들 수 있는지 시도한 뒤, 실패한 경우 Netgen으로 넘어간다.

    현재 알고리즘은 다음 순서로 동작한다.

    1. 대상 face는 outer loop가 하나이고 curve가 최소 4개 이상이어야 한다.
    2. face에 Quad Mesh Corner Hints가 있으면 그 4개의 outer-loop join point를 먼저 사용한다. 내부 side chain은 outer loop 순서로 정리된다.
    3. hint가 없으면 automatic corner detection을 시도한다. outer loop의 각 join에서 turning angle을 계산해서, 큰 양의 turn(>= 30 deg)은 hard corner로 보고, 나머지 join은 거의 smooth한 상태(|angle| <= 15 deg)여야 한다.
    4. hint가 없고 loop curve 수가 16개 이하이면 outer-loop join point 중 4개를 고르는 후보 조합도 검사한다.
    5. 후보 corner가 정해지면 boundary를 4개의 side chain으로 나눈다. 이때 하나의 logical side가 여러 connected curve로 나뉘어 있어도 하나의 side chain으로 묶어서 해석한다.
    6. 각 side chain은 curve type과 무관하게 seedPoints()로 sample된다. 따라서 line, arc, bezier, spline 모두 같은 interval matching 규칙을 따른다.
    7. 서로 마주보는 side chain의 interval 개수가 같고, 생성될 TFI grid cell이 유효하면 built-in TFI를 수행해서 현재 mesh order의 quad 요소를 생성한다.
    8. 유효한 후보가 정확히 하나가 아니거나 위 단계 중 하나라도 실패하면 해당 face는 Netgen으로 fallback된다.

    즉 Use TFI if possible는 무조건 TFI를 강제하는 옵션이 아니다. "먼저 TFI를 시도하고, 유효한 TFI patch가 아니면 Netgen으로 계속 진행한다"는 뜻이다.

    2.7.3 Auto Seed와 TFI interval correction

    Geometry > Auto seed와 Remote Control auto-seed는 먼저 선택 curve의 max-H를 맞추는 rough seed pass를 실행한다. 그 다음 가능한 face에 대해 TFI interval correction을 보수적으로 시도한다.

    • correction 대상은 hole이 없는 단일 outer-loop face이고, 해당 outer loop의 모든 curve가 이번 Auto Seed 대상에 포함되어야 한다.
    • face에 Quad Mesh Corner Hints가 있으면 그 hint plan을 먼저 사용하고, hint가 없을 때만 자동 corner 후보를 사용한다.
    • 보정은 부족한 side의 seed를 늘리는 방향으로만 수행한다. face 단위 budget은 min(4, max(1, ceil(totalSideIntervals * 0.20)))이다.
    • 보정 후 유효한 TFI 후보가 정확히 하나일 때만 seed 변경을 확정한다. 후보가 없거나 여러 개이면 rough seed만 유지한다.

    mesh 생성 자체는 seed를 바꾸지 않는다. Auto Mesh나 make-mesh build는 이미 저장된 seed와 Quad Mesh Corner Hints를 읽어서 TFI 또는 Netgen 경로를 선택한다.

    2.7.4 Enable quadrilateral-dominated meshing

    Settings > Mesh Generation Option > Enable quadrilateral-dominated meshing (Convert T3 to Q4 if possible)를 켜면 Netgen 경로에서 순수 삼각형 결과 대신 quad-dominated 결과를 우선 요청한다.

    • 이 옵션은 Netgen으로 메슁되는 face에 영향을 준다.
    • Netgen은 여전히 triangle 중심의 2D mesher이므로, 결과가 전부 Q4가 되는 것은 아니다.
    • 경계 형상과 국부 topology가 허용하면 Netgen은 적절한 T3 영역을 4각형 요소로 합치고, 그렇지 않은 부분은 삼각형으로 남긴다.
    • built-in TFI가 먼저 성공한 face는 이미 직접 Q4를 생성하므로, 이 옵션은 주로 fallback된 face나 TFI를 끈 경우에 의미가 있다.

    즉 이 옵션은 "Netgen 결과에서 4각형 비중을 더 높이도록 시도한다"는 뜻이지, "모든 face를 순수 quad mesh로 강제한다"는 뜻은 아니다.

    2.7.5 Corner Hints가 필요한 이유

    automatic corner detection만으로는 충분하지 않은 경우가 있다. 대표적인 예는 다음과 같다.

    • 하나의 logical side가 여러 connected curve로 나뉘어 있는 경우
    • rounded corner나 smooth transition 때문에 경계의 corner가 약하게 보이는 경우
    • 사람이 보기에는 quadrilateral patch인데, automatic detector가 신뢰할 수 있는 4개의 corner를 찾지 못하는 경우

    Quad Mesh Corner Hints는 이런 상황에서 face-level guidance를 제공한다. 기존 Auto Mesh 흐름은 그대로 유지하면서, mesher에게 어떤 4개의 outer-loop point를 TFI corner로 해석해야 하는지 알려주는 기능이다.

    2.7.6 Hint가 저장하는 정보

    Quad Mesh Corner Hint는 face 하나에 연결된 point id 4개이다.

    • 4개의 point는 서로 달라야 한다.
    • 4개의 point는 모두 같은 face의 outer-loop join point여야 한다.
    • 입력한 point 순서는 저장된 hint marker 번호에만 영향을 준다. 실제 side chain은 outer loop 순서로 정리된다.

    내부적으로는 임시 좌표가 아니라 point id로 저장된다.

    2.7.7 Hint 입력 방법

    편집 가능한 left view에서 face가 정확히 하나 선택되어 있으면 다음 위치에서 hint를 입력하거나 지울 수 있다.

    • Geometry > Quad Mesh Corner Hints...
    • Geometry > Clear Quad Mesh Corner Hints
    • Geometry toolbar 버튼
    • Model Tree의 face 우클릭 메뉴
    • Section view의 face 우클릭 메뉴

    Quad Mesh Corner Hints...를 열면 선택된 face에 대한 편집 세션이 시작된다.

    • 단일 입력칸에 p1, p2, p3, p4를 직접 입력하거나, view에서 corner를 바로 클릭할 수 있다.
    • Apply는 hint를 검증하고 성공하면 dialog를 닫는다.
    • Close는 pending 변경을 적용하지 않고 세션만 닫는다.
    • picking 중 Backspace는 마지막 corner를 제거한다.
    • Esc는 picking 세션을 취소한다.

    2.7.8 시각적 표시

    저장된 hint가 있는 face는 section view에서 가벼운 overlay로 표시된다.

    • 번호가 붙은 corner marker 1..4
    • 저장된 corner를 잇는 dashed polygon

    이 저장 overlay의 표시 여부는 다음 설정에서 조절할 수 있다.

    • Settings > Display Geometric Entity > Quad Mesh Corner Hints

    active editing 중에는 현재 target face에 대해 pending corner와 다음에 선택 가능한 join point hover feedback도 계속 표시된다.

    2.7.9 권장 사용 순서

    실무에서는 다음 순서를 권장한다.

    1. TFI 기반 Q4 메슁을 원하면 Use TFI if possible (Generate Q4 elements if possible)를 켠다.
    2. TFI가 안 되는 face에서도 triangle-only 결과를 줄이고 싶으면 Enable quadrilateral-dominated meshing (Convert T3 to Q4 if possible)도 함께 켠다.
    3. TFI를 의도한 face의 boundary curve 전체를 대상으로 Auto seed를 실행한다.
    4. Auto Mesh 또는 make-mesh build를 실행한다.
    5. 특정 face가 Netgen으로 fallback되거나, 의도한 quad patch가 나오지 않으면 그 face에 Quad Mesh Corner Hints를 준 뒤 다시 메슁한다.

    이 방식이면 기본 흐름은 단순하게 유지하면서, automatic interpretation이 애매한 face에만 hint를 추가할 수 있다.
