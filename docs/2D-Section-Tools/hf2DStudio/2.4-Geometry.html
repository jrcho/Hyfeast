    2.4 Geometry

    hf2DStudio의 Geometry 메뉴와 Geometry 툴바는 단면 외곽선을 그리고, 점을 편집하고, face와 rebar를 만들고, mesh seed를 조정한다.

    같은 동작을 자동화하려면 Remote Control Geometry를 본다. ortho/snap 토글은 RC에서는 View 명령군에 묶여 있다.

    2.4.1 편집 가능 조건

    geometry 작성/편집 명령은 편집 가능한 geometry section이 있어야 한다. GUI에서는 기존 mesh를 무효화하는 명령이 확정 직전에 현재 mesh를 취소할지 묻고, No를 선택하면 해당 편집을 취소하고 mesh를 유지한다. Remote Control에서는 먼저 make-mesh delete를 실행해야 한다.

    2.4.2 Drawing 보조 토글

    • Ortho mode (F3) — 마우스 드로잉을 축 정렬로 제한. RC: ortho-mode <on|off>.
    • Snap to geometry (F4) — 기존 geometry에 스냅. RC: snap-to-geometry <on|off>.
    • Snap to grid (F5) — grid에 스냅. RC: snap-to-grid <on|off>.

    두 snap은 독립이며 동시에 켤 수 있다. 둘 다 켜진 상태에서는 geometry 스냅이 grid 스냅보다 우선한다.

    2.4.3 점/선 그리기

    GUI에서는 toolbar/menu의 토글로 모드를 켠 뒤 마우스로 좌표를 클릭한다. Remote Control에서는 좌표를 인수로 직접 넘긴다.

    • Drawing Points: RC: draw-point <yp,zp>
    • Drawing Lines: RC: draw-lines <yp,zp|P<id>> <yp,zp|P<id>> ...
    • Drawing Arc: 시작/중간/끝 3점. RC: draw-arc <p1> <p2> <p3>.
    • Drawing Bezier2: 2차 bezier. RC: draw-bezier2 <p1> <p2> <p3>.
    • Drawing Bezier3: 3차 bezier. RC: draw-bezier3 <p1> <p2> <p3> <p4>.
    • Drawing RBezier2: rational 2차 bezier. RC: draw-rbezier2 <p1> <p2> <p3> --weights <w1>.
    • Drawing RBezier3: rational 3차 bezier. RC: draw-rbezier3 <p1> <p2> <p3> <p4> --weights <w1,w2>.
    • Drawing Spline: 닫으려면 마지막 점을 첫 점과 같게. RC: draw-spline <p1> <p2> <p3> [...].

    좌표는 모두 yp,zp 형식. 음수 좌표는 따옴표로 감싼다 (예: "-25,10").

    GUI 좌표 입력창은 CAD 방식의 직접 입력도 받는다.

    • yp,zp: 절대 section 좌표. 각 성분에는 math expression을 사용할 수 있다.
    • @dyp,dzp: 현재 기준점 기준 상대 좌표. 각 offset에는 math expression을 사용할 수 있다.
    • @L<A: 현재 기준점 기준 상대 극좌표. L에는 math expression을 사용할 수 있고, A는 부호가 있는 degree 숫자만 허용한다.

    Point 그리기에서는 현재 기준점이 마지막으로 확정 입력된 point이다. Line/curve 그리기에서는 현재 construction의 첫 점이 확정된 뒤에만 기준점이 있고, 그 construction에서 마지막으로 확정된 점을 사용한다. Pencil 점 수정 중에는 선택된 점의 원래 위치가 기준점이다. 기준점이 없으면 상대 입력은 실패한다. Math expression은 기존 parser 규칙을 그대로 사용하므로 삼각함수 인자는 radian이다. 극좌표 각도 A는 math expression이 아니며 degree로 해석하고, 양의 방향은 +yp에서 +zp 쪽이다.

    2.4.4 도형 Generator

    • Generate Circle: rational quadratic bezier 4개로 닫힌 원. RC: generate-circle <radius> <yp> <zp>.
    • Generate Circular Points: 원주 위 점만 생성. RC: generate-circular-points <radius> <yp> <zp> <start-angle-deg> <count>.

    2.4.5 점 편집

    • Pencil (Modify): 선택한 point 하나를 수정한다. 같은 위치에 여러 point가 있으면 수정할 point id를 선택한다. RC: move-point <id> <yp,zp> [--merge <on|off>].
    • Move Selection: 현재 선택된 point/curve/face/rebar를 기준점과 목표점으로 정의한 벡터만큼 이동한다. 두 클릭은 offset만 정의하며, 이동 대상 point id는 현재 selection에서 환산한다. 따라서 같은 좌표에 있어도 선택되지 않은 point id는 그대로 남는다. GUI 기록은 별도 move-selection 명령이 아니라 영향을 받은 point마다 move-point 명령으로 남긴다.
    • Copy Selection: 현재 선택된 point/curve/face/rebar를 기준점과 목표점으로 정의한 벡터만큼 복사한다. GUI 기록은 필요한 select 명령을 먼저 남긴 뒤 copy-selection --offset <yp,zp>를 남긴다.
    • Merge Coincident Points: 선택된 같은 좌표의 point를 한 topology point로 병합. RC: merge-selected-points.
    • Detach Selected Points: 여러 curve가 공유하는 선택 point를 분리한다. face가 참조하는 분리 후보가 있으면 실패하고, rebar가 참조하는 point는 차단한다. RC: detach-selected-points.

    move-point --merge on은 이동한 point를 기존 topology에 명시적으로 연결한다. --merge off(기본)는 좌표만 이동.

    GUI 편집이 기존 mesh를 삭제하면 Remote History에는 geometry 편집 명령 앞에 make-mesh delete가 기록된다. 사용자가 No를 선택하면 편집 명령은 기록되지 않는다.

    2.4.6 Selection

    • Select All: 모든 종류 선택 모드 (toggle). RC에서는 select <kind> ... --mode replace로 종류별 선택.
    • Select Point: point 선택 모드 (toggle). RC: select point <id,...>.
    • Select Wire: curve 선택 모드 (toggle). RC: select curve <id,...>.

    RC select는 종류(point|curve|face|rebar)와 id를 직접 받고 --mode <replace|add|remove|toggle>로 선택 결합 방식을 지정한다.

    선택된 항목 일괄 삭제는 delete-selection. face/rebar는 즉시 삭제, 참조되는 curve/point는 선택 상태로 남겨둔다.

    직접 삭제(선택 없이 id 지정):

    • delete-point <id,...> — curve/rebar가 참조하지 않는 point만 삭제, 막힌 id는 blockedIds로 보고
    • delete-curve <id,...> — face가 참조하지 않는 curve만 삭제
    • delete-face <id,...>
    • delete-rebar <id,...>

    2.4.7 Mesh Seed

    • Edit seed: 선택된 curve의 seed를 수동 입력. RC: set-seed --curve-ids <id,...> --seed <integer>.
    • Auto seed: 선택된 curve의 max-H 기반 rough seed 계산 후, 가능한 face에 대해 보수적인 TFI interval correction 수행. RC: auto-seed --curve-ids <id,...>.

    auto-seed는 GUI Auto Seed 버튼과 동일한 계산 결과를 만든다.

    2.4.8 Face와 Rebar

    • Make Face: 선택된 curve로 닫힌 region을 해석해 face 생성. RC: make-face --material <name> --curve-ids <id,...>.
    • Make Rebar: 선택된 point에 철근 생성. RC: make-rebar --material <name> --point-ids <id,...> --diameter <value>.

    make-face는 요청한 curve들이 정확한 face 하나를 이루면 그대로 생성하고, 그렇지 않으면 bounded cell을 해석해 cell마다 face 하나씩 생성한다. 같은 resolved curve 집합으로 이미 존재하는 face는 건너뛴다.

    2.4.9 Quad Mesh Corner Hints

    quad mesh가 face 코너를 어떻게 인식할지 힌트로 지정한다.

    • Quad Mesh Corner Hints (Edit) — hint editor 대화상자 열기
    • Pick Quad Mesh Corner Hints: 마우스로 hint 점 직접 picking
    • Clear Quad Mesh Corner Hints: 선택된 face의 hint 모두 지우기

    corner hint 자체는 RC에 별도 명령이 없다. mesh 생성은 Operation > Make Linear/Quadratic Mesh에서 hint를 자동으로 사용한다. hint가 있으면 auto-seed interval correction과 mesh 생성 모두에서 자동 corner 판정보다 우선한다.

    2.4.10 Renumber (geometric entities)

    선택된 active section의 point/curve/face/rebar id를 1부터 시작해 재정렬한다. 외부 참조 id는 모두 무효화되므로 이후 단계에서는 새 id를 다시 조회해서 써야 한다.

    자동화: renumber.
