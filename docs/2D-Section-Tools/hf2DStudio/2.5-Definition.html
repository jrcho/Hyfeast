    2.5 Definition

    hf2DStudio의 Definition 메뉴는 환경(unit system), function, material, section, section analysis 정의 위젯과 Section Wizard를 연다.

    같은 동작을 자동화하려면 Remote Control Definition을 본다.

    2.5.1 메뉴 구성

    • Environment: unit system 편집기 (Command dock). RC: environment-unit-system get|set <text>.
    • Edit function: Function 편집기 (Command dock). RC: function <type> <name> ....
    • Edit material: Material 편집기 (Command dock). RC: material <type> <name> ....
    • Edit section: Section 편집기 (Command dock). RC: section <name> ....
    • Edit section analysis: Analysis 편집기 (Command dock). RC: analysis <name> --section <name> ....
    • Section Wizard: H/T/C/L/2C/2L/HR 표준 단면 generator 대화상자. RC: template-mesh <H|T|C|2C|L|2L|HR> <name> ....

    GUI Apply는 같은 canonical Remote Control tail을 history와 *.ipc.txt에 기록한다.

    2.5.2 공통 본문 규칙

    블록 텍스트를 편집하는 정의 명령(function, material, section, analysis)은 모두 GUI Apply와 같은 본문 문법을 사용한다.

    • Remote Control은 --content <text> 또는 --content-file <file> 한쪽을 받는다.
    • --content 안에서는 줄바꿈을 \n으로 쓴다. \\n은 문자 그대로 유지된다.
    • 빈 본문은 거부된다.
    • 명령이 성공하면 section model을 즉시 갱신하고 변경 상태로 표시한다.

    2.5.3 Environment (Unit System)

    • force-length-time-temp 4-필드 token: N-m-s-K, kN-cm-s-K, N-mm-s-Celsius 등. section 단위계 지정.
    • none: section 단위계 해제.

    자동화: environment-unit-system get / set <token|none>. Command 패널의 Environment 편집기 Apply도 같은 결과를 만든다.

    2.5.4 Function

    *Function, TYPE=<type>, Name=<name> 정의 하나를 생성/갱신한다.

    콘크리트 DB envelope 입력은 같은 명령 형식으로 작성한다. 허용 기준은 function type별로 다르며, 예를 들어 MaekawaTEnv 본문은 KDS-2026-C30, ACI318-2025-C4000, EC2-2004-C30 또는 끝에 , ToDirectForm을 붙인 형태로 쓸 수 있다. ParabolaCEnv는 단면해석용 입력이므로 KDS/EC2 계열만 받으며 ToDirectForm 앞에 alpha를 둘 수 있다. HognestadCEnv, EC2CEnv, MPPCEnv에서 원래 초기곡선이 필요하면 EciCurve를 ToDirectForm 앞에 둔다. DB function 본문에는 local UnitSystem=... keyword를 넣지 않는다.

    ConcreteTime도 Function 편집기에서 사용할 수 있다. Builder는 User named-group 형식을 만드는 Direct 모드와 EC2-2004-C..., KDS-2026-C..., ACI209-1992-C... dataline을 만드는 Standard 모드를 제공한다. 사용자 정의형은 기존 function 이름만 참조한다. 기준식 dataline은 section global UnitSystem이 먼저 정의되어 있어야 하며, Type=ConcreteTime에는 local UnitSystem=... keyword를 쓰지 않는다.

    자동화: function <type> <name> --content ....

    2.5.5 Material

    *Material, TYPE=<type>, Name=<name> 정의 하나를 생성/갱신한다.

    추가 옵션:

    • --neg-stop-strain <value>, --pos-stop-strain <value>: material 본문 적용 후 stop strain을 덮어쓴다.
    • --signal <text> 또는 --signal-file <file>: 같은 material에 section signal 정의를 추가한다 (서로 배타적).

    자동화: material <type> <name> --content ... [--signal ...].

    2.5.6 Section

    *Section, Name=<name> 정의 하나를 생성/갱신한다.

    추가 옵션:

    • --taper <on|off>: section의 taper 속성. 생략하면 현재 상태 유지.
    • --taper on으로 전환되면 이후 생성되는 geometry는 좌/우 쪽을 독립적으로 관리할 수 있게 된다.

    자동화: section <name> --content ... [--taper <on|off>].

    2.5.7 Analysis

    *Analysis, Name=<name> 정의 하나를 생성/갱신한다. --section <name>이 반드시 필요하다.

    추가 옵션:

    • --right <on|off>: taper section에서 right-side geometry를 해석 대상으로 사용할지 (기본 off).
    • --ref <angle,yp,zp>: 해석 기준 좌표계 회전각(deg)과 원점.
    • --output <Preselect|All>: 결과 항목 범위 (기본 Preselect).

    자동화: analysis <name> --section <name> --content ....

    2.5.8 Section Wizard (Template Mesh)

    표준 단면 H, T, C, 2C, L, 2L, HR 형상 입력으로 mesh-only 단면 하나를 생성한다.

    • section geometry는 만들지 않는다. 같은 이름의 기존 geometry가 있으면 제거한다.
    • <H|T|C|2C|L|2L>: --B1, --tw, --tf1 필수. --B2 생략 시 --B1, --tf2 생략 시 --tf1 사용.
    • HR: --B(외측 폭), --t(벽 두께), --r(inner corner radius) 필수.
    • 생성 mesh는 적용 가능한 위치에서 Q8 사각 cell, T6 quarter-fillet cell, HR annular-corner Q8 cell을 사용한다.
    • mesh 생성 직후 section constants를 함께 계산한다.

    자동화: template-mesh <type> <name> --material <name> --H <value> ....
