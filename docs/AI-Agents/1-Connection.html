    1. 연결

    Claude Code, Codex, Claude 데스크톱 앱 같은 AI 에이전트에게 "frame.inp를 해석하고 Case3 변위 등고선을 그림으로 저장해 줘", "300x500 사각 단면을 만들어 hfStudio 모델에 넣어 줘"처럼 말로 요청하면, 에이전트가 실행 중인 hfStudio와 hf2DStudio를 직접 조작하게 할 수 있다. 연결에는 MCP(Model Context Protocol) 서버 hyfeast-mcp를 쓴다. 이 서버는 에이전트의 요청을 Remote Control 명령으로 바꿔 hfStudio.com --remote와 hf2DStudio.com --remote로 전달한다.

                                      ┌→ hfStudio.com --remote   → 실행 중인 hfStudio
Claude Code / Codex → hyfeast-mcp ┤
                                  └→ hf2DStudio.com --remote → 실행 중인 hf2DStudio

    에이전트는 Remote Control 명령 문법을 몰라도 된다. 서버가 명령 순서, 경로, 오류 해석을 맡고, hf2DStudio에서 만든 단면·가이드·2D 메쉬를 hfStudio 모델로 옮기는 일도 도구 하나로 처리한다. 실행한 명령은 앱 이름과 대상 인스턴스(--target)까지 포함해 결과마다 그대로 남으므로 같은 작업을 PowerShell에서 다시 실행하거나 script로 옮길 수 있다.

    1.1 준비

    서버는 ZIP을 풀어 만든 배포 폴더의 Bin\mcp\hyfeast-mcp.exe에 있다. Python 설치나 별도 설정은 필요 없다.

    • 이 exe는 한 단계 위 Bin 폴더의 hfStudio.com과 hf2DStudio.com을 스스로 찾는다. Bin\mcp 폴더를 다른 곳으로 옮기지 않는다.
    • 에이전트 프로그램(Claude Code, Codex, ChatGPT 데스크톱 앱, Claude 데스크톱 앱 중 하나)이 설치돼 있어야 한다.
    • 이 절의 배포 폴더 예시는 D:\Apps\Hyfeast-v1.0.0이다. 아래 실행 파일 경로와 JSON 설정의 경로는 실제 압축 해제 위치와 버전 이름에 맞춰 바꾼다. 배포 폴더를 옮기거나 새 버전 폴더를 사용하면 등록 경로도 갱신한다.

    등록과 확인 방법은 에이전트를 쓰는 환경에 따라 다르다. 자기 환경의 줄만 따라 하면 된다.

    사용 환경 해당 프로그램·화면 등록 확인
    코딩 에이전트 ChatGPT 데스크톱 앱의 Codex 모드, Claude 데스크톱 앱의 Code 탭, VS Code 확장 에이전트에게 말로 요청(1.3절) 에이전트에게 말로 질문(1.7.1절)
    명령창 Claude Code CLI, Codex CLI claude mcp add(1.4절), codex mcp add(1.5절) claude mcp list, codex mcp list(1.7.1절)
    채팅 Claude 데스크톱 앱의 채팅 설정 파일 직접 수정(1.6절) 앱의 Settings > Developer 화면
    • 어느 것을 쓸지 모르면 코딩 에이전트 방법이 가장 쉽다.
    • ChatGPT 데스크톱 앱에서는 Codex 모드를 쓴다.

    1.2 설정값

    보통은 아무것도 지정하지 않는다. 기본값을 바꿀 때만 에이전트 등록 설정(1.4~1.6절)의 환경변수(env)로 적는다.

    변수 내용
    HYFEAST_WORKDIR 상대 경로의 기준 폴더. 생략하면 에이전트가 서버를 시작한 폴더(보통 작업 폴더)다.
    HYFEAST_ANALYSIS_WAIT_TIMEOUT_MS 해석 완료를 기다리는 최대 시간(기본 600000). 넘으면 기다리기만 멈추고 해석은 계속된다.
    HYFEAST_HFSTUDIO_CLI hfStudio.com의 경로. hyfeast-mcp.exe를 Bin\mcp 밖으로 옮겼을 때만 지정한다. .exe를 지정하면 설정 오류로 처리한다.
    HYFEAST_HF2DSTUDIO_CLI hf2DStudio.com의 경로. 생략하면 hfStudio.com과 같은 폴더의 hf2DStudio.com을 쓴다.
    HYFEAST_MCP_LOG_FILE 서버 로그를 남길 파일 경로. 문제를 알릴 때 쓴다.

    서버는 시작할 때 두 .com의 --version을 한 번씩 실행해 설정을 확인한다. 한쪽이 실패해도 서버는 뜨고, 그 앱의 도구만 configuration_error와 원인을 돌려준다.

    1.3 에이전트에게 등록 요청

    명령을 실행할 수 있는 코딩 에이전트(ChatGPT 데스크톱 앱의 Codex 모드, Claude 데스크톱 앱의 Code 탭, VS Code 확장 등)는 말로 요청하면 직접 등록한다. 명령창이나 설정 파일을 다룰 필요가 없어 가장 쉽다.

    D:\Apps\Hyfeast-v1.0.0\Bin\mcp\hyfeast-mcp.exe를 hyfeast라는 이름의 MCP 서버로 등록해 줘.
    • 등록한 뒤 새 세션(대화)을 열어야 HYFEAST 도구가 보인다.
    • hyfeast가 이미 다른 경로로 등록돼 있으면 에이전트가 새 경로로 바꾼다. 확인 방법은 1.7.1절에 있다.
    • 채팅 모드는 명령을 실행하지 못하므로 이 방법을 쓸 수 없다. Claude 데스크톱 앱 채팅은 1.6절을 따른다.

    1.4 Claude Code에 등록 (명령창)

    Claude Code를 여는 작업 폴더에 .mcp.json을 둔다.

    {
  "mcpServers": {
    "hyfeast": {
      "type": "stdio",
      "command": "D:\\Apps\\Hyfeast-v1.0.0\\Bin\\mcp\\hyfeast-mcp.exe"
    }
  }
}

    모든 작업 폴더에서 쓰려면 .mcp.json 대신 다음 명령으로 한 번만 등록한다. 이 절의 명령은 PowerShell과 cmd(명령 프롬프트)에서 같다.

    claude mcp add --scope user hyfeast -- "D:\Apps\Hyfeast-v1.0.0\Bin\mcp\hyfeast-mcp.exe"

    .mcp.json이 있는 폴더에서 Claude Code를 처음 열면 hyfeast 서버를 쓸지 묻는다. 승인하면 연결된다. 등록 상태 확인은 1.7.1절에 있다. 확인할 때 Pending approval로 나오면 Claude Code를 대화형으로 열어 승인한다.

    1.5 Codex에 등록 (명령창)

    Codex CLI와 IDE 확장은 같은 설정 파일(~/.codex/config.toml)을 쓰므로 한 번만 등록한다. 명령은 PowerShell과 cmd(명령 프롬프트)에서 같다.

    codex mcp add hyfeast -- "D:\Apps\Hyfeast-v1.0.0\Bin\mcp\hyfeast-mcp.exe"

    등록 상태 확인은 1.7.1절에 있다. 등록을 지울 때는 codex mcp remove hyfeast를 쓴다. 설정을 바꿀 때는 지운 뒤 다시 등록한다.

    명령창에서 codex가 없거나 오류가 날 때: 위 명령은 명령창의 Codex CLI(codex)로 실행한다. Codex 앱을 설치해도 명령창용 codex는 PATH에 추가되지 않는다. 예전에 설치한 오래된 codex가 실행되면 현재 설정 파일을 읽지 못해 Error loading config.toml 같은 오류가 난다.

    • codex --version으로 확인한다. 명령을 찾지 못하거나 위 오류가 나면 아래 중 하나로 한다.
    • Node.js(npm)가 있으면 최신 CLI를 설치한다: npm install -g @openai/codex@latest. 이미 설치돼 있어도 같은 명령으로 최신으로 올라간다.
    • npm이 없으면 Codex 앱에 포함된 CLI를 전체 경로로 실행한다: %LOCALAPPDATA%\OpenAI\Codex\bin\<폴더>\codex.exe. 앱이 업데이트되면 <폴더> 이름이 바뀐다. bin 바로 아래의 codex.exe는 예전 파일일 수 있으니 쓰지 않는다.
    • Codex 앱 안에서 쓰는 데에는 영향이 없다.

    1.6 Claude 데스크톱 앱 채팅에 등록

    Claude 데스크톱 앱의 채팅에서 쓰려면 설정 파일 %APPDATA%\Claude\claude_desktop_config.json에 등록한다. 앱의 Settings > Developer > Edit Config로도 이 파일을 열 수 있다.

    {
  "mcpServers": {
    "hyfeast": {
      "command": "D:\\Apps\\Hyfeast-v1.0.0\\Bin\\mcp\\hyfeast-mcp.exe",
      "env": {
        "HYFEAST_WORKDIR": "D:\\Work\\Hyfeast"
      }
    }
  }
}
    • 파일에 이미 다른 내용이 있으면 mcpServers 안에 hyfeast 항목만 추가한다.
    • 데스크톱 앱에는 작업 폴더가 없으므로 HYFEAST_WORKDIR로 상대 경로의 기준 폴더를 정한다. 지정하지 않으면 요청할 때 파일 경로를 절대 경로로 말한다.
    • 저장한 뒤 Claude 앱을 완전히 종료했다가 다시 실행해야 반영된다.

    1.7 등록과 연결 확인

    1.7.1 등록된 MCP 확인

    코딩 에이전트(1.3절)에서는 말로 묻는다. 에이전트가 설정을 읽어 등록 여부와 실행 파일 경로를 알려 준다.

    hyfeast-mcp.exe를 MCP로 쓰고 있는지, 어디에 있는 것을 쓰는지 알려줘.

    명령창에서는 다음 명령으로 확인한다. 명령은 PowerShell과 cmd에서 같다.

    에이전트 등록된 MCP 전체 보기 hyfeast만 자세히 보기 정상이면
    Claude Code claude mcp list claude mcp get hyfeast 목록에 hyfeast가 있고 Connected로 나온다. 이 명령은 서버를 실제로 실행해 접속까지 확인한다.
    Codex codex mcp list codex mcp get hyfeast hyfeast 줄의 Command가 hyfeast-mcp.exe 경로이고 Status가 enabled다. 등록만 확인하며 서버에 접속하지는 않는다.
    Claude 데스크톱 앱 Settings > Developer 화면 같은 화면 서버 목록에 hyfeast가 있다. 등록 내용은 %APPDATA%\Claude\claude_desktop_config.json에 있다.
    • Claude Code는 작업 폴더의 .mcp.json에 등록한 서버를 그 폴더에서 명령을 실행할 때만 보여 준다. --scope user로 등록했으면 어느 폴더에서나 보인다.
    • claude를 찾을 수 없다고 나오면 Claude Code가 VS Code 확장으로만 설치된 경우다. VS Code의 Claude Code 채팅창에 /mcp를 입력하면 같은 목록이 나온다.
    • codex 명령이 없거나 오류를 내면 1.5절의 "명령창에서 codex가 없거나 오류가 날 때"를 본다.

    1.7.2 연결 확인

    등록한 뒤 hfStudio나 hf2DStudio를 하나 띄우고 에이전트에게 다음처럼 요청한다.

    HYFEAST 도구로 실행 중인 hfStudio와 hf2DStudio 목록과 상태를 알려줘.

    에이전트가 hyfeast_list_instances와 hyfeast_status를 호출해 실행 중인 프로그램의 버전과 열린 파일을 알려 주면 연결된 것이다. 사용 방법과 예는 2. 사용 예에 있다.

    1.8 문제 해결

    증상 원인과 조치
    configuration_error: .com을 찾지 못함 hyfeast-mcp.exe가 배포본의 Bin\mcp 폴더 안에 있는지 확인한다. 다른 곳으로 옮겼다면 HYFEAST_HFSTUDIO_CLI에 Bin\hfStudio.com 경로를 지정한다.
    configuration_error: .com이 아님 HYFEAST_HFSTUDIO_CLI, HYFEAST_HF2DSTUDIO_CLI를 .exe가 아니라 .com으로 지정한다.
    configuration_error: --version 실패 hfStudio.com이 실행되지 않았다. Bin 폴더의 파일(포함된 Visual C++ 런타임 DLL 포함)이 빠짐없이 풀렸는지 확인한다. 그래도 실행되지 않으면 배포본 README대로 최신 Microsoft Visual C++ 재배포 패키지를 설치해 본다.
    target_error: 인스턴스 없음 해당 프로그램을 먼저 실행한다.
    target_error: 인스턴스 여러 개 에이전트에게 대상 인스턴스를 지정하라고 요청하거나 하나만 남긴다.
    codex mcp ...가 Error loading config.toml 등으로 실패 오래된 codex가 실행됐다. 1.5절대로 최신 CLI를 설치하거나 앱에 포함된 CLI를 쓴다.
    에이전트가 HYFEAST 도구를 모름 등록 뒤 에이전트를 다시 시작하지 않았다. Claude Code·Codex는 새 세션을 열고, Claude 데스크톱 앱은 완전히 종료했다가 다시 실행한다.

    사용 중에 나오는 오류는 2. 사용 예에 있다. 서버 로그는 에이전트의 MCP 로그에 남는다. 파일로 남기려면 HYFEAST_MCP_LOG_FILE에 경로를 지정한다(1.2절).
