    2. 사용 예

    1. 연결대로 등록한 뒤 AI 에이전트에게 평소 말로 요청하는 방법과 간단한 예를 보인다. 배포 폴더는 D:\Apps\Hyfeast-v1.0.0, 작업 폴더는 D:\Work인 경우다. 경로는 실제 압축 해제 위치와 작업 폴더로 바꿔 쓴다.

    2.1 사용 방법

    1. 쓸 프로그램을 먼저 실행해 둔다. 배포 폴더의 HyfeastCmd.bat으로 연 명령 프롬프트에서 hfStudio나 hf2DStudio를 실행한다. 에이전트는 프로그램을 띄우거나 닫지 않는다.
    2. 에이전트에게 할 일을 평소 말로 요청한다. 요청 앞에 "HYFEAST로"를 붙이면 에이전트가 HYFEAST 도구를 쓴다.
    3. 에이전트가 도구를 차례로 호출하고 결과를 알려 준다. 처음 쓰는 도구는 실행해도 되는지 묻는 경우가 있다.

    요청할 때 다음을 지키면 결과가 정확해진다.

    • 파일은 경로와 이름을 함께 말한다. 상대 경로는 작업 폴더 기준이다. 저장할 폴더는 미리 있어야 한다.
    • 결과는 step 이름으로 말한다. 예: Case3, FrqStep. frame을 말하지 않으면 마지막 frame을 보여 준다.
    • 덮어쓰기는 명시한다. 같은 이름의 파일이 있으면 에이전트가 멈추고 묻는다.
    • 단면이 여러 개면 이름을 말한다. 예: "RectRC-3D 단면을 활성화해서". 에이전트가 hyfeast_status로 목록을 보고 hyfeast_2d_activate_section으로 바꾼다.
    • 요청 취소는 프로그램의 작업 취소와 다르다. 실행 중인 CLI 자식은 종료·회수한 뒤 다음 요청을 처리하지만, 프로그램에 이미 전달된 명령이나 해석이 취소되는 것은 아니다.

    2.2 간단한 사용 예

    아래 예는 실제 hfStudio와 hf2DStudio에서 실행해 확인했다. 각 예의 "도구"는 에이전트가 호출하는 순서이며 에이전트마다 조금 다를 수 있다.

    2.2.1 해석하고 결과 그림 저장하기

    HYFEAST로 D:\Apps\Hyfeast-v1.0.0\Examples\Tutorials\frame.inp를 가져와 D:\Work\frame.hdb로 저장하고 해석해 줘.
Case3의 D.MAG 등고선과 변형 형상(배율 10)을 스칼라 바, 최대·최소 표시와 함께 보여 주고
D:\Work\case3.png로 저장해 줘.
    • 도구: hyfeast_import_model → hyfeast_save_model → hyfeast_run_analysis → hyfeast_show_result → hyfeast_capture_scene
    • 결과: 해석 결과 파일(frame.hdb, .rst, .log)이 생기고, Case3 마지막 frame의 등고선 그림이 case3.png로 저장된다.
    • .inp는 열지 않고 가져온다(import). 해석하려면 먼저 .hdb로 저장해야 하므로 에이전트가 저장부터 한다.

    2.2.2 고유 모드 형상을 위에서 보기

    FrqStep의 1차 모드 형상을 변형 배율 3으로 보여 줘. 격자는 숨기고 위에서 내려다본 그림을
D:\Work\mode1-top.png로 저장해 줘.
    • 도구: hyfeast_show_result → hyfeast_set_view_display → hyfeast_capture_scene
    • 결과: 화면 왼쪽 위 정보에 모드 번호와 진동수(이 예는 Mode-1, f=0.68314 Hz)가 나오고, 그 화면이 그림으로 저장된다.
    • 시점 이름은 바라보는 방향이다. 위에서 내려다보는 시점은 -z(아래쪽을 향해 봄)이고 +z는 아래에서 올려다본 그림이다. 원하는 그림이 아니면 "아래에서 본 그림이니 반대 방향으로 바꿔 줘"처럼 고쳐 달라고 한다.

    2.2.3 표준 강재 단면을 만들어 모델에 넣기

    hf2DStudio에서 단위계를 kN-m-s-K로 두고 강재 Steel(탄성계수 2.05e8, 포아송비 0.3, 열팽창계수 1.2e-5,
밀도 7.85)을 만든 뒤, H-300×150×6.5×9(필릿 반지름 13 mm) 표준 단면을 H300 이름으로 만들어 줘.
그 단면을 hfStudio 모델에 넣고 교환 파일은 D:\Work\h300-section.inp로 남겨 줘.
    • 도구: hyfeast_2d_unit_system → hyfeast_2d_define → hyfeast_2d_template_section → hyfeast_transfer_2d_to_studio
    • 결과: hfStudio 모델에 보 단면 H300과 재료 Steel이 추가된다. 단면 상수는 hf2DStudio에서 계산된 값이 그대로 들어간다.
    • 두 모델의 단위계를 맞춘다. 이 예의 hfStudio 모델(frame.inp)은 kN-m 단위라서 hf2DStudio도 kN-m-s-K로 두고 치수를 m로 넣었다.
    • hfStudio에 해석 결과가 올라와 있으면 넣을 수 없다. 에이전트가 결과를 해제(hyfeast_unlock_model)할지 묻거나 먼저 해제한다.

    2.2.4 사각 단면을 직접 그려 모델에 넣기

    hf2DStudio에서 단위계를 N-mm-s-K로 두고, 200×300 사각 단면을 Steel 재료(탄성계수 200000)로 그려
1차 메쉬를 만들고 도심으로 옮겨 줘. 그 단면을 BOX 이름으로 hfStudio 모델에 넣어 줘.
    • 도구: hyfeast_2d_unit_system → hyfeast_2d_define → hyfeast_2d_draw(닫힌 윤곽) → hyfeast_2d_make_face → hyfeast_2d_set_seed → hyfeast_2d_make_mesh(1차) → hyfeast_2d_move_section → hyfeast_transfer_2d_to_studio
    • 결과: hfStudio 모델에 보 단면 BOX가 추가된다. 같은 단면의 2D 메쉬를 평면 요소로 넣으려면 "그 메쉬를 절점·요소 번호 10000부터 hfStudio 모델에 넣어 줘"처럼 요청한다.

    2.2.5 한 작업을 스크립트로 남기기

    지금까지 hfStudio에서 한 작업을 D:\Work\session.ipc.txt로 저장해 줘.
    • 도구: hyfeast_save_script
    • 결과: 이 세션에서 실행된 원격 제어 명령이 한 줄씩 저장된다. 같은 작업을 에이전트 없이 반복할 때 script 명령으로 다시 실행한다.

    2.3 도구 목록

    기본으로 도구 67개를 제공한다. hyfeast_2d_로 시작하는 도구는 hf2DStudio를, 나머지는 hfStudio를 다룬다. 인스턴스와 스크립트 도구는 app 인자로 앱을 고른다. 에이전트가 알아서 고르므로 이름을 외울 필요는 없다.

    분류 도구 하는 일
    인스턴스 hyfeast_list_instances, hyfeast_status, hyfeast_ping, hyfeast_focus_window 두 앱의 실행 중인 인스턴스 확인, 상태 조회, 창 앞으로 가져오기
    hfStudio 파일 hyfeast_open_model, hyfeast_import_model, hyfeast_save_model .hdb 열기, .inp 등 가져오기, 저장
    hfStudio 모델 hyfeast_get_model_info, hyfeast_define_nodes, hyfeast_define_elements, hyfeast_define, hyfeast_assign_section 모델 구성 조회(절점·요소 수, 재료·단면·집합·하중·경계조건·step 이름), 절점·요소 만들기, 재료·단면·하중·경계조건·step·함수·이력·집합 정의, 단면 지정
    hfStudio 캡처 hyfeast_capture_scene, hyfeast_capture_program 렌더 뷰 또는 프로그램 전체를 그림으로 저장. PNG·JPG는 그림을 에이전트에게도 보여 준다
    hfStudio 해석 hyfeast_check_model, hyfeast_run_analysis, hyfeast_unlock_model 모델 검사(실패하면 오류 목록), 해석 실행과 완료 대기, 결과 해제
    hfStudio 뷰·표시 hyfeast_list_views, hyfeast_add_render_view 외 8개 렌더 뷰, 카메라, 표현 방식, 격자·축·라벨
    hfStudio 후처리 hyfeast_show_result, hyfeast_get_result_data 외 10개 step·frame 선택, 등고선·변형·벡터, 스칼라 바, 등고선 구간, 변위·반력 이력 등 결과 수치 읽기(CSV 저장 가능)
    hf2DStudio 파일·단면 hyfeast_2d_open_model, hyfeast_2d_save_model, hyfeast_2d_new_model, hyfeast_2d_import_dxf, hyfeast_2d_activate_section, hyfeast_2d_unit_system .hf2d 열기·저장·새로 만들기, DXF 가져오기, 활성 단면 선택, 단위계
    hf2DStudio 정의 hyfeast_2d_define, hyfeast_2d_template_section function·material·section·analysis 정의, 표준 강재 단면(H, T, C, L, 각형관)
    hf2DStudio 형상 hyfeast_2d_draw, hyfeast_2d_generate, hyfeast_2d_make_face, hyfeast_2d_make_rebar, hyfeast_2d_set_seed, hyfeast_2d_delete, hyfeast_2d_move_point, hyfeast_2d_copy 점·선·호·곡선 그리기, 원, 면과 철근, 메쉬 seed, 삭제·이동·복사

    2.4 hf2DStudio와 hfStudio 연동

    hyfeast_transfer_2d_to_studio는 GUI에서 hf2DStudio의 Export to Clipboard를 한 뒤 hfStudio의 Import from Clipboard를 하는 흐름과 같다. 다만 클립보드 대신 교환 파일(.inp)을 남기고, 그 파일을 hfStudio import로 읽는다.

    kind 옮기는 내용 hfStudio에서 쓰는 곳
    section *Section, TYPE=Beam과 재료, 단면 메쉬 cell 보 요소의 단면
    guide *Geometry, Type=Guide (Z=0 평면) 모델링 가이드
    curve_mesh 곡선을 따라 나눈 1D 절점·요소 선 요소 모델
    domain_mesh CPS3/CPS4 2D 메쉬 평면 요소 모델
    • 활성 단면을 옮긴다. 여러 단면이 있으면 먼저 hyfeast_2d_activate_section으로 고른다.
    • 단위계를 함께 옮긴다. hf2DStudio 모델에 global UnitSystem이 있으면 내보낸 텍스트 앞에 들어간다. hfStudio 모델에도 global UnitSystem이 있으면 값이 변환된다. hfStudio 모델에 내용이 있고 UnitSystem이 없으면 값이 그대로 들어가므로, 두 모델의 단위계를 맞춰 둔다.
    • hfStudio는 전처리 상태여야 한다. 결과가 올라와 있으면 가져오기가 거부된다.
    • 2D 메쉬는 1차로 만든다. hfStudio 평면 요소는 CPS3/CPS4뿐이다. 2차 메쉬(CPS6/CPS8)는 가져오기 전에 unsupported_element로 멈추므로 hyfeast_2d_make_mesh를 order=linear로 다시 실행한다. hyfeast_2d_template_section으로 만든 표준 강재 단면은 형상 없이 메쉬만 있어 다시 만들 수 없으므로 section으로만 옮긴다.
    • 메쉬 번호가 겹치지 않게 한다. curve_mesh와 domain_mesh는 node_id_offset, element_id_offset으로 hfStudio 모델의 기존 절점·요소 번호를 피한다.
    • 함수 정의는 따라가지 않는다. section을 옮길 때 재료가 참조하는 *Function(예: 콘크리트 포락선)은 내보내지 않는다. hfStudio에 그 함수가 없으면 가져오기가 일부만 되고 import_partial_failure로 알린다. 이때는 필요한 함수를 hfStudio에 먼저 정의한 뒤 다시 옮긴다.
    • 클립보드가 바뀐다. hf2DStudio 내보내기는 같은 텍스트를 클립보드에도 복사한다.

    2.5 동작 규칙

    • 실행 중인 프로그램이 필요하다. 서버는 hfStudio나 hf2DStudio를 띄우거나 닫지 않는다. 인스턴스가 여러 개면 에이전트가 목록을 보고 대상(hfStudio는 target, hf2DStudio는 target_2d)을 지정한다.
    • 대상 지정 없는 명령은 남은 인스턴스로 간다. 인스턴스가 하나뿐이면 대상 없이 보낸 명령이 그 인스턴스로 자동 전달된다. 여러 에이전트나 스크립트가 동시에 원격 제어를 쓰면 다른 작업이 띄운 창에 명령이 갈 수 있으므로 uuid로 대상을 지정한다.
    • 저장하지 않은 변경을 버리지 않는다. hfStudio 새 모델 만들기와 두 앱의 종료는 도구로 제공하지 않는다. hyfeast_2d_new_model은 저장하지 않은 변경이 있으면 거부한다. 스크립트에 new, quit, --discard-unsaved가 들어 있으면 실행 전에 거부한다.
    • 파일을 덮어쓰지 않는다. 같은 이름의 파일이 있으면 거부하고, 덮어쓰기를 명시해야 바꾼다. 출력 폴더는 미리 있어야 한다.
    • 해석 입력은 import로 연다. hyfeast_open_model은 .hdb만 연다. .inp는 import한 뒤 저장해야 해석할 수 있다.
    • 해석은 끝날 때까지 기다린다. hfStudio는 결과가 올라오면, hf2DStudio는 모델 옆에 .xlsx가 생기면 성공이다. 결과 없이 끝나면 analysis_failed로 알린다. 성공은 계산이 끝났다는 뜻이며 결과 값의 타당성을 판단하지 않는다.
    • hf2DStudio 형상 도구는 활성 단면에 적용된다. 새로 그린 점·곡선·면의 번호가 결과에 나오므로 다음 도구에 그대로 쓴다. 좌표가 같아도 점은 합쳐지지 않으므로 면을 만들 윤곽은 hyfeast_2d_draw를 closed=true로 그린다. 메쉬가 있으면 형상을 바꿀 수 없으니 먼저 메쉬를 지운다.
    • 결과 표시는 기본으로 마지막 frame이다. post-step은 첫 frame(하중 전 상태)으로 가므로 hyfeast_show_result는 따로 지정하지 않으면 마지막 frame으로 이동한다.
    • 후처리와 캡처는 활성 렌더 뷰에 적용된다. 다른 뷰를 쓰려면 먼저 그 뷰를 활성화한다. 카메라와 표시 도구는 뷰 id를 직접 받는다.
    • 벡터 그림은 압축돼 저장된다. .svg, .ps, .eps, .tex는 hfStudio가 .gz를 붙여 압축 저장한다. .pdf는 그대로 저장한다. 결과에 실제 파일 경로가 나온다.
    • 등고선 overlay는 등치선 식이다. D.MAG=0.002, 0.004 또는 0.002@D.MAG 형식으로 쓰고, 빈 문자열이면 지운다.

    2.6 자주 나오는 오류

    에이전트는 오류가 나면 이름과 원인을 알려 주고 대개 스스로 고쳐 다시 시도한다. 연결 자체가 안 될 때는 1. 연결을 본다.

    오류 원인과 조치
    invalid_state (후처리 도구) 결과가 올라와 있지 않다. 결과가 있는 .hdb를 열거나 해석을 먼저 실행한다.
    save_path_required 이름 없는 모델이다. 경로를 정해 저장한 뒤 다시 요청한다.
    unsaved_changes (hyfeast_2d_new_model) hf2DStudio 모델을 먼저 저장한다.
    input_validation_error / FILE_EXISTS 같은 이름의 파일이 있다. 다른 이름을 쓰거나 덮어쓰기를 요청한다.
    unsupported_element 2차 2D 메쉬다. order=linear로 메쉬를 다시 만든다. 표준 강재 단면은 section으로만 옮긴다.
    import_partial_failure 모델 가져오기나 2D 전송에서 hfStudio가 일부 블록을 거부했다. hfStudio 출력 창에서 거부된 줄을 확인해 입력을 고친 뒤 저장하거나 해석한다. 단면 전송이면 재료가 참조하는 함수를 hfStudio에 먼저 정의한다. 2D 전송은 교환 파일 경로가 결과에 있다.
