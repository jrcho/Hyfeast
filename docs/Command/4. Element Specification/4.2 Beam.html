    4.2 Beam

    보 요소는 부재 종축(ECS 상의 x 축)의 치수가 타 방향의 치수에 비해 큰 부재로 축력, 휨, 비틀림 등을 전달하는 구조요소(structural element)이다. 요소 타입과 단면, distribution은 다음과 같다.

    ■ 요소 타입

    • B2D2H : 2 dimensional 2 node, Bernoulli beam(Hermitian shape function used)
    • B2D2MH : 2 dimensional 2 node, Timoshenko beam(Modified Hermitian shape function used)
    • B3D2H : 3 dimensional 2 node, Bernoulli beam(Hermitian shape function used)
    • B3D2MH : 3 dimensional 2 node, Timoshenko beam(Modified Hermitian shape function used)

    ■ 요소 단면

    • Beam: 보 요소단면. 1개 이상의 Cell로 구성

    ■ 요소 개별 물성치(Distribution)

    • BeamCS : 3차원 보요소의 ECS를 정의
    • BeamEndRelease : 요소 단부의 힌지 조건 부여(moment release). Rx1, Ry1, Rz1, Rx2, Ry2, Rz2의 조합. 예를 들어 Rz1|Rz2.

    전단변형을 무시하는 B2D2H, B3D2H는 비선형 재료 모델을 지원하며, 변단면을 모사할 수 있다. 반면에 전단변형을 고려하는 B2D2MH와 B3D2MH는 재료가 탄성일때만 적용가능하며, 이론적으로 변단면 정식화가 불가능하기 때문에 단면 물성치가 변단면으로 주어질 경우 평균값을 요소내에 적용한다.

    2차원 보 요소의 ECS는 그림 4.2-1과 같이 부재축인 x축과 이에 직교하는 y 축으로 정의된다.

    Fig. 4.2-1. 2차원 보요소의 ECS

    3차원 보요소의 경우 \(x\)축은 부재축으로 정의할 수 있지만 \(y\)축과 \(z\)축은 기준 벡터 \(\rm r\) 와 추가 단면 회전각 \(\theta\)에 의해 결정된다. 그림 4.2-2는 단면 회전각 \(\theta=0\)인 경우 ECS를 설정한 예이다. \(\rm r\) 벡터의 디폴트 값은 그림 4.2-3과 같이 \(\rm r = (0,0,1)\) 로 설정한다. 예외적으로 부재축이 전체좌표계 Z와 평행한 경우에는 \(\rm r = (1,0,0)\)이다. 이때 부재축이 Z와 1:100 경사도에 해당하는 사이각(약 0.573도)내에 존재하는 경우로 평행여부를 판단한다.

    단면회전각 \(\theta\)는 이용해 \(\rm r\) 벡터로 설정된 좌표계에서 추가적으로 회전된 좌표계를 ECS롤 정의하도록 한다. 단면회전각 \(\theta\)의 디폴트값은 0이다.

    Fig. 4.2-2. 3차원 보요소의 ECS

    Fig. 4.2-3. 디폴트 기준 벡터

    Hyfeast에서 보 요소의 기준축은 절점을 잇는 선분을 기준으로 정의되며, 도심일 필요는 없다. 하지만 정식화가 도심에서 이루어진다. 특히 단면력 및 단면변형 등은 도심을 대상으로 계산되므로 주의한다.

    보 요소의 단면인 Beam 단면은 같은 재료를 적용하는 기하 형상으로 정의되는 Cell의 집합으로 정의한다. 다음 그림은 사용가능한 셀을 나타낸 것이다.

    Fig. 4.2-4. 보 단면의 셀 (viewed from the local +z direction)

    다음은 셀과 관련된 사항을 정리한 것이다.

    1. 단면을 하나의 cell로 구성하면 균질 보 단면이며, 두 개 이상의 cell로 구성하는 합성 보 단면이다.
    2. 두 개 이상의 cell로 보 단면을 구성하는 경우 사용하는 cell의 타입에 따라 제한 조건이 있다.
    3. Value, Rectangle, Circle, H/T/C/L/2C/2L/HR[-YUp] 셀은 탄성재료(IsoElasticity)만을 허용하며, 그림 4.2-5처럼 미리 정의된 몇 개의 재료점에 대해서만 응력(S), 전체 변형률(E), 기계 변형률(EM), 탄성 변형률(EE) 등 탄성재료의 필드값을 출력할 수 있다
    4. 직접 H/T/C/L/2C/2L/HR[-YUp] 표준 형상 cell은 단면상수를 2차원 유한요소 해석으로 계산한다. 이때 내부적으로 생성하는 mesh는 필렛 등 곡선 경계를 잘 표현하기 위해 Q8, T6 같은 2차 요소를 사용한다.
    5. 표준 형상 cell에서 H-YUp, Mesh,H-YUp처럼 형상 token에 -YUp이 붙은 단면은 높이 방향이 local y 방향인 단면이다. 대응하는 기본 형상 cell을 90도 회전한 것으로 이해할 수 있으며, 보 요소의 국부좌표계를 사용자가 정의할 수 없는 2차원 보(B2D2H, B2D2MH)에서 유용하다.
    6. Point, Layer, Mesh 셀은 탄성/비탄성 재료 모두 사용가능하다.
    7. Point 셀은 셀을 구성하는 모든 재료점에서 응력(S), 변형률(E, EM) 등 사용된 재료의 필드값을 출력할 수 있다.
    8. Layer 셀은 각 층의 상하단에서 응력(S), 변형률(E, EM) 등 사용된 재료의 필드값을 출력할 수 있다.
    9. Mesh 셀은 *CellMeshPonts로 메쉬를 수성하는 재료점을 미리 정의하는데, 이들 재료점에서 응력(S), 변형률(E, EM) 등 사용된 재료의 필드값을 출력할 수 있다.
    10. Value, Rectangle, Circle, H/T/C/L/2C/2L/HR[-YUp] 셀은 단독으로 존재하거나 Point 셀과의 조합만이 허용된다.(예. Rectangle (OK), Rectange+Point (OK), Rectangle+Rectangle (NG), Rectange+Value(NG))
    11. Layer 셀은 Layer 셀과 Point 셀과의 조합만이 허용된다. (예, Layer (OK) Layer+Mesh(OK), Layer+Point (OK), Layer+Layer+Point (OK), Layer+Rectangle (NG))
    12. Mesh 셀은 Mesh 셀과 Point 셀과의 조합만이 허용된다. (예, Mesh (OK) Mesh+Mesh(OK), Mesh+Point (OK), Mesh+Mesh+Point (OK), Mesh + Rectangle (NG))
    13. Point 셀은 주로 다른 타입의 셀과 조합되어야 하나, 단독으로도 사용될 수 있다. (예, Value+Point(OK) Rectangle+Point(OK), Point (OK), Point+Point(OK))
    14. Point 셀을 사용된 단면의 경우 Point 셀은 휨과 압축에만 기여하고 전단이나 비틈의 계산에는 기여분이 없다. 예를 들어 단면상수를 계산하는 단계에서 EA, EI 등은 Point 셀의 기여분을 고려하여 계산하지만 GJ, GAs 등을 계산에는 고려되지 않는다. (EA, EIy, EIz, EIyz)
    15. Layer 셀은 2차원 보요소(B2D2H, B2D2MH)에서만 사용가능하다.

    4.2.1 *Element, Type=B2D2H

    2차원 2절점 베르누이 보 요소를 정의

    *Element, Type=B2D2H, Elset=elset
 id, n1, n2, [, S=section, R=beamEndRelease]
 ...
    Specifications
    • No. of nodes: 2
    • No. of gauss points: 4 (Gauss-Lobatto rule used)
    • Fields: BSF=[Nx Mz Vy], BSE=[Ex Kz Gxy], BST=[T0 Tz] at Gauss point about centroid. Uniaxial model response at each layer of Gauss point
    • Compatible section: Beam
    • Active DOFs: X,Y,RZ

    베르누이 보요소는 전단변형을 0으로 가정하면 전단력은 상태변수로 정의되지 않으며 평형조건을 이용해 계산해야 한다. 여기에서는 단면 전단변형은 항상 0이고, \(Vy=–dM_z/dx\)로 계산하였다. 적분점에서의 모멘트 응답으로부터 polynomial로 보간한 후 \(M_z(x)\)를 계산한 후 이를 미분하는 방식으로 \(V_y\)를 계산하였다.

    beamEndRelease에는 Rx1, Ry1, Rx2, Ry2의 조합이 가능하다(Rx1, Ry1은 시작절점의 두회전, Rx2, Ry2는 끝절점의 두회전). 예를 들어 Ry1|Ry2.

    4.2.2 *Element, Type=B3D2H

    3차원 2절점 베르누이 보 요소를 정의

    *Element, Type=B3D2H, Elset=elset
 id, n1, n2, [, S=section, CS=beamCS, R=beamEndRelease]
 ...
    Specifications
    • No. of nodes: 2
    • No. of gauss points: 4 (Gauss-Lobatto rule used)
    • Fields: BSF=[Nx My Mz Vy Vz T], BSE=[Ex Ky Kz Gxy Gxz Hx], BST=[T0 Ty Tz] at Gauss point about centroid. Uniaxial model response at each layer of Gauss point
    • Compatible section: Beam
    • Active DOFs: X, Y, Z, RX, RY, RZ

    베르누이 보요소는 전단변형을 0으로 가정하면 전단력은 상태변수로 정의되지 않으며 평형조건을 이용해 계산해야 한다. 여기에서는 단면 전단변형은 항상 0이고, \(V_y= –dM_z/dx, V_z= dM_y/dx\)로 계산하였다. 적분점에서의 모멘트 응답으로부터 polynomial로 보간한 후 \(M_z(x)\)를 계산한 후 이를 미분하는 방식으로 \(V_y\)를 계산하였다. Hx는 \(d\theta / dx\)를 의미한다.

    beamEndRelease에는 Rx1, Ry1, Rz1, Rx2, Ry2, Rz2의 조합이 가능하다(Rx1, Ry1, Rz1은 시작절점의 세회전, Rx2, Ry2, Rz2는 끝절점의 세회전). 예를 들어 Rz1|Rz2.

    Data line forms

    *Cell의 data line은 직접 값을 입력하는 형식과 section DB를 참조하는 형식으로 나뉜다.

    • numeric/direct data line: Type=별 치수, mesh point, layer, point 항목을 직접 입력하는 기본 형식.
    • section DB reference data line: DB, item으로 catalog 항목을 참조하는 형식. 지원되는 cell에서 numeric geometry data line을 대신한다.

    Syntax block에서 {A} | {B}는 A 또는 B 중 하나의 data line 형식을 선택한다는 뜻이다. {}, | 문자는 입력하지 않는다.

    Common data-line options

    아래 option은 keyword line이 아니라 data line 끝에 붙이는 option이다.

    • C=yc, zc: 직접 Mesh, Layer, Point를 제외한 cell type에서 해당 cell의 도심 위치를 지정한다.
    • ExtraArea=area 또는 ExtraArea=area0, area1: numeric/direct data line에 붙이는 추가 면적 [L^2]이다. 질량 및 자중 계산에만 사용하며, 구조 단면상수, 강성, 응력/변형률 복원, 결과 출력점에는 영향을 주지 않는다.
    • ToDirectForm: 생성형 mesh cell을 저장/재출력할 때 생성 결과를 직접 mesh data로 펼쳐서 출력한다. 첫 번째 data line에서만 사용한다.

    C는 cell centroid coordinate의 약어이다. yc, zc는 보 요소 절점을 잇는 기준선에서 정해지는 section reference axes 기준으로 측정한 해당 cell의 도심 좌표이며, cell이 하나뿐인 경우를 제외하면 조립된 Beam section 전체의 도심이 아니다. 조립된 전체 section의 도심은 section property 결과에서 별도의 yc, zc로 표시한다.

    ExtraArea는 직접 Value, Rectangle, Circle, H/T/C/L/2C/2L/HR[-YUp] 셀에서는 해당 형상 data line 끝에 붙인다. taper section에서는 시작/끝 형상 data line마다 값을 지정할 수 있으며, 중간 단면에서는 기존 taper 규칙에 따라 보간된다. 직접 Mesh, Layer, Point 셀에서는 첫 번째 cell data line에만 지정한다. 값이 하나이면 시작/끝에 같은 값을 사용하고, taper section에서 ExtraArea=area0, area1을 쓰면 시작/끝 값을 각각 지정한다. ToDirectForm과 함께 쓸 때는 ExtraArea=...를 먼저 쓰고 ToDirectForm을 data line의 마지막 token으로 둔다.

    Section DB reference data lines

    section DB 참조는 별도 cell type이나 keyword option이 아니라 data line 대체 형식이다. Type= keyword는 여전히 Hyfeast cell 계열을 선택하므로, 참조한 DB item은 그 cell 계열과 일치해야 한다. 별도의 DB marker token은 쓰지 않는다.

    section DB 참조에는 다음 규칙이 적용된다.

    • global *Environment, Type=UnitSystem이 먼저 정의되어 있어야 한다.
    • runtime section DB 파일은 tools/db/sections/*.hfdb.json에서 읽어온다.
    • 각 section DB 파일은 source 길이 단위를 선언하며, DB 치수와 DB ExtraArea는 현재 global UnitSystem으로 변환되어 적용된다.
    • C=는 사용자가 입력한 현재 모델 단위 값으로 해석한다.
    • 사용자가 직접 입력하는 ExtraArea=는 DB 참조 data line에 붙일 수 없다. DB가 제공하는 ExtraArea만 자동 적용된다.
    • taper section에서는 두 번째 data line도 DB 참조로 쓸 수 있으며, 끝단 형상을 표현하기 위해 첫 번째 line과 다른 DB item을 지정할 수 있다.

    아래 표의 DB data line 형식은 첫 번째 data line에서 사용할 수 있는 추가 field까지 함께 표시한다.

    4.2.7.1 *Cell, Type=Value

    단면 상수를 직접 지정 – 탄성 재료만 적용 가능

    *Cell, Type=Value, Mat=mat
  A, Iy, Iz, Iyz, J, Asy, Asz, ys, zs, C=yc, zc, ExtraArea=area
  ...add the above line if tapered section
    First dataline
    • A: Area [L^2]
    • Iy: 2nd moment of inertia about y w.r.t centroid(optional, default 0.) [L^4]
    • Iz: 2nd moment of inertia about z w.r.t centroid(optional, default 0.) [L^4]
    • Iyz: Cross product w.r.t centroid(optional, default 0.) [L^4]
    • J: torsional constant w.r.t centroid(optional, default 0.) [L^4]
    • Asy,Asz: Shear area [L^2]. If 0, it means use A. (optional, default 0.)
    • ys,zs: Shear centers w.r.t centroid(optional, default 0.) [L].

    • Repeat if tapered section

    *Cell, Type=Value에 적용하는 재료는 항상 *Material, Type=IsoElasticity으로 정의되는 탄성재료이여야 한다. *Cell, Type=Value는 단독으로 사용되거나 *Cell, Type=Point과 조합하여 사용한다. Point 셀과 합성된 단면 상수는 휨에 대한 값만을 조정하여 전체 합성 단면 상수로 사용한다.

    변단면 보이면 다음과 같이 길이에 단면 상수를 보간한다.

    \[ \begin{aligned} &A(x) = A_0 + (A_1 - A_0) \frac{x}{L} \\ &J(x) = J_0 + (J_1 - J_0) \frac{x}{L} \\ &I_y(x) = \left[ I_{y0} ^{1/m_y} + (I_{y1} ^{1/m_y} - I_{y0} ^{1/m_y} ) \frac{x}{L} \right] ^{m_y} \\ &I_z(x) = \left[ I_{z0} ^{1/m_z} + (I_{z1} ^{1/m_z} - I_{z0} ^{1/m_z} ) \frac{x}{L} \right] ^{m_z} \\ &I_yz(x) = \left[ I_{yz0} ^{1/m_{yz}} + (I_{yz1} ^{1/m_{yz}} - I_{yz0} ^{1/m_{yz}} ) \frac{x}{L} \right] ^{m_{yz}} \\ \end{aligned} \]

    여기에서 \(I_y\), \(I_z\), \(I_{yz}\)의 보간차수로 \(m_y=2, m_z=2, m_{yz}=1\)가 사용된다. 나머지 형상은 주어진 형상대로 정확하게 단면 상수를 보간한다.

    *Cell, Type=Circle에 적용하는 재료는 항상 *Material, Type=IsoElasticity으로 정의되는 탄성재료이여야 한다. *Cell, Type=Circle는 단독으로 사용되거나 *Cell, Type=Point과 조합하여 사용한다. Point 셀과 합성된 단면 상수는 휨에 대한 값만을 조정하여 전체 합성 단면 상수로 사용한다.

    단면 상수를 다음 식으로 계산한다.

    \[ \begin{aligned} &A = \pi (r_1^2-r_2^2), I_y = I_z = \frac{\pi (r_1^4 - r_2^4)}{4}, I_yz = 0,\\ &J = \frac{\pi (r_1^4 - r_2^4)}{2}, y_s = z_s = 0, \\ &A_{sy} = A_{sz} = k_s A, ~{\rm where,~} k_s = \frac{6(1+m^2)^2}{7(1+m^2)^2+20m^2}, m=\frac{r_2}{r_1} \\ \end{aligned} \]
    • yc, zc는 section reference axes에서 측정한 circle cell의 도심 좌표이다.
    • Note that typical value of solid circle, \(k_s = 0\), but Cowper(1966)’s formula in case of \(\nu = 0\) is used here.

    ※ 참고: Thin-walled H-shape 참고

    H 단면에서 필릿이 없는 경우 다음과 같은 thin-walled 근사식을 사용할 수 있다.

    \[ \begin{aligned} &A = h_c t_w + 2bt_f,\quad I_y=\frac{h_c^2}{12}(h_c t_w+6bt_f),\quad I_z = \frac{b^3t_f}{6},\quad I_{yz}=0 \\ &J \approx \frac{1}{3}(h_c t_w^3+2bt_f^3),\quad y_s=z_s=0 \\ &A_{sy}=k_{sy}A,\quad k_{sy}=\frac{5}{3}\frac{bt_f}{A} \\ &A_{sz}=k_{sz}A,\quad k_{sz}=\frac{h_ct_w}{A} \\ &\mathrm{where,}\quad h_c = h - t_f \end{aligned} \]

    하지만, Hyfeast는 2차원 유한요소를 통해 단면상수를 계산한다. 예를 들어 b=0.20, h=0.40, tw=0.008, tf=0.013인 경우 thin-walled 공식 결과는 유한요소를 적용한 결과와 비교할 때 면적은 약 1.3%, 주축 휨 관성모멘트는 약 1.6%, 비틀림 상수는 약 2.4%, 한쪽 전단면적은 약 2.5% 정도 차이가 난다.

    4.2.7.11 *Cell, Type=Layer, Stack

    스택 형의 Layer 생성

    # Pismatic seciton
*Cell, Type=Layer,Stack, Mat=mat
  y0, b0, ExtraArea=area, ToDirectForm
  y1, b1, n1
  ...
  yn, bn, nn

# Taper section
*Cell, Type=Layer,Stack, Mat=mat
  y0, b0, y0, b0, ExtraArea=area0, area1, ToDirectForm
  y1, b1, y1, b1, n1
  ...
  yn, bn, yn, bn, nn
    First dataline
    • y0,b0: y coordinate and width for prismatic seciton [L].
    • y0,b0, y0, b0: y coordinate and b width for taper seciton [L]. The first pair of y0, b0 indicates start section, and the second pair of y0, b0 indicated end section.
    • ExtraArea=area 또는 ExtraArea=area0, area1: 질량 및 자중 계산에만 사용하는 추가 면적(optional) [L^2]. 첫 번째 data line에만 지정한다. 값 하나는 시작/끝 공통으로 쓰고, taper section에서는 ExtraArea=area0, area1로 시작/끝 값을 지정할 수 있다.
    • ToDirectForm: optional. 지정하면 저장할 때 생성형 layer 명령을 일반 *Cell, Type=Layer direct form으로 변환한다.
    2nd dataline
    • yn,bn, yn, bn, nn: y coordinate and b width for taper seciton [L]. The first pair of y0, b0 indicates start section, and the second pair of y0, b0 indicated end section. nn is the number of layers from n-1 to n.

    4.2.7.12 *Cell, Type=Layer, Circle

    원에 대한 Layer 생성

    *Cell, Type=Layer,Circle, Mat=mat
  outerR, innerR, nOuterR, nInnerR, C=yc, ExtraArea=area, ToDirectForm
  outerR, innerR, C=yc, ExtraArea=area
    First dataline
    • outerR,innerR: outer and inner radius (outerR is required, but innerR is optional(default 0.)) [L].
    • nOuterR,nInnerR: No. of layers for outer radius and inner radius. If innerR is zero, nInnerR is neglected. If innerR is nonzero, nOuterR is the number of layers for the shell,i.e. the portion of outerR-innerR. (optional. default 4,4)
    • C=yc: section reference axes에서 측정한 layer circle 중심의 y 좌표(optional, default 0.) [L].
    • ExtraArea=area: 질량 및 자중 계산에만 사용하는 추가 면적(optional) [L^2].
    • ToDirectForm: optional. 지정하면 저장할 때 생성형 layer 명령을 일반 *Cell, Type=Layer direct form으로 변환한다.
    2nd dataline
    • Repeat if tapered section for outerR, innerR, C=yc

    3차원 MeshedBeam 단면은 강제로 전단관련 상수를 지정하지 않는 경우 디폴트로 비틀림 상수 , 전단수정계수, 전단중심 등을 구하기 위해서는 2차원 포텐셜 문제에 대한 유한요소해석을 수행한다.

    4.2.7.13 *Cell, Type=Point, Circle

    원형의 Point를 생성

    *Cell, Type=Point,Circle, Mat=mat
  r, a, angle, npoints, C=yc, zc, ExtraArea=area, ToDirectForm
 {r, a, angle, C=yc, zc, ExtraArea=area}
    First dataline
    • r: radius (required) [L].
    • a: area of each point (required) [L^2].
    • angle: counter-clockwise angle from y-axis of the starting layer (required)

    • ExtraArea=area: 질량 및 자중 계산에만 사용하는 추가 면적(optional) [L^2].
    • ToDirectForm: optional. 지정하면 저장할 때 생성형 point 명령을 일반 *Cell, Type=Point direct form으로 변환한다.
    2nd dataline
    • Repeat if tapered section for r, a, angle, C=yc, zc

    4.2.8 *ShearTorsionMaterial

    전단 및 torsion에 대해 1축 재료모델을 참조 재료 모델 지정

    *ShearTorsionMaterial
  ShearX|ShearY|Torsion, material, localUnitSystem
  ...
    First dataline and subsequent datalines if necessary
    • ShearX|ShearY|Torsion: 지정한 유형. ShearX, ShearY는 방향별 전단거동. Torsion은 비틈거동.
    • material: 참조 재료 모델. 1축 재료모델만 허용. 전단의 경우 “scaled shear force”-전단변형 관계로, Torsion인 경우 “scaled torsional moment”-회전각 관계로 취급함. 전단력 및 회전모멘트는 “scaled shear force” 또는 “scaled torsional moment”에 단면에서 정의된 선형 단면 상수인 GAsy, GAsz, GJ를 추가 곱하여 계산함.
    • referenceUnitSystem: 참조 재료 모델을 사용할 때 재료의 기준 단위계. 옵션이며 기본값을 현재 단위계.
    • locaUnitSystem: local UnitSystem with force-length form (optional).

    보 요소에 전단 및 비틂 거동은 선형이다. 만약 강제로 비선형 거동을 포함할 때 1축 재료 모델을 참조하여 “scaled shear force-shear strain”, “scaled torsional moment-rotation” 관계로 사용할 수 있다. 최종적으로 전단력 및 비틈모멘트는 GAsy, GAsz, GJ를 곱하여 산정한다.

    전단 거동에 적용할 때 만약 localUnitSystem고 *Environment, Type=UnitSystem에서 지정된 현재의 단위계가 같다면 scale shear force와 응력은 물리적인 의미없이 1:1로 변환된다. 만약 단위계가 다르다면 내부적으로 적절하게 스케일링을 하게 된다. 마찬가지로 비틈 거동에 적용할 때 scaled torsional moment와 응력, rotation과 변형률 사이에서 물리적 의미없이 단위계를 고려하여 변환하게 된다.
