    13. Step

    해석 관련 명령은 크게 *Step과 *PostStep이 있다. *Step은 실제 해석을 수행할 단계를 지정하며, *PostStep은 해석된 결과를 정리하는 데 사용한다.

    *Step 명령에서 Static, Dynamic, Frequency, Buckling 등의 해석 유형을 지정할 수 있으며, *Step의 사전 단계를 지정하는 방식으로 여러 해석 단계로 구성된 시뮬레이션을 수행할 수 있다. *Step의 하위명령어로는 요소, 하중, 구속조건을 지정하거나 변경하는 *Activate, *Inactivate 명령, 해석옵션을 지정하는 *Solver, *SolutionAlgorithm, *Convergence, *RayleighDamping, *Modal 명령, Step 시작 상태를 지정하는 *InitialCondition, *State 명령, 출력을 지정하는 *Output, *Print, *History, *Check 등이 있다.

    *Step 명령이 수행되면 HDB 파일(.hdb)에 ResultStep이라는 출력 스텝이 생성되며 *Output에서 지정한 결과가 저장되게 된다. *PostStep은 이미 존재하는 ResultStep을 대상으로 결과값의 일부를 발췌하거나 최대/최소, 결과의 조합 등을 수행하여 새로운 ResultStep을 만드는 명령이다.

    *Step과 *PostStep에 사용되는 이름은 자신만의 중복되지 않는 이름을 지정해야 한다.

    13.1 *Step

    해석 단계(analysis step)을 정의한다.

    *Step, Type=type,...  Name=name[, PREV=prevStep, ...]
 ...
    Keyword line
    • Type=step_type,...: 해석유형 및 부가옵션
      • Static: 정적해석
      • Dynamic: 동해석
      • Frequency: 주파수해석
      • ResponseSpectrum: 응답스펙트럼해석
      • Seepage: 침투해석
    • Name=name: 해석의 이름
    • PREV=prevStep: 이전 해석단계. 지정하지 않는 경우 초기상태에서 해석이 시작됨

    다음 해석 유형에 따른 분류이다.

    ▪표준 해석 단계(Standard analysis step)

    ▪정적 해석 단계(Static analysis step)

    • 표준 정적 해석(Standard load-displacement controlled static analysis step)

    • Arclength 정적 해석(Arclength-controlled static analysis step)

    • 시간 의존 정적 해석(Quasi-static analysis step)

    ▪동적 해석 단계(Dynamic analysis step)

    • 시간 영역 동적 해석(Time-domain analysis step)

    ▪고유치 해석 단계(Eigen analysis step)

    • 고유진동수 추출 해석(Frequecny extraction analysis step)

    • 응답스펙트럼 해석(Response spectrum analysis step)

    ▪침투 해석 단계(Eigen analysis step)

    • 정상 침투 해석 단계(Steady state seepage analysis step)

    • 과도 침투 해석 단계(Transient seepage analysis step)

    해석 단계 유형에 따라 시간을 다루는 방식이 다르다.

    ▪ 표준 정적 해석(Standard load-displacement controlled static analysis step)

    주어진 시간이 하중계수(load factor)인 유사시간(pseudo-time)이다.

    ▪ Arclength 정적 해석(Arclength-controlled static analysis step)

    주어진 시간은 arclength를 선형거동시 하중계수가 1일 때 발생하는 arclength로 정규화된 유사시간(pseudo-time)이다. 따라서 Arclength control을 선형해석에 적용하면 표준 방법과 동일한 시간 증분을 주는 것과 같다.

    ▪ 시간 의존 정적 해석(Quasi-static analysis step)

    질량효과를 고려하지 않지만 시간의존성을 고려하는 정적해석을 의미한다. 주어진 시간은 아래 시간 해석 표의 Static, Quasi 행을 따른다. 시간의존성은 시간함수를 부여한 하중과 시간의존 재료모델 등에서 발생하는데 정적 해석시 시간 의존 해석을 수행해야 시간의존성을 반영할 수 있다.

    ▪ 동적 해석 단계(Dynamic analysis step)

    질량효과와 시간의존성을 모두 고려하는 동해석을 의미한다. 주어진 시간은 아래 시간 해석 표의 Dynamic 행을 따른다. 시간 적분을 수행하는 방법으로는 Newmark 법과 Hilbert-Hughes-Taylor 법(이하 HHT 법)을 지원하며, *TimeIntegration에서 지정할 수 있다. 디폴트 수치적분법은 \(\gamma=0.5\), \(\beta=0.25\)의 계수를 갖는 Newmark 법(또는 평균가속도법)이다. HHT법은 적용할 경우 \(\alpha=-0.05\)의 디폴트 값을 가진다.

    ▪ 정상 침투 해석(Steady state seepage analysis type)

    주어진 시간이 하중계수(load factor)인 유사시간(pseudo-time)이다.

    ▪ 과도 침투 해석 단계(Transient seepage analysis step)

    주어진 시간은 아래 시간 해석 표의 Seepage, Transient 행을 따른다.

 BC

    Static, Dynamic, Seepage 해석에서 해석시 시간 증분(Static에서 유사 시간 증분)은 Uniform, Given, Auto이라는 세가지 옵션으로 지정할 수 있다. 한편 결과가 *Output, *Print, *History 등을 통해 출력되는 시간은 OutFreq 또는 OutTime을 통해 지정할 수 있다. 입력형식은 다음과 같다.

    *Step, Type=Static|Dynamic|Seepage,...,  Name=name, PREV=prevStep, NLGeom=ON|OFF
 Uniform, dt, ntime[, TUnit=tUnit], OutFreq=freq
 Given, timeSpec[, TUnit=tUnit], OutFreq=freq|OutTime=timeSpec
 Auto, t0, tmax, dtmin, dtmax, maxInc[, TUnit=tUnit], OutFreq=freq|OutTime=timeSpec
    • Uniform는 등간격으로 해석시간을 지정하고, Given은 시간을 직접기입하고, Auto는 자동증분 제어이다.
    • OutFreq와 OutTime은 동시에 지정할 수 없고, OutTime은 Given과 Auto에서 사용할 수 있다.
    • OutFreq=freq는 “해석 increment 기준”으로 freq increments 마다 출력한다.
    • OutFreq=0과 같이 지정할 경우에는 최종 시간에서만 출력한다.
    • Given의 OutTime=timeSpec은 0 또는 Given에 포함된 해석 시각만 지정할 수 있다. 0을 지정하면 step 시작 상태도 출력한다.
    • Auto의 OutTime=timeSpec은 “출력 앵커 시간”이며, 해당 시간에 출력하도록 해석 시간 증분을 추가로 자동 조정한다.
    • OutFreq, OutTime 모두 최종 시간(마지막 해석시간 또는 수렴 실패시에도 최종 수렴 성공 시간)에서는 항상 출력한다.
    • Given 과 OutTime 지정시 timeSpec은 tStart:tEnd:tSpacing 형태의 범위식을 사용할 수 있다. 예를 들어 Given, 0.5, 2.5:7.5:2.5, 10 등과 같은 표현이 가능하다. 이때 2.5:7.5:2.5는 2.5, 5.0, 7.5로 해석된다.
    • tStart:tEnd:tSpacing 범위식에 tEnd가 간격에 정확히 맞지 않는 경우, tEnd를 초과하지 않는 범위내에서 시간 값이 생성된다. 예를 들어 1:10:2 이면 1,3,...,9로 해석되며, 이는 1:9:2를 대입한 것과 같다.
    • TUnit=tUnit은 step에서 쓰는 시간 기준 단위를 지정한다. 지원하는 tUnit 값은 s, min, hr, day이다. 이 항목은 Static, Quasi와 Seepage, Transient에서 필수이다. Seepage, Steady를 포함한 그 밖의 pseudo-time 해석이나 global UnitSystem의 time field를 따르는 해석에서는 사용할 수 없다.
    시간 해석

    다음 표는 Uniform, Given, Auto, OutTime의 시간값을 해석하는 중심 규칙이다.

    Step 유형 시간 분류 의미와 일관성 규칙
    Static, Standard/Arclength pseudo-time 하중계수 또는 arc-length 진행 좌표이며 global UnitSystem과 무관하다.
    Dynamic global UnitSystem이 정의되어 있으면 그 time field를 따르는 physical time 관성, 질량, 감쇠, 가속도 관련 물리량과 일관되어야 하는 물리 시간이다.
    Static, Quasi global UnitSystem과 무관한 step-defined time으로 표현되는 physical time 관성항에는 쓰이지 않지만, 시간의존 하중과 재료가 참조하는 물리 시간이다. 첫 dataline의 TUnit=tUnit으로 시간 단위를 지정한다.
    Seepage, Steady 무차원 진행 좌표 하중ㆍPTCㆍ재료 경로의 진행값이다. 물리 시간을 나타내지 않으며 rtime을 증가시키지 않는다.
    Seepage, Transient global UnitSystem과 무관한 step-defined time으로 표현되는 physical time 투수계수, flux, 저장항, 경계조건과 일관되어야 하는 침투 과도 시간이다. 첫 dataline의 TUnit=tUnit으로 시간 단위를 지정한다.

    step-defined time은 특정 해석 step에서 정의하는 물리 시간 좌표를 뜻한다. 이 시간 단위는 global UnitSystem의 time field에서 가져오지 않고, 해당 step의 첫 dataline에 지정한 TUnit을 따른다. Static, Quasi에서 표준 ConcreteTime 함수를 사용하는 경우 콘크리트 시간 변수는 day 기준이므로 step TUnit도 day여야 한다.

    Hyfeast는 step 안에서 진행되는 시간 좌표를 stime, 여러 step을 관통하는 물리 시간을 rtime으로 구분한다. rtime은 내부적으로 초 단위로 누적되지만, 입력과 출력은 해당 step의 시간 단위를 따른다. Dynamic step에서는 global UnitSystem의 time field를 사용하고, Static, Quasi와 Seepage, Transient에서는 TUnit을 사용한다. Seepage, Steady와 Static, Standard/Arclength의 pseudo-time은 진행 좌표일 뿐 rtime을 증가시키지 않는다.

    요소가 활성화되면 현재 rtime이 그 요소의 birthTime으로 기록된다. 요소 경과시간 ELTIME은 저장 필드가 아니라 다음 식으로 계산되는 derived field이다.

    \[ \mathrm{ELTIME}=\mathrm{rtime}-\mathrm{birthTime} \]

    ELTIME 출력 단위는 현재 step의 물리 시간 단위를 따른다. pseudo-time step에서는 rtime이 증가하지 않으므로 ELTIME도 직전 물리 시간 기준 값으로 출력된다. 직전에 물리 시간 step이 없으면 s를 사용한다.

    *Step, Type=Static|Dynamic|Seepage,...,  Name=name, PREV=prevStep, NLGeom=ON|OFF
 Uniform, 0.02, 100, OutFreq=2
    - 해석 시간: 0, 0.02, 0.04, ..., 2 (초기시간 0은 항상 포함) - 출력 시간 : 0, 0.04, 0.08, ..., 2 (마지막 해석 시간은 항상 포함)

    *Step, Type=Static|Dynamic|Seepage,...,  Name=name, PREV=prevStep, NLGeom=ON|OFF
 Uniform, 0.02, 100, OutFreq=0
    - 해석 시간: 0, 0.02, 0.04, ..., 2 (초기시간 0은 항상 포함) - 출력 시간 : 2 (OutFreq=0이므로 마지막 시간만 출력)

    *Step, Type=Static|Dynamic|Seepage,...,  Name=name, PREV=prevStep, NLGeom=ON|OFF
 Given, 0.02, 0.05, 1:5:2, OutFreq=2
    - 해석 시간: 0, 0.02, 0.05, 1, 3, 5 (초기시간 0은 항상 포함) - 출력 시간 : 0, 0.05, 3, 5 (마지막 해석 시간은 항상 포함)

    *Step, Type=Static|Dynamic|Seepage,...,  Name=name, PREV=prevStep, NLGeom=ON|OFF
 Auto, 0.02, 1, 0.001, 0.02, OutFreq=2
    • 해석 시간: 0.02부터 0.02 시간간격으로 1까지 풀지만, 수렴성에 따라 0.001, 0.02까지 시간간격을 조정 (초기시간 0은 항상 포함)
    • 출력 시간 : 초기시간(0)부터 빈도 2씩 증분되는 해석 시간 (마지막 해석 시간은 항상 포함)

    *Step, Type=Static|Dynamic|Seepage,...,  Name=name, PREV=prevStep, NLGeom=ON|OFF
 Auto, 0.02, 1.6, 0.01, 0.02, OutTime=0.03, 0.8:1.2:0.2
    - 해석 시간: 0.02부터 0.02 시간간격으로 1.6까지 풀지만, 수렴성에 따라 0.01, 0.02까지 시간간격을 조정 (초기시간 0은 항상 포함) - 출력 시간 : 0.03, 0.8, 1.0, 1.2, 1.6에 출력(해석 마지막 시간은 자동 추가)

    13.1.1 *Step, Type=Static

    정적 해석 단계를 지정

    *Step, Type=Static,Standard|Arclength|Quasi,  Name=name, PREV=prevStep, NLGeom=ON|OFF
 Uniform, dt, ntime, OutFreq=freq
 Uniform, dt, ntime, TUnit=tUnit, OutFreq=freq
 Given, timeSpec, OutFreq=freq|OutTime=timeSpec
 Given, timeSpec, TUnit=tUnit, OutFreq=freq|OutTime=timeSpec
 Auto, t0, tmax, dtmin, dtmax, maxInc, OutFreq=freq|OutTime=timeSpec
 Auto, t0, tmax, dtmin, dtmax, maxInc, TUnit=tUnit, OutFreq=freq|OutTime=timeSpec
    Keyword line
    • Standard: 표준 정적 해석(Standard load-displacement controlled static analysis step). Standard는 생략 가능.
    • Arclength: Arclength 정적 해석(Arclength-controlled static analysis step).
    • Quasi: 시간 의존 정적 해석(Quasi-static analysis step). Uniform, Given, Auto dataline에 TUnit=tUnit을 지정해야 한다.
    • NLGeom=On|Off: 기하비선형 지정(optional, default Off). [Reserved. Currently Unused]
    First dataline starting with Uniform (optional)
    • Uniform,dtime,ntime: 등간격의 해석시간간격(time increment)을 지정한다. dtime, 2*dtime, ..., ntime*dtime의 시간을 지정하는 것과 같다. dtime의 의미와 단위는 시간 해석 표를 따른다. ntime은 무차원 정수이다.
    • TUnit=tUnit: Static, Quasi에서 step-defined time의 단위를 지정한다. Static, Standard와 Static, Arclength에서는 사용할 수 없다.
    • OutFreq=freq: 출력할 increment 빈도. 만약 0이면 최종 시간만 출력, (디폴트값은 1)
    First dataline starting with Given (optional)

    Algorithm description

    Seepage, Steady의 dataline에 입력하는 값은 물리시간이 아니라 최종 정상상태 문제에 접근하는 정도를 나타내는 무차원 진행값 \(s\)이다. Path는 \(s\)에 따라 풀어 가는 보조문제를 정한다. 세 경로 모두 \(s=1\)에서 보조 과정이 끝나 원래의 정상상태 문제에 도달하므로 마지막 진행값은 정확히 1이어야 한다. Steady에는 TUnit을 지정하지 않는다. 투수계수의 시간 단위는 재료에 TUnit을 지정하면 그 값을 따르고, 생략하면 *Environment, Type=UnitSystem의 전역 시간 단위를 따른다. 전역 단위계가 없으면 모든 시간 차원 물리량에 서로 일관된 동일한 단위 \([T]\)를 사용하며, 프로그램은 이를 초나 분 등의 특정 단위로 가정하거나 변환하지 않는다.

    Seepage, Transient의 dataline에 입력하는 값은 실제 물리시간이며, TUnit으로 그 단위를 지정한다. 이 값은 투수계수의 입력 단위를 바꾸지 않는다. 투수계수는 재료의 TUnit 또는 전역 UnitSystem의 시간 단위에서 step의 TUnit으로 변환하여 사용한다.

    Steady에서 선택 가능한 경로는 다음과 같다. Path를 생략하면 Material이다.

    Path 공통 진행값 \(s\)에 따른 변화
    Load 입력한 하중과 지정 수압을 \(s\)에 따라 목표값까지 증가시킨다. 재료관계는 처음부터 입력값을 사용한다.
    PTC 하중, 지정 수압 및 재료관계를 처음부터 모두 적용한다. 중간 진행점에서는 대각 안정화항을 사용하고 최종점에서 완전히 제거한다.
    Material 하중과 지정 수압을 처음부터 모두 적용하고, VGM 상대투수계수만 포화값에서 입력한 재료값까지 변화시킨다.

    Seepage, Steady의 dataline을 생략하면 Auto,1,1,0,1,1000, Path=Material, OutFreq=0과 같다. 첫 시도에서는 \(s=1\)의 원래 정상상태 문제를 직접 풀고, 실패하여 Auto가 진행 증분을 줄이면 \(s<1\)에서 Material continuation이 활성화된다.

    Steady에서는 각 진행 증분에서 비선형 평형 반복과 PSF boundary interaction이 수렴한 뒤, 그 증분을 받아들이기 전에 전체 경계의 유량평형을 확인한다. 전체 유입량과 유출량의 상대 오차가 내부 허용값 \(10^{-4}\) 이하일 때만 현재 증분을 수렴한 것으로 받아들인다. 일반 수렴 조건을 먼저 만족했더라도 유량평형이 부족하면 같은 증분의 평형 반복을 계속한다. 허용된 반복 횟수 안에 유량평형까지 만족하지 못하면 현재 증분을 실패로 처리하며, Auto에서는 진행간격을 줄여 다시 시도한다. Uniform과 Given에서는 자동 cutback을 수행하지 않는다.

    LScheme은 Seepage, Transient의 각 물리 시간증분 안에서 저류 접선을 안정화한다. 정상상태 연속화 경로를 선택하는 Path와는 다른 기능이며, 시간증분을 정의하는 Uniform, Given, Auto와도 구별된다.

    LScheme 저류 접선 적용 조건
    None 현재 압력에서 계산한 재료의 저류 접선을 사용한다. 기본값
    Auto 각 재료의 압력 용량 상한으로 \(L\)을 자동 산정한다. 포화 재료는 \(S_s/\gamma_w\)를, VGM 재료는 air-entry 보정을 포함한 \(d\theta/dp\)의 상한과 \(S_s/\gamma_w\) 중 큰 값을 사용한다. 포화 또는 VGM 재료
    Fixed,value 모든 침투 재료에 사용자가 지정한 양의 \(L\)을 적용한다. value의 단위는 현재 압력 단위의 역수이다. 사용자 정의 SWCC에는 이 방법을 사용한다.

    LScheme=Auto|Fixed에서는 보정방정식의 저류 접선행렬을 다음과 같이 구성한다.

    \[ \mathbf M_L=\int_\Omega \mathbf N^{\mathsf T}L\mathbf N\,d\Omega, \qquad \mathbf H_{\mathrm{eff}}=\mathbf H_{\mathrm{flow}}+\frac{1}{\Delta t}\mathbf M_L \]

    여기서 \(\mathbf N\)은 압력 보간함수 행렬, \(\Delta t\)는 물리 시간증분이며, \(\mathbf H_{\mathrm{flow}}\)는 선택한 비선형 알고리즘에 따라 구성한 투수항의 접선행렬이다. 실제 저류 잔차 \((\theta(p_{n+1})-\theta(p_n))/\Delta t\)는 바꾸지 않으므로 수렴한 해는 원래의 과도 이산방정식을 만족한다. StepCtrl도 그대로 함께 적용할 수 있다. LScheme=Auto는 \(L\)의 자동 산정이며, 시간증분의 Auto를 뜻하지 않는다. 사용자 정의 SWCC는 전 압력 범위의 미분 상한을 프로그램이 보장할 수 없으므로 LScheme=Auto를 허용하지 않는다.

    Eigen solver는 \(Kx = \lambda Mx\) 형태의 일반 고유치 문제를 풀기 위해 사용된다. 기본 설정은 General이며, 필요하면 LDR(Load-Dependent Ritz)과 같은 특수 솔버를 적용할 수 있다. General 고유치 솔버는 행렬 크기에 따라 LAPACK 또는 ARPACK을 사용한다.

    Solver, Type=Eigen, General에서는 Range, Threshold, ZeroEigTol, Strategy 옵션을 사용할 수 있다. Range=lowFreq로 지정하면 lowFreq 이상의 고유치를 선별하며 단위는 [1/T]이다. Range=lowFreq,highFreq,maxnev로 지정하면 [lowFreq, highFreq] 범위의 고유치를 선별하고, maxnev는 선별 가능한 최대 고유치 수를 뜻하며 기본값은 200이다. Threshold=EMMR,value 또는 Threshold=MPR,value로 지정하면 EMMR(Effective Modal Mass Ratio) 또는 MPR(Modal Participation Ratio)이 주어진 값 이상인 모드만 채택한다. ZeroEigTol=tol로 지정하면 tol 이하의 고유치는 zero 고유치로 간주하며 기본값은 1E-8이다. Strategy=Expansion 또는 Strategy=Sweep으로 고유치 필터링 방식을 선택할 수 있고, Expansion은 candidate-expansion 방식을 사용하며 Sweep은 filtered-sweep 알고리즘을 사용한다. 기본값은 Sweep이다.

    Range 또는 Threshold 조건이 주어지면 solver는 후보 고유치 수인 nev를 단계적으로 늘려 가며 조건을 만족하는 모드를 탐색한다. 이 과정에서 내부적으로 nevLimit가 자동 설정되어 후보 고유치 수의 상한을 제한하며, 이 값은 활성 질량 자유도, 사용 가능한 메모리, 그리고 solver 특성을 함께 고려해 결정된다. 따라서 필터 조건을 사용하더라도 계산 시간과 메모리 사용이 과도하게 증가하지 않도록 제어된다.

    Threshold=EMMR은 누적 유효질량비를 기준으로 모드를 선별하는 방식에 대응하며, 주어진 하중패턴에 대해 충분한 모드 기여를 확보하는 데 유리하다. 반면 Threshold=MPR은 먼저 관심 주파수 대역의 후보 모드를 확보한 뒤, 그 대역 내부에서의 상대적인 modal participation을 기준으로 모드를 선별하는 방식에 대응한다. 따라서 MPR 기준은 주파수 대역 기반 선별과 함께 사용할 때 특히 유효하며, 비대칭계처럼 generalized EMMR의 누적값이 단조롭게 증가하지 않을 수 있는 경우에 더 적합하다. 실무적으로는 EMMR 또는 MPR 필터와 내부 nevLimit 제어를 함께 사용하여 탐색 범위를 관리한다. Strategy=Expansion에서 nevLimit에 도달한 경우 이는 오류가 아니라 정상적인 종료 사유(stop reason)로 처리되며, Strategy=Sweep에서 nevLimit는 종료 조건이 아니라 한 sweep 창에서 사용하는 후보 고유치 수의 상한으로만 작동한다.

    비대칭계에서는 고유치가 일반적으로 복소수가 될 수 있으므로, 특정 실수 구간을 기준으로 고유치를 제한하는 방식이 제대로 작동하지 않을 수 있다. 한편 대칭계에서는 고유치가 항상 실수이지만 음수로 계산될 수도 있으므로, 이 경우에도 단순한 주파수 범위 제한이 항상 유효한 것은 아니다. 따라서 대칭계와 비대칭계 모두에서 Range 기반 추출은 고유치가 0 이상인 실수로 계산되는 특별한 경우에만 안정적으로 유효하다.

    Algorithm description

    *NonlinearAlgorithm은 반복에 사용할 접선과 계수행렬 갱신 방법을 선택한다. StepCtrl은 선택한 알고리즘으로 계산한 보정량에 적용할 스텝 크기를 별도로 제어한다.

    계수행렬 갱신

    Picard, Newton, HNewton은 현재 반복 상태에서 계수행렬을 매 평형반복마다 재구성한다. MNewton은 증분 시작에서 구성한 Newton 접선행렬을 재사용하고 kernelUpdate로 지정한 반복 간격마다 다시 구성한다. 이때 잔차와 현재 상태는 매 반복 다시 계산하며, 접선행렬과 그 분해 결과만 재사용한다. Seepage에서는 새 증분, cutback 재시도 및 새 PSF 활성집합 반복을 시작할 때 항상 행렬을 다시 구성한다. BFGS와 Secant는 기준 계수행렬을 kernelUpdate 간격으로 재구성하고, 그 사이에는 각각의 quasi-Newton 갱신식을 사용한다.

    다만 Static Arclength 해석은 선택한 알고리즘과 관계없이 계수행렬을 매 반복 재구성한다.

    Hybrid Newton

    HNewton은 기준 접선과 Newton 접선을 혼합한다. Seepage에서 기준 접선은 Picard 접선이며, 혼합접선은 다음과 같다.

    \[ \mathbf K_H(r)=(1-r)\mathbf K_P+r\mathbf K_N \]

    여기서 \(\mathbf K_P\)는 재료 미분항을 제외한 Picard 접선이고 \(\mathbf K_N\)은 사용 가능한 재료 미분항을 포함한 Newton 접선이다. 고정형 HNewton은 \(0<r<1\)을 사용한다. \(r=0\)에 해당하는 방법은 Picard로, \(r=1\)에 해당하는 방법은 Newton으로 입력한다.

    적응형 HNewton에서 각 PSF 활성집합 평형해석의 첫 두 압력 보정 방향은 r0 접선으로 계산한다. 두 번째 보정량을 적용한 상태부터 Picard 접선을 사용하며, 이 보정량을 이후 상대 압력 보정량의 고정 기준으로 삼는다. 혼합비를 조절하는 지표는 다음과 같다. 여기서 \(p_{guard}\)는 분모가 0이 되는 것을 막기 위한 프로그램 내부의 작은 양수이다.

    \[ q_k = \frac{\lVert \Delta p_k \rVert_\infty}{\max(\lVert \Delta p_2 \rVert_\infty,p_{guard})} \]

    \(q_k\)가 tolSwitch보다 작고 계속 개선되면 \(r\)을 grow만큼 증가시키고, 그 밖에는 shrink만큼 감소시킨다. PSF 활성집합이 바뀌면 \(r\)과 기준값을 초기화한다. 과도 Seepage에서는 각 물리 시간증분에서도 기준을 새로 설정한다. grow=1과 shrink=1은 직접 전환을, 권장값 grow=0.2와 shrink=0.3은 연속 혼합을 선택한다. 갱신된 \(r\)은 다음 평형반복에서 재구성하는 혼합접선에 반영된다.

    Seepage에서 Picard를 사용하면 *Convergence의 Warmup 기본값은 100이고, 그 밖의 비선형 Seepage 해석에서는 20이다.

    스텝 크기 제어

    StepCtrl은 선형계에서 계산한 보정량 \(\delta\mathbf x^i\)에 스텝 크기 \(\eta_i\)를 적용하여 실제 반복해를 갱신하는 방법을 정한다.

    \[ \mathbf x^{i+1}=\mathbf x^i+\eta_i\,\delta\mathbf x^i \]

    StepCtrl은 접선 종류나 행렬 재구성 주기를 바꾸지 않는다. None은 \(\eta_i=1\)을 사용하고, SchedRelax은 반복 횟수에 따라 미리 정한 규칙으로 스텝 크기를 줄인다. RelaxBack, ArmijoBack, Bracketed는 반복 중 시험 상태를 평가하여 허용할 스텝 크기를 찾는다.

    비선형 해석에서의 수렴 조건(convergence criteria)을 지정한다. 선형해석이나 고유치해석에서는 무시된다. 다음과 같은 하중 및 변위 조건을 병진운동, 회전, 압력, 온도 등 물리량 별로 적용한다.

    ** 하중/모멘트 조건

    \[ \left\lVert \mathbf r^i_{g,n+1} \right\rVert_2 \le \max\left(\epsilon_F \left\lVert \mathbf r^1_{g,n+1} \right\rVert_2, R_{min,g}\right) \]

    ** 변위/회전/압력 보정량 조건

    \[ D_{tol,g}^{i+1} = \max\left( \epsilon_{D,g}\left\lVert \Delta \mathbf u^{i+1}_{g,n+1} \right\rVert_\infty, D_{min,g} \right) \]

    양의 \(D_{max,g}\)가 지정된 경우에만 다음과 같이 상한을 적용한다.

    \[ D_{tol,g}^{i+1} \leftarrow \min\left(D_{tol,g}^{i+1},D_{max,g}\right) \]
    \[ \left\lVert \delta \mathbf u^i_{g,n+1} \right\rVert_\infty \le D_{tol,g}^{i+1} \]

    아래첨자 \(g\)는 물리량 그룹을 나타낸다. \(\Delta\mathbf u^{i+1}_{g,n+1}\)은 이전 수렴 증분의 해로부터 현재 반복해까지 누적된 증분이고, \(\delta\mathbf u^i_{g,n+1}\)은 현재 반복에서 적용한 보정량이다. 하중 조건에는 잔차의 L2 노름을 사용하고, 보정량 조건에는 이 두 증분의 infinite 노름을 사용한다. dmax가 None이면 상한 갱신을 적용하지 않는다.

    하중 조건에서는 모든 물리량에 동일한 \(\epsilon_F\)를 사용하며, \(\epsilon_F\)를 1차 허용치(primary tolerance)와 2차 허용치(secondary tolerance)로 구분한다. 1차 허용치는 반복단계 8까지, 2차 허용치는 반복단계 9부터 적용한다. 명시적으로 입력한 fmin의 수치는 활성 잔차 그룹에 공통으로 적용한다. 생략된 기본값은 XYZ와 RXYZ에서만 힘 단위를 따르며, P, T, General에서는 각 잔차의 고유 단위에 있는 raw 값으로 사용한다. 회전 자유도에는 \(R_{min}L_{global}\)을 적용하며, \(L_{global}\)은 요소 변 길이 중앙값으로 정한 모델의 전역 대표 길이이다.

    한편 보정량 조건에서는 물리량별로 서로 다른 \(\epsilon_D\), \(D_{min}\), \(D_{max}\)를 적용한다. \(D_{min}\)은 상대 허용값이 지나치게 작아지는 것을 막는 하한이고, 양의 \(D_{max}\)는 상대 허용값이 지나치게 커지는 것을 막는 상한이다. dmax가 None이면 상한을 적용하지 않는다.

    수렴 조건의 디폴트값은 다음과 같다.

    물리량 Force/residual 기준 디폴트 Displacement 기준 디폴트 UnitSystem 적용
    XYZ \(\epsilon_F=1E-5, 0.01\), \(R_{min}=1E-4\) N \(\epsilon_D=0.01\), \(D_{min}=1E-6\) m, dmax=None \(R_{min}\)은 힘 단위로 변환, \(D_{min}\)은 길이 단위로 변환, 상한 없음
    RXYZ \(\epsilon_F=1E-5, 0.01\), \(R_{min}=1E-4\) N \(\times L_{global}\) \(\epsilon_D=0.005\), \(D_{min}=2E-6\), dmax=None \(R_{min}\)은 힘 단위 변환 후 \(L_{global}\)을 곱함, \(D_{min}\)은 무차원, 상한 없음

    비선형 equilibrium loop에서는 정상 수렴 여부와 함께 residual 이력에 따른 발산(Divergent)과 정체(Stagnated), 계산값의 수치 이상(NumericalFailure)을 검사한다. 이 판정을 통해 수렴 가능성이 낮거나 수치적으로 신뢰할 수 없는 반복을 maxIter에 도달하기 전에 종료할 수 있다.

    각 loop의 처음 Warmup회, 즉 반복 번호 1부터 n까지는 초기의 하중 재분배나 상태 전이로 인한 residual 변화를 추세로 오인하지 않도록 Divergent와 Stagnated 판정을 보류한다. Warmup=0이면 해당 loop의 최초 residual부터 추세 이력을 구성한다.     Newmark 법에서 \(\beta\), \(\gamma\)는 수치안정성과 정확성에 따라 결정되는 계수이다. \(\gamma=1/2\)이면 수치감쇠를 도입하지 않으며, \(\gamma>1/2\)이면 수치감쇠를 도입한다. 보통 \(\gamma=1/2\), \(1/6 \le \beta \le 1/4\) 를 선택하는데, \(\gamma=1/2\), \(\beta=1/4\)인 경우는 시간간격내 가속도가 일정하다고 가정하는 것으로 평균가속도법 (average acceleration method)이라 하고,\(\gamma=1/2\), \(\beta=1/6\)인 경우는 시간간격내 가속도가 선형적으로 변화한다고 가정하는 것으로 선형가속도법 (linear acceleration method)이라 한다. 다음 조건을 만족해야 수치적으로 안정이다.

    \[ \frac{\Delta t}{T_n} <= \frac{1}{\pi \sqrt 2} \frac{1}{\sqrt {\gamma-2\beta}} , ~~ {\rm where ~} T_n {\rm ~is~natural~frequency} \]

    즉, 평균가속도법을 사용하면 무조건적으로 안정(unconditionally stable)이고, 선형가속도법을 사용하면 \(\frac{\Delta t}{T_n}\)을 만족해야 안정하다. 다자유도로 구성되는 유한요소문제에서 고차의 낮은 고유주기(높은 고유진동수)까지 이러한 안정조건을 만족하도록 를 선택하는 것은 쉽지 않기 때문에 정밀도가 떨어지더라도 평균가속도법을 사용하는 것이 일반적이다. Hibert-Hughes-Taylor 법(HHT 법, \(\alpha\)-method)은 Newmark 법을 확장한 방법으로 해의 정확도를 유지하면서 제어가능한(controllable) 수치감쇠(numerical damping)을 도입한다. \(-1/3 \le \alpha \le 0\)이고, 무조건적으로 안정(unconditionally stable)한 방법이다. \(\alpha=0\)이면 평균가속도법을 적용한 Newmark 법과 동일하다. 일반적으로 \(\alpha=-0.05\)를 사용하며, \(\alpha=0\)는 수치감쇠가 없는 것을, \(\alpha=-1/3\)은 수치감쇠가 가장 큰 것을 의미한다. 수치감쇠는 low-frequency 모델에서는 그 영향이 작고, high-frequency 모델에서는 영향이 크다.

    • Equivalent, fm, fn, xim, xin: 등가감쇠비 xim, xin와 이에 대응하는 구조물의 고유진동수 fm, fn(Hz), 보통 1차 및 2차 고유진동수를 지정. 보통 xim과 xin을 동일하게 설정(모두 required)

    등가감쇠비를 지정할 경우 Rayleigh damping coeficient alpha, beta를 다음과 같은 관계식을 통해 계산해서 설정한다.

    \[ \left[ \begin{matrix} \xi_m \\ \xi_n \\ \end{matrix} \right] = \frac{1}{2} \left[ \begin{matrix} 1/\omega_m & \omega_m\\ 1/\omega_n & \omega_n\\ \end{matrix} \right] \left[ \begin{matrix} \alpha \\ \beta \\ \end{matrix} \right] \]

    위에서, \(\omega_m = 2\pi f_m\), \(\omega_n = 2\pi f_n\)이고, 결정된 \(\alpha\), \(\beta\)는 다음과 같이 구성되는 Rayleigh damping matrix(\(C^R = \alpha M + \beta K\))에 대한 상수들이다.

*RayleighDamping
 Direct, 0.5, 0.1    # Specifies all elsets in Step 1, such as ELSET1, ELSET2

*Step, Type=Dynamic, Name=2

    동해석(*Step, Type=Dynamic)에서 모달 해석과 모달 감쇠비 배정을 지정한다.

    *MODAL, nmode, dampingRatio[, Elset=targetElset]

    • nmode: 고유치 해석에 요청할 모드 수이다. 의미는 *Step, Type=Frequency의 nev와 같으며, 계산할 최고 모드 수이거나 고유치 솔버에 범위 필터가 있을 때는 초기 제안치이다.

    • imode, dampingRatio: ByIndex에서 특정 참여 모드 하나와 그 감쇠비를 지정한다.
    • fromMode, toMode, dampingRatio: ByIndex에서 참여 모드 구간과 그 감쇠비를 지정한다.
    • fromFreq, toFreq, dampingRatio: ByFreq에서 주파수 구간(Hz)에 해당하는 참여 모드들과 그 감쇠비를 지정한다.

    ByIndex에서는 dataline에 적힌 모드만 모달 해석에 참여한다. 같은 모드를 두 번 이상 지정하면 입력 오류로 처리한다.

    ByFreq에서는 먼저 nmode까지 고유치 해석을 수행한 뒤, 지정한 주파수 구간 가운데 하나 이상에 해당하는 모드만 모달 해석에 참여한다. 즉 지정한 구간 밖의 모드는 참여하지 않는다. 하나의 모드가 여러 구간에 동시에 걸리면 아래쪽에 적은 dataline이 앞의 dataline을 덮어쓴다. 어떤 모드도 선택되지 않으면 오류가 발생한다.

    모달 해석은 선형계를 대상으로 동해석을 수행하는 특수 기법이다.

    1. *Modal을 지정하면 *RayleighDamping은 무시된다.
    2. *Modal에서는 시간적분법으로 Newmark만 허용된다. HHT나 FrequencyDomain을 지정하면 오류가 발생한다.
    3. 균일 형식에서는 1번부터 nmode까지의 모드가 모달 해석에 참여한다. ByIndex와 ByFreq에서는 선택된 모드만 참여한다. 고유치 해석에 필요한 요청 모드를 구하지 못하면 오류가 발생한다.
    4. 모달 해석에서는 *Load, Type=Displacement를 적용할 수 없다.
    5. 모달 해석의 반력은 모달 감쇠의 영향은 고려하지 않는다.
    6. 모달 해석은 선형 요소집합에만 적용할 수 있다.
    7. targetElset를 생략하면 전체 모델을 대상으로 모달 해석을 수행하며, 이 경우 전체 모델이 선형이어야 한다.
    8. targetElset를 지정하면 해당 요소집합에 대해서만 partial modal analysis를 수행한다. 이 경우 지정된 targetElset만 선형 조건을 만족하면 된다. 이 기능은 요소가 접촉점의 변경으로 인해 비선형성이 발생하는 차량-교량 상호작용해석에서 유용하게 사용될 수 있다.
    9. *Modal 뒤에 *Solver, Type=Eigen을 둘 수 있으며, 이때 지정한 고유치 솔버 옵션이 모드 추출에 사용된다. *Solver, Type=Eigen을 생략하면 기본 고유치 솔버 설정이 사용된다.

    13.10 *Spectrum

    응답스펙트럼 해석(*Step, Type=ResponseSpectrum, 13.1.4)에서 지진 입력 방향과 설계스펙트럼 배정을 지정한다.

    *Spectrum, dampingRatio, Dir=rx, ry, rz, Function=func[, scaleFactor]

*Spectrum, ByIndex, Dir=rx, ry, rz
 imode, dampingRatio, func[, scaleFactor]
 fromMode, toMode, dampingRatio, func[, scaleFactor]
 ...

*Spectrum, ByFreq, Dir=rx, ry, rz
 fromFreq, toFreq, dampingRatio, func[, scaleFactor]
 ...
    Keyword line
    • dampingRatio: 모든 모드에 적용하는 균일 감쇠비. 값 범위는 [0,1)이다. CQC 상관계수 계산에 사용되고, SRSS 조합식에는 사용되지 않는다.
    • Dir=rx, ry, rz: 전역 좌표계 기준 지진 입력 방향 벡터. 내부에서 정규화된다.
    • Function=func: 모든 모드에 적용하는 설계스펙트럼 함수 이름이다. *Function, Type=MultiLinear 또는 *Function, Type=ResponseSpectrum으로 정의한다. x축은 주기 \(T\) [s], y축은 스펙트럼가속도계수 \(S_a/g\)이다.
    • scaleFactor: 스펙트럼 배율(optional, 디폴트 \(1.0\)).
    • ByIndex: 모드 번호 기준으로 감쇠비와 spectrum을 배정한다. dataline이 필수이다.
    • ByFreq: 고유진동수 구간 기준으로 감쇠비와 spectrum을 배정한다. dataline이 필수이다.
    First dataline and subsequent datalines
    • imode, dampingRatio, func[, scaleFactor]: ByIndex에서 모드 하나에 감쇠비와 spectrum 함수를 배정한다. 모드 번호는 1-based이다.
    • fromMode, toMode, dampingRatio, func[, scaleFactor]: ByIndex에서 모드 구간에 배정한다. 단일/구간 형식은 함수 이름 앞의 숫자 개수로 구분한다(숫자 2개 = 단일 모드, 숫자 3개 = 구간).
    • fromFreq, toFreq, dampingRatio, func[, scaleFactor]: ByFreq에서 고유진동수 구간(Hz)에 배정한다. 구간 판정은 fromFreq <= f < toFreq이다.
    1. *Spectrum은 *Step, Type=ResponseSpectrum의 하위 명령으로만 사용할 수 있다.
    2. 각 *Spectrum은 독립된 가진 케이스이며 하나의 envelope frame을 만든다.
    3. 계산에 사용된 모든 모드에 (감쇠비, spectrum) 쌍이 정확히 하나 배정되어야 한다. 누락이나 중복은 오류 처리한다.
    4. 주기가 spectrum 정의 구간을 벗어나면 양 끝값으로 평탄 외삽한다.
    5. zero 고유치로 판정된 모드는 spectrum 평가에서 제외하고 경고를 출력한다.
    6. 비대칭(예: 유체-구조 연성) 시스템은 left participation factor를 가진 크기로, 우고유벡터를 응답 회복에 사용한다. 모든 고유치가 실수여야 한다.

    13.11 *InteractionControl

    해석도중 동적으로 변경되는 경계조건 및 접촉조건을 부과한다. 현재는 PSF만 지원한다.

    *InteractionControl, Type=PSF, maxIter=maxIter
 targetNode|targetNGroup, ...
    Keyword line
    • maxIter=maxIter: Maximum number of iterations used to identify changing boundary conditions and contact conditions. Optional; the default value is 20.
    First dataline
    • targetNode: PSF(Potential Seepage Face)로 지정할 target node (required)
    • targetNGroup: PSF(Potential Seepage Face)로 지정할 node group(required). targetNGroup은 nset, surface, 절점번호패턴(start:end:spacing 형태, spacing은 1일 때 생략 가능) 형식으로 지정하며, surface로 지정하는 경우 surface 내의 절점들을 의미.

    PSF(Potential Seepage Face)는 *Step, Type=Seepage 해석에서만 유효하다. PSF는 해석 도중 Seepage Face로 지정될 수 있는 후보로 지정한다는 의미이다.

    PSF 절점은 무유량 상태와 대기압 상태를 active set으로 전환한다. 무유량 상태에서 계산된 간극수압이 양수가 되면 절점을 \(p=0\)으로 고정하여 외향 유출을 허용한다. \(p=0\)으로 고정된 절점에서 반력 flux가 유입을 요구하면 고정을 해제하고 무유량 상태로 되돌린다.

    정상 및 비정상 Seepage에서 active set이 A→B→A로 반복되면 직전 active set을 유지하고 interaction 수렴으로 수용한다. \(p=0\)으로 고정된 절점의 release 판정에는 항상 비마스킹 잔차를 사용한다.

    따라서 PSF로 지정된 절점에 *Constraint, Type=Support나 *Load, Type=Displacement를 통해 간극수압이나 총수두를 지정하면 안 된다.

    Example
    *STEP, Type=Seepage, Name=name
...
*InteractionControl, Type=PSF
 downStream

      • Posttension: 텐던 긴장력 도입(Force hold 조건)

    • ByStartForce: - Posttension으로 긴장력 부과시 시작단 긴장력 부과(긴장력 분포는 계산)
    • ByStartIncrementalDelta: - Posttension으로 긴장력 부과시 시작단에 변위 부과(긴장력 분포는 내부 계산)
    • ByEndForce: - Posttension으로 긴장력 부과시 끝단단 긴장력 부과(긴장력 분포는 계산)
    • ByEndIncrementalDelta: - Posttension으로 긴장력 부과시 끝단에 변위 부과(긴장력 분포는 내부 계산)
    • value: 지정할 값(required). 단위는 Pretention의 경우 [F], Posttension에서 ByStartForce, ByEndForce이면 [F], ByStartIncrementalDelta, ByEndIncrementalDelta이면 [L], CableLength는 [L], MovingSpringSpeed는 [L/T]이다.

    Pretension는 해당 해석 단계(*Step)에서 초기 긴장력 분포를 부여한다. 해석이 종료될 때 긴장력 분포는 평형상태를 만족되도록 변화된다. Posttension는 초기 긴장력 분포가 해석 단계내 일정하게 유지하는 것을 의미한다. Pretension와 Posttension 모두 일정한 긴장력을 부여할 수 있다. Posttension의 경우 추가로 Jacking 옵션(ByStartForce, ByStartIncrementalDelta, ByEndForce, ByEndIncrementalDelta 옵션)으로 시작단 및 양단을 jacking하여 초기긴장력을 부여할 수 있다. 이때 텐던의 곡률마찰계수(curvature fricition coefficient)와 파상마찰계수(wobble friction coefficient)를 이용하여 초기 분포를 계산하게 된다. 다음에 주의한다.

    • Pretention을 가력한 요소에는 또 다른 Pretension이나 Posttension을 가력할 수 없다.
    • Postension을 Value로 가력한 요소에는 또 다른 Pretension이나 Posttension을 가력할 수 없다.
    • Postension을 Jacking 옵션(ByStartForce, ByStartIncrementalDelta, ByEndForce, ByEndIncrementalDelta 옵션)으로 가력하기 위해서는 그 요소의 물성치인 곡률마찰계수와 파상마찰계수가 둘다 0이어서는 안된다.
    • Postension을 Jacking 옵션(ByStartForce, ByStartIncrementalDelta, ByEndForce, ByEndIncrementalDelta 옵션)으로 같은 요소에 가력하면 순차적으로 프리스트트레스가 가력된다.

    이외에도 CableLength와 MovingSpringSpeed는 각각 Cable 요소의 초기 길이, MovingSpring 요소의 이동속도를 지정한다.

      • Head: 절점의 전수두 \(H\) [L]. Seepage, Transient에서만 사용

    • z0: 수평 지하수위의 표고 [L]. WaterTable은 데이터라인이 한 줄이다.
    • x1, z1, x2, z2, ...: 2차원 경사 지하수위선의 꼭짓점(표고축은 2차원에서 Y). 값의 개수는 짝수이고 2점 이상이어야 하며 \(x_i\)는 엄격한 오름차순이다. 범위 밖은 끝 값으로 연장한다. 3차원에서는 수평 수위 z0만 사용할 수 있다.

    • H, p: 절점의 전수두 또는 간극수압. 두 값은 \(p=\gamma_w(H-z)\)로 등가이며 \(\gamma_w\)는 절점에 연결된 Seepage 재료에서 가져온다.
    • dof, value: Velocity의 자유도(X|Y|Z|RX|RY|RZ)와 속도.

    *InitialCondition은 해당 Step의 시작에 한 번 적용되고 다음 Step으로 전파되지 않는다. 이후의 상태는 보통의 상태변수로 진화하며 Prev=로 이어진다. *State가 요소 내부상태(긴장력, 케이블 길이 등)를 지정하는 데 비해 *InitialCondition은 절점 자유도 필드의 값을 지정한다. 두 명령은 서로 다른 상태를 다루므로 함께 쓸 수 있다.

    Step 시작 상태는 다음 순서로 만들어진다. ① Prev=가 있으면 이전 Step의 끝 상태, 없으면 기본 초기상태 ② *InitialCondition ③ *State ④ 시각 0 상태결정(침투: 초기 압력에서 함수비ㆍ포화도 재계산, 동적: 초기 속도로 감쇠력 재조립) ⑤ 첫 증분. STime=0 프레임은 OutFreqㆍOutTime이 요청할 때만 기록되며 초기조건 적용 후의 값을 담는다.

    WaterTable은 수위선 \(z_w(x)\) 아래에 \(p=\gamma_w(z_w-z)\), 위에 같은 식의 부압을 주고 PMin이 있으면 \(p\ge p_{\min}\)으로 자른다. HeadㆍPressure는 WaterTable보다 우선하며, 같은 절점에 Head와 Pressure를 함께 주거나 같은 종류를 다른 값으로 중복 지정하면 오류이다. 두 WaterTable이 절점을 공유하면 오류이므로 Nset으로 영역을 나눈다. prescribed 압력(*Load, Type=Displacement의 H/P, Support)과 겹치는 절점은 첫 증분부터 경계값이 우선하므로 두 값이 다르면 첫 증분에 점프가 생긴다. 과도 침투에서 P 필드 초기조건이 없고 Prev=도 없으면 기본 초기상태 \(H=0\)(\(p=-\gamma_w z\))을 사용한다. 정상 침투에는 물리적 초기시간이 없으므로 *InitialCondition을 사용할 수 없고, 평형 초기장이 필요하면 정상 Step을 Prev=로 연결한다.

    Velocity는 자유 자유도에만 지정할 수 있다. Support로 고정된 자유도, prescribed motion 자유도, MPCㆍ변환구속의 slave 자유도에 지정하면 오류이며, slave 속도는 master에서 복원된다. *Modal이 있는 Dynamic Step에서는 사용할 수 없다. 초기 변위는 *InitialCondition이 아니라 정적 Step을 Prev=로 연결해 만든다. 초기 가속도는 이전 Step의 값(없으면 0)을 유지하며 정합 가속도 \(a_0=M^{-1}(f_0-Cv_0-f_k(d_0))\)를 따로 계산하지 않는다. 무감쇠ㆍ평형 시작이면 \(a_0=0\)이 정확하고, 그 외에는 첫 증분에 \(O(\Delta t)\) 초기자료 오차가 생긴다.

    Example
    *Step, Type=Seepage, Transient, Name=Rain, Prev=Stress
 Uniform, 0.1, 100, TUnit=day
*InitialCondition, Type=WaterTable, PMin=-20000
 0, 8, 10, 4
*InitialCondition, Type=Head
 Reservoir, 16

*Step, Type=Dynamic, Name=Impact, Prev=Dead
 Uniform, 0.01, 200
*InitialCondition, Type=Velocity
 Deck, Y, -1.2

    13.14 *Output

    HDB 파일('hdb)로 출력되는 결과값을 지정한다.

    *Output[, Elset=elset1, elset2, ..., Constraint=constraint1, constraint2, ...]
 field|sensorName,...
 ...
    Keyword line
    • Elset=elset1, elset2, ...: HDB 파일('hdb)의 결과값을 출력할 대상 요소집합. 없으면 *Activate, Type=Element에서 지정한 요소집합이 사용됨
    • Constraint=constraint1, constraint2, ...: HDB 파일('hdb)의 결과값을 출력할 대상 구속조건, 없으면 *Activate, Type=Constraint에서 지정한 구속조건이 사용됩.
    First dataline and subsequent datalines (optional for FrequencyStep)
    • field, ...: Name of field
    • sensorName: 출력한 센서 명칭

    *Output은 HDB 파일('hdb)에 출력할 절점이나 요소의 필드값, 또는 센서값을 지정하는 명령이다. Element나 Constraint로 출력할 요소집합이나 구속조건을 지정할 수 있다. 만약이 대상 요소집합이나 구속조건을 지정하지 않으면 *Activate, Type=Element/Constraint에서 지정한 요소집합이나 구속조건이 사용된다. 대상 요소집합과 구속조건으로 대상 절점들이 결정되게 된다. 다시 말하면 대상 요소집합은 지정한 요소집합으로 결정하고, 대상 절점집합은 지정한 요소집합과 구속조건으로 결정된다. 데이터라인에 출력할 센서을 지정하는 것은 Element나 Constraint로 지정하는 출력대상에 무관하다.

    HDB 파일('hdb)에서는 *Step에 대응하는 *ResultStep를 생성하며 *TargetElements, *TargetConstraints, *TargetLoads 등을 출력한다. 이때 *TargetElements, *TargetConstraints가 *Output에서 지정한 대상 요소집합과 구속조건이다. 만약 *Output에 대상 요소집합과 구속조건을 지정하지 않으면 이들은 *Activate, Type=Element/Constraint에서 지정한 요소집합이나 구속조건과 같다. *TargetLoads는 *Activate, Type=Load와 항상 같다.

    필드값은 절점 단위의 요소 단위로 필드값으로 구분할 수 있다.

    ▪ 절점 단위 필드

    • FN, FE: Equivalent nodal loads for applied loads and element loads at nodes
    • FK, FC, FM: Internal forces including elastic, damping, and inertial forces
    • D: Degree of freedom field (displacements, temperature, etc., at nodes; represents modes in frequency analysis)
    • V: First time derivative of the degree of freedom field (e.g., velocity for displacement, temperature rate, etc.)
    • A: Second time derivative of the degree of freedom field (e.g., acceleration for displacement, temperature acceleration, etc.)

    절점의 하중은 FN+FE=FK+FC+FM의 관계를 만족하게 된다

    ▪ 요소 단위 필드

    • BSF, BSE, BST: Cross-sectional force, strain, and temperature for beam elements (including truss/cable elements)
    • SSF, SSE, SST: Cross-sectional force, strain, and temperature for shell elements
    • SF, SE, DF, DE: Cross-sectional force and strain for spring elements, and force and strain for damper sections
    • S: Stress
    • E, EM, EE: Total, mechanical, and elastic strain
    • EP: Plastic strain
    • ENM, ETH: Non-mechanical strain and thermal strain
    • SB: Back stress
    • IEC, IET: Compressive and tensile inelastic strain
    • ECUN, ETUN: Last committed compressive/tensile unloading strain
    • PEEQ, PEEQT, PEEQC: Equivalent plastic strain, and tensile/compressive equivalent plastic strain
    • MTEMP: Material temperature
    • ITR, IRD : interfacial traction and relative displacement
    • ELTIME: Element elapsed physical time after activation. This is a derived field computed from rtime - birthTime.
    • ECR, ESH, EAG: Creep strain, shrinkage strain, and aging strain
    • PEL: Element pressure
    • VOL: Element volumetric strain

    요소 단위 필드는 요소점(element point)[요소 중심점, 요소 절점, 적분점 등 요소의 특성에 따라 정의되는 결과값이 정의되는 점]에 따라 순차적으로 출력된다. 예를 들어 8개의 적분점이 있는 C3D8에 대해 S를 출력하는 경우 다음과 같이 출력된다.

    (요소번호), (첫번째 적분점의 S), (두번째 적분점의 S), ... (8번째 적분점의 S)

    보요소, 스프링/댐퍼 요소, 경계면 요소 등에는 셀(cell)이라는 개념이 존재한다. 예를 들어 보요소의 단면을 2개의 서로 다른 재료를 갖는 셀(cell)로 구성하고, 각 셀은 재료점이 10개, 2개 라고 가정하기로 한다. 이때 S의 출력을 요청하면 다음과 같은 순서로 출력된다.

    (요소번호), [첫번째 셀 - 첫 번째 적분점 S[재료점 10개] -... - 4번째 적분점 S[재료점 10개] ] , [두번째 셀 - 첫 번째 적분점 S[재료점 2개] -... - 4번째 적분점 S[재료점 2개] ]

    이와 같은 출력 순서는 텍스트 HDB로 출력하거나 *Print 문으로 출력하면 확인가능하다. 바이너리나 hdf5 형태의 HDB 역시 내부적으로 이 순서에 따라 저장하게 된다.

    ▪ 주의 1. 주파수 해석 단계(*Step, Type=Frequency)에서는 HDB 파일('hdb)에서 모드 별로 프레임이 출력된다. 이때 각 프레임은 하나의 모드에 대응하며, 모드 형상이 D에 출력된다. 나머지 필드값은 이때의 D에 의해 유발되는 값이다. 2. 필드는 하위 성분을 가질 수 있다. 예를 들어 D는 D.X, D.Y, D.Z, .... 등의 하위 성분으로 구성된다. 자세한 하위 성분은 *History를 참조한다.

    Example
    *Step, Type=Static, Name=Case1
*Activate, Type=Element
 dam, water, farField
*Output
 D, SF, S, mySensor
*Print File=Case1.prn
 D@Left, SF@Bearing

*Step, Type=Frequency, Name=FRQ
 10
*Output
 D, SSF
*Print, File=FRQMode.prn

    13.15 *Print

    별도 파일로 출력되는 결과값을 지정한다.

    *Print, File=file
 field[:orientation]@target|sensorName...
 ...
    Keyword line
    • File=file: *Print 명령에서 출력 대상 파일 이름((optional). 지정하지 않는 경우 filename-stepname-P#.csv 형태로 자동 지정됨(filename은 확장자를 제외한 파일 이름, #은 연번). 파일이름에 , 이 포함되는 경우 현재의 DB 이름(입력파일에서 확장자를 뺀 이름)과 현재의 스텝 명칭으로 치환됨.
    First dataline and subsequent datalines
    • field[:orientation]@target: 출력할 필드와 대상. 절점에서 정의되는 필드의 경우 target에는 절점번호, 절점번호패턴, 절점집합이 가능하며, 요소에서 정의되는 필드의 경우 target에는 요소번호, 요소번호패턴, 요소집합이 가능하다. orientation은 선택 항목이며 *CoordinateSystem, Type=Orientation의 명칭 또는 GCS를 지정한다.
    • sensorName: 출력한 센서 명칭

    *Print 명령은 *Output과 유사하나 지정한 절점 집합이나 요소 집합을 대상으로 그 결과값을 텍스트 값으로 출력한다.

    orientation을 지정하면 결과를 출력하기 전에 해당 orientation 좌표계의 성분으로 변환한다. 출력 heading에는 field:orientation@target 형태가 유지되므로 같은 필드를 전역좌표계와 orientation 좌표계로 함께 출력해도 구분할 수 있다.

    지원 범위는 다음과 같다.

    • 절점 벡터 필드 D, V, A, FN, FE, FK, FC, FM
    • 연속체 요소의 텐서 필드 S, E, EM, EE, EP, ENM, ETH, SB
    • 침투해석 연속체 요소의 벡터 필드 GRADP, GRADH, FLX

    지원하지 않는 결과에는 orientation을 붙일 수 없다. 예를 들어 보/쉘/스프링/인터페이스의 고유 국부 결과(BSF, BSE, BST, SSF, SSE, SST, SF, SE, DF, DE, ITR, IRD 등)와 텐서의 주응력/불변량 성분(P1, P2, P3, Mises)은 orientation 변환 대상이 아니다. 2D 연속체 요소 결과는 면내 orientation만 지원한다.
