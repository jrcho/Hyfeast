    15. Modelling

    15.1 *Include

    *INCLUDE는 외부 텍스트 파일을 삽입하는 명령이다. 입력파일이 복잡해 질 경우 적절히 사용된다.

    *Include, File=file, [P=parameters]
    Keyword line
    • File=file: file name
    • parameters: parameter expression. 이중따옴표(")로 둘러싸여야 함. 생략 가능함.
    Example
    *INCLUDE, File=concrete.inp

*INCLUDE, File=model.inp, P="<S>=100. <T>=15.3, <Solver>={A,10}"
    UnitSystem 주의사항
    • *Include는 포함 파일의 텍스트를 현재 입력 흐름에 삽입하는 방식이다.
    • hfAnalyzer와 hfStudio는 *Include에 대해 같은 UnitSystem 해석 규칙을 사용한다.
    • 현재 입력 또는 host DB에 global *Environment, Type=UnitSystem이 있으면, 포함 파일 안의 global UnitSystem은 source unit으로 해석되고 입력값은 현재 global UnitSystem 기준으로 변환된다.
    • 현재 입력 또는 host DB에 global UnitSystem이 없으면, 포함 파일 안의 global UnitSystem은 자동으로 도입되지 않으며 값은 변환 없이 raw 숫자로 읽힌다.
    • 단면, 함수, 특수 section 등이 자기 단위를 함께 가져가야 하는 경우에는 각 명령의 local UnitSystem 또는 그에 해당하는 입력 필드를 사용한다.
    • hfStudio의 File > Import File, File > From Clipboard, Inp Text > Apply도 같은 규칙을 따른다. 자세한 내용은 GUI Guide - File.

    15.2 *Parameter

    파라미터 표현식을 정의한다.

    *Parameter, Name=name, "key=val, ..." [,Default]
    Keyword line

    • parameters: parameter expression. 이중따옴표(")로 둘러싸여야 함.

    • Name=name: 파라미터 표현식 이름

    • "key=value, ...": 파라미터 표현식, ""로 둘러싸여야 함.
    • Default: 지정하는 경우 Default 파라미터 표현식으로 지정 (optional)

    *Parameter 표현식의 이름은 중복하여 지정할 수 없다. 여러개의 *Parameter 문이 있는 경우 Default는 한번만 사용할 수 있다. 또한 *Parameter 문은 최상위 입력파일에서만 사용가능하다(*Include 등으로 포함되는 경우 사용불가).

    파라미터 표현식은 반드시 ""로 둘러싸여야 하며, key=value, ... 형태로, 적용될 경우 key가 value로 치환되게 된다. 이때 key는 다른 문자열과 구분되어야 하기 때문에 <A>, $A$ 등과 같이 일반적으로 잘 사용하지 않는 기호로 둘러싸는 것이 좋다. 예를 들어 예를 들어 "<E>=20E9, <B>=7.3" 와 같이 쓰면 <K>는 20E9로, <B>는 7.3으로 치환하게 된다. 한편 파라미터 표현식 내부에서 토큰은 {}로 묶을 수 있다. 예를 들어 "<K>={R,12.3}, <B>=7.3" 등과 같이 쓰면 <K>는 R,12.3로 치환된다.

    파라미터 표현식 사용에 대한 자세한 사용법은 개요 부분을 참조한다.

    Example
    *Parameter, Name=VM, "<E>=2E9, <nu>=0.18", Default
*Parameter, Name=CM, "<E>=2E9, <nu>=0.18"

*Material, Type=IsoElasticity, Name=myMat
 <E>, <nu>

    15.3 *Distribution

    요소 물성을 지정하거나 해제하거나 기본값으로 되돌린다.

    *Distribution, Type=type[, Remove]
  target, ...
  ...
    Keyword line

    • TYPE=type: 분포 물성 타입(required)

      • Section: 요소 단면 지정 또는 해제
      • BeamCS: 보 요소 ECS 지정 또는 해제
      • BeamEndRelease: 보 요소 end release 지정 또는 해제
      • EmbeddedLineSpline: EmbeddedLine 요소 spline 지정 또는 해제
      • EmbeddedLineHostElset: EmbeddedLine 요소 host elset 지정 또는 해제
      • MCKElementScaleFactor: Spring, EarthSpring, PointMass 요소의 ScaleFactor 지정 또는 기본값 복원
      • MCKElementCS: Spring, EarthSpring, PointMass 요소의 ECS 지정 또는 해제
      • MovingSpringInitialPosition: 이동스프링 초기위치 지정 또는 기본값 복원
      • ShellThickness: projection plane으로 쉘 절점 두께를 유도해 지정

    • Remove: 선택 사항. 지정하면 각 data line에는 target만 적고, 해당 물성을 해제하거나 기본값으로 되돌린다.

    공통 규칙:

    • target에는 요소번호, 요소집합, start:end[:spacing] 형태의 요소번호패턴을 사용할 수 있다. 단, Type=ShellThickness는 절점을 대상으로 하며 target 규칙이 다르다(15.3.9 참조).
    • 한 data line 안에서 target 중복은 허용되지 않는다.
    • 요소번호패턴에 존재하지 않는 요소가 포함되어 있으면 오류 없이 무시된다.
    • 해제나 기본값 복원은 반드시 keyword line의 Remove로 표현한다. 일반 data line에서 마지막 토큰을 생략하는 방식은 더 이상 clear 문법이 아니다.

    15.3.1 *Distribution, Type=Section

    요소의 단면을 지정하거나 해제한다.

    *Distribution, Type=Section
  target1,target2,..., section
  ...

*Distribution, Type=Section, Remove
  target1,target2,...
  ...
    Data lines
    • target1,target2,...: 요소번호, 요소집합, 또는 요소번호패턴(required)
    • section: 단면 이름(Remove가 없을 때 required)

    단면은 *Element에서 바로 지정할 수도 있고, 나중에 *Distribution, Type=Section으로 다시 지정하거나 해제할 수도 있다.

    Example
    *Distribution, Type=Section
 left, section1
 right, middle, section2
 1,2,3,4, section3

*Distribution, Type=Section, Remove
 2:10

    15.3.2 *Distribution, Type=BeamCS

    3차원 보 요소의 ECS(Element Coordinate System)를 지정하거나 해제한다.

    *Distribution, Type=BeamCS
  target1,target2,..., beamcs
  ...

*Distribution, Type=BeamCS, Remove
  target1,target2,...
  ...
    Data lines
    • target1,target2,...: 3차원 보 요소를 가리키는 요소번호, 요소집합, 또는 요소번호패턴(required)
    • beamcs: BeamCS 이름(Remove가 없을 때 required)
    Example
    *CoordinateSystem, Type=BeamCS, Name=beamcs
 90

*Distribution, Type=BeamCS
 1, 2, 3, beamcs
 beamSet, beamcs

*Distribution, Type=BeamCS, Remove
 beamSet2, beamSet3

    15.3.3 *Distribution, Type=BeamEndRelease

    보 요소의 end release를 지정하거나 해제한다.

    *Distribution, Type=BeamEndRelease
  target1,target2,..., releaseCode
  ...

*Distribution, Type=BeamEndRelease, Remove
  target1,target2,...
  ...
    Data lines
    • target1,target2,...: 보 요소를 가리키는 요소번호, 요소집합, 또는 요소번호패턴(required)
    • releaseCode: Rx1, Ry1, Rz1, Rx2, Ry2, Rz2의 조합 (Remove가 없을 때 required). 2차원 보 요소에서는 Rz1, Rz2만 유효
    Example
    *Distribution, Type=BeamEndRelease
 1, 2, 3, Rz1|Rz2
 beamSet, Rx1|Ry1|Rz1

*Distribution, Type=BeamEndRelease, Remove
 1:10

    15.3.4 *Distribution, Type=EmbeddedLineSpline

    EmbeddedLine 요소의 spline을 지정하거나 해제한다.

    *Distribution, Type=EmbeddedLineSpline
  target1,target2,..., spline
  ...

*Distribution, Type=EmbeddedLineSpline, Remove
  target1,target2,...
  ...
    Data lines
    • target1,target2,...: EmbeddedLine 요소를 가리키는 요소번호, 요소집합, 또는 요소번호패턴(required)
    • spline: spline 이름(Remove가 없을 때 required)
    Example
    *Distribution, Type=EmbeddedLineSpline
 1,2,3, curve1
 tendonSet, curve2

*Distribution, Type=EmbeddedLineSpline, Remove
 tendonSet1,tendonSet2

    15.3.5 *Distribution, Type=EmbeddedLineHostElset

    EmbeddedLine 요소의 host elset을 지정하거나 해제한다.

    *Distribution, Type=EmbeddedLineHostElset
  target1,target2,..., hostElset
  ...

*Distribution, Type=EmbeddedLineHostElset, Remove
  target1,target2,...
  ...
    Data lines
    • target1,target2,...: EmbeddedLine 요소를 가리키는 요소번호, 요소집합, 또는 요소번호패턴(required)
    • hostElset: host elset 이름(Remove가 없을 때 required)

    15.3.6 *Distribution, Type=MCKElementScaleFactor

    Spring, EarthSpring, PointMass 요소의 ScaleFactor를 지정하거나 기본값으로 되돌린다.

    *Distribution, Type=MCKElementScaleFactor
  target1,target2,..., sf
  ...

*Distribution, Type=MCKElementScaleFactor, Remove
  target1,target2,...
  ...
    Data lines
    • target1,target2,...: Spring, EarthSpring, PointMass 요소를 가리키는 요소번호, 요소집합, 또는 요소번호패턴(required)
    • sf: scale factor(Remove가 없을 때 required)

    Remove를 쓰면 ScaleFactor는 기본값 1.0으로 돌아간다.

    Example
    *Distribution, Type=MCKElementScaleFactor
 1, 2, 3, 2.5
 wall, 2.5

*Distribution, Type=MCKElementScaleFactor, Remove
 wall

    15.3.7 *Distribution, Type=MCKElementCS

    Spring, EarthSpring, PointMass 요소의 ECS(Element Coordinate System)를 지정하거나 해제한다.

    *Distribution, Type=MCKElementCS
  target1,target2,..., ucs
  ...

*Distribution, Type=MCKElementCS, Remove
  target1,target2,...
  ...
    Data lines
    • target1,target2,...: Spring, EarthSpring, PointMass 요소를 가리키는 요소번호, 요소집합, 또는 요소번호패턴(required)
    • ucs: UCS 이름(Remove가 없을 때 required)
    Example
    *CoordinateSystem, Type=UCS, Name=springCS
 1, 1, 0, 0, 1, 0

*Distribution, Type=MCKElementCS
 1, 2, 3, springCS
 springSet, springCS

*Distribution, Type=MCKElementCS, Remove
 springSet2, springSet3

    15.3.8 *Distribution, Type=MovingSpringInitialPosition

    MovingSpring 요소의 초기위치를 지정하거나 기본값으로 되돌린다.

    *Distribution, Type=MovingSpringInitialPosition
  target1,target2, ..., x, y
  ...

*Distribution, Type=MovingSpringInitialPosition, Remove
  target1,target2, ...
  ...
    Data lines
    • target1,target2,...: MovingSpring 요소를 가리키는 요소번호, 요소집합, 또는 요소번호패턴(required)
    • x, y: 초기위치 값(Remove가 없을 때 required)

    Remove를 쓰면 초기위치는 0,0으로 돌아간다. 보 요소를 대상으로 하는 이동스프링에서는 x 값만 참조한다.

    Example
    *Distribution, Type=MovingSpringInitialPosition
 100, -5, 0.

*Distribution, Type=MovingSpringInitialPosition, Remove
 101:110

    15.3.9 *Distribution, Type=ShellThickness

    projection plane으로 쉘 요소(S3, S3F, S4, S4F)의 절점 두께를 유도해 지정한다.

    *Distribution, Type=ShellThickness
  target1,target2,...
  n1, h1
  n2, h2
  n3, h3
 [n4, h4]

*Distribution, Type=ShellThickness
  target1,target2,...
  x1, y1, z1, h1
  x2, y2, z2, h2
  x3, y3, z3, h3
 [x4, y4, z4, h4]
    Data lines
    • target1,target2,...: 첫 data line. 두께를 적용할 절점번호, 절점번호패턴, 절점집합, 또는 surface(required). 절점번호패턴은 start:end:spacing 형태이고, spacing은 1인 경우 생략가능. Surface를 지정하면 Surface 내의 절점이 대상
    • n, h: 앵커 절점 번호와 그 위치의 두께(required) [L]
    • x, y, z, h: 앵커 위치 좌표 [L]와 그 위치의 두께(required) [L]

    이 타입은 블록 구조다. 다른 *Distribution 타입은 data line 하나가 독립적인 지정이지만, 이 타입은 블록 하나가 projection 한 건이다. 첫 data line이 투영 대상이고, 이후 3~4줄의 앵커가 projection plane과 두께 분포를 정의한다. 각 target 절점 위치에서 평면을 평가한 두께가 절점별 값으로 확정 저장되며, export는 *Nprop, Type=ShellThickness 형식으로만 출력된다.

    • 앵커는 절점 형식(n, h)과 좌표 형식(x, y, z, h) 중 하나로 통일해야 하며, 한 블록에서 혼용할 수 없다.
    • 각 앵커 두께는 0 이상이어야 하고, 계산된 절점 두께가 음수이면 오류다.
    • 앵커가 한 직선 위에 있으면(collinear) 오류다.
    • target 절점의 수선의 발이 앵커가 정의하는 면 영역 안에 있어야 한다. 면 영역 밖이면 오류다. 외삽은 지원하지 않는다.
    • 4개 앵커가 같은 평면 위에 있지 않으면(warped) 4개 앵커를 형상함수로 보간한 bilinear 곡면에 투영한다.
    • 평면이 여러 개 필요하면 블록을 여러 개 쓴다.
    • 이 타입에는 Remove를 쓸 수 없다. 절점 두께의 해제는 *Nprop, Type=ShellThickness, Remove를 사용한다(2.6.1 참조).
    Example
    *Distribution, Type=ShellThickness
 slab
 1, 0.1
 100, 0.2
 105, 0.3

*Distribution, Type=ShellThickness
 1:200:5, wall
 0., 0., 0., 0.1
 10., 0., 0., 0.2
 10., 5., 0., 0.3
 0., 5., 0., 0.4

    15.4 *Model

    미리 정의된 템플릿 모델을 생성

    *Model, Type=type
  ...
    Keyword line

    • Type=type: type of model (required)

      • Block2D: 2차원 솔리드 요소로 직사각형 메쉬를 생성
      • Block3D: 3차원 솔리드 요소로 직육면체 메쉬를 생성
      • Cylinder: 3차원 솔리드 요소로 원통 메쉬를 생성
      • Wall: 쉘 요소로 직사각 메쉬를 생성
      • RectangularTank: 쉘 요소로 직사각 탱크 메쉬를 생성
      • CylindericalTank: 쉘 요소로 원통 탱크 메쉬를 생성

      • FarField2D: SSI 해석을 위한 2차원 메쉬 생성과 자유장해석 수행후 그 결과를 유효하중으로 생성
      • FarField3D: SSI 해석을 위한 3차원 메쉬 생성과 자유장해석 수행후 그 결과를 유효하중으로 생성

    15.4.7 *Model, Type=CurveExtrusion

    스플라인 경로를 따라 2차원 단면 곡선을 Extrusion하여 쉘 요소 메쉬를 생성

    *Model, Type=CurveExtrusion
 name, spline, nseg, startNodeId, startElementId, elementType, section
 x1,y1
 x2,x2
 ...
    First dataline
    • name: 대표 이름. 이 명령을 통해 생성하는 절점집합, 요소집합, 면, 하중 등의 이름의 기초로 사용
    • spline: Extrusion 기준이 되는 스플라인
    • nseg: Extrusion 방향의 생성할 요소 개수
    • startNodeId, startElementId: 시작 절점 및 요소 번호. Auto이면 자동 계산
    • elementType: 적용 요소 타입, S4F와 같은 사각형 쉘요소 타입
    • section: 생성할 요소의 단면(optional, 없으면 요소에 단면을 적용하지 않음)
    Second dataline and subsequent datalines
    • xi, yi: 2차원 단면 상의 좌표

    입력된 2차원 단면 좌표들 (xi, yi)을 순서대로 연결하여 단면 형상을 만든 뒤, 이를 spline 경로를 따라 그대로 이동(Extrusion)시키면서 S4/S4F 쉘 요소로 메쉬를 생성한다. 마지막 단면 점이 첫 번째 점과 동일하면 단면을 폐곡선으로 판단하여, 곡선 경로를 따라 이어지는 원통형 또는 곡면 튜브 형태의 쉘 메쉬가 생성된다.

    각 단면 좌표 (xi, yi)는 스플라인 경로상의 각 지점에서 정의되는 국부 좌표계로 변환되어 3차원 위치를 가지게 된다. 이 국부 좌표계는 스플라인 접선 ex를 기준으로 하여, up 벡터와의 외적을 통해 ey를 만들고, 이어서 ez = ex × ey 를 통해 완전한 직교 좌표계를 형성한다. (ey, ez) 평면이 바로 단면이 배치되는 2차원 좌표계이다. 기본 up 벡터는 (0, 0, 1)이지만, 접선 벡터 ex가 z축과 거의 평행해지는 경우에는 외적이 0이 되는 특이점을 방지하기 위해 up 벡터를 자동으로 (0, 1, 0)으로 전환하여 안정적인 단면 좌표계를 유지한다.

 {bottomNSet} | {EHalf, nuHalf, densityHalf, xiHalf, farMeshSizeY, farMeshCountY}
    First dataline
    • name: 대표 이름. 이 명령을 통해 생성하는 절점집합, 요소집합, 면, 하중 등의 이름의 기초로 사용
    • startNodeId, startElementId: 시작 절점 및 요소 번호. Auto이면 자동 계산
    • outputFormat: 유효하중과 바닥면 운동에 대한 출력 시간이력 파일 포맷. auto, csv, npy 중 하나. csv는 csv로만, npy는 npy로만 출력. auto 이면 생성되는 함수 파일에서 열의 개수가 16,364 이하이면 csv 파일로 그 이상이면 npy 파일로 출력. 디폴트는 auto.
    Second dataline
    • acceleration: 가속도 시각 이력 함수. TimeSeries 함수이어야 하고, 2개의 성분을 가져야 함. 세 성분은 순차적으로 X, Y 방향의 가속도 성분.
    • iz, Direct|Outcrop: 시간이력이 가력되는 지층경계면 번호(1-based)와 입력방식(Direct 이면 iz 위치에 가속도입력이 주어진 것으로 취급하고, Outcrop이면 outcrop motion으로 취급). iz는 ‘(지층개수)+1’까지 지정할 수 있음. 다만 기반면 조건이 강체인 경우(Rigid)이고, Outcrop으로 지정하는 경우에는 (지층개수)까지 지정가능(Outcrop으로 지정하기 위해서는 그 하부에 지층 정보가 있어야 함)
    • rcx: 입사 지진파의 수평 방향 겉보기 속도의 역수. rcx = 1/cx이고, cx=cp/lx=cs/mx 등으로 계산됨. 여기에서 cp, cs는 P파와 S파의 속도, (lx, ly, lz)는 P파, (mx, my, mz)는 S파의 단위 방향 벡터. cx 대신 rcx를 사용한 이유는 수직 입사파인 경우 direct cosine lx, mx가 0이기 때문
    • x0: 입사 지진파의 기준점.
    Third dataline
    • nearMinX, nearMaxX, nearMeshCountX, farMeshSizeX, farMeshCountX: X방향 근역의 범위와 메쉬 개수, 원역 메쉬 크기 및 개수
    Fourth dataline
    • ytop: 지상면의 위치
    • f0: 기준 주파수(Hz). 유효하중 계산시 stiffness-proportional damping으로 근사할 때 적용(단층 지반일 경우 첫 번째 고유진동수는 vs/4H, 다층 지반이면 등가속력 vse=sum(Hi)/sum(Hi/Vsi)를 계산한후 vse/4H에 적용, 감쇠비는 재료감쇠비 5% 적용)
    Fifth dataline and subsequent datalines
    • E1, nu1, density1, xi1, h1, nz1: 지상으로부터 첫 번째 층상 지반의 물성치와 높이
    • E2, nu2, density2, xi2, h2, nz2: 지상으로부터 두 번째 층상 지반의 물성치와 높이 (optional)
    • ...
    • En, nun, densityn, xin, hn, nzn: 지상으로부터 n 번째 층상 지반의 물성치와 높이 (optional)
    Last dataline
    • bottomNset: Rigid 조건인 경우 기초면의 절점집합명
    • EHalf, nuHalf, densityHalf, xiHalf, farMeshSizeY, farMeshCountY: Flexible인 경우 기반암의 물성치 및 y방향 원역의 메쉬 크기 및 개수.

    기반면의 강성 고려 유무에 따라 Rigid 및 Flexible 조건을 부과할 수 있다. 무한영역을 처리하기 위해 SimplePMDL 정식화를 사용하는 CPE4PMDL 요소와 원역 바깥 경계에 점성경계가 설정된다. 절점, 요소 외에 기준이름으로 주어진 name과 bottomNset의 이름을 기준으로 다음을 생성한다.

    • 재료: name-1, name-2, ... (레이어에 대응하는 재료), name-half (half space에 대응하는 재료)
    • 단면: name-1, name-2, ... (레이어에 대응하는 단면), name-half (half space에 대응하는 단면)
    • 요소집합: name (모든 요소), name-1, name-2, ...(레이어에 대응하는 요소), name-half (half space에 대응하는 요소)
    • 표면 : name-Boundary (원역 외곽), name-NNX (X=nearXMin인 근역-원역 경계), name-NPX (X=nearXMax인 근역-원역 경계), name-NBottom (Flexible인 경우 하단부 근역-원역 경계)
    • 구속조건 : name-Boundary (점성경계)
    • 하중 : name-Effective (유효하중), bottomNset-Motion(Rigid한 경우 근역하면 움직임 하중)
    • 함수 : name-Effective (유효하중에 사용되는 시간함수), bottomNset-Motion (Rigid한 경우 근역하면 절점의 움직임에 사용될 시간함수)

    다음은 생성되는 시간이력 파일이다.
