    4.5 Shell

    쉘 구조는 자신의 전장(span)에 비해 두께가 얇은 구조로 정의할 수 있다. 응력 조건 측면에서 볼 때 두께가 얇은 방향으로 응력이 0이며, 쉘 구조의 모델링에는 쉘 요소가 사용되어야 한다. 쉘 유한요소의 종류로는 일반 쉘 요소(conventional shell element)와 연속체 쉘 요소(continumn shell) 등으로 크게 구분된다(Figure 7.1참조). 보통 일반 쉘 요소는 보통 중간면(mid-surface)으로 설정되는 기준면(reference plane)을 기준으로 이산화가 이루지는 쉘 요소를 의미한다. 기준면에 존재하는 절점에서는 3개의 평행이동 자유도와 2개 또는 3개의 회전자유도가 존재할 수 있다. 연속체 쉘의 경우 일반 연속체 요소와 같이 절점 단위에서 평행이동 자유도가 존재하며, 연속체 요소와 동일한 모델링이 가능하므로 경우에 따라서 편리하게 사용할 수 있다.

    Fig. 4.5-1. Shell elements

    요소 타입

    • S3F : 3 node triagular flat shell
    • S4F : 4 node quadlrangle flat shell
    • S3 : 3 node triagular general shell
    • S4 : 4 node quadlrangle general shell
    • CS6 : 6 node triagular continuum shell
    • CS8 : 8 node quadlrangle continuum shell

    요소 단면

    • Shell : 균일 단면 또는 일반 적층 쉘 단면을 정의
    • CompositePlate : S3F/S4F용 라미네이트 복합재 평판 쉘 단면을 정의

    요소 개별 물성치(Distribution)

    • NodalThickness : 변단면 요소에서 각 절점에 두께를 지정

    일반 쉘 요소는 flat shell 요소(S3F, S4F)와 general shell 요소(S3, S4)로 구분된다. Flat shell은 편평하다고 가정한다. 따라서 요소의 두께 방향 벡터가 일정하기 때문에 요소의 ECS가 정의된다. 요소 정식화 과정에서 단면력-단면변형 관계를 구성방정식으로 사용한다. General shell 요소는 절점에 두께 방향 벡터인 디렉터 벡터를 지정이 가능한 곡면까지 모델링이 가능하며, 응력-변형률 관계를 구성방정식으로 사용한다. 정식화 과정에서 연속체 요소를 기준면으로 축약하는 방식을 적용하기 때문에 degenerated shell로도 불린다. General shell 요소는 곡면이므로 재료점에서 서로 다른 국부좌표계(LCS)가 정의된다. 편평한 조건에 적용할 경우 flat shell과 동일한 결과를 유도한다.

    일반 쉘 요소는 모두 전단잠금(shear locking)을 제거하기 위해 MITC 기법에 의한 AS(Assumed Strain)법을 적용한다. 두께 뱡향의 적분은 Lobatto, Legendre, Newon-Cotes 등 3가지 방식을 지원한다. 디폴트로 Lobatto는 선형재료 3점, 비선형재료 4점을, Legendre는 선형재료 2점, 비선형재료 3점을, Newton-Cotes는 선형재료 3점, 비선형재료 5점을 사용한다.

    Fig. 4.5-2. S4F, S3F의 요소좌표계

    Fig. 4.5-3. S4, S3의 국부좌표계

    Conventional shell 요소는 절점당 5자유도를 인접요소가 3개의 회전자유도를 갖거나 회전자유도에 대한 구속조건이나 하중조건이 부과된 경우, 또는 인접한 쉘 요소과 절점의 법선 벡터가 다른 경우 자동으로 6자유도로 변경된다.

    Fig. 4.5-4. S3, S4, S3F, S4F의 ⅚ 자유도 처리

    솔리드 쉘요소는 일반 솔리드 요소와 동일하게 모델링이 가능한 쉘 요소이다. 절점당 3개의 자유도를 가진다. AS법 뿐만아니라 EAS(Enhanced Assumed Strain)을 적용하여 다양한 잠김을 제거하였다. 한편 재료모델은 3차원 재료 모델을 적용하였다. 따라서 임의 방향 또는 필요한 방향으로 직교좌표계를 국부좌표계로 선택하면 된다. 하지만 일반 쉘요소와 일관성을 유지하기 위해 두께방향을 국부좌표계의 z 방향이 되도록 설정하였다. 두께 뱡향의 적분은 general shell 요소와 같다. Lobatto, Legendre, Newon-Cotes 등 3가지 방식을 지원하며 디폴트로 Lobatto는 선형재료 3점, 비선형재료 4점을, Legendre는 선형재료 2점, 비선형재료 3점을, Newton-Cotes는 선형재료 3점, 비선형재료 5점을 사용한다.

    Fig. 4.5-5. SC8, SC6의 국부좌표계

    쉘 요소는 평면내에서 그림처럼 4점 또는 3점의 적분점에서 그 결과를 출력할 수 있다. S3F, S4F는 중립면에서의 단면력, 단면변형을 제공하지만, S3, S4, CS6, CS8은 두께방향으로 최하, 최상의 적분점에서의 응력, 변형률 등을 출력한다. 단면력은 적분을 통해 중립면을 기준으로 계산되어 제공된다.

    Fig. 4.5-6. 4절점, 3절점 쉘요소의 적분점

    Fig. 4.5-7. Shell 요소의 단면력 정의점

*Section, Type=Shell,Name=sec
 mat, 0.01     # h

*Element, Type=S4F

    4.5.7 *Section, Type=Shell

    균질 쉘 단면 또는 일반 적층 쉘 단면을 정의한다. 재료 data line이 하나이면 균질 쉘 단면이고, 두 줄 이상이면 layered shell 단면이다. Layered shell 단면은 S3, S4, S3F, S4F, CS6, CS8에서 사용할 수 있다.

    균질 단면:

    *Section, Type=Shell, Name=name[, Offset=offset][, Mass=Consistent|Lumped][, Thickness=Uniform|Nodal]
 material, h[, integration[, ngauss]]
 material, h, NSLayer

    Layered 단면:

    *Section, Type=Shell, Name=name[, Offset=offset][, Mass=Consistent|Lumped][, Thickness=Uniform|Nodal]
 material1, h1[, integration[, ngauss]]
 material2, h2
 ...
 material, h, NSLayer
    Keyword line
    • Name=name: 단면 이름(required). 단면 이름은 중복될 수 없다.
    • Offset=offset: 절점으로 정의되는 reference surface와 쉘 midsurface 사이의 거리. structural 단면 두께에 대한 비율로 입력하며, layered 단면에서는 structural layer 전체 두께에 대한 비율이다. +0.5이면 reference surface가 structural top surface에, -0.5이면 structural bottom surface에 놓인다. NSLayer가 있더라도 이 두께에는 포함하지 않으며, 절점으로 정의되는 reference surface를 이동시키지 않는다. ContinuumShell에는 사용하지 않는다.
    • Mass=Consistent|Lumped: consistent mass 또는 lumped mass를 지정한다. (Optional, default: Consistent)
    • Thickness=Uniform|Nodal: *Nprop, Type=ShellThickness 사용 여부를 지정한다. Nodal이면 절점 두께가 있을 때 절점 두께를 사용한다. Uniform이면 절점 두께를 무시하고 section data line의 두께를 사용한다. (Optional, default: Nodal)
    Data lines
    • material: 재료 이름(required).
    • h: 두께(required) [L]. Thickness=Nodal이고 *Nprop, Type=ShellThickness가 지정되면 절점 두께가 structural 단면 전체 두께가 된다. layered 단면에서는 각 structural layer 두께가 같은 비율로 스케일링되어 structural 전체 두께가 절점 두께와 같아진다.
    • integration: 두께방향 공통 적분 방법. Lobatto, Legendre, NewtonCotes 중 하나이다. layered shell 입력에서는 첫 번째 material data line에만 지정한다. (Optional, default: Lobatto)
    • ngauss: 두께방향 공통 적분점 개수. 지정하지 않으면 Lobatto는 선형재료 3점, 비선형재료 4점, Legendre는 선형재료 2점, 비선형재료 3점, NewtonCotes는 선형재료 3점, 비선형재료 5점을 기본값으로 사용한다. layered shell 단면에서 명시적으로 지정하는 경우 2 이상이어야 한다.
    • material, h, NSLayer: 선택 사항. 구조 layer 또는 균질 단면 위쪽에 붙는 non-structural layer를 정의한다. 이 data line은 있으면 반드시 마지막 data line이어야 하며 NSLayer 표식은 하나만 허용한다. material은 density가 양수인 기존 재료여야 하고, h는 양수 두께 [L]여야 한다. NSLayer는 질량과 gravity/self-weight 하중에만 기여하며 강성이나 내력에는 기여하지 않는다. NSLayer는 structural layer 수와 LayerId, 재료장 출력 대상에 포함되지 않는다. 또한 절점 좌표, reference surface, structural bottom/top surface 위치를 바꾸지 않으며, 이 위치들은 structural shell stack만 기준으로 정한다.

    재료 data line이 두 줄 이상이면 각 줄은 하나의 layer를 정의하고, LayerId는 입력 순서대로 1부터 부여된다. 첫 번째 data line의 integration[, ngauss]는 단면 전체의 공통 두께방향 적분 옵션이며, 각 layer 두께 구간에 동일하게 적용된다.

    균질 쉘 단면에서 재료점 응답은 ngauss가 1이면 중앙점, 2 이상이면 두께방향 적분점에 정의된다.

    Layered shell 단면에서는 두께방향 적분점 개수가 2 이상이어야 한다. 두께방향 적분은 homogeneous shell과 동일한 적분룰을 각 layer 두께 구간에 독립적으로 적용한다. 응력, 변형률 등 재료장 출력은 각 layer의 최하/최상 두께방향 적분점만 노출한다. Legendre처럼 끝점을 포함하지 않는 적분룰에서는 이 점들이 물리적 layer 표면이 아니라 해당 layer 내부의 가장 아래/위 적분점이다.

    CS6/CS8 layered shell은 기본 해석, 질량, 중력하중, 재료장 출력, embedded constraint, point/line sensor를 지원한다. point/line sensor는 각 layer의 두께방향 적분을 반영한 방향 변형률 행렬을 사용하고, embedded constraint는 같은 field-matrix 경로에서 계산된 변위 보간 행렬을 사용한다.

    NSLayer 검증 예제는 S3, S3F, S4, S4F, CS6, CS8에 대한 Example/V.4 Shell Element/*-SSPlate40x14-NSLayerVV.inp 파일들을 참조한다. 이 예제들은 non-structural layer가 구조 강성에는 기여하지 않아 점하중 응답이 대응되는 structural layered shell과 같고, 질량 추가로 고유진동수가 낮아지며, 자중 응답에서 Scope=All이 Scope=Structural과 Scope=NonStructural 응답의 합과 같음을 확인한다.

    Example
    *MATERIAL, Type=IsoElasticity Name=matDeck
 25.000e9, 0.18, 0, 2500.

    4.5.8 *Section, Type=CompositePlate

    평판 쉘 요소용 laminated composite plate 단면을 정의한다. 이 단면은 S3F, S4F에만 적용할 수 있다. 각 ply 재료는 laminar shell response를 지원하는 탄성재료여야 한다.

    *Section, Type=CompositePlate, Name=name[, Offset=offset][, Mass=Consistent|Lumped][, Thickness=Uniform|Nodal]
 material1, h1[, angle1[, auto|standard]]
 material2, h2[, angle2]
 ...
 material, h, NSLayer
    Keyword line
    • Name=name: 단면 이름(required). 단면 이름은 중복될 수 없다.
    • Offset=offset: structural ply stack의 midsurface와 reference surface 사이의 거리. structural ply 전체 두께에 대한 비율로 입력한다. NSLayer가 있더라도 이 두께에는 포함하지 않으며, 절점으로 정의되는 reference surface를 이동시키지 않는다.
    • Mass=Consistent|Lumped: consistent mass 또는 lumped mass를 지정한다. (Optional, default: Consistent)
    • Thickness=Uniform|Nodal: *Nprop, Type=ShellThickness 사용 여부를 지정한다. Nodal이면 절점 두께가 있을 때 절점 두께를 사용한다. Uniform이면 절점 두께를 무시하고 ply 두께 합을 사용한다. (Optional, default: Nodal)
    Data lines
    • material: laminar shell response를 지원하는 탄성재료 이름(required).
    • h: ply 두께(required) [L]. Thickness=Nodal이면 각 structural ply 두께가 같은 비율로 스케일링되어 structural 전체 두께가 절점 두께와 같아진다.
    • angle: ply 각도(optional, default 0.). 재료의 optional cs가 있으면 먼저 cs의 1축을 shell local plane에 투영해 기준축을 만들고, 그 기준축을 shell normal 주위로 angle만큼 회전한다. cs가 없으면 shell local 1축을 기준으로 angle을 적용한다. 이 회전 순서는 강성 및 열팽창 성분에 동일하게 적용된다.
    • auto|standard: 단면 전체의 횡전단 보정 모드. auto는 횡전단 보정을 자동 계산하고, standard는 표준 전단 보정계수를 사용한다. 이 옵션은 첫 번째 data line에만 올 수 있다. (Optional, default: auto)
    • material, h, NSLayer: 선택 사항. 구조 ply stack 위쪽에 붙는 non-structural layer를 정의한다. 이 data line은 있으면 반드시 마지막 data line이어야 하며 NSLayer 표식은 하나만 허용한다. material은 density가 양수인 기존 재료이면 되고, structural ply처럼 laminar shell response를 지원할 필요는 없다. h는 양수 두께 [L]여야 한다. NSLayer는 질량과 gravity/self-weight 하중에만 기여하며 강성이나 내력에는 기여하지 않는다. NSLayer는 ply 수와 LayerId, 재료장 출력 대상에 포함되지 않는다. 또한 절점 좌표, reference surface, structural bottom/top surface 위치를 바꾸지 않으며, 이 위치들은 structural ply stack만 기준으로 정한다.

    CompositePlate는 층별 두께방향 수치적분을 수행하는 일반 layered shell이 아니다. 각 ply/lamina는 중앙 평가점에서 한 번 laminar response로 평가되며, 응력과 변형률 같은 재료장 출력도 각 LayerId에 대해 이 중앙 평가점 1개에서 제공된다.
