    3.5 hf2DStudio 원격 제어 Geometry

    3.5.1 Geometry

    hf2DStudio --remote [--target <id>] draw-point <yp,zp>
hf2DStudio --remote [--target <id>] draw-lines <yp,zp|P<point-id>> <yp,zp|P<point-id>> [<yp,zp|P<point-id>> ...]
hf2DStudio --remote [--target <id>] draw-arc <yp,zp> <yp,zp> <yp,zp>
hf2DStudio --remote [--target <id>] draw-bezier2 <yp,zp> <yp,zp> <yp,zp>
hf2DStudio --remote [--target <id>] draw-bezier3 <yp,zp> <yp,zp> <yp,zp> <yp,zp>
hf2DStudio --remote [--target <id>] draw-rbezier2 <yp,zp> <yp,zp> <yp,zp> --weights <w1>
hf2DStudio --remote [--target <id>] draw-rbezier3 <yp,zp> <yp,zp> <yp,zp> <yp,zp> --weights <w1,w2>
hf2DStudio --remote [--target <id>] draw-spline <yp,zp> <yp,zp> <yp,zp> [<yp,zp> ...]
hf2DStudio --remote [--target <id>] generate-circle <radius> <yp> <zp>
hf2DStudio --remote [--target <id>] generate-circular-points <radius> <yp> <zp> <start-angle-deg> <count>
hf2DStudio --remote [--target <id>] set-seed --curve-ids <id,id,...> --seed <integer>
hf2DStudio --remote [--target <id>] auto-seed --curve-ids <id,id,...>
hf2DStudio --remote [--target <id>] make-face --material <name> --curve-ids <id,id,...>
hf2DStudio --remote [--target <id>] make-rebar --material <name> --point-ids <id,id,...> --diameter <value> [--diameter-right <value>]
hf2DStudio --remote [--target <id>] move-point <point-id> <yp,zp> [--merge <on|off>]
hf2DStudio --remote [--target <id>] delete-point <id,id,...>
hf2DStudio --remote [--target <id>] delete-curve <id,id,...>
hf2DStudio --remote [--target <id>] delete-face <id,id,...>
hf2DStudio --remote [--target <id>] delete-rebar <id,id,...>
hf2DStudio --remote [--target <id>] select <point|curve|face|rebar> <id,id,...> [--mode <replace|add|remove|toggle>]
hf2DStudio --remote [--target <id>] delete-selection
hf2DStudio --remote [--target <id>] merge-selected-points
hf2DStudio --remote [--target <id>] detach-selected-points
    • Geometry 작성 명령은 편집 가능한 geometry section이 있어야 한다.
    • 이미 mesh가 있으면 먼저 make-mesh delete를 실행하기 전까지 geometry 작성 명령을 사용할 수 없다.
    • 좌표 인자는 yp,zp 형식을 사용한다.
    • 필요하면 좌표 토큰을 따옴표로 감싼다. 특히 "-25,10"처럼 음수로 시작하는 경우는 따옴표 사용을 권장한다.
    • 좌표 기반 draw 명령은 start-section geometry를 기준으로 좌표를 해석한다.
    • draw-lines에서 좌표 토큰 <yp,zp>은 별도 point를 생성하고, P<point-id>는 기존 point에 연결한다.
    • 요청 좌표와 일치하는 기존 point가 있더라도, 좌표 토큰은 각 좌표마다 새 point를 생성한다.
    • 새 point는 start/end 좌표를 동일하게 생성하므로, taper section에서도 초기 geometry는 양쪽이 같은 상태로 시작한다.
    • move-point는 기존 point id 하나를 대상으로 하며, 연결된 모든 curve를 함께 갱신한다.
    • 직접 삭제 명령은 실제로 삭제된 id를 기록하므로, GUI Delete 재생이 이전 선택 상태 복원에 의존하지 않는다.
    • select는 geometry 자체를 바꾸지 않으므로 mesh 삭제 없이 사용할 수 있다.
    • delete-selection은 선택된 개체를 실제로 제거하므로 편집 가능한 geometry가 필요하다.
    • move-point --merge on은 이동한 point를 기존 topology에 명시적으로 연결하는 원격 제어 경로다.
    • merge-selected-points는 현재 선택된 point 중 이미 같은 좌표에 있는 point만 명시적으로 병합한다.
    • detach-selected-points는 선택된 공유 point를 분리 복제하지만, 기존 face 또는 rebar가 참조하는 point는 차단하고 그대로 둔다.

    3.5.1.1 Draw Point

    구문:

    hf2DStudio --remote [--target <id>] draw-point <yp,zp>

    인자와 동작:

    • <yp,zp>는 하나의 geometry point 좌표쌍이다.
    • 이 명령은 정확히 한 개의 point만 생성한다.
    • 같은 좌표에 다른 point가 이미 있어도 새 point를 생성한다.
    • 이 명령만으로 curve, face, rebar는 생성되지 않는다.

    예시:

    hf2DStudio --remote draw-point "0,0"

    3.5.1.2 Draw Lines

    구문:

    hf2DStudio --remote [--target <id>] draw-lines <yp,zp|P<point-id>> <yp,zp|P<point-id>> [<yp,zp|P<point-id>> ...]

    인자와 동작:

    • point 토큰을 최소 두 개 이상 전달해야 한다.
    • 좌표 토큰 <yp,zp>은 별도 point를 생성한다.
    • point 참조 토큰 P<point-id>는 기존 point를 재사용하고 새 line segment를 해당 topology에 연결한다.
    • 인접한 두 점마다 하나의 line segment가 생성된다.
    • 점 두 개면 line 1개, 점 세 개면 연결된 line 2개가 생성된다.
    • 연속한 두 점이 완전히 같으면 실패한다.
    • 연속하지 않은 반복 좌표는 허용되므로, polyline이 이전 점으로 되돌아갈 수 있다.
    • 좌표와 일치하는 기존 point는 재사용하지 않고, 각 좌표 토큰마다 새 point를 생성한다.
    • GUI Remote History는 그리기 중 connect to existing point를 선택한 점은 P<point-id>로, create separate point를 선택한 점은 좌표로 기록한다.

    예시:

    hf2DStudio --remote draw-lines "0,0" "300,0" "300,120"
hf2DStudio --remote draw-lines P1 "300,0" P2

    3.5.1.3 Draw Arc

    구문:

    hf2DStudio --remote [--target <id>] draw-arc <yp,zp> <yp,zp> <yp,zp>

    인자와 동작:

    • 정확히 세 점을 전달해야 한다.
    • 세 점은 모두 서로 달라야 한다.
    • 세 점은 서로 일직선 위에 있으면 안 된다.
    • 이 명령은 시작점, 중간점, 끝점을 사용하는 2차원 arc 1개를 생성한다.
    • curve seed는 현재 section model의 기본 curve seed로 초기화된다.
    • 일치하는 기존 point는 재사용하지 않고, 각 좌표마다 새 point를 생성한다.

    예시:

    hf2DStudio --remote draw-arc "0,0" "150,80" "300,0"

    3.5.1.4 Draw Bezier2

    구문:

    hf2DStudio --remote [--target <id>] draw-bezier2 <yp,zp> <yp,zp> <yp,zp>

    인자와 동작:

    • 제어점 세 개를 정확히 전달해야 한다.
    • 세 점은 모두 서로 달라야 한다.
    • 이 명령은 순수 2차 bezier curve 1개를 생성한다.
    • 내부 가중치는 w1 = 1.0으로 기록된다.
    • curve seed는 현재 section model의 기본 curve seed로 초기화된다.
    • 일치하는 기존 point는 재사용하지 않고, 각 좌표마다 새 point를 생성한다.

    예시:

    hf2DStudio --remote draw-bezier2 "0,0" "150,80" "300,0"

    3.5.1.5 Draw Bezier3

    구문:

    hf2DStudio --remote [--target <id>] draw-bezier3 <yp,zp> <yp,zp> <yp,zp> <yp,zp>

    인자와 동작:

    • 제어점 네 개를 정확히 전달해야 한다.
    • 네 점은 모두 서로 달라야 한다.
    • 이 명령은 3차 bezier curve 1개를 생성한다.
    • 내부 가중치는 w1 = 1.0, w2 = 1.0으로 기록된다.
    • curve seed는 현재 section model의 기본 curve seed로 초기화된다.
    • 일치하는 기존 point는 재사용하지 않고, 각 좌표마다 새 point를 생성한다.

    예시:

    hf2DStudio --remote draw-bezier3 "0,0" "100,90" "220,90" "320,0"

    3.5.1.6 Draw Rational Bezier2

    구문:

    hf2DStudio --remote [--target <id>] draw-rbezier2 <yp,zp> <yp,zp> <yp,zp> --weights <w1>

    인자와 동작:

    • 제어점 세 개와 내부 가중치 하나를 정확히 전달해야 한다.
    • 세 점은 모두 서로 달라야 한다.
    • 이 명령은 rational 2차 bezier curve 1개를 생성한다.
    • --weights <w1>은 내부 제어점의 가중치를 지정한다.
    • curve seed는 현재 section model의 기본 curve seed로 초기화된다.
    • 일치하는 기존 point는 재사용하지 않고, 각 좌표마다 새 point를 생성한다.

    예시:

    hf2DStudio --remote draw-rbezier2 "0,0" "150,80" "300,0" --weights "0.70710678"

    3.5.1.7 Draw Rational Bezier3

    구문:

    hf2DStudio --remote [--target <id>] draw-rbezier3 <yp,zp> <yp,zp> <yp,zp> <yp,zp> --weights <w1,w2>

    인자와 동작:

    • 제어점 네 개와 내부 가중치 두 개를 정확히 전달해야 한다.
    • 네 점은 모두 서로 달라야 한다.
    • 이 명령은 rational 3차 bezier curve 1개를 생성한다.
    • --weights <w1,w2>는 두 내부 제어점의 가중치를 지정한다.
    • curve seed는 현재 section model의 기본 curve seed로 초기화된다.
    • 일치하는 기존 point는 재사용하지 않고, 각 좌표마다 새 point를 생성한다.

    예시:

    hf2DStudio --remote draw-rbezier3 "0,0" "100,90" "220,90" "320,0" --weights "0.85,0.85"

    3.5.1.8 Draw Spline

    구문:

    hf2DStudio --remote [--target <id>] draw-spline <yp,zp> <yp,zp> <yp,zp> [<yp,zp> ...]

    인자와 동작:

    • 제어점은 최소 세 개 이상 전달해야 한다.
    • 이 명령은 전달한 점들을 지나는 spline curve 1개를 생성한다.
    • 반복 좌표는 기본적으로 허용되지 않으며, 아래 한 가지 닫힘 경우만 예외이다.
    • 마지막 점이 첫 번째 점과 같으면 closed spline으로 생성된다.
    • curve seed는 현재 section model의 기본 curve seed로 초기화된다.
    • 일치하는 기존 point는 재사용하고, 없는 point는 자동으로 생성한다.

    예시:

    hf2DStudio --remote draw-spline "0,0" "120,80" "240,40" "240,-40" "0,0"

    3.5.1.9 Move Point

    구문:

    hf2DStudio --remote [--target <id>] move-point <point-id> <yp,zp> [--merge <on|off>]

    인자와 동작:

    • <point-id>는 기존 geometry point id 하나이다.
    • <yp,zp>는 해당 point의 목적 좌표쌍이다.
    • 이 명령은 point를 이동한 뒤, 연결된 모든 curve를 함께 갱신한다.
    • 기본 동작은 병합하지 않는 것이다.
    • --merge on이면 이동한 point id를 유지하면서 목적지의 중복 point를 그 id로 병합한다.
    • --merge off이면 목적지에 다른 point가 이미 있어도 그 point는 건드리지 않고 좌표만 이동한다.
    • 목적지 좌표가 현재 좌표와 같으면 no-op으로 성공한다.

    예시:

    hf2DStudio --remote move-point 12 "250,100" --merge off

    3.5.1.10 Make Face

    구문:

    hf2DStudio --remote [--target <id>] make-face --material <name> --curve-ids <id,id,...>

    인자와 동작:

    • --material <name>은 기존 section material 하나를 지정한다.
    • --curve-ids <id,id,...>는 비어 있지 않은 쉼표 구분 curve id 목록이다.
    • 요청한 curve들이 이미 hole loop까지 포함한 정확한 face 하나를 이루면, 그 face를 그대로 생성한다.
    • 그렇지 않으면 요청한 curve들에서 bounded cell을 해석하고, 새로 판별된 cell마다 face를 하나씩 생성한다.
    • shared boundary curve는 인접한 cell을 서로 다른 face로 분리하는 경계로 유지한다.
    • 어떤 cell도 만들지 못하는 extra curve는 무시한다.
    • 같은 resolved curve 집합으로 이미 존재하는 face는 건너뛴다.
    • 요청한 curve들로부터 새 face를 하나도 해석하지 못할 때만 명령이 실패한다.
    • 성공 JSON에는 항상 faceIds가 들어가고, 정확히 한 개 face만 생성되면 faceId도 함께 들어간다.

    예시:

    hf2DStudio --remote make-face --material CONC --curve-ids "1,2,3,4"

    3.5.1.11 Delete Point

    구문:

    hf2DStudio --remote [--target <id>] delete-point <id,id,...>

    인자와 동작:

    • <id,id,...>는 쉼표로 구분한 point id 목록이다.
    • point는 남아 있는 curve 또는 rebar가 참조하지 않을 때만 삭제된다.
    • 안전하게 지울 수 있는 id는 삭제되고, 막힌 id는 JSON 결과의 blockedIds로 보고된다.

    예시:

    hf2DStudio --remote delete-point "8,12"

    3.5.1.12 Delete Curve

    구문:

    hf2DStudio --remote [--target <id>] delete-curve <id,id,...>

    인자와 동작:

    • <id,id,...>는 쉼표로 구분한 curve id 목록이다.
    • curve는 남아 있는 face가 참조하지 않을 때만 삭제된다.
    • 안전하게 지울 수 있는 id는 삭제되고, 막힌 id는 JSON 결과의 blockedIds로 보고된다.

    예시:

    hf2DStudio --remote delete-curve "3,7"

    3.5.1.13 Delete Face

    구문:

    hf2DStudio --remote [--target <id>] delete-face <id,id,...>

    인자와 동작:

    • <id,id,...>는 쉼표로 구분한 face id 목록이다.
    • 요청한 face id는 직접 삭제된다.

    예시:

    hf2DStudio --remote delete-face "4,5"

    3.5.1.14 Delete Rebar

    구문:

    hf2DStudio --remote [--target <id>] delete-rebar <id,id,...>

    인자와 동작:

    • <id,id,...>는 쉼표로 구분한 rebar id 목록이다.
    • 요청한 rebar id는 직접 삭제된다.

    예시:

    hf2DStudio --remote delete-rebar "2,9"

    3.5.1.15 Select

    구문:

    hf2DStudio --remote [--target <id>] select <point|curve|face|rebar> <id,id,...> [--mode <replace|add|remove|toggle>]

    인자와 동작:

    • <point|curve|face|rebar>는 선택할 geometry 개체 종류이다.
    • <id,id,...>는 양의 정수 id를 쉼표로 나열한 목록이다.
    • --mode replace는 요청한 id 집합으로 선택을 다시 구성한다.
    • --mode add, remove, toggle은 현재 선택 상태를 기준으로 갱신한다.
    • 이 명령은 선택만 변경하며 geometry를 생성하거나 삭제하지 않는다.

    예시:

    hf2DStudio --remote select curve "3,7,9" --mode add

    3.5.1.16 Delete Selection

    구문:

    hf2DStudio --remote [--target <id>] delete-selection

    인자와 동작:

    • 현재 활성 section에서 선택된 삭제 가능한 개체를 제거한다.
    • 선택된 face와 rebar는 즉시 삭제된다.
    • face가 참조하는 curve는 삭제되지 않고 선택 상태로 남는다.
    • curve 또는 rebar가 참조하는 point는 삭제되지 않고 선택 상태로 남는다.
    • 삭제 가능한 선택이 없으면 no-op으로 성공한다.

    예시:

    hf2DStudio --remote select face "4"
hf2DStudio --remote delete-selection

    3.5.1.17 Merge Selected Points

    구문:

    hf2DStudio --remote [--target <id>] merge-selected-points

    인자와 동작:

    • 위치 인자는 없다.
    • 활성 section에서 현재 선택된 point 집합을 검사한다.
    • 이미 같은 좌표를 공유하는 선택 point를 좌표 그룹별로 하나의 topology point로 병합한다.
    • 살아남는 point는 기존 id를 유지하고, 제거된 duplicate id는 result JSON에 기록된다.
    • 이 명령은 topology를 명시적으로 바꾸는 명령이다. 한 point를 다른 위치로 이동시키며 연결하려면 move-point --merge on을 사용한다.

    예시:

    hf2DStudio --remote select point "12,18"
hf2DStudio --remote merge-selected-points

    3.5.1.18 Detach Selected Points

    구문:

    hf2DStudio --remote [--target <id>] detach-selected-points

    인자와 동작:

    • 위치 인자는 없다.
    • 활성 section에서 현재 선택된 point 집합을 검사한다.
    • 여러 curve가 공유하는 선택 point를 분리해서, 연결된 curve들이 더 이상 하나의 topology point를 공유하지 않도록 같은 좌표의 새 point로 복제한다.
    • 새로 생성된 duplicate point id는 result JSON에 기록된다.
    • 기존 face 또는 rebar가 여전히 참조하는 point는 차단되고 변경되지 않는다.

    예시:

    hf2DStudio --remote select point "21"
hf2DStudio --remote detach-selected-points

    3.5.1.19 Set Seed

    구문:

    hf2DStudio --remote [--target <id>] set-seed --curve-ids <id,id,...> --seed <integer>

    인자와 동작:

    • --curve-ids <id,id,...>는 쉼표로 구분한 curve id 목록이다.
    • --seed <integer>는 요청한 모든 curve에 같은 seed 개수를 직접 지정한다.
    • seed 값은 양의 정수여야 한다.
    • line은 1 이상을 허용하고, arc, bezier, spline은 필요하면 내부 최소 seed로 보정된다.
    • 이 명령은 편집 가능한 geometry가 필요하며, 요청한 curve id 중 하나라도 없으면 실패한다.
    • 이 명령은 수동 seed 지정만 수행하며, auto-seed의 TFI interval correction은 실행하지 않는다.

    예시:

    hf2DStudio --remote set-seed --curve-ids "2" --seed 3

    3.5.1.20 Auto Seed

    구문:

    hf2DStudio --remote [--target <id>] auto-seed --curve-ids <id,id,...>

    인자와 동작:

    • --curve-ids <id,id,...>는 쉼표로 구분한 curve id 목록이다.
    • --seed 옵션과 함께 쓸 수 없다.
    • 요청한 curve들의 max-H 값 중 가장 작은 값을 기준으로 rough seed 개수를 일괄 재계산한다.
    • rough pass 이후, hole이 없는 단일 outer-loop face 중 outer loop의 모든 curve가 이번 --curve-ids에 포함된 face에 대해 보수적인 TFI interval correction을 시도한다.
    • correction은 부족한 side의 curve seed를 늘리는 방향으로만 수행한다. face 단위 budget은 min(4, max(1, ceil(totalSideIntervals * 0.20)))이고, 보정량이 크거나 후보가 애매하면 rough seed만 유지한다.
    • face에 Quad Mesh Corner Hints가 있으면 hint plan을 자동 corner 후보보다 우선한다.
    • 이 명령은 편집 가능한 geometry가 필요하며, 요청한 curve id 중 하나라도 없으면 실패한다.
    • GUI의 Auto Seed 버튼과 동일한 계산 결과를 만든다.
    • 성공 응답의 intervalCorrections 값은 추가로 증가시킨 저장 seed 개수이다.

    예시:

    hf2DStudio --remote auto-seed --curve-ids "1,2,3,4"

    3.5.1.21 Generate Circle

    구문:

    hf2DStudio --remote [--target <id>] generate-circle <radius> <yp> <zp>

    인자와 동작:

    • <radius>는 양의 finite number이다.
    • <yp>, <zp>는 원 중심의 section 좌표이다.
    • 이 명령은 4개의 rational quadratic bezier segment로 이루어진 닫힌 circle을 생성한다.
    • 각 segment의 seed는 현재 section model의 기본 curve seed로 초기화된다.
    • 이 명령은 편집 가능한 geometry가 필요하다.

    예시:

    hf2DStudio --remote generate-circle 50 0 0

    3.5.1.22 Generate Circular Points

    구문:

    hf2DStudio --remote [--target <id>] generate-circular-points <radius> <yp> <zp> <start-angle-deg> <count>

    인자와 동작:

    • <radius>는 양의 finite number이다.
    • <yp>, <zp>는 원 중심의 section 좌표이다.
    • <start-angle-deg>는 첫 번째 점의 각도이며, 양수 방향은 +y 축에서 +z 축으로 회전하는 쪽이다.
    • <count>는 생성할 점 개수이며, 양의 정수여야 한다.
    • 이 명령은 반지름이 <radius>인 원 위에 <count>개의 점을 균등 간격으로 찍는다.
    • curve는 생성하지 않으며, 점만 만든다. rebar group 구성 등에 직접 사용할 수 있다.
    • 이 명령은 편집 가능한 geometry가 필요하다.

    예시:

    hf2DStudio --remote generate-circular-points 60 0 0 0 8
