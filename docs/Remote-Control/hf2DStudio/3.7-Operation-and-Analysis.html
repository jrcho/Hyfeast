    3.7 hf2DStudio 원격 제어 Operation 및 Analysis

    3.7.1 Operation

    hf2DStudio --remote [--target <id>] make-mesh [build|delete|toggle]
hf2DStudio --remote [--target <id>] make-mesh --mode <build|delete|toggle>
hf2DStudio --remote [--target <id>] compute-section-constants [compute|invalidate|toggle]
hf2DStudio --remote [--target <id>] compute-section-constants --mode <compute|invalidate|toggle>
hf2DStudio --remote [--target <id>] renumber
hf2DStudio --remote [--target <id>] move <top-left|top-middle|top-right|middle-left|middle-middle|middle-right|bottom-left|bottom-middle|bottom-right|centroid|shear-center|offset> [--offset <yp,zp>]
hf2DStudio --remote [--target <id>] rotate <angle-deg>
hf2DStudio --remote [--target <id>] export-section [--name <name>]
hf2DStudio --remote [--target <id>] export-guide-geometry [--side <left|right>] [--ref-cs <name>] [--name <name>]
hf2DStudio --remote [--target <id>] export-curve-mesh [--side <left|right>] [--node-id-offset <id>] [--element-id-offset <id>] [--ref-cs <name>]
hf2DStudio --remote [--target <id>] export-domain-mesh [--side <left|right>] [--node-id-offset <id>] [--element-id-offset <id>] [--ref-cs <name>]
    • move offset는 --offset <yp,zp>가 필요하다.
    • make-mesh build는 mesh를 만들고 section constants를 함께 계산한다.
    • 모든 export 명령은 결과 텍스트를 클립보드에 복사하고, 같은 텍스트를 result JSON payload로도 반환한다.
    • section model에 global *Environment, TYPE=UnitSystem이 정의되어 있으면, 모든 export 텍스트는 그 UnitSystem 블록을 맨 앞에 함께 기록한다.

    3.7.1.1 export-section

    • 현재 단면 정의를 *Section, TYPE=Beam 입력 텍스트로 export한다.
    • 옵션: --name <name>은 export되는 section 이름을 바꾼다. 생략하면 현재 section 이름을 사용한다.
    • 검증: 대상 hf2DStudio에 활성 단면이 있어야 한다. 기존 section mesh가 있어야 한다.
    • 동작: 생성된 beam-section 텍스트를 클립보드에 복사한다. 같은 텍스트를 remote result JSON으로 반환한다. 출력에는 section을 다시 만들기 위한 section 정의와 section 데이터가 포함된다. 현재 section mesh가 quadratic cell을 포함하면 export된 *Cell, TYPE=Mesh 블록은 T6/Q8 connectivity를 그대로 유지하며, 이를 T3/Q4로 조용히 낮추지 않는다.

    예시:

    hf2DStudio --remote export-section

    3.7.1.2 export-guide-geometry

    • 현재 단면 geometry를 *Geometry, TYPE=Guide 텍스트로 export한다.
    • 옵션: --side <left|right>는 taper-aware 데이터가 있는 경우 어느 쪽 geometry를 export할지 선택한다. --ref-cs <name>는 export되는 *Geometry keyword line 끝에 Ref=<name>을 추가한다. --name <name>은 export되는 geometry 이름을 바꾼다. 생략하면 현재 section 이름을 사용한다.
    • 검증: 대상 hf2DStudio에 활성 단면이 있어야 한다. curve 데이터가 있는 active geometry가 있어야 한다.
    • 동작: 생성된 guide geometry 텍스트를 클립보드에 복사한다. 같은 텍스트를 remote result JSON으로 반환한다. Guide 점은 section의 yp/zp를 x/y로 사용해서 Z=0 평면에 export한다. reference coordinate system 이름이 지정되면 export된 keyword line에만 기록한다. 출력은 현재 section geometry에 맞는 Guide primitive 형식을 사용한다.

    예시:

    hf2DStudio --remote export-guide-geometry --side left --ref-cs CS-1 --name Guide-1

    3.7.1.3 export-curve-mesh

    • 현재 단면 curve를 1D curve mesh로 export한다.
    • 옵션: --side <left|right>는 geometry가 side-aware인 경우 어느 쪽 curve set을 export할지 선택한다. --node-id-offset <id>는 생성되는 node ID에 지정한 offset을 더한다. --element-id-offset <id>는 생성되는 element ID에 지정한 offset을 더한다. --ref-cs <name>는 export되는 *Node block에 사용할 reference coordinate system 이름을 지정한다.
    • 검증: 대상 hf2DStudio에 활성 단면이 있어야 한다. curve 데이터가 있는 active geometry가 있어야 한다.
    • 동작: 생성된 curve mesh 텍스트를 클립보드에 복사한다. 같은 텍스트를 remote result JSON으로 반환한다. 출력은 GUI에서 사용하는 현재 curve mesh export 형식을 따른다. 이것은 geometry curve sampling을 사용하는 seed-point 기반 1D curve-mesh export이며, domain-mesh 차수와는 독립적으로 현재 GUI의 1D FE 형식을 쓴다.

    예시:

    hf2DStudio --remote export-curve-mesh --side right --node-id-offset 1000 --element-id-offset 2000 --ref-cs CS-1

    3.7.1.4 export-domain-mesh

    • 현재 단면 domain mesh를 2D FE 입력 텍스트로 export한다.
    • 옵션: --side <left|right>는 taper-aware 데이터가 있는 경우 어느 쪽 domain을 export할지 선택한다. --node-id-offset <id>는 생성되는 node ID에 지정한 offset을 더한다. --element-id-offset <id>는 생성되는 element ID에 지정한 offset을 더한다. --ref-cs <name>는 export 텍스트에 사용할 reference coordinate system 이름을 지정한다.
    • 검증: 대상 hf2DStudio에 활성 단면이 있어야 한다. 기존 section mesh가 있어야 한다.
    • 동작: 생성된 domain mesh 텍스트를 클립보드에 복사한다. 같은 텍스트를 remote result JSON으로 반환한다. 출력은 GUI에서 사용하는 mesh-only domain mesh 형식으로 고정된다. 이 명령은 현재 domain mesh 차수를 그대로 유지한다. Linear mesh는 CPS3/CPS4로 export되고, quadratic mesh는 CPS6/CPS8로 export된다.

    예시:

    hf2DStudio --remote export-domain-mesh --side left --node-id-offset 1000 --element-id-offset 2000 --ref-cs CS-1

    3.7.1.5 make-mesh

    • 활성 단면 mesh를 만들거나 삭제하거나 토글한다.
    • 검증: build는 section geometry가 필요하다. delete는 현재 mesh가 있을 때만 제거한다.
    • 동작: build는 mesh를 만든 뒤 section constants까지 바로 계산한다. 즉, centroid, shear-center, 그 밖의 파생 section constants가 같은 단계에서 준비된다. remote command에는 linear/quadratic 옵션이 없으며, 현재 hf2DStudio 세션이 들고 있는 mesh-order 상태를 그대로 사용한다. build는 현재 저장된 curve seed와 Quad Mesh Corner Hints를 사용하며, auto-seed interval correction을 새로 실행하거나 seed를 변경하지 않는다. TFI interval 조건이 맞지 않거나 후보가 유일하게 안전하지 않으면 해당 face는 Netgen fallback으로 진행된다. 이미 mesh가 있으면 build는 기존 mesh를 바꾸지 않고 성공으로 반환한다. 다른 차수로 다시 만들려면 먼저 현재 mesh를 삭제해야 한다. GUI에서는 Operation > Make Linear Mesh, Operation > Make Quadratic Mesh, Operation > Delete Mesh가 대응된다.

    예시:

    hf2DStudio --remote make-mesh build

    3.7.1.6 compute-section-constants

    • 활성 단면 mesh에 대한 section constants를 계산, 무효화, 또는 토글한다.
    • 검증: 기존 mesh가 필요하다.
    • 동작: 이미 존재하는 mesh에 대해 section constants를 다시 계산하거나 무효화할 때 사용한다. make-mesh build는 기본적으로 section constants를 함께 계산한다.

    3.7.1.7 renumber

    • 활성 단면의 geometry 개체 id를 재정렬한다.
    • 문법: renumber
    • 검증: 위치 인수를 받지 않는다. 대상 hf2DStudio에 활성 단면이 있어야 한다.
    • 동작: point, curve, face, rebar에 대해 각각 1부터 시작하는 연속 id를 새로 부여한다. 외부에서 참조하던 id는 모두 무효화되므로, 이후 단계에서는 새로 부여된 id를 다시 조회해서 써야 한다. GUI Operation > Renumber 액션과 동일한 결과를 만들며, Remote Control History에도 같은 형식으로 기록된다.

    예시:

    hf2DStudio --remote renumber

    3.7.1.8 move

    • 활성 단면 전체를 지정한 기준점 규칙 또는 명시적 offset만큼 평행이동한다.
    • 문법: move <anchor> [--offset <yp,zp>]
    • 검증: <anchor>는 다음 중 하나여야 한다. top-left, top-middle, top-right, middle-left, middle-middle, middle-right, bottom-left, bottom-middle, bottom-right, centroid, shear-center, offset. --offset <yp,zp>는 offset 앵커일 때만 허용되며, 이 앵커에서는 반드시 필요하다. 다른 앵커에 --offset을 주면 실패한다.
    • 동작: 9방위 앵커는 단면의 axis-aligned bounding box를 기준으로 해당 위치를 원점(0,0)으로 옮기도록 전체 geometry를 평행이동한다. centroid는 현재 section constants의 centroid를, shear-center는 shear center를 원점으로 옮긴다. offset은 geometry 전체를 <yp,zp>만큼 평행이동하며, 기준점 자체는 바꾸지 않는다. GUI Operation > Move 관련 액션과 동일한 결과를 만들며, Remote Control History에도 같은 형식으로 기록된다.

    예시:

    hf2DStudio --remote move centroid
hf2DStudio --remote move offset --offset "10,5"

    3.7.1.9 rotate

    • 활성 단면 전체를 지정한 각도만큼 회전한다.
    • 문법: rotate <angle-deg>
    • 검증: angle은 finite number 하나여야 한다. 대상 hf2DStudio에 활성 단면이 있어야 한다.
    • 동작: 현재 원점(yp=0, zp=0)을 중심으로, +y 축에서 +z 축으로 회전하는 방향을 양의 각으로 해석해서 geometry를 회전한다. 회전 후 필요하면 move centroid, move shear-center 등을 이어 붙여 기준점을 다시 정렬할 수 있다. GUI Operation > Rotate 액션과 동일한 결과를 만들며, Remote Control History에도 같은 형식으로 기록된다.

    예시:

    hf2DStudio --remote rotate 30
hf2DStudio --remote rotate -90

    3.7.2 Analysis

    hf2DStudio --remote [--target <id>] run-analysis
hf2DStudio --remote [--target <id>] unlock-model
    • 저장된 현재 파일 경로가 필요하다.
    • 미저장 변경이 있으면 analysis 시작 전에 자동 저장을 시도한다.
    • 추가 CLI 옵션은 받지 않는다. remote command는 GUI action과 같은 analyzer launch 경로를 사용한다.
    • unlock-model은 GUI의 Unlock model action과 같으며, 현재 section-analysis 결과를 삭제해서 편집 상태로 되돌린다.
    • unlock-model은 결과 파일이 있거나 analysis 결과가 현재 로드되어 있을 때만 사용할 수 있다.

    3.7.2.1 run-analysis

    • GUI analysis action과 같은 방식으로 section analysis를 시작한다.
    • 검증: 저장된 현재 파일 경로가 필요하다. analysis가 이미 실행 중이면 실패한다.
    • 동작: 미저장 변경이 있으면 현재 파일을 먼저 저장한다. 새 실행을 시작하기 전에 현재 section 파일의 기존 .xlsx 결과 출력은 제거한다.

    예시:

    hf2DStudio --remote run-analysis

    3.7.2.2 unlock-model

    • 현재 section-analysis 결과를 삭제하고 모델을 다시 편집 가능한 preprocessing 상태로 되돌린다.
    • 검증: 위치 인수를 받지 않는다. analysis가 실행 중이면 실패한다. 저장되었거나 로드된 결과가 없으면 실패한다.
    • 동작: 현재 .xlsx analysis 결과 파일이 있으면 제거한다. 메모리상에만 남아 있는 결과도 active session에서 모두 지운다. GUI Unlock model도 성공 후 같은 canonical unlock-model tail을 Remote Control History에 추가한다.

    예시:

    hf2DStudio --remote unlock-model
