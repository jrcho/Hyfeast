    2.4 hfStudio 원격 제어 File

    GUI 메뉴를 열지 않고 모델을 새로 만들고, 열고, 저장하고, export하거나 종료할 때 이 명령들을 사용한다.

    대부분의 file 명령은 성공 시 별도 JSON을 출력하지 않는다. 내부 기록용 필드인 scriptTail은 계속 Remote Control History와 script-save에 남지만, 일반 CLI JSON 출력에는 보이지 않는다.

    2.4.1 new

    hfStudio --remote [--target <id>] new [--discard-unsaved]
    • 새 빈 모델을 만든다.
    • --discard-unsaved가 없으면 GUI File > New와 같은 저장 확인 흐름을 따른다.
    • Yes를 고르면 현재 모델을 먼저 저장한다. 아직 한 번도 저장한 적이 없으면 Save As 대화상자가 열린다.
    • No를 고르면 미저장 변경을 버리고 새 빈 모델을 만든다.
    • Cancel을 고르면 현재 모델을 유지한 채 명령이 NEW_FAILED로 끝난다.
    • --discard-unsaved는 미저장 변경을 즉시 버리고 GUI 저장 확인 대화상자도 띄우지 않는다.

    2.4.2 open

    hfStudio --remote [--target <id>] open <file>
    • 지정한 모델 파일을 연다.
    • 미저장 변경이 있고 현재 파일 경로가 있으면 먼저 자동 저장한다.
    • 미저장 변경이 있는데 현재 파일 경로가 없으면 SAVE_PATH_REQUIRED로 실패한다. 단, Untitled 모델에 global UnitSystem만 있는 경우는 예외로 저장 없이 계속 진행한다.

    2.4.3 save

    hfStudio --remote [--target <id>] save [file]
    • [file]이 없으면 현재 파일에 저장한다.
    • [file]이 있으면 그 경로로 저장하고 현재 파일 경로도 함께 갱신한다.

    2.4.4 write-scene

    hfStudio --remote [--target <id>] write-scene <file>
    • active render scene을 출력 파일로 저장한다.
    • 지원 확장자:
    • .png
    • .jpg
    • .bmp
    • .pnm
    • .tif
    • .svg
    • .ps
    • .eps
    • .pdf
    • .tex

    2.4.5 write-program-shot

    hfStudio --remote [--target <id>] write-program-shot <file>
    • 메뉴 바, 툴바, dock widget, central view, 상태 바를 포함한 hfStudio 프로그램 영역 전체를 캡처한다.
    • <file>의 상위 디렉터리는 미리 존재해야 한다.
    • 파일 확장자는 현재 Qt image writer runtime이 지원하는 형식이어야 한다.
    • runtime이 지원하는 raster 형식으로 저장한다.
    • .svg, .pdf, .ps, .eps, .tex 같은 vector 형식은 지원하지 않는다.
    • canonical write-program-shot ... tail을 Remote Control History와 script-save에 기록한다.

    2.4.6 import

    hfStudio --remote [--target <id>] import <file> [--type <Hyfeast|DXF|MGT|MCT|Abaqus|GMSH>]
    • 외부 모델 파일을 현재 세션으로 가져온다.
    • --type은 선택 사항이다.
    • DXF는 GUI File > Import와 같은 DXF importer를 통해 Guide primitive로 가져온다.
    • DXF 단위 변환은 현재 DB/global UnitSystem과 DXF $INSUNITS가 모두 유효할 때만 적용한다. 둘 중 하나가 없거나 지원되지 않으면 좌표값을 스케일 변환 없이 가져온다.
    • 문서상 보장 범위는 LINE, LWPOLYLINE, POLYLINE 같은 선분/폴리라인 기반 엔터티로 구성된 ASCII DXF이다.
    • binary DXF와 버전별 고급 엔터티는 보장 범위 밖이다.
    • 생략하면 확장자로 타입을 추론한다.
    • .inp -> Hyfeast
    • .dxf -> DXF
    • .mgt -> MGT
    • .mct -> MCT
    • .msh -> GMSH

    2.4.7 export

    hfStudio --remote [--target <id>] export <file>
    • 현재 모델을 지정한 출력 경로로 export한다.
    • 기존 export 흐름이 지원하는 출력 경로와 확장자를 사용해야 한다.

    2.4.8 quit

    hfStudio --remote [--target <id>] quit [--discard-unsaved]
    • 대상 창을 닫는다.
    • 미저장 변경이 있고 현재 파일 경로가 있으면 먼저 자동 저장한다.
    • 미저장 변경이 있는데 현재 파일 경로가 없으면 SAVE_PATH_REQUIRED로 실패한다.
    • --discard-unsaved는 자동 저장 없이 미저장 변경을 버리고 GUI 저장 확인 대화상자도 띄우지 않으며, remote 요청이 수락되면 바로 대상 창을 닫는다.

    예시:

    hfStudio --remote open D:\Work\beam.inp
hfStudio --remote save
hfStudio --remote write-program-shot D:\Work\hfStudio-program.png
hfStudio --remote quit --discard-unsaved
