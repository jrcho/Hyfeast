    2.7.1 hfStudio 원격 제어 Environment

    2.7.1.1 environment-unit-system

    hfStudio --remote [--target <id>] environment-unit-system get
hfStudio --remote [--target <id>] environment-unit-system set <force-length-time-temp|none>
    • set으로 길이 단위가 바뀌면 hfStudio는 렌더 뷰에서 크기가 바뀐 모델이 다시 보이도록 카메라를 reset한다.
    • get은 현재 전역 *Environment, TYPE=UnitSystem 토큰을 JSON으로 반환한다.
    • set은 GUI Environment > UnitSystem 편집기와 같은 전역 UnitSystem 동작을 적용한다.
    • set은 preprocessing mode가 필요하다.
    • 값은 kN-mm-s-K 같은 4필드 토큰이거나 전역 UnitSystem을 지우는 none이어야 한다.
    • 함수나 단면에 로컬 UnitSystem 정의가 남아 있으면 none으로 지우는 것은 거부된다.
    • 공유 material function에 서로 맞지 않는 단위 변환 계수가 필요하면 set은 INVALID_STATE를 반환한다.
    • GUI Environment > UnitSystem Apply도 같은 정규 tail environment-unit-system set ...를 Remote Control History와 *.ipc.txt에 남긴다.

    예시:

    hfStudio --remote environment-unit-system get
hfStudio --remote environment-unit-system set kN-mm-s-K
hfStudio --remote environment-unit-system set none

    2.7.1.2 coincidence-tolerance

    hfStudio --remote [--target <id>] coincidence-tolerance get
hfStudio --remote [--target <id>] coincidence-tolerance set <non-negative-value>
    • coincidence geometry check에 사용하는 shared tolerance를 조회하거나 설정한다.
    • 값은 session-wide 설정이며 다음 경로들이 함께 공유한다.
    • node/element create의 coincidence check
    • divide/extrude의 교차 판정과 zero-length 검증
    • coincidence test를 사용하는 picking/intersection workflow
    • set에는 0 이상의 finite number가 필요하다.
    • get과 set은 항상 result JSON을 출력한다.
    • GUI Settings > General Apply도 같은 정규 tail coincidence-tolerance set ...를 Remote Control History와 *.ipc.txt에 남긴다.

    예시:

    hfStudio --remote coincidence-tolerance get
hfStudio --remote coincidence-tolerance set 1e-10

    2.7.1.3 environment-info

    hfStudio --remote [--target <id>] environment-info get
hfStudio --remote [--target <id>] environment-info set (--content <text> | --content-file <file>)
    • get은 현재 정규화된 *Environment, TYPE=Info 본문을 JSON으로 반환한다.
    • set은 GUI Environment > Info 편집기의 본문 내용을 그대로 적용한다.
    • set은 preprocessing mode에서 사용할 수 있고, GUI와 같은 예외 경로로 postprocessing mode에서도 수정할 수 있다.
    • --content와 --content-file 중 정확히 하나가 필요하다.
    • --content 안에서는 줄바꿈을 \n으로 쓴다. \\n은 문자 그대로 유지된다.
    • 빈 내용은 허용되지 않는다.
    • postprocessing mode에서는 성공 시 DB file을 즉시 갱신하며, 이는 GUI Environment > Info 동작과 같다.
    • GUI Environment > Info Apply도 같은 정규 tail environment-info set --content ...를 Remote Control History와 *.ipc.txt에 남긴다.

    예시:

    hfStudio --remote environment-info get
hfStudio --remote environment-info set --content "The bridge is analyzed by Hyfeast.\nReviewed on site."

    2.7.1.4 environment-control

    hfStudio --remote [--target <id>] environment-control get
hfStudio --remote [--target <id>] environment-control set (--content <text> | --content-file <file>)
    • get은 다음 정보를 반환한다.
    • 정규화된 *Environment, TYPE=Control 본문
    • 구조화된 제어 필드 compact, equationPrint, shell5Dof, outputPrecision, constraintHandler, nonsmoothIntegrationLevel, boundaryTolerance
    • set은 GUI Environment > Control 편집기의 본문 내용을 그대로 적용한다.
    • set은 preprocessing mode가 필요하다.
    • --content와 --content-file 중 정확히 하나가 필요하다.
    • --content 안에서는 줄바꿈을 \n으로 쓴다. \\n은 문자 그대로 유지된다.
    • 빈 내용은 허용되지 않는다.
    • GUI Environment > Control Apply도 같은 정규 tail environment-control set --content ...를 Remote Control History와 *.ipc.txt에 남긴다.

    예시:

    hfStudio --remote environment-control get
hfStudio --remote environment-control set --content "Compact=Off, OutputPrecision=double, BoundaryTolerance=1e-5"
