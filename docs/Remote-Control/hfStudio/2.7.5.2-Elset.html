    2.7.5.2 hfStudio 원격 제어 Elset

    2.7.5.2.1 elset

    hfStudio --remote [--target <id>] elset <name> (--content <text> | --content-file <file>)
    • *Elset, Name=<name> 정의 하나를 생성하거나 갱신한다.
    • --content와 --content-file 중 정확히 하나가 필요하다.
    • preprocessing mode와 postprocessing mode 모두에서 사용할 수 있다.
    • 정의 계열 명령 중 드물게 postprocessing mode에서도 수정이 허용되는 예외 경로이다.
    • 동작 규칙:
    • preprocessing: 새 set 생성과 기존 set 갱신이 모두 가능하다.
    • postprocessing: 새 set 생성은 가능하고, 기존 elset 갱신은 다른 객체에서 사용하지 않을 때만 가능하다.
    • postprocessing에서 성공하면 GUI Define Elset 위젯과 같이 현재 DB/HDB file에 즉시 반영한다.
    • 내용은 GUI Define Elset과 같은 본문 문법을 사용한다.
    • 10,20,30, 100:110, 1:101:10 같은 정수 id 패턴
    • 기존 elset 이름
    • 대상 set에서 제외할 -token
    • 현재 element selection을 확장하는 __selected__
    • 현재 element selection을 제거하는 -__selected__

    예시:

    hfStudio --remote elset COLUMN --content "101:120\nFRAME_OUTER"
hfStudio --remote elset PICKED --content "__selected__,FRAME_OUTER"
hfStudio --remote elset POST_FACE --content "__selected__,-FRAME_OUTER"

    2.7.5.2.2 elset-rename

    hfStudio --remote [--target <id>] elset-rename <old-name> <new-name>
    • element-set 정의 하나의 이름을 변경한다.
    • preprocessing mode에서만 사용할 수 있다.
    • ModelTree rename과 같은 이름 정규화와 중복 이름 검사를 사용한다.

    예시:

    hfStudio --remote elset-rename COLUMN COLUMN_REVIEW

    2.7.5.2.3 elset-delete

    hfStudio --remote [--target <id>] elset-delete <name>
    • element-set 정의 하나를 삭제한다.
    • preprocessing mode에서만 사용할 수 있다.
    • ModelTree delete와 같은 참조 정리 규칙을 사용한다.
    • 해당 elset을 참조하던 load, constraint, embedded-line host elset, step target 목록은 자동으로 정리된다.
    • 이름으로 지정한 elset이 실제로 삭제되지 않으면 명령은 실패한다.

    예시:

    hfStudio --remote elset-delete COLUMN_REVIEW
