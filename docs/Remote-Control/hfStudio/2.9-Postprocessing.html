    2.9 hfStudio 원격 제어 결과 보기

    해석 결과가 준비된 뒤 step, frame, contour, vector, scale, overlay 표시를 제어할 때 이 명령들을 사용한다.

    get 조회는 JSON을 반환하고 scriptTail을 추가하지 않는다. 설정형 명령은 canonical post-* ... tail을 Remote Control History와 *.ipc.txt에 기록한다.

    대부분의 definition 명령은 preprocessing 전용이지만, postprocessing mode에서도 현재 HDB를 직접 바꾸는 GUI 예외 경로인 environment-info set, nset, elset, step Post ..., step-delete-from ..., history PostHistory ...는 수정할 수 있다.

    2.9.1 post-plot

    hfStudio --remote [--target <id>] post-plot <contour|diagram|vector|sensor|deformed> <on|off>
hfStudio --remote [--target <id>] post-plot plot <x-tag> <y-tag> [--id <cN>]
hfStudio --remote [--target <id>] post-plot series list
hfStudio --remote [--target <id>] post-plot series details <tag>
hfStudio --remote [--target <id>] post-plot series add <tag>...
hfStudio --remote [--target <id>] post-plot series remove <tag>
hfStudio --remote [--target <id>] post-plot series clear
hfStudio --remote [--target <id>] post-plot series expr <expression> --var <name=tag> [--var <name=tag> ...]
hfStudio --remote [--target <id>] post-plot curve list [--id <cN>]
hfStudio --remote [--target <id>] post-plot curve add <x-tag> <y-tag> [--id <cN>]
hfStudio --remote [--target <id>] post-plot curve show <x-tag> <y-tag> <on|off> [--id <cN>]
hfStudio --remote [--target <id>] post-plot curve remove <x-tag> <y-tag>
hfStudio --remote [--target <id>] post-plot curve clear
hfStudio --remote [--target <id>] post-plot view show
hfStudio --remote [--target <id>] post-plot export <file> [--id <cN>]
hfStudio --remote [--target <id>] post-plot copy [--id <cN>]
    • active view의 postprocessing plot toggle을 제어한다.
    • postprocessing 모드에서만 사용할 수 있다.
    • deformed on은 현재 result step에 변위 출력 D가 없으면 실패한다.
    • plot은 postprocessing series 하나를 공유 PostPlot data model에 등록하고 대상 PostPlot composition에 표시한 뒤 열린 PostPlot view들을 refresh한다.
    • series 명령은 XY Plot Editor 왼쪽 Series 후보 목록을 공유 PostPlot data model에 저장된 source tag 단위로 관리한다. Index는 암시적으로 제공되며 series add로 추가하지 않는다.
    • series expr은 MathExpression 기반 derived source tag를 만든다. --var <name=tag> 형식으로 변수를 매핑하며, 모든 operand는 같은 source group에 속하고 point count가 같아야 한다.
    • curve 명령은 오른쪽 Curves 목록을 관리한다. curve add는 기존 plot의 정식 형태이고, curve show는 선택한 PostPlot composition의 checkbox/visible 상태를 바꾼다. curve remove와 curve clear는 공유 등록 curve를 제거한다.
    • view show는 editor의 Show Plot 버튼과 같이 floating PostPlot 표시 창을 연다.
    • <x-tag>와 <y-tag>는 XY Plot Editor와 같은 source key를 쓴다. 예를 들어 header:history-name.H, (index):history-name.H, N:0:53:D.Z.R 같은 result field tag, R1:STime, R1:RTime, R1:LF 같은 result frame-axis tag를 사용할 수 있다.
    • R1:RTime 값은 해당 result step을 소유한 Step의 TUnit을 따른다. XY Plot Editor와 plot 축에는 RTime [day]처럼 단위를 표시하지만, 명령의 source key는 R1:RTime 형식을 유지한다. export와 copy도 이 단위로 변환된 숫자 값을 사용한다.
    • export <file>은 대상 composition에서 현재 visible 상태인 PostPlot series를 CSV 파일로 저장한다.
    • copy는 같은 CSV 내용을 clipboard에 복사한다. script-save로 기록한 뒤 재실행하면 clipboard 내용도 다시 바뀐다.
    • --id <cN>은 대상 floating PostPlot 표시 창과 그 visible-series composition을 지정한다. 별도 PostPlot data cache를 고르는 옵션은 아니며, cache는 공유된다. 열린 PostPlot view가 없으면 default composition에 대해 post-plot을 실행할 수 있다.
    • script-save는 표시 창 --id를 기록하지 않는다. 재실행된 PostPlot data 명령은 열린 PostPlot이 있으면 active PostPlot composition에, 없으면 default composition에 적용된다.
    • plot과 curve add는 series, added, seriesCount, xPointCount, yPointCount, plotted를 포함한 JSON을 반환한다.
    • series list, series details, curve list, view show는 JSON을 반환하며 CSV export가 필요하지 않다.
    • export와 copy는 seriesCount와 rowCount를 포함한 JSON을 반환한다.

    2.9.2 post-step

    hfStudio --remote [--target <id>] post-step <step-name>
hfStudio --remote [--target <id>] post-step get
    • post-step <step-name>은 이름으로 result step을 선택하고, 해당 step의 frame 1로 이동한다.
    • post-step get은 현재 step과 frame 상태를 JSON으로 반환한다.
    • postprocessing 모드에서만 사용할 수 있다.
    • <step-name>은 기존 result-step 이름과 정확히 일치해야 한다.
    • 단일 토큰 get은 이 명령의 조회 키워드로 예약된다.

    2.9.3 post-frame

    hfStudio --remote [--target <id>] post-frame <frame-index>
hfStudio --remote [--target <id>] post-frame get
    • post-frame <frame-index>는 현재 result step의 frame을 선택한다.
    • post-frame get은 현재 step과 frame 상태를 JSON으로 반환한다.
    • postprocessing 모드에서만 사용할 수 있다.
    • <frame-index>는 1 기반이며 현재 step의 frame 범위 안에 있어야 한다.

    2.9.4 post-scalar

    hfStudio --remote [--target <id>] post-scalar <field> [<average-threshold>]
hfStudio --remote [--target <id>] post-scalar get
    • active result step의 scalar field를 선택한다.
    • get은 현재 scalar field 상태를 JSON으로 반환한다.
    • postprocessing 모드에서만 사용할 수 있다.
    • <field>는 현재 step과 frame에서 유효한 scalar field 이름이어야 한다.
    • [<average-threshold>]는 선택 사항이며 0..100 정수여야 한다.
    • <average-threshold>는 element scalar 값을 element node로 외삽한 뒤 공유 절점에서 평균할지 결정한다. 0은 평균을 끄고, 1..100은 같은 평균 그룹의 값이 아래 조건을 만족할 때만 평균한다.
    \[ \max(v_i)-\min(v_i) \le \frac{\mathrm{threshold}}{100} \left(\max(v_\mathrm{region})-\min(v_\mathrm{region})\right) \]
    • 평균 그룹은 같은 section 안에서 구성되며, \(v_\mathrm{region}\)은 그 section 그룹의 scalar 값 범위이다. 연속체 요소는 공유 절점별로 평균한다. 쉘 요소는 bottom/top을 분리하고 shell element coordinate system이 같은 값끼리만 평균한다. 보 요소는 section/material point index와 beam element coordinate system이 같은 값끼리만 평균한다.

    2.9.5 post-vector

    hfStudio --remote [--target <id>] post-vector <field>
hfStudio --remote [--target <id>] post-vector get
    • active result step의 vector 또는 tensor field를 선택한다.
    • get은 현재 vector field 상태를 JSON으로 반환한다.
    • postprocessing 모드에서만 사용할 수 있다.
    • <field>는 현재 step과 frame에서 유효한 vector 또는 tensor field 이름이어야 한다.

    2.9.6 post-contour

    hfStudio --remote [--target <id>] post-contour auto-range <on|off>
hfStudio --remote [--target <id>] post-contour auto-range get
hfStudio --remote [--target <id>] post-contour range <min> <max>
hfStudio --remote [--target <id>] post-contour range get
hfStudio --remote [--target <id>] post-contour bands <n>
hfStudio --remote [--target <id>] post-contour bands get
hfStudio --remote [--target <id>] post-contour mode <uniform|custom>
hfStudio --remote [--target <id>] post-contour mode get
hfStudio --remote [--target <id>] post-contour levels <v1,v2,...>
hfStudio --remote [--target <id>] post-contour levels get
hfStudio --remote [--target <id>] post-contour overlay <text>
hfStudio --remote [--target <id>] post-contour overlay get
hfStudio --remote [--target <id>] post-contour overlay-color <r,g,b[,a]>
hfStudio --remote [--target <id>] post-contour overlay-color get
    • active postprocessing view의 contour 설정을 제어한다.
    • postprocessing 모드에서만 사용할 수 있다.
    • auto-range, range, bands의 설정형 명령은 custom contour mode에서 거부된다.
    • mode custom은 필요하면 현재 uniform range와 band 상태로 custom boundary level을 초기화한다.
    • levels 설정은 엄격히 증가하는 2..31개의 경계값을 요구한다.
    • overlay-color는 0..255 정수 채널 값을 사용한다.
    • get은 전체 contour 상태와 함께 enabled, min, max, text, color 같은 action별 별칭도 반환한다.

    2.9.7 post-scale

    hfStudio --remote [--target <id>] post-scale deformed auto <on|off>
hfStudio --remote [--target <id>] post-scale deformed auto get
hfStudio --remote [--target <id>] post-scale deformed value <scale>
hfStudio --remote [--target <id>] post-scale deformed value get
hfStudio --remote [--target <id>] post-scale diagram auto <on|off>
hfStudio --remote [--target <id>] post-scale diagram auto get
hfStudio --remote [--target <id>] post-scale diagram value <scale>
hfStudio --remote [--target <id>] post-scale diagram value get
hfStudio --remote [--target <id>] post-scale vector auto <on|off>
hfStudio --remote [--target <id>] post-scale vector auto get
hfStudio --remote [--target <id>] post-scale vector value <scale>
hfStudio --remote [--target <id>] post-scale vector value get
hfStudio --remote [--target <id>] post-scale sensor auto <on|off>
hfStudio --remote [--target <id>] post-scale sensor auto get
hfStudio --remote [--target <id>] post-scale sensor <e|d|v|a> <scale>
hfStudio --remote [--target <id>] post-scale sensor <e|d|v|a> get
    • active postprocessing view의 deformed, diagram, vector, sensor scale factor를 제어한다.
    • postprocessing 모드에서만 사용할 수 있다.
    • 명시적 value 또는 e|d|v|a 입력은 대응되는 auto-scale을 먼저 끈다.
    • get은 전체 scale 상태와 함께 enabled, value 같은 조회별 별칭도 반환한다.

    2.9.8 post-display

    hfStudio --remote [--target <id>] post-display <information|scalarbar|min-max-tag> <on|off>
    • active view의 postprocessing overlay와 display 항목을 토글한다.
    • postprocessing 모드에서만 사용할 수 있다.
    • information: 좌상단 정보 텍스트
    • scalarbar: scalar bar widget
    • min-max-tag: min과 max caption tag

    2.9.9 post-animation-time-history

    hfStudio --remote [--target <id>] post-animation-time-history <on|off>
    • Postprocessing > Play > Time History Ani와 같다.
    • postprocessing 모드에서만 사용할 수 있다.
    • scale-factor animation이 이미 켜져 있으면 실패한다.

    2.9.10 post-animation-scale-factor

    hfStudio --remote [--target <id>] post-animation-scale-factor <on|off>
    • Postprocessing > Play > Scale Factor Ani와 같다.
    • postprocessing 모드에서만 사용할 수 있다.
    • time-history animation이 이미 켜져 있으면 실패한다.

    2.9.11 post-animation-loop

    hfStudio --remote [--target <id>] post-animation-loop <on|off>
    • Postprocessing > Play > Loop와 같다.
    • postprocessing 모드에서만 사용할 수 있다.
    • 현재 animation의 자동 반복 여부를 제어한다.

    2.9.12 post-animation-record

    hfStudio --remote [--target <id>] post-animation-record <on|off> [<file>]
    • Postprocessing > Play > Record와 같다.
    • postprocessing 모드에서만 사용할 수 있다.
    • on은 .avi 또는 .mp4 확장자를 가진 쓰기 가능한 출력 파일 경로가 필요하다.
    • off는 현재 animation record 대상을 지운다.
    • animation이 실행 중이 아닐 때만 변경할 수 있다.

    예시:

    hfStudio --remote post-step "LC1-DeadLoad"
hfStudio --remote post-frame 7
hfStudio --remote post-scalar "S.Mises" 85
hfStudio --remote post-contour mode get
hfStudio --remote post-plot plot "(index):result-history.H" "D.X@2:result-history.H"
hfStudio --remote post-plot plot "R1:STime" "R1:LF"
hfStudio --remote post-plot series expr "A-B" --var "A=R1:STime" --var "B=R1:RTime"
hfStudio --remote post-plot series list
hfStudio --remote post-plot export "tmp/postplot-result.csv"
hfStudio --remote post-plot view show
hfStudio --remote post-plot copy
hfStudio --remote post-animation-record on "D:/work/result.avi"
