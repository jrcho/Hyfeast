    3 Solid Cantilever

    3.1 목표

    Tutorial 01의 같은 cantilever 문제를 solid 요소로 다시 풀어 본다. 이 문서의 핵심은 beam과 solid의 차이를 추상적으로 설명하는 것이 아니라, 같은 문제를 두 방식으로 직접 비교하게 만드는 데 있다.

    3.2 이 예제에서 확인할 것

    • solid 모델이 왜 beam보다 입력이 많아지는지
    • 같은 하중 조건에서도 어떤 결과를 더 직접적으로 볼 수 있는지
    • 전역 거동과 국부 응력 검토가 어떻게 달라지는지

    3.3 예제 파일

    • 입력 파일: Example/Tutorials/tutorial-solid-cantilever.inp
    • 결과 파일: tutorial-solid-cantilever.hdb
    • 출력 파일: tutorial-solid-cantilever.prn

    3.4 beam 예제와 비교해서 보는 법

    3.4.1 그대로 유지되는 것

    • 부재 길이 2.4 m
    • 콘크리트 재료 상수
    • 고정단 cantilever라는 구조 개념
    • service 하중을 본다는 목적

    3.4.2 바뀌는 것

    • line 요소 대신 3차원 solid mesh를 사용한다
    • 단면 정보 대신 블록 전체 형상을 직접 만든다
    • line load 대신 윗면 pressure를 준다
    • 결과에서 부재력보다 응력 contour 해석 비중이 커진다

    3.5 모델 개요

    • 형상: 2.4 m x 0.30 m x 0.60 m
    • 요소 타입: C3D8
    • mesh: 8 x 2 x 4
    • 구속: x=0 면 전체 고정
    • 하중: 윗면에 60 kPa 하향 pressure

    윗면 pressure 60 kPa는 beam 예제의 선하중과 크기가 대응한다.

    60 kN/m^2 x 0.30 m = 18 kN/m

    그래서 beam 결과와 solid 결과를 나란히 비교하기 좋다.

    3.6 입력 파일에서 먼저 볼 블록

    *Section, Type=Solid, Name=ConcreteSolid
 Concrete, 1

*Model, Type=Block3D
 Cantilever, Auto, Auto, C3D8, ConcreteSolid
 0.0, 2.4, 8
 0.0, 0.30, 2
 0.0, 0.60, 4

    이 블록은 3차원 블록과 mesh를 한 번에 만든다.

    *Constraint, Type=Support, Name=FixedEnd
 Cantilever-NX, X|Y|Z

*Load, Type=SurfaceDistributed, Name=DeckPressure
 Cantilever-PZ, Pressure, 60000

    이 블록은 고정면과 압력 하중을 정의한다.

    3.7 해석 실행

    저장소 루트에서 바로 실행한다.

    hfAnalyzer .\Example\Tutorials\tutorial-solid-cantilever.inp

    hfStudio에서 바로 가져와 저장한 뒤 해석하는 흐름도 가능하다.

    hfStudio --remote import .\Example\Tutorials\tutorial-solid-cantilever.inp --type Hyfeast
hfStudio --remote save .\Example\Tutorials\tutorial-solid-cantilever.hdb
hfStudio --remote run-analysis

    3.8 결과에서 먼저 볼 것

    • 자유단 변위가 beam 예제와 같은 방향과 비슷한 크기로 나온다
    • 고정단 근처에서 응력이 가장 크게 나타난다
    • mesh를 더 촘촘하게 하면 contour가 부드러워지면서 값이 안정되는지 확인한다

    후처리는 다음 순서로 진행한다.

    hfStudio --remote open .\Example\Tutorials\tutorial-solid-cantilever.hdb
hfStudio --remote post-step Service
hfStudio --remote post-frame 1
hfStudio --remote post-plot contour on
hfStudio --remote post-plot deformed on
hfStudio --remote post-scalar S.Mises
hfStudio --remote post-display scalarbar on

    아래 그림은 변형 형상과 von Mises 응력 contour를 함께 표시한 예시다.

    3.9 이 문서에서 가져가야 할 감각

    • beam은 전체 거동을 빠르게 보는 데 강하다
    • solid는 국부 응력과 형상 효과를 읽는 데 강하다
    • 실제 작업에서는 beam으로 먼저 검토하고, 필요한 구간만 solid로 상세화하는 흐름이 가장 흔하다
