    5 hfStudio Basics

    5.1 목표

    • 어떤 hfStudio 인스턴스에 명령을 보낼지
    • 어떤 view가 현재 선택되어 있는지
    • 어떤 render view가 표시 명령을 받을지
    • --view-id를 언제 써야 하는지

    5.2 시작 전제

    이 튜토리얼은 다음 상태를 전제로 한다.

    • hfStudio가 이미 실행 중이다
    • 명령은 저장소 루트에서 실행한다
    • 예제 결과 파일 Example/Tutorials/frame.hdb를 바로 열 수 있다

    처음에는 결과 파일이 이미 있는 예제로 시작한다. 그래야 원격 제어 자체에 집중할 수 있다.

    5.3 왜 list부터 보는가

    원격 제어는 실행 중인 프로그램 인스턴스에 명령을 보내는 방식이다. 따라서 첫 단계는 언제나 “지금 어느 인스턴스가 떠 있는가”를 확인하는 것이다.

    hfStudio --remote list
hfStudio --remote focus

    인스턴스가 하나뿐이면 이후 명령은 --target 없이 보내도 된다. 여러 개가 떠 있다면 list 결과에서 target id를 확인한 뒤 다음처럼 기본 대상을 지정한다.

    hfStudio --remote target set <target-id>

    5.4 가장 먼저 해 볼 최소 흐름

    hfStudio --remote open .\Example\Tutorials\frame.hdb
hfStudio --remote camera fit
hfStudio --remote representation both
hfStudio --remote display-control grid off

    이 네 줄만 실행해도 예제 결과 파일을 열고, 장면을 보기 좋은 상태로 정리하는 흐름을 익힐 수 있다.

    아래 그림은 frame 예제를 연 뒤 장면을 정리한 화면 예시다.

    5.5 꼭 구분해야 하는 세 가지 이름

    이름 뜻 언제 중요해지는가
    target 명령을 받을 hfStudio 프로세스 여러 인스턴스가 동시에 떠 있을 때
    currentView 지금 사용자가 선택한 탭 표, 차트, render view 중 무엇이 전면에 있는지 볼 때
    activeRenderView 표시와 camera 명령이 기본으로 적용되는 render view camera, display-control, visibility를 보낼 때

    헷갈리기 쉬운 부분은 currentView와 activeRenderView가 항상 같지 않다는 점이다. 예를 들어 표 탭을 보고 있어도 마지막으로 활성화한 render view가 따로 남아 있을 수 있다.

    5.6 view를 확인하고 추가하는 법

    hfStudio --remote view list
hfStudio --remote view add render
hfStudio --remote view activate --id r1

    view list는 현재 어떤 view가 열려 있는지 보여 준다. view add render는 새 render view를 하나 더 만든다.

    5.7 --view-id는 언제 쓰는가

    표시나 camera 명령은 기본적으로 activeRenderView에 적용된다. 특정 render view를 직접 겨냥하고 싶다면 --view-id를 붙인다.

    hfStudio --remote --view-id r0 camera view +z
hfStudio --remote --view-id r1 camera view +z
hfStudio --remote --view-id r1 display-control grid off

    이 방식은 active 상태를 바꾸지 않고도 다른 render view를 정리할 수 있어서 안정적이다.

    5.8 처음에는 이렇게 기억하면 된다

    • list로 대상 프로세스를 확인한다
    • open으로 예제 파일을 연다
    • camera fit과 representation both로 장면을 정리한다
    • render view를 둘 이상 쓸 때만 --view-id를 붙인다
