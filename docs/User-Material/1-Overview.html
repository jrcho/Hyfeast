    1 개요

    사용자 재료는 직접 작성한 재료 모델을 DLL(플러그인)로 만들어 Hyfeast 해석에 쓰는 기능이다. 입력 파일에서는 *Material, Type=User로 정의하고, 단면에서는 다른 재료와 같이 이름으로 참조한다.

    이 절(1~5장)은 사용자 재료에 필요한 내용을 모두 담는다.

    장 내용
    1 개요 구조, 작성 방법, 개발 키트, 사용 흐름, 지원 범위
    2 입력 *Material, Type=User 문법과 데이터라인
    3 플러그인 인터페이스 hf_umat_v1 인자, 호출 규칙, 성분 순서, 전달값
    4 플러그인 빌드 C, Native Fortran, Abaqus UMAT 빌드와 오류 대처
    5 예제 Examples/UMAT 따라 하기와 내장 재료 비교

    1.1 구조

    Hyfeast가 부르는 플러그인 함수는 hf_umat_v1 하나다. 인자 목록, 인자 의미, 성분 순서는 Abaqus/Standard UMAT와 같다. 이 함수는 C로도 Fortran으로도 작성할 수 있다.

                     *Material, Type=User
                          |
                   Hyfeast (hfAnalyzer)
                          |
     hf_umat_v1(STRESS, STATEV, DDSDDE, ..., KINC)    <- UMAT argument list, C ABI
                          |
        +-----------------+------------------+
        |                                    |
     C plugin                        Native Fortran plugin
                                             |
                                  Abaqus UMAT connection
                                  (bridge + unchanged UMAT source)

    플러그인을 만드는 방법은 세 가지다.

    방법 작성하는 것 빌드
    C hf_umat_v1 함수 Visual Studio C++ (cl, 권장) 또는 MinGW-w64 GCC (gcc)
    Native Fortran bind(C)로 내보내는 hf_umat_v1 서브루틴 Intel Fortran (build_umat.cmd native)
    Abaqus UMAT 기존 SUBROUTINE UMAT 소스를 그대로 사용 Intel Fortran (build_umat.cmd abaqus), 키트의 브리지가 자동 포함

    Abaqus UMAT 연결은 Native Fortran의 한 형태다. 키트의 브리지(hfAbaqusUmatBridge.f90)가 hf_umat_v1을 구현하고, 재료 이름을 Abaqus 형식(CHARACTER*80)으로 바꿔 원본 UMAT를 호출한다. Hyfeast는 DLL이 어느 방법으로 만들어졌는지 구분하지 않는다.

    1.2 역할 분담

    Hyfeast가 하는 일 플러그인이 하는 일
    Hyfeast 성분 순서와 Abaqus 성분 순서 사이의 변환 응력(STRESS), 상태변수(STATEV), 접선강성(DDSDDE) 계산
    응력, 전체 변형률, 온도, 에너지 저장. STATEV는 사용자 영역으로 따로 보관 열변형 처리(DSTRAN은 전체 변형률 증분)
    반복 중에는 수렴 상태에서 다시 시작, 채택된 증분만 확정 증분을 줄이고 싶으면 PNEWDT < 1 반환
    셸에서 \(\sigma_{33}=0\) 반복과 33 성분 소거
    Unsymm=No이면 접선강성 대칭화
    PNEWDT < 1이면 증분 거부 후 축소

    1.3 개발 키트

    플러그인 작성에 필요한 헤더, 템플릿, 브리지와 빌드 스크립트는 배포 폴더의 Examples/UMAT/UserMaterial에 있다. 아래 경로는 이 키트 폴더를 기준으로 한다.

    경로 내용
    include/hfUserMaterialAPI.h C 공개 헤더(hf_umat_v1 프로토타입)
    fortran/hf_umat_template.f90 Native Fortran 템플릿(선언부)
    abaqus/hfAbaqusUmatBridge.f90 Abaqus UMAT 브리지
    abaqus/ABA_PARAM.INC Abaqus UMAT가 포함하는 기본 형 선언
    build_umat.cmd Fortran 플러그인 빌드 스크립트(ifx)
    examples/NativeElasticC/hfUmatElasticC.c C 탄성 재료 예제
    examples/NativeElasticFortran/hfUmatElasticF.f90 Native Fortran 탄성 재료 예제
    examples/AbaqusElasticUMAT/umat_elastic.for Abaqus 형식 탄성 UMAT 예제
    examples/AbaqusPlasticUMAT/umat_vonmises.for Abaqus 형식 von Mises 소성 UMAT 예제

    1.4 사용 흐름

    1. 재료 모델을 C, Native Fortran 또는 Abaqus UMAT 형식으로 작성한다(3장).
    2. DLL로 빌드한다(4장).
    3. 입력 파일에 *Material, Type=User로 DLL 경로와 물성을 준다(2장).
    4. *TestMaterial로 재료점 응답을 먼저 확인한다(16.3 *TestMaterial).
    5. 해석하고 결과를 확인한다(5장).

    1.5 지원 범위

    조건 요소 비고
    3D C3D4, C3D6, C3D8, C3D8I, C3D8PMDL
    연속체 셸 CS6, CS8 3D 조건으로 호출
    셸 S3, S3F, S4, S4F 3D로 호출하고 Hyfeast가 \(\sigma_{33}=0\)을 맞춤
    평면변형, 축대칭 CPE3, CPE4, CAX3, CAX4 등 2D solid
    평면응력 CPS3, CPS4 등 2D solid 플러그인이 \(\sigma_{33}=0\)을 맞춤
    미지원 보, 트러스, 스프링 등 1축 재료, 적층판, interface 요소 입력 또는 해석 중 오류
    • 출력 필드는 S, E, MTEMP이다. STATEV는 결과 파일에 출력하지 않는다.
    • 미소변형만 다룬다. 유한변형 관련 인자는 중립값으로 전달한다(3장).
    • 자체 완결형 Abaqus UMAT만 지원한다. Abaqus 유틸리티 루틴을 호출하는 UMAT는 빌드할 수 없다.
    • hfStudio는 사용자 재료를 표시하고 저장만 한다. DLL은 해석기(hfAnalyzer)만 불러온다.
