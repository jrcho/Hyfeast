    3 플러그인 인터페이스

    3.1 내보내야 할 함수

    플러그인 DLL은 다음 두 함수를 C 이름 그대로 내보내야 한다.

    함수 역할
    hf_umat_v1 재료점 하나를 계산한다. 인자 목록은 Abaqus UMAT와 같다(3.3절).
    hf_umat_abi_version 인자가 없고 정수 1(HF_UMAT_ABI_VERSION)을 반환한다. Hyfeast는 DLL을 불러올 때 한 번 부르고, 값이 다르면 해석 전에 오류로 멈춘다.

    *Material 첫 데이터라인에서 다른 함수 이름(symbol)을 주면 hf_umat_v1 대신 그 함수를 부른다. 인자 목록은 같아야 한다.

    3.2 Abaqus UMAT와의 차이

    항목 Abaqus UMAT hf_umat_v1
    함수 이름 컴파일러마다 다름(UMAT, umat_ 등) hf_umat_v1로 고정. Fortran은 bind(C, name="hf_umat_v1")
    CMNAME CHARACTER*80, 길이를 숨은 인자로 전달 81바이트 char 배열(이름 최대 80자, NUL, 나머지 0). 숨은 인자 없음

    그 밖의 인자 이름, 순서, 의미, 성분 순서는 Abaqus와 같다. 기존 Abaqus UMAT는 이 두 차이를 메우는 키트의 브리지와 함께 빌드하면 소스를 고치지 않고 쓸 수 있다(4장).

    3.3 인자

    모든 인자는 참조(포인터)로 전달되며 null이 아니다. 행렬은 열 우선이다. C에서 DDSDDE(i,j)는 ddsdde[(i-1) + (j-1)*ntens]이다.

    # 인자 형 입출력 크기 의미와 Hyfeast v1 값
    1 STRESS double 입출력 NTENS 증분 시작 응력 → 증분 끝 응력
    2 STATEV double 입출력 NSTATV 증분 시작 상태변수 → 증분 끝 상태변수. 첫 증분에서는 0
    3 DDSDDE double 출력 NTENS×NTENS 접선강성 \(\partial\Delta\sigma/\partial\Delta\varepsilon\). 호출 전 0으로 채움
    4 SSE double 입출력 1 단위 체적당 탄성 변형 에너지. Hyfeast가 저장해 다음 증분에 돌려준다(출력하지 않음)
    5 SPD double 입출력 1 단위 체적당 소성 소산. 저장 방식은 SSE와 같다
    6 SCD double 입출력 1 단위 체적당 크리프 소산. 저장 방식은 SSE와 같다
    7 RPL double 출력 1 사용하지 않음
    8 DDSDDT double 출력 NTENS 사용하지 않음
    9 DRPLDE double 출력 NTENS 사용하지 않음
    10 DRPLDT double 출력 1 사용하지 않음
    11 STRAN double 입력 NTENS 증분 시작 전체 변형률
    12 DSTRAN double 입력 NTENS 변형률 증분(열변형 포함 전체 변형률 증분)
    13 TIME double 입력 2 TIME(1) 증분 시작 step time, TIME(2) 증분 시작 total time
    14 DTIME double 입력 1 시간 증분(3.5절)
    15 TEMP double 입력 1 증분 시작 온도(해석 시작 이후 누적 온도 변화)
    16 DTEMP double 입력 1 온도 증분
    17 PREDEF double 입력 1 0
    18 DPRED double 입력 1 0
    19 CMNAME char 입력 81 재료 이름(3.2절)
    20 NDI int32 입력 1 직접 성분 수(3.4절)
    21 NSHR int32 입력 1 전단 성분 수
    22 NTENS int32 입력 1 전체 성분 수
    23 NSTATV int32 입력 1 NState 값
    24 PROPS double 입력 NPROPS 재료 물성
    25 NPROPS int32 입력 1 물성 개수
    26 COORDS double 입력 3 0
    27 DROT double 입력 3×3 단위행렬
    28 PNEWDT double 입출력 1 호출 전 \(10^{30}\). 1보다 작게 돌려주면 증분 축소 요청(3.6절)
    29 CELENT double 입력 1 요소 특성 길이(3.5절)
    30 DFGRD0 double 입력 3×3 단위행렬
    31 DFGRD1 double 입력 3×3 단위행렬
    32 NOEL int32 입력 1 0
    33 NPT int32 입력 1 0
    34 LAYER int32 입력 1 0
    35 KSPT int32 입력 1 0
    36 JSTEP int32 입력 4 0
    37 KINC int32 입력 1 0
    • 정수는 4바이트(int32_t, Fortran integer(c_int))다. Windows x64 Abaqus의 기본 INTEGER와 같다.
    • 입력 인자에 값을 써도 Hyfeast에는 영향이 없다. Hyfeast는 호출마다 새로 채운 버퍼를 넘긴다.
    • 함수는 값을 반환하지 않는다. 실패는 PNEWDT < 1로 알린다.

    C 선언(include/hfUserMaterialAPI.h):

    typedef int32_t hf_int;

  const double* stran, const double* dstran, const double* time, const double* dtime,
  const double* temp, const double* dtemp, const double* predef, const double* dpred,
  const char* cmname,
  const hf_int* ndi, const hf_int* nshr, const hf_int* ntens, const hf_int* nstatv,
  const double* props, const hf_int* nprops, const double* coords, const double* drot,
  double* pnewdt, const double* celent, const double* dfgrd0, const double* dfgrd1,
  const hf_int* noel, const hf_int* npt, const hf_int* layer, const hf_int* kspt,
  const hf_int* jstep, const hf_int* kinc);

HF_UMAT_EXPORT hf_int hf_umat_abi_version(void);

    3.4 조건별 성분

    Hyfeast는 요소 조건에 따라 다음 차원으로 부른다. 전단변형률은 공학 전단변형률(\(\gamma_{12}=2\varepsilon_{12}\))이다.

    조건 요소 NDI NSHR NTENS 성분 순서
    3D C3D4, C3D6, C3D8, C3D8I, C3D8PMDL, CS6, CS8 3 3 6 11, 22, 33, 12, 13, 23
    셸 S3, S3F, S4, S4F 3 3 6 11, 22, 33, 12, 13, 23
    평면변형, 축대칭 CPE3, CPE4, CAX3, CAX4 등 3 1 4 11, 22, 33, 12
    평면응력 CPS3, CPS4 등 2 1 3 11, 22, 12
    • 평면변형: DSTRAN(3)=0을 넘긴다. 돌려받은 STRESS(3)은 S33 출력에 쓰고, DDSDDE의 33 행과 열은 쓰지 않는다.
    • 평면응력: 플러그인이 \(\sigma_{33}=0\)을 만족시키고 축약된 3×3 DDSDDE를 돌려줘야 한다. 변형률 출력의 33 성분은 0이다.
    • 셸: 3D로 부른다. Hyfeast가 \(\sigma_{33}=0\)이 될 때까지 \(\varepsilon_{33}\) 증분을 뉴턴 반복으로 보정하며, 반복마다 증분 시작 상태에서 플러그인을 다시 부른다. 수렴하면 접선강성에서 33 성분을 소거한다. 횡전단(13, 23) 강성은 플러그인이 돌려준 값을 그대로 쓴다. 따라서 3D UMAT를 셸에 추가 입력 없이 쓸 수 있고, NTENS=3만 처리하는 셸 전용 Abaqus UMAT는 쓸 수 없다. 반복은 최대 20회이며, 수렴하지 않으면 증분을 줄인다.
    • 축대칭: 33 성분은 원주 방향이다.

    3.5 시간, 온도, 특성 길이

    인자 준정적·동해석 정적해석
    TIME(1) 증분 시작 step time 증분 시작 step time(하중계수)
    TIME(2) 증분 시작 total time 이전 스텝까지의 실시간 + TIME(1)
    DTIME 시간 증분 step time 증분
    • 시간 단위는 스텝의 해석 시간 단위(TUnit)다.
    • TEMP는 해석 시작 이후 누적된 온도 변화량이며 0에서 시작한다. 절대 온도가 필요하면 기준 온도를 PROPS에 넣는다.
    • DSTRAN은 전체 변형률 증분이다. 열팽창은 플러그인이 TEMP, DTEMP로 직접 처리한다.
    CELENT 요소
    \(\sqrt[3]{V}\) 3D solid(C3D4는 적분점별), 연속체 셸(CS6, CS8)
    \(\sqrt{A}\) 2D solid, 셸(S3, S3F, S4, S4F)

    해석 증분이 아닌 호출에서는 다음 값을 받는다.

    호출 TIME DTIME CELENT
    *TestMaterial 0, 0 0 1
    CS6, CS8의 방향성 필드 계산 0, 0 1 1

    3.6 호출 규칙

    • 상태: 평형 반복 중에는 매번 마지막 수렴 상태(STRESS, STATEV, STRAN, TEMP, 에너지)에서 호출하고, 채택된 증분의 결과만 확정한다. 플러그인은 입력 상태에서 DSTRAN만큼 갱신하면 된다.
    • 접선강성 대칭: Unsymm=No(default)이면 \((C+C^T)/2\)로 대칭화한다. Unsymm=Yes이면 그대로 쓰고 비대칭 강성행렬로 푼다.
    • 증분 축소: PNEWDT를 1보다 작게 돌려주면 현재 증분을 거부하고 Hyfeast 시간 제어기가 정한 비율로 증분을 줄여 다시 푼다. 돌려준 비율 자체는 쓰지 않는다. 1보다 큰 값은 무시한다.
    • 비유한값: STRESS, DDSDDE, STATEV, 에너지에 NaN이나 무한대가 있으면 실패로 보고 증분을 줄인다.
    • 동시 호출: 여러 적분점을 동시에(OpenMP) 계산한다. 플러그인은 재진입 가능해야 하며, 쓰기 가능한 전역·정적 변수를 쓰면 안 된다. Fortran은 /recursive로 빌드해 지역 배열이 스택에 놓이게 한다(build_umat.cmd가 지정한다). COMMON, SAVE 등으로 호출 사이에 값을 공유하는 기존 UMAT는 Thread=No를 지정한다(2.3절).
    • 출력: 결과 파일의 S는 STRESS, E는 누적 전체 변형률, MTEMP는 누적 온도 변화다. STATEV는 출력하지 않는다.
