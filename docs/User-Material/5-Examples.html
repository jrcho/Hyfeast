    5 예제

    C로 만든 탄성 플러그인과, Abaqus 형식으로 작성한 von Mises 소성 UMAT를 원본 그대로 빌드해 쓰는 두 경우를 따라 하고, 결과를 내장 재료와 비교한다. 입력 문법은 2장, 인자와 호출 규칙은 3장, 빌드 방법은 4장에 있다.

    이 장의 배포 폴더 예시는 D:\Apps\Hyfeast-v1.0.0이다. 경로는 실제 압축 해제 위치와 버전 이름에 맞춰 바꿔 쓴다.

    • 예제 폴더: D:\Apps\Hyfeast-v1.0.0\Examples\UMAT
    • 개발 키트 폴더: D:\Apps\Hyfeast-v1.0.0\Examples\UMAT\UserMaterial (1.3절)
    예제 폴더의 파일 내용
    build.bat 예제 플러그인 두 개를 이 폴더에 빌드한다
    run.bat 세 모델을 플러그인과 내장 재료로 각각 해석한다
    01-elastic-cantilever.inp C 탄성 플러그인, 외팔보
    02-plastic-cyclic.inp von Mises UMAT, 단일 요소 반복 하중
    03-plastic-cantilever.inp von Mises UMAT, 항복 이후까지 미는 외팔보

    5.1 플러그인 빌드

    플러그인은 Abaqus UMAT와 같은 인자 목록을 가진 함수 hf_umat_v1을 내보내는 DLL이다. C 플러그인은 Visual Studio C++ 컴파일러로, Fortran 플러그인과 Abaqus UMAT는 Intel Fortran(ifx)으로 빌드한다.

    예제 폴더의 build.bat을 실행하면 플러그인 두 개가 예제 폴더에 만들어진다. 탐색기에서 build.bat을 더블클릭하거나, 명령 창에서 다음을 입력한다.

    cd /d "D:\Apps\Hyfeast-v1.0.0\Examples\UMAT"
build.bat

    build.bat은 Visual Studio와 Intel Fortran을 자동으로 찾아 다음 두 명령을 실행한다. 직접 입력한다면 다음과 같다(C 빌드는 설치한 Visual Studio 또는 Build Tools의 x64 개발자 명령 프롬프트에서). 필요한 빌드 도구와 Fortran 컴파일러의 호환 조건은 4.1절을 따른다.

    cd /d "D:\Apps\Hyfeast-v1.0.0\Examples\UMAT"
cl /nologo /O2 /LD /I"D:\Apps\Hyfeast-v1.0.0\Examples\UMAT\UserMaterial\include" "D:\Apps\Hyfeast-v1.0.0\Examples\UMAT\UserMaterial\examples\NativeElasticC\hfUmatElasticC.c" /Fe"hfUmatElasticC.dll"
"D:\Apps\Hyfeast-v1.0.0\Examples\UMAT\UserMaterial\build_umat.cmd" abaqus umat_vonmises.dll "D:\Apps\Hyfeast-v1.0.0\Examples\UMAT\UserMaterial\examples\AbaqusPlasticUMAT\umat_vonmises.for"

    끝나면 예제 폴더에 hfUmatElasticC.dll과 umat_vonmises.dll이 생긴다.

    첫 명령은 C 소스를 DLL로 만든다. 소스는 공개 헤더 hfUserMaterialAPI.h를 포함하고 hf_umat_v1과 hf_umat_abi_version을 내보낸다.

    둘째 명령의 build_umat.cmd abaqus는 Abaqus UMAT 소스에 Hyfeast 브리지(hfAbaqusUmatBridge.f90)와 ABA_PARAM.INC를 더해 DLL을 만든다. umat_vonmises.for는 Abaqus에서 쓰는 형식 그대로의 SUBROUTINE UMAT이며, Hyfeast를 위해 고친 곳이 없다. Native Fortran으로 새로 작성할 때는 4.3절을 따른다.

    해석하려면 배포 폴더의 HyfeastCmd.bat을 실행한다. Bin이 실행 경로에 추가된 명령 창이 열리면 다음을 입력한다. 세 모델을 플러그인과 내장 재료로 각각 해석해 결과 파일(*.csv, *.hdb, *.log)을 예제 폴더에 만든다.

    cd /d "D:\Apps\Hyfeast-v1.0.0\Examples\UMAT"
run.bat

    run.bat은 명령 hfAnalyzer를 쓴다. 실행 환경의 자세한 설명은 3.1 hfAnalyzer 실행에 있다.

    5.2 C 탄성 플러그인

    C 플러그인의 본문은 Abaqus UMAT와 같은 일을 한다. DDSDDE를 채우고 STRESS를 갱신한다. 배열은 0부터 색인하며 DDSDDE(i,j)는 ddsdde[(i-1) + (j-1)*ntens]이다.

    void hf_umat_v1(double* stress, double* statev, double* ddsdde, /* ... Abaqus UMAT arguments ... */)
{
  const int n = *ntens;
  const double E = props[0], nu = props[1];
  /* fill ddsdde[i + j*n] for NDI = 3 or 2, then */
  for (i = 0; i < n; i++)
    for (j = 0; j < n; j++) stress[i] += ddsdde[i + j * n] * dstran[j];
}

    01-elastic-cantilever.inp는 2000×400×100 mm 외팔보 끝을 5 mm 내린다. 재료는 다음과 같이 정의한다.

    *Material, Type=User, Name=umatC
 hfUmatElasticC.dll, NProps=2
 200000., 0.3

    첫 데이터라인에 DLL 경로를 준다. 상대 경로는 입력 파일 폴더를 기준으로 찾는다. NProps=2는 PROPS 값 개수를 확인하는 선택 항목이다. 둘째 줄부터는 PROPS로 플러그인에 그대로 전달된다. 단면은 다른 재료와 같이 *Section, Type=Solid에서 이름으로 지정한다.

    hfAnalyzer 01-elastic-cantilever.inp -p "<M>=umatC"
hfAnalyzer 01-elastic-cantilever.inp -p "<M>=iso"

    <M>=iso는 같은 물성의 내장 IsoElasticity로 같은 모델을 해석한다. 두 결과의 끝단 반력은 모두 \(2.0365\times10^{5}\) N으로 같다.

    5.3 Abaqus UMAT: 반복 하중

    umat_vonmises.for는 선형 등방경화 von Mises 소성 모델이다. 반경 방향 복귀(radial return)로 응력을 갱신하고 일관 접선강성(consistent tangent)을 돌려준다.

    PROPS 의미 STATEV 의미
    1 \(E\) 1 등가소성변형률
    2 \(\nu\)
    3 초기 항복응력 \(\sigma_{y0}\)
    4 경화계수 \(H\) 
    *Material, Type=User, Name=umatVM
 umat_vonmises.dll, NState=1, NProps=4
 200000., 0.3, 250., 2000.

    NState는 UMAT가 쓰는 STATEV 개수이며 Abaqus의 *DEPVAR에 해당한다. 비교할 내장 재료는 같은 법칙의 vonMises(항복응력 250, \(H=2000\), \(\theta=1\) 등방경화)이다.

    02-plastic-cyclic.inp는 1 mm 정육면체 C3D8 요소 하나에 \(\varepsilon_{11}\)을 0 → 0.005 → −0.005 → 0으로 준다. 두 재료의 응력은 모든 증분에서 같다.

    \(\varepsilon_{11}\) 단계 \(\sigma_{11}\) (UMAT) [MPa] \(\sigma_{11}\) (vonMises) [MPa]
    0.0015 첫 항복 직후 250.50 250.50
    0.005 인장 최대 257.43 257.43
    0.002 하중 반전 후 재항복 −258.27 −258.27
    −0.005 압축 최대 −272.13 −272.13
    0 재반전 후 276.64 276.64

    5.4 Abaqus UMAT: 소성 외팔보

    03-plastic-cantilever.inp는 5.2절의 외팔보 끝을 50 mm까지 자동 증분으로 내린다. 반력은 끝단 변위 9.75 mm까지 선형이고, 그 뒤 고정단 쪽 적분점이 항복하면서 강성이 줄어든다.

    끝단 변위 [mm] 반력 (UMAT) [N] 반력 (vonMises) [N]
    2.5 \(1.0183\times10^{5}\) \(1.0183\times10^{5}\)
    9.75 \(3.9713\times10^{5}\) \(3.9713\times10^{5}\)
    19.75 \(5.8732\times10^{5}\) \(5.8732\times10^{5}\)
    32.25 \(6.5045\times10^{5}\) \(6.5045\times10^{5}\)
    50 \(6.9987\times10^{5}\) \(6.9987\times10^{5}\)

    두 해석 모두 22개 증분, 평형 반복 69회로 끝난다. UMAT가 돌려준 접선강성이 내장 재료와 같은 수렴을 보인다는 뜻이다.

    결과는 다른 재료와 같이 hfStudio에서 S, E 등고선으로 볼 수 있다. STATEV는 결과 파일에 출력되지 않는다.

    5.5 재료점 확인

    요소 해석 전에 *TestMaterial로 재료점 응답을 확인한다. 명령은 입력을 읽는 도중 실행되고 결과를 CSV로 쓴다(16.3 *TestMaterial).

    *TestMaterial, Mat=umatVM, File=umatVM-G.csv
 Type=G, Field=DSDE,E,S
 0.005, -0.0015, -0.0015, 0, 0, 0, N=10
 -0.005, 0.0015, 0.0015, 0, 0, 0, N=20

    Type=G는 3D 조건이며, 각 줄은 6개 변형률 성분의 목표값과 그 사이 분할 수 N이다. PE, AX, PS로 다른 조건을 확인할 수 있다. 데이터라인의 항목은 쉼표로 구분한다. 이 명령에서 플러그인은 TIME, DTIME을 0, CELENT를 1로 받으므로 시간이나 요소 크기에 의존하는 모델은 요소 해석으로 확인한다.

    5.6 직접 만든 UMAT를 쓸 때

    • 먼저 재료점에서 확인한다. *TestMaterial로 S, E, DSDE를 내장 재료나 손 계산과 비교한다(5.5절).
    • NState와 NProps를 Abaqus 입력에 맞춘다. *DEPVAR의 개수는 NState, *USER MATERIAL, CONSTANTS=n의 n은 NProps로 옮긴다.
    • 단위를 모델 단위계로 준다. PROPS는 단위 변환을 하지 않는다.
    • 전역 상태를 쓰는 UMAT는 Thread=No를 지정한다. COMMON, SAVE로 값을 공유하는 UMAT는 여러 적분점을 동시에 계산할 때 값이 섞인다(2.3절).
    • 비대칭 접선강성이면 Unsymm=Yes를 지정한다. 지정하지 않으면 \((C+C^T)/2\)로 대칭화한다.
    • 증분을 줄이려면 PNEWDT를 1보다 작게 돌려준다. Hyfeast는 현재 증분을 거부하고 증분을 줄여 다시 푼다.
    • 지원 요소를 확인한다. 3D solid, 셸(S3, S3F, S4, S4F), 연속체 셸(CS6, CS8), 2D solid를 지원한다. 셸은 3D UMAT를 그대로 쓴다. 보, 트러스, 스프링, 적층판, interface 요소는 지원하지 않는다.
    • DLL 경로는 절대 경로가 안전하다. 모델을 다른 폴더의 HDB로 저장해 실행하면 상대 경로의 기준이 HDB 폴더로 바뀐다.
