    V.18 Seepage Comparison with SEEP/W

    GeoStudio SEEP/W 2025.1의 예제와 검증 문제 네 가지를 Hyfeast로 재현하고 저장된 SEEP/W 결과와 비교한다. 원본 모델 파일과 추출한 비교 자료는 Example/V.18 Seepage Comparison with SEEPW/SeepW-Reference/에 있다.

    V.18.1 정상 흙댐

    높이 \(10\ \mathrm{m}\), 바닥폭 \(44\ \mathrm{m}\)인 사다리꼴 흙댐의 2차원 정상 침투 문제다. 모델 좌표 범위는 \(3\le x\le47\ \mathrm{m}\), \(0\le y\le10\ \mathrm{m}\)이다. 상류 저수위는 전수두 \(H=8\ \mathrm{m}\)로 유지하고, 하류 사면은 잠재 침투면, 하류 선단은 \(H=0\)으로 둔다. 같은 형상에서 네 구성을 비교한다.

    Table V.18.1 Earth Dam Cases

    구성 추가 영역 요소 / 활성 절점
    Homogeneous 없음 501 / 540
    Toe underdrain 하류 선단의 포화 배수재 511 / 554
    Core 10x less 투수계수가 성토의 1/10인 코어와 배수재 511 / 554
    Core 100x less 투수계수가 성토의 1/100인 코어와 배수재 511 / 554

    Figure V.18.1 Earth Dam Mesh and Section Regions

    일반 성토의 포화 투수계수는 \(K_s=1.0\times10^{-5}\ \mathrm{m/s}\), 코어는 각각 \(1.0\times10^{-6}\)과 \(1.0\times10^{-7}\ \mathrm{m/s}\)이며, 배수재는 포화 전용 재료로 \(K_s=1\ \mathrm{m/s}\)를 사용한다. 물의 단위중량은 \(\gamma_w=9.807\ \mathrm{kN/m^3}\)이다. 불포화 투수곡선은 SEEP/W의 20점 표를 다음 van Genuchten-Mualem 매개변수로 근사했으며, 표 점에서 근사의 최대 상대오차는 0.71%다.

    \[ a=0.06978534784\ \mathrm{kPa^{-1}},\quad n=2.138679612,\quad m=0.532421783,\quad l=0.461295978 \]

    요소망은 SEEP/W의 절점 번호와 요소 연결을 그대로 옮겨 절점별 값을 보간 없이 비교한다. 절점 압력, 압력이 0인 침윤선의 위치, 정상 배수량을 비교한다. 압력 NRMSE는 절점 압력 차이의 제곱평균제곱근을 상류 수두에 해당하는 \(78.456\ \mathrm{kPa}\)로 나눈 값이며, 통과 기준은 압력 NRMSE 1%와 유량 상대오차 5%다.

    Table V.18.2 Earth Dam Comparison Results

    구성 압력 NRMSE 침윤선 최대 차이 유량 상대오차
    Homogeneous 0.0015% \(0.001315\ \mathrm{m}\) 0.0079%
    Toe underdrain 0.0068% \(0.005384\ \mathrm{m}\) 0.0289%
    Core 10x less 0.0027% \(0.001564\ \mathrm{m}\) 0.0021%
    Core 100x less 0.0110% \(0.000750\ \mathrm{m}\) 0.0004%

    Figure V.18.2 Pore Pressure p [kPa] of the Four Earth Dam Cases

    네 구성 모두 기준을 통과한다. 다만 재료는 SEEP/W의 표 함수 그대로가 아니라 위 VGM 근사이므로, 이 결과는 근사 재료 조건에서의 일치다. SEEP/W 추출값과 절점별 비교표는 SeepW-Reference/reference-data/steady-earth-dam/에 있다.

    Input File
    • seepw-earth-dam-homogeneous.inp : Homogeneous
    • seepw-earth-dam-toe-underdrain.inp : Toe underdrain
    • seepw-earth-dam-core-10x-less.inp : Core 10x less
    • seepw-earth-dam-core-100x-less.inp : Core 100x less

    V.18.2 건조토 과도 침투

    높이 \(1\ \mathrm{m}\)인 매우 건조한 토주에 위쪽부터 물이 침투하는 문제다. 초기 간극수압은 전체에서 \(-78.48\ \mathrm{kPa}\)이고, 과도해석이 시작되면 상단 압력을 0으로 올리되 하단 압력수두는 \(-8\ \mathrm{m}\)로 유지한다. 시간에 따라 습윤 전선이 아래로 내려간다.

    SEEP/W 원형은 101절점, 100개 1차원 선요소다. Hyfeast에는 1차원 침투 요소가 없으므로 폭 \(0.01\ \mathrm{m}\), 높이 \(1\ \mathrm{m}\)의 2차원 띠를 높이 방향으로 100개의 SC2D4 요소로 나누고 좌우 측면은 무유량으로 둔다. 좌우 대응 절점의 압력이 같은지 확인하여 2차원 변환이 결과에 영향을 주지 않음을 점검한다.

    포화 투수계수는 \(K_s=1.0\times10^{-6}\ \mathrm{m/s}\), 비저류계수는 \(S_s=9.97788\times10^{-5}\ \mathrm{m^{-1}}\)이다. 함수비 곡선과 상대 투수곡선은 SEEP/W의 20점 표를 User 재료로 지정하며, 상대 투수곡선은 log-log 공간에서 형상을 보존하는 3차 보간(DataCurve)을 사용한다. 시간증분은 \(468\ \mathrm{s}\)이고 100 증분으로 총 \(46{,}800\ \mathrm{s}\)를 해석하며, 시간 단위는 TUnit=s다.

    최종 압력 분포, \(p=-39.24\ \mathrm{kPa}\)가 되는 습윤 전선 표고, 상단 단위면적 유량을 비교한다. 통과 기준은 압력 NRMSE 1%, 습윤 전선 차이 \(0.01\ \mathrm{m}\), 유량 상대오차 5%다.

    Table V.18.3 Dry-Soil Infiltration Results

    비교량 SEEP/W Hyfeast 차이
    압력 NRMSE 0.478%
    습윤 전선 표고 \(0.371589\ \mathrm{m}\) \(0.372475\ \mathrm{m}\) \(0.000886\ \mathrm{m}\)
    최종 상단 단위 유량 \(1.02112\times10^{-6}\ \mathrm{m/s}\) \(1.02162\times10^{-6}\ \mathrm{m/s}\) 0.049%

    Figure V.18.3 Final Pressure Profile of the Dry-Soil Infiltration

    세 기준을 모두 통과한다. 1차원 문제를 2차원 띠로 바꾼 비교라는 점에 유의한다. SEEP/W 추출값과 깊이별 비교표는 SeepW-Reference/reference-data/transient-dry-soil-user/에 있다.

    Input File
    • seepw-transient-dry-soil-infiltration.inp

    V.18.3 급강하

    저수위 \(H=8\ \mathrm{m}\)인 흙댐을 먼저 정상해석하고 그 압력장을 과도해석의 초기 상태로 사용한다. 모델 좌표 범위는 \(3\le x\le50\ \mathrm{m}\), \(-1\le y\le10\ \mathrm{m}\)이며 553개 절점을 사용한다. 일반 성토의 포화 투수계수는 \(1.0\times10^{-6}\ \mathrm{m/s}\), 선단 배수재는 \(1.157\times10^{-5}\ \mathrm{m/s}\), 비저류계수는 \(S_s=9.82583\times10^{-4}\ \mathrm{m^{-1}}\)이다. 함수비와 상대 투수계수는 SEEP/W 표를 User 재료로 지정한다. 모든 과도 step은 SEEP/W와 같은 TUnit=day를 사용한다.

    순간 강하. 정상해 직후 상류 수두 하중을 제거한다. 상류 사면에는 잠재 침투면을 적용하고 상류 선단과 배수재의 전수두는 0으로 둔다. 0.25일부터 30일까지 저장된 10개 시각의 압력장을 비교한다.

    완속 강하. 저수위를 5일 동안 \(8\ \mathrm{m}\)에서 0까지 선형으로 낮춘다. 수위가 상류 사면 절점의 표고보다 낮아지면 그 절점의 수두 하중을 해제하고 잠재 침투면 후보로 바꾼다. 두 방식으로 입력을 만들었다.

    • 단계별 경계: 17개 절점 통과 시각과 10개 저장 시각을 합친 27개 step으로 나누고, 각 step에서 노출된 절점을 직접 잠재 침투면으로 바꾼다. 각 step의 종료 시각은 Given으로 지정하고 같은 시각만 OutTime으로 저장한다.
    • SeepageWaterLevel: 시간함수로 수위를 연속적으로 낮추는 transient step 하나로 나타낸다. Given에 27개 경계 절점 통과 시각을 넣어 경계 변화 시각을 정확히 해석하고, OutTime에는 비교 시각 10개만 둔다.

    비선형 반복의 허용치는 SEEP/W의 최대 압력수두 차이 \(0.005\ \mathrm{m}\)를 압력으로 환산한 \(\Delta p=\gamma_w\Delta h=0.049035\ \mathrm{kPa}\)를 사용한다. 통과 기준은 저장 시각마다 압력 NRMSE 1%다.

    Table V.18.4 Rapid Drawdown Results

    시나리오 최대 압력 NRMSE 최대 절점 압력 차이
    순간 강하 0.183% \(0.46510\ \mathrm{kPa}\)
    완속 강하, 단계별 경계 0.188% \(0.49296\ \mathrm{kPa}\)
    완속 강하, SeepageWaterLevel 0.188% \(0.49296\ \mathrm{kPa}\)

    Figure V.18.4 Pore Pressure p [kPa] during the Instantaneous Drawdown

    세 시나리오의 저장 시각 10개가 모두 기준을 통과한다. SeepageWaterLevel 입력은 단계별 경계 입력과 같은 정확도를 step 하나로 재현한다. SEEP/W 추출값과 시각별 비교표는 SeepW-Reference/reference-data/rapid-drawdown/에 있다.

    Input File
    • seepw-rapid-drawdown-instantaneous.inp : 순간 강하
    • seepw-rapid-drawdown-slow.inp : 완속 강하, 27개 step의 단계별 경계
    • seepw-rapid-drawdown-slow-water-level.inp : 완속 강하, SeepageWaterLevel

    V.18.4 축대칭 양수정

    SEEP/W 2025.1의 검증 문제 "Radial flow to a well"이다. 360도 축대칭 포화 대수층의 과도 양수 문제로, 계산 영역은 \(0.15\le r\le40\ \mathrm{m}\), \(0\le z\le5\ \mathrm{m}\)이다. 반지름 좌표 81개와 표고 좌표 11개로 이루어진 891절점, 800개 사각형 요소망을 SCAX4 요소로 그대로 옮겼다.

    포화 투수계수는 \(k=0.002\ \mathrm{m/s}\), 물의 단위중량은 \(\gamma_w=9.807\ \mathrm{kN/m^3}\)이다. 원본의 체적압축계수 \(m_v=0.001\ \mathrm{kPa^{-1}}\)를 환산한 비저류계수는 \(S_s=m_v\gamma_w=0.009807\ \mathrm{m^{-1}}\)이며, 공식 문서의 \(S_s=0.01\ \mathrm{m^{-1}}\)는 이를 반올림한 값이다. 전체 영역을 \(H_0=16\ \mathrm{m}\)로 정상 초기화한 뒤 과도 step에서 바깥 경계 \(r=40\ \mathrm{m}\)를 \(H=16\ \mathrm{m}\)로 유지하고 우물 면 \(r_w=0.15\ \mathrm{m}\)에 \(q=-0.025\ \mathrm{m/s}\)를 적용한다. 총 양수량은 다음과 같다.

    \[ Q=2\pi r_w b\,|q|=0.117810\ \mathrm{m^3/s} \]

    SEEP/W 저장 시각과 같은 10, 26, 48, 83, 135, 214, 334, 514, 788, 1200초를 Given으로 해석한다. \(r=4\ \mathrm{m}\), \(z=2.5\ \mathrm{m}\)의 전수두를 SEEP/W 저장값과 직접 비교하고, 우물 면 등가 절점유량의 합과 그 시간적분을 \(Q\)와 \(Qt\)에 견주어 \(2\pi r\,ds\) 표면 적분을 확인한다. 무한 대수층의 Theis 해도 보조 기준으로 사용한다.

    \[ H(r,t)=H_0-\frac{Q}{4\pi T}E_1\!\left(\frac{r^2S}{4Tt}\right),\qquad T=kb,\quad S=S_sb \]

    Table V.18.5 Pumping Well Results

    비교량 기준 최대 차이
    \(r=4\ \mathrm{m}\) 전수두 SEEP/W \(0.001328\ \mathrm{m}\)
    우물 면 유량 합 \(Q\) 상대차 \(2.17\times10^{-6}\)
    누적 양수량 \(Qt\) 상대차 \(2.17\times10^{-6}\)
    \(r=4\ \mathrm{m}\) 전수두 Theis 해, \(S=0.049035\) \(0.10124\ \mathrm{m}\)

    Figure V.18.5 Total Head H [m] of the Pumping Well at t = 1200 s

    Figure V.18.6 Total Head at r = 4 m Compared with SEEP/W and the Theis Solution

    SEEP/W와의 수두 차이는 요소망과 저장 시각이 같으므로 주로 두 프로그램의 시간적분 방식 차이를 반영한다. Theis 해와의 차이에는 반지름 \(40\ \mathrm{m}\)의 고정수두 바깥 경계와 시간·공간 이산화가 함께 들어 있다. SEEP/W 추출값은 SeepW-Reference/reference-data/axisymmetric-pumping-well/에 있다.

    Input File
    • seepw-axisymmetric-pumping-well-scax4.inp
