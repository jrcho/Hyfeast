    2.7 Mesh Generation

    2.7.1 Background

    • Domain meshing in hf2DStudio uses built-in TFI and the external Netgen module together.
    • TFI (Transfinite Interpolation) works on a 4-side patch. The face boundary must be organized into four side chains, and the opposite side chains must have matching seed/sample counts. When this succeeds, TFI generates Q4 or Q8 elements directly, depending on the current mesh order.
    • Netgen is an external 2D mesher. Its natural result is triangular meshing. Depending on the mesh options, the generated triangles can later be merged into a quad-dominated mesh.
    • In practice, the automatic mesher tries to obtain clean Q4 meshing with TFI when possible, and otherwise falls back to Netgen.

    2.7.2 Use TFI If Possible

    When Settings > Mesh Generation Option > Use TFI if possible (Generate Q4 elements if possible) is enabled, Auto Mesh first tries to build a TFI boundary plan for each face before falling back to Netgen.

    The current algorithm is:

    1. The face must have one outer loop and at least 4 curves.
    2. If the face already has Quad Mesh Corner Hints, the mesher uses those four outer-loop join points first. The internal side chains are ordered along the outer loop.
    3. If there are no hints, the mesher tries automatic corner detection. It evaluates the turning angle at each outer-loop join. Large positive turns (>= 30 deg) are treated as hard corners, and the other joins must stay nearly smooth (|angle| <= 15 deg).
    4. If there are no hints and the loop has 16 curves or fewer, the mesher also checks candidate combinations of four outer-loop join points.
    5. Once candidate corners are available, the boundary is divided into four side chains. One logical side may contain several connected curves.
    6. Each side chain is sampled with seedPoints() regardless of curve type, so lines, arcs, bezier curves, and splines all follow the same interval matching rule.
    7. If the opposite side chains have matching interval counts and the resulting TFI grid cells are valid, built-in TFI is used and quad elements are generated with the current mesh order.
    8. If there is not exactly one valid candidate, or if any check fails, the face falls back to Netgen.

    So Use TFI if possible does not force TFI at all costs. It means "try TFI first, and if the face is not a valid TFI patch, continue with Netgen".

    2.7.3 Auto Seed And TFI Interval Correction

    Geometry > Auto seed and Remote Control auto-seed first run a rough seed pass that matches the selected curves by max-H. They then conservatively try TFI interval correction where possible.

    • Correction applies only to hole-free single-outer-loop faces whose outer-loop curves are all included in the current Auto Seed target set.
    • If the face has Quad Mesh Corner Hints, the hint plan is used first. Automatic corner candidates are used only when there are no hints.
    • Correction only increases seeds on deficient sides. The per-face budget is min(4, max(1, ceil(totalSideIntervals * 0.20))).
    • Seed changes are accepted only when exactly one valid TFI candidate remains after correction. If there are no valid candidates or multiple candidates, the rough seeds are kept.

    Mesh generation itself does not change seeds. Auto Mesh and make-mesh build read the stored seeds and Quad Mesh Corner Hints, then choose either TFI or Netgen.

    2.7.4 Enable Quadrilateral-Dominated Meshing

    When Settings > Mesh Generation Option > Enable quadrilateral-dominated meshing (Convert T3 to Q4 if possible) is enabled, the Netgen path requests a quad-dominated result instead of a purely triangular one.

    • This option affects faces that are meshed by Netgen.
    • Netgen still starts from a triangle-oriented 2D mesher, so the result is not guaranteed to be all Q4.
    • When the boundary and local topology allow it, Netgen merges suitable T3 regions into quadrilateral elements and leaves the remaining parts as triangles.
    • If built-in TFI succeeds first, that face already receives direct Q4 elements from TFI, so this option mainly matters on fallback faces or when TFI is disabled.

    This option is best understood as "prefer more quads in the Netgen result", not as "force every face to become a pure quad mesh".

    2.7.5 Why Corner Hints Are Useful

    Automatic corner detection is not always enough. Typical difficult cases are:

    • one logical side is split into several connected curves
    • rounded or smooth corners make the boundary look less explicit
    • the shape is visually quadrilateral, but the automatic detector cannot identify four reliable corners

    Quad Mesh Corner Hints are face-level guidance for those cases. They let you keep the normal Auto Mesh workflow while telling the mesher which four outer-loop points should be treated as the TFI corners.

    2.7.6 What A Hint Stores

    A Quad Mesh Corner Hint is a set of four point ids stored on one face.

    • the four points must be distinct
    • all four points must be outer-loop join points of the same face
    • the entered order affects only the stored hint marker numbers; the actual side chains are ordered along the outer loop

    Internally, the hint is stored as point ids, not as temporary picked coordinates.

    2.7.7 How To Enter Hints

    You can edit or clear hints when exactly one face is selected in the editable left view:

    • Geometry > Quad Mesh Corner Hints...
    • Geometry > Clear Quad Mesh Corner Hints
    • Geometry toolbar buttons
    • Model Tree face context menu
    • Section view face context menu

    Open Quad Mesh Corner Hints... to start one editing session for the selected face.

    • type p1, p2, p3, p4 in the single input field, or click corners directly in the view
    • Apply validates the hint and closes the dialog on success
    • Close closes the session without applying pending changes
    • Backspace removes the last picked corner while picking is active
    • Esc cancels the picking session

    2.7.8 Visual Feedback

    Faces with stored hints are shown with a lightweight overlay in the section view:

    • numbered corner markers 1..4
    • a dashed polygon that connects the stored corners

    The visibility of this stored overlay can be controlled from:

    • Settings > Display Geometric Entity > Quad Mesh Corner Hints

    During active editing, the target face still shows pending corners and hover feedback for the next selectable join point.

    2.7.9 Practical Workflow

    The recommended workflow is:

    1. Enable Use TFI if possible (Generate Q4 elements if possible) when you want TFI-based Q4 meshing.
    2. Enable Enable quadrilateral-dominated meshing (Convert T3 to Q4 if possible) when you also want the Netgen fallback to prefer more quadrilateral elements.
    3. Run Auto seed on the full boundary curve set of each face intended for TFI.
    4. Run Auto Mesh or make-mesh build.
    5. If a face still falls back to Netgen, or the result is not the intended quad patch, add Quad Mesh Corner Hints to that face and mesh again.

    This keeps the normal workflow simple and uses hints only on faces where automatic interpretation is ambiguous.
