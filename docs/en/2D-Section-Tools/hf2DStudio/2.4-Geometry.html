    2.4 Geometry

    The hf2DStudio Geometry menu and Geometry toolbar draw section outlines, edit points, build faces and rebars, and adjust mesh seeds.

    For automation, see Remote Control Geometry. The ortho and snap toggles live in the RC View command set.

    2.4.1 Editable preconditions

    Geometry create/edit commands require an editable geometry section. In the GUI, commands that invalidate an existing mesh ask whether to cancel the current mesh at commit time; choosing No cancels that edit and keeps the mesh. In Remote Control, delete the mesh first with make-mesh delete.

    2.4.2 Drawing aids

    • Ortho mode (F3) — constrain mouse drawing to axis-aligned segments. RC: ortho-mode <on|off>.
    • Snap to geometry (F4) — snap to existing geometry. RC: snap-to-geometry <on|off>.
    • Snap to grid (F5) — snap to the grid. RC: snap-to-grid <on|off>.

    The two snaps are independent and can be on at the same time. When both are on, geometry snap takes precedence over grid snap.

    2.4.3 Point and line drawing

    In the GUI, toggle the drawing mode on the toolbar/menu and then click coordinates. In Remote Control, pass coordinates as arguments directly.

    • Drawing Points: RC: draw-point <yp,zp>
    • Drawing Lines: RC: draw-lines <yp,zp|P<id>> <yp,zp|P<id>> ...
    • Drawing Arc: start/middle/end. RC: draw-arc <p1> <p2> <p3>.
    • Drawing Bezier2: quadratic. RC: draw-bezier2 <p1> <p2> <p3>.
    • Drawing Bezier3: cubic. RC: draw-bezier3 <p1> <p2> <p3> <p4>.
    • Drawing RBezier2: rational quadratic. RC: draw-rbezier2 <p1> <p2> <p3> --weights <w1>.
    • Drawing RBezier3: rational cubic. RC: draw-rbezier3 <p1> <p2> <p3> <p4> --weights <w1,w2>.
    • Drawing Spline: repeat the first point at the end to close. RC: draw-spline <p1> <p2> <p3> [...].

    Coordinates use the yp,zp form. Quote tokens with negative coordinates (e.g., "-25,10").

    The GUI coordinate input box also accepts CAD-style typed coordinates:

    • yp,zp: absolute section coordinates. Each component may be a math expression.
    • @dyp,dzp: relative coordinates from the current base point. Each offset may be a math expression.
    • @L<A: relative polar coordinates from the current base point. L may be a math expression. A is a signed degree number only.

    For point drawing, the current base point is the latest committed point. For line and curve drawing, a base point exists only after the first point of the current construction has been fixed, and the latest fixed point in that construction is used. During Pencil point modification, it is the selected point's original position. If no base point exists, relative input is rejected. Math expressions keep the existing parser rule: trigonometric functions use radians. The polar angle A is not a math expression and is interpreted in degrees, positive from +yp toward +zp.

    2.4.4 Shape generators

    • Generate Circle: closed circle of four rational quadratic bezier segments. RC: generate-circle <radius> <yp> <zp>.
    • Generate Circular Points: only points on the circle. RC: generate-circular-points <radius> <yp> <zp> <start-angle-deg> <count>.

    2.4.5 Point editing

    • Pencil (Modify): modify one picked point at a time. If coincident points are under the cursor, choose the point id to edit. RC: move-point <id> <yp,zp> [--merge <on|off>].
    • Move Selection: move the current point/curve/face/rebar selection by picking a base point and destination point. The two clicks define only the offset; the moved point ids come from the current selection, so coincident but unselected point ids stay put. GUI recording writes one move-point command for each affected point instead of a separate move-selection command.
    • Copy Selection: copy the current point/curve/face/rebar selection by picking a base point and destination point. GUI recording writes the required select commands first, then copy-selection --offset <yp,zp>.
    • Merge Coincident Points: merge selected points sharing the same coordinate into one topology point. RC: merge-selected-points.
    • Detach Selected Points: split selected points shared by multiple curves. Face-referenced split candidates fail the command; rebar-referenced points are blocked. RC: detach-selected-points.

    move-point --merge on explicitly connects the moved point to the existing topology at the destination. --merge off (default) only moves the coordinate.

    When a GUI edit deletes an existing mesh, Remote History records make-mesh delete before the geometry edit command. If the user chooses No, no edit command is recorded.

    2.4.6 Selection

    • Select All: all-kinds selection mode (toggle). In RC, use select <kind> ... --mode replace per kind.
    • Select Point: point selection mode (toggle). RC: select point <id,...>.
    • Select Wire: curve selection mode (toggle). RC: select curve <id,...>.

    RC select takes the kind (point|curve|face|rebar) and ids directly, with --mode <replace|add|remove|toggle> for combination.

    Bulk delete of the current selection: delete-selection. Faces and rebars are deleted immediately; referenced curves/points stay selected.

    Direct id-based delete (without selecting first):

    • delete-point <id,...> — points unreferenced by curves/rebars only; blocked ids reported as blockedIds
    • delete-curve <id,...> — curves unreferenced by faces only
    • delete-face <id,...>
    • delete-rebar <id,...>

    2.4.7 Mesh seeds

    • Edit seed: set the seed of selected curves manually. RC: set-seed --curve-ids <id,...> --seed <integer>.
    • Auto seed: compute rough seeds from the curves' max-H values, then apply conservative TFI interval correction where possible. RC: auto-seed --curve-ids <id,...>.

    auto-seed produces the same result as the GUI Auto Seed button.

    2.4.8 Face and rebar

    • Make Face: resolve closed regions from selected curves and create faces. RC: make-face --material <name> --curve-ids <id,...>.
    • Make Rebar: place rebars at selected points. RC: make-rebar --material <name> --point-ids <id,...> --diameter <value>.

    make-face creates one face directly when the requested curves form an exact face; otherwise it resolves bounded cells and creates a face per cell. Faces that already exist for the resolved curve set are skipped.

    2.4.9 Quad Mesh Corner Hints

    Hint how the quad mesh recognizes face corners.

    • Quad Mesh Corner Hints (Edit) — open the hint editor dialog
    • Pick Quad Mesh Corner Hints: pick hint points with the mouse
    • Clear Quad Mesh Corner Hints: clear all hints from the selected face

    There is no separate RC command for the hints themselves. Mesh generation in Operation > Make Linear/Quadratic Mesh uses the hints automatically. When hints exist, both auto-seed interval correction and mesh generation use them before automatic corner inference.

    2.4.10 Renumber (geometric entities)

    Reassign sequential ids starting from 1 to the active section's points/curves/faces/rebars. External references to old ids become invalid; subsequent steps must look up the new ids.

    Automation: renumber.
