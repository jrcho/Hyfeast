    2.5 Definition

    The hf2DStudio Definition menu opens the environment (unit system), function, material, section, and section-analysis editors, plus the Section Wizard.

    For automation, see Remote Control Definition.

    2.5.1 Menu layout

    • Environment: unit system editor (Command dock). RC: environment-unit-system get|set <text>.
    • Edit function: Function editor (Command dock). RC: function <type> <name> ....
    • Edit material: Material editor (Command dock). RC: material <type> <name> ....
    • Edit section: Section editor (Command dock). RC: section <name> ....
    • Edit section analysis: Analysis editor (Command dock). RC: analysis <name> --section <name> ....
    • Section Wizard: standard-section generator dialog (H/T/C/L/2C/2L/HR). RC: template-mesh <H|T|C|2C|L|2L|HR> <name> ....

    GUI Apply records the same canonical Remote Control tail into history and *.ipc.txt.

    2.5.2 Common content rules

    Definition commands that edit block text (function, material, section, analysis) all use the same body syntax as GUI Apply.

    • Remote Control accepts either --content <text> or --content-file <file>.
    • Inside --content, line breaks are written \n. \\n is preserved as a literal.
    • Empty bodies are rejected.
    • On success, the section model is updated immediately and marked modified.

    2.5.3 Environment (Unit System)

    • force-length-time-temp 4-field token: N-m-s-K, kN-cm-s-K, N-mm-s-Celsius, ... Sets the section unit system.
    • none: clears the section unit system.

    Automation: environment-unit-system get / set <token|none>. Apply in the Command dock's Environment editor produces the same result.

    2.5.4 Function

    Creates or updates one *Function, TYPE=<type>, Name=<name> definition.

    Concrete-DB envelope inputs use the same command form, but the allowed standards depend on the function type. For example, a MaekawaTEnv body can be KDS-2026-C30, ACI318-2025-C4000, EC2-2004-C30, or those forms with a trailing , ToDirectForm. ParabolaCEnv is section-analysis input, accepts only the KDS/EC2 family, and may include alpha before ToDirectForm. For HognestadCEnv, EC2CEnv, and MPPCEnv, put EciCurve before ToDirectForm when the original initial curve is required. DB function bodies do not include a local UnitSystem=... keyword.

    ConcreteTime is available in the Function editor. Its Builder provides a Direct mode for the User named-group form and a Standard mode for EC2-2004-C..., KDS-2026-C..., and ACI209-1992-C... datalines. The user-defined form only references existing functions. Standard datalines require the section global UnitSystem to be defined first, and Type=ConcreteTime does not use a local UnitSystem=... keyword.

    Automation: function <type> <name> --content ....

    2.5.5 Material

    Creates or updates one *Material, TYPE=<type>, Name=<name> definition.

    Extra options:

    • --neg-stop-strain <value>, --pos-stop-strain <value>: override stop strain after the material body is applied.
    • --signal <text> or --signal-file <file>: append a section-signal definition to the same material (mutually exclusive).

    Automation: material <type> <name> --content ... [--signal ...].

    2.5.6 Section

    Creates or updates one *Section, Name=<name> definition.

    Extra options:

    • --taper <on|off>: section taper attribute. Omit to keep the current state.
    • Switching to --taper on lets subsequent geometry manage left/right sides independently.

    Automation: section <name> --content ... [--taper <on|off>].

    2.5.7 Analysis

    Creates or updates one *Analysis, Name=<name> definition. --section <name> is required.

    Extra options:

    • --right <on|off>: in a taper section, use the right-side geometry as the analysis target (default off).
    • --ref <angle,yp,zp>: rotation angle (deg) and origin of the analysis reference coordinate system.
    • --output <Preselect|All>: result-item scope (default Preselect).

    Automation: analysis <name> --section <name> --content ....

    2.5.8 Section Wizard (Template Mesh)

    Generate a mesh-only standard section (H, T, C, 2C, L, 2L, HR) from dimension inputs.

    • Does not create section geometry. Removes any existing geometry of the same name.
    • <H|T|C|2C|L|2L>: --B1, --tw, --tf1 required. --B2 defaults to --B1; --tf2 defaults to --tf1.
    • HR: --B (outer width), --t (wall thickness), --r (inner corner radius) required.
    • The generated mesh uses Q8 quad cells, T6 quarter-fillet cells, and HR annular-corner Q8 cells where applicable.
    • Section constants are computed immediately after mesh generation.

    Automation: template-mesh <type> <name> --material <name> --H <value> ....
