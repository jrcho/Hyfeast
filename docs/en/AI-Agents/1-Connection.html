    1. Connection

    You can ask an AI agent such as Claude Code, Codex, or the Claude desktop app in plain words, for example "analyze frame.inp and save the Case3 displacement contour as an image" or "make a 300x500 rectangular section and put it into the hfStudio model", and let the agent operate a running hfStudio and hf2DStudio directly. The connection uses the MCP (Model Context Protocol) server hyfeast-mcp. The server turns agent requests into Remote Control commands and passes them to hfStudio.com --remote and hf2DStudio.com --remote.

                                      ┌→ hfStudio.com --remote   → running hfStudio
Claude Code / Codex → hyfeast-mcp ┤
                                  └→ hf2DStudio.com --remote → running hf2DStudio

    The agent does not need to know the Remote Control syntax. The server handles command order, paths, and error interpretation, and one tool moves sections, guides, and 2D meshes built in hf2DStudio into the hfStudio model. Every result lists the executed commands, including the application and the target instance (--target), so the same work can be repeated in PowerShell or moved into a script.

    1.1 Preparation

    The server is at Bin\mcp\hyfeast-mcp.exe inside the distribution folder obtained by extracting the ZIP. No Python installation or extra setup is needed.

    • The exe finds hfStudio.com and hf2DStudio.com in the Bin folder one level up. Do not move the Bin\mcp folder elsewhere.
    • An agent program (Claude Code, Codex, the ChatGPT desktop app, or the Claude desktop app) must be installed.
    • The example distribution folder in this section is D:\Apps\Hyfeast-v1.0.0. Change executable paths and paths in JSON settings to match your actual extraction location and version name. Update registered paths when moving the distribution folder or using a new version folder.

    How to register and check depends on where you use the agent. Follow only the row for your environment.

    Environment Programs and screens Register Check
    Coding agent The Codex mode of the ChatGPT desktop app, the Code tab of the Claude desktop app, the VS Code extensions Ask the agent (section 1.3) Ask the agent (section 1.7.1)
    Command prompt Claude Code CLI, Codex CLI claude mcp add (section 1.4), codex mcp add (section 1.5) claude mcp list, codex mcp list (section 1.7.1)
    Chat The chat of the Claude desktop app Edit the configuration file (section 1.6) Settings > Developer in the app
    • If you are not sure which to use, the coding agent way is the easiest.
    • In the ChatGPT desktop app, use the Codex mode.

    1.2 Settings

    Usually nothing needs to be set. To change a default, add it as an environment variable (env) in the agent registration (sections 1.4 to 1.6).

    Variable Meaning
    HYFEAST_WORKDIR Base folder for relative paths. When omitted, the folder where the agent started the server (usually the working folder).
    HYFEAST_ANALYSIS_WAIT_TIMEOUT_MS Maximum wait for an analysis to finish (default 600000). When exceeded, only the waiting stops; the analysis keeps running.
    HYFEAST_HFSTUDIO_CLI Path to hfStudio.com. Set it only if hyfeast-mcp.exe was moved out of Bin\mcp. A .exe path is reported as a configuration error.
    HYFEAST_HF2DSTUDIO_CLI Path to hf2DStudio.com. When omitted, hf2DStudio.com in the same folder as hfStudio.com is used.
    HYFEAST_MCP_LOG_FILE File path for the server log. Useful when reporting a problem.

    At startup the server runs --version of both .com clients once to check the settings. If one fails, the server still starts, and only that application's tools return configuration_error with the reason.

    1.3 Ask the agent to register it

    A coding agent that can run commands (the Codex mode of the ChatGPT desktop app, the Code tab of the Claude desktop app, the VS Code extensions, and so on) registers the server when you ask. It is the easiest way, because you do not need a command prompt or a configuration file.

    Register D:\Apps\Hyfeast-v1.0.0\Bin\mcp\hyfeast-mcp.exe as an MCP server named hyfeast.
    • Open a new session (conversation) after registering to see the HYFEAST tools.
    • If hyfeast is already registered with another path, the agent changes it to the new path. How to check is in section 1.7.1.
    • Chat modes cannot run commands, so this does not work there. For the chat of the Claude desktop app, follow section 1.6.

    1.4 Register with Claude Code (command prompt)

    Put .mcp.json in the working folder where you open Claude Code.

    {
  "mcpServers": {
    "hyfeast": {
      "type": "stdio",
      "command": "D:\\Apps\\Hyfeast-v1.0.0\\Bin\\mcp\\hyfeast-mcp.exe"
    }
  }
}

    To use it in every working folder, register it once with the following command instead of .mcp.json. The commands in this section are the same in PowerShell and cmd (Command Prompt).

    claude mcp add --scope user hyfeast -- "D:\Apps\Hyfeast-v1.0.0\Bin\mcp\hyfeast-mcp.exe"

    When Claude Code first opens a folder with .mcp.json, it asks whether to use the hyfeast server. Approve it to connect. How to check the registration is in section 1.7.1. If the check shows Pending approval, open Claude Code interactively and approve it.

    1.5 Register with Codex (command prompt)

    The Codex CLI and IDE extension share one configuration file (~/.codex/config.toml), so register once. The commands are the same in PowerShell and cmd (Command Prompt).

    codex mcp add hyfeast -- "D:\Apps\Hyfeast-v1.0.0\Bin\mcp\hyfeast-mcp.exe"

    How to check the registration is in section 1.7.1. Remove the registration with codex mcp remove hyfeast. To change settings, remove and register again.

    When codex is missing or fails in a command prompt: the command above runs with the Codex CLI (codex) in a command prompt. Installing the Codex app does not add a command-prompt codex to PATH. If an older codex installed earlier runs, it cannot read the current configuration file and fails with errors such as Error loading config.toml.

    • Check with codex --version. If the command is not found or fails with that error, do one of the following.
    • If Node.js (npm) is installed, install the latest CLI: npm install -g @openai/codex@latest. The same command upgrades an existing installation.
    • Without npm, run the CLI bundled with the Codex app by its full path: %LOCALAPPDATA%\OpenAI\Codex\bin\<folder>\codex.exe. The <folder> name changes when the app updates. Do not use the codex.exe directly under bin; it can be an old copy.
    • Using Codex inside the Codex app is not affected.

    1.6 Register with the Claude desktop app chat

    To use the server in the chat of the Claude desktop app, register it in the configuration file %APPDATA%\Claude\claude_desktop_config.json. You can also open this file from Settings > Developer > Edit Config in the app.

    {
  "mcpServers": {
    "hyfeast": {
      "command": "D:\\Apps\\Hyfeast-v1.0.0\\Bin\\mcp\\hyfeast-mcp.exe",
      "env": {
        "HYFEAST_WORKDIR": "D:\\Work\\Hyfeast"
      }
    }
  }
}
    • If the file already has other content, add only the hyfeast entry inside mcpServers.
    • The desktop app has no working folder, so set the base folder for relative paths with HYFEAST_WORKDIR. Otherwise give absolute file paths in your requests.
    • After saving, quit the Claude app completely and start it again.

    1.7 Checking the registration and connection

    1.7.1 Checking the registered MCP servers

    In a coding agent (section 1.3), just ask. The agent reads its settings and reports whether the server is registered and which executable it uses.

    Tell me whether you use hyfeast-mcp.exe as an MCP server, and which one (its path).

    In a command prompt, check with the commands below. They are the same in PowerShell and cmd.

    Agent List all registered MCP servers Details of hyfeast only When it is fine
    Claude Code claude mcp list claude mcp get hyfeast hyfeast is listed as Connected. This command actually starts the server and checks the connection.
    Codex codex mcp list codex mcp get hyfeast The hyfeast row shows the hyfeast-mcp.exe path as Command and enabled as Status. It checks the registration only and does not connect to the server.
    Claude desktop app Settings > Developer Same screen hyfeast is in the server list. The registration is stored in %APPDATA%\Claude\claude_desktop_config.json.
    • Claude Code shows servers registered in a working folder's .mcp.json only when the command runs in that folder. Servers registered with --scope user show in every folder.
    • If claude is not recognized, Claude Code is installed only as the VS Code extension. Type /mcp in the Claude Code chat in VS Code to see the same list.
    • If the codex command is missing or fails, see "When codex is missing or fails in a command prompt" in section 1.5.

    1.7.2 Checking the connection

    After registering, start hfStudio or hf2DStudio and ask the agent:

    Use the HYFEAST tools to list the running hfStudio and hf2DStudio instances and their status.

    If the agent calls hyfeast_list_instances and hyfeast_status and reports the version and the open file of the running programs, the connection works. How to use it, with examples, is in 2. Examples.

    1.8 Troubleshooting

    Symptom Cause and fix
    configuration_error: .com not found Check that hyfeast-mcp.exe is inside the Bin\mcp folder of the release package. If you moved it, set HYFEAST_HFSTUDIO_CLI to the path of Bin\hfStudio.com.
    configuration_error: not a .com Point HYFEAST_HFSTUDIO_CLI and HYFEAST_HF2DSTUDIO_CLI to the .com files, not .exe.
    configuration_error: --version failed hfStudio.com did not run. Check that all files of the Bin folder, including the bundled Visual C++ runtime DLLs, were extracted. If it still does not run, install the latest Microsoft Visual C++ Redistributable as described in the release README.
    target_error: no instance Start that program first.
    target_error: several instances Ask the agent to name the target instance, or keep only one running.
    codex mcp ... fails with Error loading config.toml or similar An older codex ran. Install the latest CLI or use the app-bundled CLI as in section 1.5.
    The agent does not know the HYFEAST tools The agent was not restarted after registration. Open a new Claude Code or Codex session; quit the Claude desktop app completely and start it again.

    Errors during use are listed in 2. Examples. Server logs go to the agent's MCP log. To keep a file, set a path in HYFEAST_MCP_LOG_FILE (section 1.2).
