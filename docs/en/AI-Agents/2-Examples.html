    2. Examples

    How to ask an AI agent in plain words after registering it as in 1. Connection, with simple examples. The distribution folder is D:\Apps\Hyfeast-v1.0.0, and the working folder is D:\Work. Replace the paths with your actual extraction location and working folder.

    2.1 How to use it

    1. Start the programs you need first: run hfStudio or hf2DStudio from the command prompt opened by HyfeastCmd.bat in the distribution folder. The agent does not start or close them.
    2. Ask the agent in ordinary words. Starting the request with "Use HYFEAST to" makes the agent use the HYFEAST tools.
    3. The agent calls the tools in turn and reports the result. It may ask for permission the first time it uses a tool.

    Requests give better results when they follow these points.

    • Give file paths and names. Relative paths are based on the working folder. Output folders must already exist.
    • Name results by step. For example Case3 or FrqStep. Without a frame, the last frame is shown.
    • Say when overwriting is fine. If a file with the same name exists, the agent stops and asks.
    • Name the section when there are several. For example "activate the RectRC-3D section". The agent reads the list with hyfeast_status and switches with hyfeast_2d_activate_section.
    • Cancelling a request does not cancel the application's work. Its running CLI child is stopped and reaped before another request proceeds, but commands or analyses already sent to the application are not cancelled.

    2.2 Simple examples

    The examples below were run and checked on real hfStudio and hf2DStudio instances. "Tools" lists the order in which the agent calls them; it may differ slightly between agents.

    2.2.1 Run an analysis and save a result image

    Use HYFEAST to import D:\Apps\Hyfeast-v1.0.0\Examples\Tutorials\frame.inp, save it as D:\Work\frame.hdb and run
the analysis. Show the D.MAG contour of Case3 with the deformed shape at scale 10, the scalar bar and
the min/max tags, and save it as D:\Work\case3.png.
    • Tools: hyfeast_import_model → hyfeast_save_model → hyfeast_run_analysis → hyfeast_show_result → hyfeast_capture_scene
    • Result: the result files (frame.hdb, .rst, .log) are created, and the contour of the last frame of Case3 is saved as case3.png.
    • An .inp file is imported, not opened. It must be saved as .hdb before the analysis, so the agent saves first.

    2.2.2 View a mode shape from above

    Show the first mode shape of FrqStep with deformation scale 3. Hide the grid and save a view looking
down from above as D:\Work\mode1-top.png.
    • Tools: hyfeast_show_result → hyfeast_set_view_display → hyfeast_capture_scene
    • Result: the information text at the top left shows the mode number and frequency (here Mode-1, f=0.68314 Hz), and that view is saved as an image.
    • View names give the viewing direction. Looking down from above is -z (looking toward -z); +z looks up from below. If the image is not what you wanted, ask for a correction such as "that is the view from below, turn it around".

    2.2.3 Create a standard steel section and add it to the model

    In hf2DStudio set the unit system to kN-m-s-K, create the material Steel (elastic modulus 2.05e8,
Poisson's ratio 0.3, thermal expansion 1.2e-5, density 7.85), and make the standard section
H-300x150x6.5x9 (fillet radius 13 mm) named H300. Put that section into the hfStudio model and keep
the exchange file as D:\Work\h300-section.inp.
    • Tools: hyfeast_2d_unit_system → hyfeast_2d_define → hyfeast_2d_template_section → hyfeast_transfer_2d_to_studio
    • Result: the beam section H300 and the material Steel are added to the hfStudio model, with the section constants computed by hf2DStudio.
    • Keep the unit systems of the two models consistent. The hfStudio model in this example (frame.inp) uses kN-m, so hf2DStudio was set to kN-m-s-K and the dimensions were given in m.
    • The section cannot be added while results are loaded in hfStudio. The agent asks whether to unload the results (hyfeast_unlock_model) or does so first.

    2.2.4 Draw a rectangular section and add it to the model

    In hf2DStudio set the unit system to N-mm-s-K, draw a 200x300 rectangular section with a Steel
material (elastic modulus 200000), build a linear mesh and move it to the centroid. Put that section
into the hfStudio model as BOX.
    • Tools: hyfeast_2d_unit_system → hyfeast_2d_define → hyfeast_2d_draw (closed outline) → hyfeast_2d_make_face → hyfeast_2d_set_seed → hyfeast_2d_make_mesh (linear) → hyfeast_2d_move_section → hyfeast_transfer_2d_to_studio
    • Result: the beam section BOX is added to the hfStudio model. To add the 2D mesh of the same section as plane elements, ask for example "put that mesh into the hfStudio model with node and element numbers starting at 10000".

    2.2.5 Keep the work as a script

    Save what has been done in hfStudio so far as D:\Work\session.ipc.txt.
    • Tools: hyfeast_save_script
    • Result: the Remote Control commands run in this session are saved one per line. To repeat the same work without the agent, run them with the script command.

    2.3 Tool list

    The server provides 67 tools by default. Tools starting with hyfeast_2d_ address hf2DStudio; the others address hfStudio. Instance and script tools pick the application with the app argument. The agent chooses the tools, so the names need not be memorized.

    Group Tools Purpose
    Instances hyfeast_list_instances, hyfeast_status, hyfeast_ping, hyfeast_focus_window Find running instances of both applications, read status, bring a window forward
    hfStudio files hyfeast_open_model, hyfeast_import_model, hyfeast_save_model Open .hdb, import .inp and others, save
    hfStudio model hyfeast_get_model_info, hyfeast_define_nodes, hyfeast_define_elements, hyfeast_define, hyfeast_assign_section Read the model contents (node and element counts; names of materials, sections, sets, loads, constraints, steps), create nodes and elements, define materials, sections, loads, constraints, steps, functions, histories and sets, assign sections
    hfStudio capture hyfeast_capture_scene, hyfeast_capture_program Save the render view or the whole program as an image; PNG and JPG images are also shown to the agent
    hfStudio analysis hyfeast_check_model, hyfeast_run_analysis, hyfeast_unlock_model Check the model (with the error list on failure), run and wait for the analysis, remove results
    hfStudio views and display hyfeast_list_views, hyfeast_add_render_view and 8 more Render views, camera, representation, grid, axes, and labels
    hfStudio postprocessing hyfeast_show_result, hyfeast_get_result_data and 10 more Step and frame, contour, deformed shape, vectors, scalar bar, contour bands, read result values such as displacement or reaction histories (optionally saved as CSV)
    hf2DStudio files and sections hyfeast_2d_open_model, hyfeast_2d_save_model, hyfeast_2d_new_model, hyfeast_2d_import_dxf, hyfeast_2d_activate_section, hyfeast_2d_unit_system Open, save, or start .hf2d models, import DXF, choose the active section, unit system
    hf2DStudio definitions hyfeast_2d_define, hyfeast_2d_template_section Function, material, section, and analysis definitions; standard steel sections (H, T, C, L, hollow rectangle)
    hf2DStudio geometry hyfeast_2d_draw, hyfeast_2d_generate, hyfeast_2d_make_face, hyfeast_2d_make_rebar, hyfeast_2d_set_seed, hyfeast_2d_delete, hyfeast_2d_move_point, hyfeast_2d_copy Draw points, lines, arcs, and curves; circles; faces and rebars; mesh seeds; delete, move, copy
    hf2DStudio operations hyfeast_2d_make_mesh, hyfeast_2d_section_constants, hyfeast_2d_move_section, hyfeast_2d_rotate_section, hyfeast_2d_renumber, hyfeast_2d_export, hyfeast_2d_set_view Linear or quadratic mesh, section constants, move and rotate, renumber, export input text, view
    hf2DStudio analysis hyfeast_2d_run_analysis, hyfeast_2d_unlock_model Run and wait for section analysis (result .xlsx), remove results
    Interop hyfeast_transfer_2d_to_studio Move a section, guide, curve mesh, or 2D mesh from hf2DStudio into the hfStudio model
    Scripts hyfeast_run_script, hyfeast_save_script Run Remote Control scripts and save the history for either application

    hyfeast_show_result, hyfeast_set_view_display, and hyfeast_transfer_2d_to_studio run several commands in a fixed order in one call.

    2.4 hf2DStudio and hfStudio interop

    hyfeast_transfer_2d_to_studio does what the GUI does with Export to Clipboard in hf2DStudio followed by Import from Clipboard in hfStudio. Instead of the clipboard it keeps an exchange file (.inp) and reads that file with hfStudio import.

    kind What moves Where hfStudio uses it
    section *Section, TYPE=Beam with materials and section mesh cells Beam element sections
    guide *Geometry, Type=Guide (on the Z=0 plane) Modeling guides
    curve_mesh 1D nodes and elements divided along curves Line element models
    domain_mesh CPS3/CPS4 2D mesh Plane element models
    • The active section is moved. With several sections, choose one first with hyfeast_2d_activate_section.
    • The unit system goes along. If the hf2DStudio model has a global UnitSystem, it heads the exported text. When the hfStudio model also has a global UnitSystem, values are converted. When the hfStudio model has content but no UnitSystem, values come in unchanged, so align the unit systems of the two models.
    • hfStudio must be in preprocessing mode. Imports are rejected while results are loaded.
    • Build 2D meshes as linear meshes. hfStudio plane elements are CPS3/CPS4 only. A quadratic mesh (CPS6/CPS8) stops with unsupported_element before anything is imported; rebuild it with hyfeast_2d_make_mesh and order=linear. A standard steel section made with hyfeast_2d_template_section has only a mesh and no geometry, so it cannot be rebuilt; transfer it only as section.
    • Keep mesh numbers apart. curve_mesh and domain_mesh take node_id_offset and element_id_offset to avoid existing node and element numbers in the hfStudio model.
    • Function definitions do not travel. When a section moves, the *Function blocks its materials reference (for example concrete envelopes) are not exported. If hfStudio lacks those functions, the import is only partial and import_partial_failure is reported. Define the functions in hfStudio first, then transfer again.
    • The clipboard changes. hf2DStudio exports also copy the same text to the clipboard.

    2.5 Behavior rules

    • Running programs are required. The server does not start or close hfStudio or hf2DStudio. With several instances, the agent lists them and names the target (target for hfStudio, target_2d for hf2DStudio).
    • Commands without a target go to the remaining instance. When only one instance runs, a command sent without a target reaches it automatically. If several agents or scripts use Remote Control at the same time, a command can land in a window another job opened, so name the target by uuid.
    • Unsaved changes are never discarded. Creating a new hfStudio model and quitting either application are not offered as tools. hyfeast_2d_new_model refuses when there are unsaved changes. A script that contains new, quit, or --discard-unsaved is rejected before it runs.
    • Files are not overwritten. An existing file is refused unless overwriting is requested explicitly. The output folder must already exist.
    • Analysis input is opened by import. hyfeast_open_model opens .hdb only. An .inp must be imported and saved before it can be analyzed.
    • The analysis is awaited. hfStudio succeeds when results are loaded; hf2DStudio succeeds when an .xlsx appears next to the model. An analysis that ends without results is reported as analysis_failed. Success means the run finished, not that the results are correct.
    • hf2DStudio geometry tools act on the active section. New point, curve, and face ids are in the result, ready for the next tool. Points with equal coordinates are not merged, so draw outlines for faces with hyfeast_2d_draw and closed=true. Geometry cannot change while a mesh exists; delete the mesh first.
    • Results are shown at the last frame by default. post-step goes to the first frame (before loading), so hyfeast_show_result moves to the last frame unless a frame is given.
    • Postprocessing and capture act on the active render view. Activate another view first to use it. Camera and display tools accept a view id directly.
    • Vector images are saved compressed. hfStudio saves .svg, .ps, .eps, and .tex with an added .gz. .pdf is saved as is. The result shows the actual file path.
    • The contour overlay is an iso-line expression. Write D.MAG=0.002, 0.004 or 0.002@D.MAG; an empty string removes it.

    2.6 Common errors

    When an error occurs, the agent reports its name and cause and usually fixes the request and tries again. If the connection itself fails, see 1. Connection.

    Error Cause and fix
    invalid_state (postprocessing tools) No results are loaded. Open an .hdb with results or run the analysis first.
    save_path_required The model is Untitled. Save it to a path and ask again.
    unsaved_changes (hyfeast_2d_new_model) Save the hf2DStudio model first.
    input_validation_error / FILE_EXISTS A file with the same name exists. Use another name or ask for overwriting.
    unsupported_element The 2D mesh is quadratic. Rebuild it with order=linear. Transfer a standard steel section only as section.
    import_partial_failure hfStudio rejected some blocks during a model import or a 2D transfer. Find the rejected lines in the hfStudio output window and fix the input before saving or running the analysis. For a section transfer, define the functions the materials reference in hfStudio first. For 2D transfers, the result shows the exchange file path.
