    4.2 Beam

    The beam element is a structural element that transmits axial force, bending, and torsion, with its dimension along the longitudinal axis (x-axis in the ECS) being larger compared to other directions. The element type, cross-section, and distribution are as follows:

    ■ Element Type

    • B2D2H: 2-dimensional 2-node, Bernoulli beam (Hermitian shape function used)
    • B2D2MH: 2-dimensional 2-node, Timoshenko beam (Modified Hermitian shape function used)
    • B3D2H: 3-dimensional 2-node, Bernoulli beam (Hermitian shape function used)
    • B3D2MH: 3-dimensional 2-node, Timoshenko beam (Modified Hermitian shape function used)

    ■ Element Cross-Section

    • Beam: Beam element cross-section. Composed of one or more Cells.

    ■ Element-Specific Properties (Distribution)

    • BeamCS: Defines the ECS for the 3D beam element.
    • BeamEndRelease: Applies hinge conditions (moment release) at the element ends. Combination of Rx1, Ry1, Rz1, Rx2, Ry2, and Rz2. For example, Rz1|Rz2.

    The B2D2H and B3D2H elements, which ignore shear deformation, support nonlinear material models and can simulate variable cross-sections. On the other hand, the B2D2MH and B3D2MH elements, which consider shear deformation, are applicable only for elastic materials. Since variable cross-section formulation is theoretically not possible, when cross-sectional properties are given as a variable cross-section, an average value is applied within the element.

    The ECS of a 2D beam element is defined as the x-axis (member axis) and the y-axis perpendicular to it, as shown in Figure 4.2-1 below.

    Fig. 4.2-1. 2D Beam Element ECS

    For 3D beam elements, while the x-axis can be defined as the member axis, the y and z axes are determined by the reference vector r and an additional section rotation angle θ. Figure 4.2-2 below shows an example where the ECS is set with a section rotation angle θ=0. The default value of the r vector is set to r = (0,0,1), as shown in Figure 4.2-3. Exceptionally, when the member axis is parallel to the global coordinate system's Z-axis, the value of r is set to (1,0,0). Parallelism is determined when the member axis is within a slope of 1:100 (approximately 0.573 degrees) relative to the Z-axis.

    The ECS can be further defined using a rotated coordinate system based on the section rotation angle θ from the r vector. The default value of θ is 0.

    Fig. 4.2-2. 3D Beam Element ECS

    Fig. 4.2-3. Default Reference Vector

    In Hyfeast, the reference axis of the beam element is defined based on the line segment connecting the nodes, and it does not need to coincide with the centroid. However, the formulation is performed at the centroid. In particular, section forces and deformations are calculated with reference to the centroid, so caution is required.

    The cross-section of the beam element, referred to as the Beam cross-section, is defined as a set of Cells that represent a geometric shape to which the same material is applied. The figure below shows the available Cells.

    Fig. 4.2-4. Cell in Beam Section (viewed from the local +z direction)

    The following is a summary of items related to cells:

    1. If the cross-section consists of a single cell, it is a homogeneous beam cross-section. If it consists of two or more cells, it is a composite beam cross-section.
    2. When configuring a beam cross-section with two or more cells, there are restrictions depending on the type of cell used.
    3. Value, Rectangle, Circle, and H/T/C/L/2C/2L/HR[-YUp] cells only allow elastic material (IsoElasticity) and can only output stress (S), total strain (E), mechanical strain (EM), elastic strain (EE), and other elastic-material field values at a few predefined material points, as shown in Figure 4.2-5.
    4. Direct H/T/C/L/2C/2L/HR[-YUp] standard-shape cells compute section constants using two-dimensional finite element analysis. The internally generated mesh uses quadratic elements such as Q8 and T6 to represent fillets and other curved boundaries accurately.
    5. For standard-shape cells, a shape token with -YUp, such as H-YUp or Mesh,H-YUp, aligns the section height with the local y-direction. It can be understood as a 90-degree rotation of the corresponding base shape cell and is useful for two-dimensional beams (B2D2H, B2D2MH) where the user cannot define the beam local coordinate system.
    6. Point, Layer, and Mesh cells can be used with both elastic and inelastic materials.
    7. Point cells can output the field values of the used materials, such as stress (S) and strain (E, EM), at all material points that constitute the cell.
    8. Layer cells can output the field values of the used materials, such as stress (S) and strain (E, EM), at the top and bottom of each layer.
    9. Mesh cells predefine the material points that form the mesh using *CellMeshPoints, and these material points can be used to output field values, such as stress (S) and strain (E, EM), for the used materials.
    10. Value, Rectangle, Circle, and H/T/C/L/2C/2L/HR[-YUp] cells are allowed to exist independently or in combination with Point cells only. (e.g., Rectangle (OK), Rectangle+Point (OK), Rectangle+Rectangle (NG), Rectangle+Value (NG))
    11. Layer cells are allowed to be combined only with Layer and Point cells. (e.g., Layer (OK), Layer+Mesh (OK), Layer+Point (OK), Layer+Layer+Point (OK), Layer+Rectangle (NG))
    12. Mesh cells are allowed to be combined only with Mesh and Point cells. (e.g., Mesh (OK), Mesh+Mesh (OK), Mesh+Point (OK), Mesh+Mesh+Point (OK), Mesh+Rectangle (NG))
    13. Point cells should generally be combined with other types of cells, but they can also be used independently. (e.g., Value+Point (OK), Rectangle+Point (OK), Point (OK), Point+Point (OK))
    14. When a cross-section uses Point cells, the Point cells only contribute to bending and compression calculations but do not contribute to shear or torsion calculations. For example, when calculating section constants, EA and EI are calculated considering the contribution of the Point cells, but GJ and GAs are not considered. (EA, EIy, EIz, EIyz)
    15. Layer cells are only applicable to 2D beam elements (B2D2H, B2D2MH).

    Fig. 4.2-5. Output points in elastic cell (viewed from the local +z direction)

    4.2.1 *Element, Type=B2D2H

    2D 2-Node Bernoulli Beam Element

    *Element, Type=B2D2H, Elset=elset
 id, n1, n2, [, S=section, R=beamEndRelease]
 ...
    Specifications
    • No. of nodes: 2
    • No. of gauss points: 4 (Gauss-Lobatto rule used)
    • Fields: BSF=[Nx Mz Vy], BSE=[Ex Kz Gxy], BST=[T0 Tz] at Gauss point about centroid. Uniaxial model response at each layer of Gauss point
    • Compatible section: Beam
    • Active DOFs: X,Y,RZ

    The Bernoulli beam element assumes zero shear deformation, meaning that shear forces are not defined as state variables and must be calculated using equilibrium conditions. In this formulation, the cross-sectional shear deformation is always zero, and \(V_y=–dM_z/dx\) is used to calculate the shear force.

    \(V_y\) is computed by first interpolating \(M_z(x)\) using a polynomial based on the moment response at the integration points, and then differentiating \(M_z(x)\) to obtain \(V_y\).

    The beamEndRelease option allows combinations of Rx1, Ry1, Rx2, and Ry2 (Rx1 and Ry1 correspond to the two rotations at the start node, and Rx2 and Ry2 correspond to the two rotations at the end node). For example, Ry1|Ry2.

    4.2.2 *Element, Type=B3D2H

    3D 2-Node Bernoulli Beam Element

    *Element, Type=B3D2H, Elset=elset
 id, n1, n2, [, S=section, CS=beamCS, R=beamEndRelease]
 ...
    Specifications
    • No. of nodes: 2
    • No. of gauss points: 4 (Gauss-Lobatto rule used)
    • Fields: BSF=[Nx My Mz Vy Vz T], BSE=[Ex Ky Kz Gxy Gxz Hx], BST=[T0 Ty Tz] at Gauss point about centroid. Uniaxial model response at each layer of Gauss point
    • Compatible section: Beam
    • Active DOFs: X, Y, Z, RX, RY, RZ

    If the Bernoulli beam element assumes zero shear deformation, shear forces are not defined as state variables and must be calculated using equilibrium conditions. In this formulation, cross-sectional shear deformations \(\gamma_y\) and \(\gamma_z\) are always zero, and shear forces are calculated as follows:

    \(V_y = –dM_z/dx, \quad V_z = dM_y/dx\)

    \(V_y\) is computed by first interpolating \(M_z(x)\) using a polynomial based on the moment response at the integration points, and then differentiating \(M_z(x)\) to obtain \(V_y\). \(Hx\) represents \(d\theta / dx\).

    The beamEndRelease option allows combinations of Rx1, Ry1, Rz1, Rx2, Ry2, and Rz2 (Rx1, Ry1, and Rz1 correspond to the three rotations at the start node, and Rx2, Ry2, and Rz2 correspond to the three rotations at the end node). For example, Rz1|Rz2.

    4.2.5 *Section, Type=Beam

    Defines a beam section.

    *Section, Type=Beam,  Name=name, Taper=Group|Element, Mass=Consistent|Lumped
*CellMeshPoint
 ...
*Cell, Type=Rectangle|Circle|H/T/C/L/2C/2L/HR[-YUp]|Mesh|Mesh,Rectangle|Mesh,Circle|Mesh,H/T/C/L/2C/2L/HR[-YUp]|Layer|Point, Mat=mat
 ...
*ShearTorsionMaterial
 ...
    Keyword line
    • Name=name: Section name (required). Section names must be unique.
    • Taper=Group|Element: Variable cross-section beam designation. Group treats connected beam elements as a group and assigns a variable cross-section, and Element assigns a variable cross-section for individual elements. If not specified, it means a constant cross-section beam (Optional, default None).
    • Mass={Consistent|Lumped}: Consistent or Lumped, which means consistent mass or lumped mass, respectively. (Optional, default Consistent)
    Sub-keywords
    • *CellMeshPoint: Specifies the coordinates of points used when defining *Cell, Type=Mesh.
    • *Cell, Type=type, Mat=mat: Defines a cell within the cross-section. mat indicates the material used.
      • Value: Specifies the cross-sectional constants as values; mat must be linearly elastic.
      • Rectangle: Rectangular cross-section; mat must be linearly elastic.
      • Circle: Circular or hollow circular cross-section; mat must be linearly elastic.
      • H/T/C/L/2C/2L/HR[-YUp]: Standard steel shape cell; mat must be linearly elastic. These direct shape cells are treated as ShapeSection.
      • Mesh: Arbitrary cross-section given as a mesh. Cross-sectional constants are calculated using 2D finite element analysis.
      • Mesh,Rectangle: Generates a rectangular material point mesh.
      • Mesh,Circle: Generates a circular or hollow circular material point mesh.
      • Mesh,H/T/C/L/2C/2L/HR[-YUp]: Generates a material point mesh from a standard steel shape. These generated mesh cells are treated as MeshedSection.
      • Layer: Arbitrary cross-section given as a layer (only applicable to 2D beam elements).
      • Point: Point-shaped cell. Used for rebar modeling, etc.
    • *ShearTorsionMaterial: Specifies reference materials for shear and torsion behavior using uniaxial material model.

    When a beam section is written in direct mesh form, the *Cell, Type=Mesh data lines are not limited to linear cells. The same *CellMeshPoint table can be referenced by T3, Q4, T6, or Q8 cells.

    4.2.6 *CellMeshPoint

    Specifies the coordinates of points used when defining *Cell, Type=Mesh.

    *CellMeshPoint
 pointId, y, z, {y, z}
 ...
    First data line and subsequent data lines
    • pointId: Point ID
    • y, z, {y, z}: Point coordinates [L]. If two values are given, they define a constant cross-section; if four values are given, they define a tapered cross-section.

    The point table is shared by every direct mesh cell of the section, regardless of whether the mesh cell uses 3, 4, 6, or 8 point IDs.

    4.2.7 *Cell

    Defines the geometry, materials, and related properties within a beam-element cross-section.

    *Cell, Type=type, Mat=mat
  data line
  ...
    Keyword line
    • Type=type: Type of the Cell
      • Value: Specifies cross-sectional constants as values
      • Rectangle: Rectangular cross-section
      • Circle: Circular or hollow circular cross-section
      • H/T/C/L/2C/2L/HR[-YUp]: Standard steel shape cell. Add -YUp to align the shape height with the local y-direction.
      • Mesh: Arbitrary cross-section given as a mesh. Cross-sectional constants are calculated using 2D finite element analysis.
      • Mesh,Rectangle: Generates a rectangular material point mesh.
      • Mesh,Circle: Generates a circular or hollow circular material point mesh.
      • Mesh,H/T/C/L/2C/2L/HR[-YUp]: Generates a material point mesh from a standard steel shape.
      • Layer: Layered cross-section that can be used only for 2D beams
      • Layer,Stack: Generates layers by subdividing stacked layer data.
      • Layer,Circle: Generates a circular or hollow circular layered section.
      • Point: Point-shaped cell. Used for rebar modeling, etc.
      • Point,Circle: Generates a circular point pattern.
    • Mat=mat: Material used in the Cell
    Data line forms

    *Cell data lines are divided into direct input forms and section DB reference forms.

    • numeric/direct data line: Default form that directly lists the dimensions, mesh points, layer fields, or point fields for the selected Type=.
    • section DB reference data line: Catalog-reference form written as DB, item. In supported cells, this form replaces a numeric geometry data line.

    In syntax blocks, {A} | {B} means choose one of the two data-line forms. Do not type the braces or the | character.

    Common data-line options

    The following options are appended to data lines; they are not keyword-line options.

    • C=yc, zc: Specifies the centroid location of the cell for cell types other than direct Mesh, Layer, and Point.
    • ExtraArea=area or ExtraArea=area0, area1: Additional area [L^2] appended to a numeric/direct data line. It is used only for mass and self-weight, and does not affect structural section constants, stiffness, stress/strain recovery, or result output locations.
    • ToDirectForm: Expands a generated mesh cell to direct mesh data when the model is saved or formatted. It is used only on the first data line.

    C is an abbreviation for cell centroid coordinate. yc and zc are the centroid coordinates of that cell measured in the section reference axes, which are defined from the beam reference line connecting the beam element nodes. yc and zc are not the centroid of the assembled Beam section unless the section has only that one cell. The assembled section centroid is reported separately as yc and zc in section-property output.

    For direct Value, Rectangle, Circle, and H/T/C/L/2C/2L/HR[-YUp] cells, append ExtraArea to the corresponding geometry data line. For tapered sections, each start/end geometry data line may have its own value, and the value is interpolated along the member. For direct Mesh, Layer, and Point cells, specify ExtraArea only on the first cell data line. A single value is used for both ends; in a tapered section, ExtraArea=area0, area1 gives the start and end values. When ToDirectForm is also used, write ExtraArea=... before ToDirectForm, and keep ToDirectForm as the last token on the data line.

    Section DB reference data lines

    A section DB reference is a data-line alternative, not a separate cell type or keyword option. The Type= keyword still selects the Hyfeast cell family, so the referenced DB item must match that family. Do not add a DB marker token.

    The following rules apply to section DB references.

    • A global *Environment, Type=UnitSystem must already be defined.
    • Runtime section DB files are loaded from tools/db/sections/*.hfdb.json.
    • Each section DB file declares its source length unit; DB dimensions and DB-provided ExtraArea are converted to the current global UnitSystem.
    • C= remains user input in the current model units.
    • User-authored ExtraArea= is not allowed on DB reference data lines. Only DB-provided ExtraArea is applied automatically.
    • For tapered sections, the second data line may also be a DB reference and may name a different item for the end-section geometry.

    The DB data-line forms below include additional fields that may appear on the first data line.

    Supported cell DB data-line form Note
    Circle DB, item, C=yc, zc Input shortcut for catalog radii. C is optional and defaults to 0, 0; saved/formatted as numeric circle data.

    4.2.7.1 *Cell, Type=Value

    Defines the shape and material within the cross-section of the beam element.

    *Cell, Type=Value, Mat=mat
  A, Iy, Iz, Iyz, J, Asy, Asz, ys, zs, C=yc, zc, ExtraArea=area
  ...add the above line if tapered section
    First data line
    • A: Area [L^2]
    • Iy: 2nd moment of inertia about y w.r.t centroid(optional, default 0.) [L^4]
    • Iz: 2nd moment of inertia about z w.r.t centroid(optional, default 0.) [L^4]
    • Iyz: Cross product w.r.t centroid(optional, default 0.) [L^4]
    • J: torsional constant w.r.t centroid(optional, default 0.) [L^4]
    • Asy,Asz: Shear area [L^2]. If 0, it means use A. (optional, default 0.)
    • ys,zs: Shear centers w.r.t centroid(optional, default 0.) [L].
    • C=yc,zc: Centroid coordinates of this value cell in the section reference axes (optional, default 0.) [L].
    • ExtraArea=area: Optional additional area used only for mass and self-weight [L^2].
    2nd data line
    • Repeat if tapered section

    The material applied to *Cell, Type=Value must always be an elastic material defined as *Material, Type=IsoElasticity. *Cell, Type=Value is used either independently or in combination with *Cell, Type=Point. When combined with a Point cell, only the constants for bending are adjusted and used as the overall composite cross-sectional constants.

    For variable cross-section beams, the cross-sectional constants are interpolated along the length as follows.

    \[ \begin{aligned} &A(x) = A_0 + (A_1 - A_0) \frac{x}{L} \\ &J(x) = J_0 + (J_1 - J_0) \frac{x}{L} \\ &I_y(x) = \left[ I_{y0} ^{1/m_y} + (I_{y1} ^{1/m_y} - I_{y0} ^{1/m_y} ) \frac{x}{L} \right] ^{m_y} \\ &I_z(x) = \left[ I_{z0} ^{1/m_z} + (I_{z1} ^{1/m_z} - I_{z0} ^{1/m_z} ) \frac{x}{L} \right] ^{m_z} \\ &I_yz(x) = \left[ I_{yz0} ^{1/m_{yz}} + (I_{yz1} ^{1/m_{yz}} - I_{yz0} ^{1/m_{yz}} ) \frac{x}{L} \right] ^{m_{yz}} \\ \end{aligned} \]

    Here, the interpolation orders for \(I_y\), \(I_z\), and \(I_{yz}\) are set as \(m_y=2, m_z=2, m_{yz}=1\). The remaining shapes are interpolated for the cross-sectional constants based on the given shapes.

    The cross-sectional constants for the centroid are calculated using the following equations.

    Reference: Thin-walled H-shape

    For an H section without fillets, the following thin-walled approximation can be used.

    \[ \begin{aligned} &A = h_c t_w + 2bt_f,\quad I_y=\frac{h_c^2}{12}(h_c t_w+6bt_f),\quad I_z = \frac{b^3t_f}{6},\quad I_{yz}=0 \\ &J \approx \frac{1}{3}(h_c t_w^3+2bt_f^3),\quad y_s=z_s=0 \\ &A_{sy}=k_{sy}A,\quad k_{sy}=\frac{5}{3}\frac{bt_f}{A} \\ &A_{sz}=k_{sz}A,\quad k_{sz}=\frac{h_ct_w}{A} \\ &\mathrm{where,}\quad h_c = h - t_f \end{aligned} \]

    Hyfeast computes the section constants using two-dimensional finite elements. For example, with b=0.20, h=0.40, tw=0.008, and tf=0.013, the thin-walled formula differs from the finite-element result by about 1.3% in area, 1.6% in major-axis bending inertia, 2.4% in torsional constant, and 2.5% in one shear area.

    4.2.8 *ShearTorsionMaterial

    Specifies reference materials for shear and torsion behavior using uniaxial material model.

    *ShearTorsionMaterial
  ShearX|ShearY|Torsion, material, localUnitSystem
  ...
    First data line and subsequent data lines if necessary
    • ShearX|ShearY|Torsion: Specified type. ShearX and ShearY correspond to shear behavior in two orthogonal directions, while Torsion refers to torsional behavior.
    • material: Referenced material model. Only uniaxial material models are allowed. Interpreted as a scaled shear force–shear strain relationship for shear, or as a scaled torsional moment–rotation relationship for torsion. The actual shear force or torsional moment is computed by multiplying the scaled quantity by the corresponding section stiffness constants—GAsy, GAsz, or GJ—defined in the section.
    • locaUnitSystem: local UnitSystem with force-length form (optional).

    Shear and torsional behavior in beam elements is linear by default. To enforce nonlinear behavior, a uniaxial material model can be referenced to define a scaled shear force–shear strain or scaled torsional moment–rotation relationship. The resulting actual shear force and torsional moment are obtained by multiplying the scaled response by the corresponding section constants (GAsy, GAsz, or GJ).

    When applied to shear behavior, if the local unit system is the same as the current unit system specified by *Environment, Type=UnitSystem, the scaled shear force and stress are converted on a 1:1 basis without any physical reinterpretation. If the unit systems differ, appropriate internal scaling is applied automatically. Likewise, when applied to torsional behavior, the scaled torsional moment and stress, as well as rotation and strain, are converted with the unit system taken into account, again without implying any direct physical equivalence.
