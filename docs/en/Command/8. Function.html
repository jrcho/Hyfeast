    8. Function

    *Function defines a named function object. Defined functions are referenced by material-model envelopes, load time histories, and similar inputs. Names must be globally unique.

    Function-related commands define relationships such as \(y=f(x)\) or \(y_1=f_1(x), y_2=f_2(x), ...\).

    Some function types support DB sources. TimeSignal reads time-history DB records, and concrete-related function types create compressive, tensile, and time-dependent properties from concrete DB items.

    • *Function, Type=TimeSignal: time-history DB
    • *Function, Type=ParabolaCEnv|HognestadCEnv|EC2CEnv|MPPCEnv: concrete DB for compressive behavior
    • *Function, Type=MaekawaTEnv: concrete DB for tensile behavior
    • *Function, Type=ConcreteTime: concrete DB for time-dependent properties

    See *Function, Type=TimeSignal for TimeSignal DB input. The following sections describe the common concrete DB rules.

    Concrete DB overview

    Concrete DB items are not material names entered directly in a Material dataline. They are sources used in concrete *Function datalines to fill the parameters of the selected function model. The current built-in envelope DB item forms are KDS-2026-C<fck>, ACI318-2025-C<fck>, and EC2-2004-C<fck>; the built-in time-dependent DB item forms are KDS-2026-C<fck>, EC2-2004-C<fck>, and ACI209-1992-C<fc>. Each function type supports a specific subset of those DB standards, and a UGeneric material dataline references the generated function name instead of the DB item itself.

    The first distinction is ParabolaCEnv. Its DB input is a separate section-analysis parabolic compression input. It does not use the DB-derived concrete material-property recipe introduced below: fcm, Ec, Eci, ft, and the per-model recipe mapping. The DB supplies section-analysis fck, n, eco, and ecu; the optional alpha token applies the design reduction to fck. ACI318-2025-C<fck> is not accepted by ParabolaCEnv.

    By contrast, HognestadCEnv, EC2CEnv, MPPCEnv, and MaekawaTEnv use concrete mechanical properties derived from the DB item as inputs to Hyfeast's built-in recipes. ConcreteTime uses standard-dependent aging, creep, and shrinkage equations. The reference below is organized by standard so the mechanical properties and time-dependent properties are read together.

    For concrete envelope functions, Type means the function model to create. The same Type is used for both direct numeric input and DB item input. For example, with Type=ParabolaCEnv, a dataline of fck, n, eco, ecu, alpha is direct numeric input, while KDS-2026-C30 or EC2-2004-C30 fills the section-analysis parameters of the same Parabola model from the DB. TimeSignal DB records also keep Type=TimeSignal; they are referenced by source lines in the form DB, recordName[, scaleFactor].

    Function inputs that use the concrete material DB require a prior global *Environment, Type=UnitSystem. DB source values are converted by the parser to the current global UnitSystem. These inputs do not allow UnitSystem on the keyword line; specifying it is an input error. TimeSignal DB source lines follow the unit metadata carried by each record; see the Type=TimeSignal section for details.

    For concrete envelope DB item datalines, append ToDirectForm as the last token when the saved/formatted input should show the resolved numeric parameters. With ToDirectForm, the saved/formatted direct numeric form is written in the current global UnitSystem. If that unit system is the same as the global UnitSystem, no local UnitSystem is attached to the keyword line. Without ToDirectForm, the DB item dataline is preserved and no local UnitSystem is attached to the keyword line. HognestadCEnv, EC2CEnv, and MPPCEnv also accept EciCurve before ToDirectForm; when omitted, HognestadCEnv and EC2CEnv are linearized from the origin to 0.4*fco or 0.4*fcm using Ec, while MPPCEnv derives the internal curve from the unconfined secant Ec and then linearizes to the current 0.4 strength point.

    Function-type DB dataline syntax is documented in the later Type= subsections. This front reference is limited to standard-specific properties and unit systems.

    Common rules for concrete DB

    Each standard subsection below uses the same order.

    • DB item forms and source units: the envelope DB item name, the ConcreteTime item name when available, and the units used by the standard equations.
    • Mechanical envelope properties: the 28-day properties and strain coefficients used by concrete envelope functions.
    • ConcreteTime properties: the aging, creep, and shrinkage series for the same standard. These subsections do not repeat mechanical properties already defined above; they only add coefficients required by the time-dependent equations.

    ConcreteTime stores six function series in the following order:

    \[ \left[a_c(t),\;a_t(t),\;a_E(t),\;c_r(t-\tau),\;c_l(\tau),\;\varepsilon^{sh}(t)\right] \]

    For a user-defined function set, the intended material-level use is:

    \[ f_c(t)=a_c(t)f_c(28) \]
    \[ f_t(t)=a_t(t)f_t(28) \]
    \[ E_c(t)=a_E(t)E_c(28) \]
    \[ C(t,\tau)=c_r(t-\tau)c_l(\tau) \]
    \[ \varepsilon^{sh}(t)=-e_{sh}(t) \]

    Shrinkage distinguishes positive shrinkage magnitudes from the signed shrinkage/swelling strain stored by Hyfeast. For a user-defined shrinkage Function, \(e_{sh}(t)\) is a positive shrinkage magnitude. In the EC2 equations, \(\varepsilon_{cd}\) and \(\varepsilon_{ca}\) are positive magnitudes; in the ACI equations, \(\varepsilon_{sh,u}\) is a positive magnitude. The final series \(\varepsilon^{sh}(t)\) is the signed value stored by Hyfeast: contraction is stored as negative, and swelling is stored as positive. In the KDS equations, the computed \(\varepsilon^{sh}(t)\) itself is used as the signed stored value; it is negative shrinkage for \(RH<99\%\) and positive swelling for \(RH\ge99\%\).

    Here, \(t\) is the concrete age, \(\tau\) is the loading age, and \(t-\tau\) is the creep duration. Standard and User ConcreteTime inputs evaluate these age variables in days, so a Static, Quasi step that uses them must specify TUnit=day. This does not imply changing the time field of the global UnitSystem to days. The function does not decide \(\tau\); the later concrete material implementation supplies it from the analysis state.

    Here \(C(t,\tau)\) is creep compliance, not the dimensionless creep coefficient \(\phi(t,\tau)\). If \(c_r\) is dimensionless, \(c_l\) has inverse-stress units.

    The KDS and EC2 built-in creep equations use the same separated form. The duration part is dimensionless, and the loading-age part includes the elastic-modulus denominator. The standard-specific subsections give only \(E_{ci,28}\), \(\phi_{RH}\), and \(\beta_H\).

    \[ C(t,\tau)=c_r(\max(t-\tau,0))c_l(\tau) \]
    \[ \Delta t=\max(t-\tau,0) \]
    \[ c_r(\Delta t)= \begin{cases} 0 & (\Delta t=0) \\ \left(\dfrac{\Delta t}{\beta_H+\Delta t}\right)^{0.3} & (\Delta t>0) \end{cases} \]
    \[ c_l(\tau)=\dfrac{1}{E_{ci,28}}\phi_{RH}\dfrac{16.8}{\sqrt{f_{cm}}}\dfrac{1}{0.1+\tau^{0.2}} \]

    ConcreteTime does not allow keyword-line UnitSystem. A User dataline references existing function names and does not require a global UnitSystem at input time. The six referenced Functions are evaluated with day-based \(x\) values supplied by ConcreteTime; therefore, a referenced Function must not define keyword-line UnitSystem=....

    ConcreteTime standard datalines require a global *Environment, Type=UnitSystem, but the input units of the standard equations are fixed to the units specified by each standard. EC2/KDS strengths are entered in MPa, ACI strength is entered in psi, EC2/KDS h0 is entered in mm, ACI 209 V/S and slump are entered in inch, and time variables are entered in days. The parser does not convert these length inputs from the global length unit. Elastic moduli in the creep-compliance denominator are converted to the current global stress unit before storage.

    KDS-2026 concrete DB

    DB item forms and source units. KDS envelope functions use KDS-2026-C<fck>; ConcreteTime uses the same KDS-2026-C<fck> item form. Strengths and elastic moduli are evaluated in MPa, length parameters in mm, and time variables in days.

    Mechanical envelope properties (KDS-2026-C<fck>).

    \[ f_{cm}=f_{ck}+\Delta f \]
    \[ \Delta f= \begin{cases} 4 & (f_{ck} \le 40) \\ 4 + 0.1(f_{ck}-40) & (40 < f_{ck} < 60) \\ 6 & (f_{ck} \ge 60) \end{cases} \]
    \[ E_c=8500\sqrt[3]{f_{cm}}\;[\mathrm{MPa}] \]
    \[ E_{ci}=E_c \]
    \[ f_t=f_{ctm}=0.30\,f_{cm}^{2/3} \]

    This \(E_c\) expression applies the KDS normal-weight concrete assumption \(m_c=2300\,\mathrm{kg/m^3}\); material density does not recompute it. Use direct numeric input when fck exceeds 90 MPa.

    EC2CEnv nonlinear-analysis strain coefficients. For KDS DB input, strengths are in MPa and strains are dimensionless:

    \[ \varepsilon_{co}=\min\left(0.7 f_{cm}^{0.31},\,2.8\right)/1000 \]
    \[ \varepsilon_{cu}= \begin{cases} 0.0033 & (f_{ck}\le 40) \\ \left(3.3-0.1(f_{ck}-40)/10\right)/1000 & (40<f_{ck}\le 90) \end{cases} \]

    ConcreteTime properties (KDS-2026-C<fck>).

    The KDS-2026-C<fck> time-dependent equations use the \(f_{cm}\) and \(E_c\) defined above as the 28-day values. \(h_0\) is evaluated in mm, and the time variables \(t\), \(\tau\), and \(t_s\) are evaluated in days. The creep-compliance denominator uses the following initial modulus:

    \[ E_{ci,28}=1.18E_c \]

    The age factors are:

    \[ \beta_c(t)=\exp\left[\beta_{sc,a}\left(1-\sqrt{28/t}\right)\right] \quad (t>0) \]
    \[ a_c(t)=\beta_c(t) \]
    \[ a_t(t)=\beta_c(t)^{2/3} \]
    \[ a_E(t)=\sqrt{\beta_c(t)} \]

    The aging coefficient \(\beta_{sc,a}\) is 0.35 for Moist and 0.15 for Steam with Type1, 0.40 and 0.40 with Type2, 0.25 and 0.12 with Type3, and 0.35 and 0.15 with Type5.

    KDS creep uses the common KDS/EC2 separated form. Its humidity and size factors are:

    \[ \phi_{RH}=1+\dfrac{1-RH/100}{0.1h_0^{1/3}} \]
    \[ \beta_H=\min\left(1.5\left[1+(0.012RH)^{18}\right]h_0+250,\;1500\right) \]

    In the KDS expression, \(\varepsilon_s(f_{cm})\) and \(\beta_s\) are positive, with \(\beta_{RH}<0\) for \(RH<99\%\) and \(\beta_{RH}=0.25>0\) for \(RH\ge99\%\). Therefore \(\varepsilon^{sh}(t)\) is computed as negative shrinkage under ordinary drying conditions and positive swelling under near-saturated conditions, and the computed value is stored directly as the signed Hyfeast shrinkage/swelling strain without adding another leading minus sign.

    \[ \varepsilon^{sh}(t)= \begin{cases} 0 & (t<t_s) \\ \varepsilon_{sho}\beta_s(t-t_s) & (t\ge t_s) \end{cases} \]
    \[ \varepsilon_{sho}=\varepsilon_s(f_{cm})\beta_{RH} \]
    \[ \varepsilon_s(f_{cm})=\left[160+10\beta_{sc,s}\left(9-f_{cm}/10\right)\right]10^{-6} \]
    \[ \beta_{RH}= \begin{cases} -1.55\left[1-\left(RH/100\right)^3\right] & (RH<99) \\ 0.25 & (RH\ge 99) \end{cases} \]
    \[ \beta_s(t-t_s)=\sqrt{\dfrac{t-t_s}{0.035h_0^2+(t-t_s)}} \]

    The shrinkage coefficient \(\beta_{sc,s}\) is 4 for Type2, 5 for Type1 or Type5, and 8 for Type3.

    EC2-2004 concrete DB

    DB item forms and source units. EC2 envelope functions use EC2-2004-C<fck>; ConcreteTime uses the same EC2-2004-C<fck> item form. Strengths and elastic moduli are evaluated in MPa, length parameters in mm, and time variables in days.

    Mechanical envelope properties (EC2-2004-C<fck>).

    \[ f_{cm}=f_{ck}+8 \]
    \[ E_c=E_{cm}=22000\left(f_{cm}/10\right)^{0.3} \]
    \[ E_{ci}=1.05\,E_c \]
    \[ f_t= \begin{cases} 0.30\,f_{ck}^{2/3} & (f_{ck} \le 50) \\ 2.12\ln(1+f_{cm}/10) & (50 < f_{ck} \le 90) \end{cases} \]

    Here <fck> is the EC2 cylinder strength in MPa. Use direct numeric input when fck exceeds 90 MPa.

    EC2CEnv nonlinear-analysis strain coefficients. For EC2 DB input, strengths are in MPa and strains are dimensionless:

    \[ \varepsilon_{co}=\min\left(0.7 f_{cm}^{0.31},\,2.8\right)/1000 \]
    \[ \varepsilon_{cu}= \begin{cases} 0.0035 & (f_{ck}\le 50) \\ \left(2.8+27\left((98-f_{cm})/100\right)^4\right)/1000 & (50<f_{ck}\le 90) \end{cases} \]

    ConcreteTime properties (EC2-2004-C<fck>).

    The EC2-2004-C<fck> time-dependent equations use the \(f_{cm}\) and \(E_c=E_{cm}\) defined above as the 28-day values. \(h_0\) is evaluated in mm, and the time variables \(t\), \(\tau\), and \(t_s\) are evaluated in days. The creep-compliance denominator uses the following initial modulus:

    \[ E_{ci,28}=1.05E_c \]

    The age factors are:

    \[ \beta_{cc}(t)=\exp\left[s\left(1-\sqrt{28/t}\right)\right] \quad (t>0) \]
    \[ a_c(t)=\beta_{cc}(t) \]
    \[ a_t(t)= \begin{cases} \beta_{cc}(t) & (t<28) \\ \beta_{cc}(t)^{2/3} & (t\ge 28) \end{cases} \]
    \[ a_E(t)=\beta_{cc}(t)^{0.3} \]

    The cement-class coefficient \(s\) is 0.38 for S, 0.25 for N, and 0.20 for R.

    EC2 creep uses the common KDS/EC2 separated form. Its humidity and size factors depend on the strength range.

    For \(f_{cm}\le 35\):

    \[ \phi_{RH}=1+\dfrac{1-RH/100}{0.1h_0^{1/3}} \]
    \[ \beta_H=\min\left(1.5\left[1+(0.012RH)^{18}\right]h_0+250,\;1500\right) \]

    For \(f_{cm}>35\):

    \[ \alpha_1=\left(35/f_{cm}\right)^{0.7} \]
    \[ \alpha_2=\left(35/f_{cm}\right)^{0.2} \]
    \[ \alpha_3=\left(35/f_{cm}\right)^{0.5} \]
    \[ \phi_{RH}=\left(1+\dfrac{(1-RH/100)\alpha_1}{0.1h_0^{1/3}}\right)\alpha_2 \]
    \[ \beta_H=\min\left(1.5\left[1+(0.012RH)^{18}\right]h_0+250\alpha_3,\;1500\alpha_3\right) \]

    The following \(\varepsilon_{cd}\) and \(\varepsilon_{ca}\) are positive shrinkage magnitudes from the EC2 equations. The shrinkage strain stored by Hyfeast is negative for contraction:

    \[ \varepsilon^{sh}(t)=-\left(\varepsilon_{cd}(t,t_s)+\varepsilon_{ca}(t)\right) \]
    \[ \varepsilon_{cd}(t,t_s)=\beta_{ds}(t,t_s)\varepsilon_{cd,\infty} \]
    \[ \beta_{ds}(t,t_s)= \begin{cases} 0 & (t<t_s) \\ \dfrac{t-t_s}{(t-t_s)+0.04h_0^{3/2}} & (t\ge t_s) \end{cases} \]
    \[ \varepsilon_{cd,\infty}=0.85k_h\left[(220+110\alpha_{ds1}) \exp\left(-\alpha_{ds2}\dfrac{f_{cm}}{10}\right)\right]10^{-6}\beta_{RH} \]
    \[ \beta_{RH}=1.55\left[1-\left(RH/100\right)^3\right] \]
    \[ \varepsilon_{ca}(t)=\beta_{as}(t)\varepsilon_{ca,\infty} \]
    \[ \beta_{as}(t)= \begin{cases} 0 & (t\le 0) \\ 1-\exp(-0.2\sqrt{t}) & (t>0) \end{cases} \]
    \[ \varepsilon_{ca,\infty}=2.5(f_{ck}-10)10^{-6} \]

    The drying shrinkage coefficients are \(\alpha_{ds1}=3\) and \(\alpha_{ds2}=0.13\) for S, \(\alpha_{ds1}=4\) and \(\alpha_{ds2}=0.12\) for N, and \(\alpha_{ds1}=6\) and \(\alpha_{ds2}=0.11\) for R.

    The size factor \(k_h\) is 1.00, 0.85, and 0.75 at \(h_0=100\), 200, and 300 mm, respectively, and 0.70 for \(h_0\ge500\) mm. Intermediate values are linearly interpolated.

    ACI concrete DB

    DB item forms and source units. ACI envelope functions use ACI318-2025-C<fck>, where <fck> represents the specified compressive strength \(f'_c\) in psi. ConcreteTime uses ACI209-1992-C<fc>, also with \(f'_c\) in psi. ACI 209 length correction equations are evaluated in inch, time variables are evaluated in days, and detailed cementContent is evaluated in \(\mathrm{lb/yd^3}\).

    Mechanical envelope properties (ACI318-2025-C<fck>).

    \[ f_{cm}=f'_c \]
    \[ E_c=57000\sqrt{f'_c}\;[\mathrm{psi}],\quad w_c\approx145\,\mathrm{lb/ft^3} \]
    \[ E_{ci}=E_c \]
    \[ f_t=7.5\sqrt{f'_c}\;[\mathrm{psi}] \]

    Here <fck> is the ACI specified compressive strength \(f'_c\) in psi. ACI DB items are used by HognestadCEnv, MPPCEnv, and MaekawaTEnv; they are not accepted by ParabolaCEnv or EC2CEnv.

    ConcreteTime properties (ACI209-1992-C<fc>).

    For ACI209-1992-C<fc>, \(f'_c\) is evaluated in psi, detailed cementContent is evaluated in \(\mathrm{lb/yd^3}\), and the time variables \(t\), \(\tau\), \(t_s\), and moistCuringDuration are evaluated in days. V/S and slump are entered in inch, the standard unit used by the ACI 209 length correction equations; the parser does not convert them from the global length unit. The 28-day modulus \(E_c(28)\) is the ACI mechanical-property \(E_c\) above. In the ACI 209 correction equations, V/S is the volume-to-surface ratio in inch. The implemented age factor is normalized by its 28-day value:

    \[ g(t)=\dfrac{t}{a+bt} \]
    \[ a_c(t)=\dfrac{g(t)}{g(28)} \]
    \[ a_t(t)=\sqrt{a_c(t)} \]
    \[ a_E(t)=\sqrt{a_c(t)} \]

    The ACI 209 coefficients are:

    curingType cementType \(a\) \(b\) \(c\) \(d\) \(f\)
    Moist TypeI 4.0 0.85 1.25 0.118 35
    Moist TypeIII 2.3 0.92 1.25 0.118 35
    Steam TypeI 1.0 0.95 1.13 0.094 55
    Steam TypeIII 0.7 0.98 1.13 0.094 55

    The dimensionless ACI 209 creep coefficient is converted to creep compliance with the loading-age elastic modulus:

    \[ C(t,\tau)=c_r(\Delta t)c_l(\tau) \]
    \[ \Delta t=\max(t-\tau,0) \]
    \[ c_r(\Delta t)= \begin{cases} 0 & (\Delta t=0) \\ \dfrac{\Delta t^{0.6}}{10+\Delta t^{0.6}} & (\Delta t>0) \end{cases} \]
    \[ E_c(\tau)=a_E(\tau)E_c(28) \]
    \[ c_l(\tau)=\dfrac{2.35c\tau^{-d}\gamma_{RH,c}\gamma_{VS,c}\gamma_{add,c}}{E_c(\tau)} \]
    \[ \gamma_{RH,c}=1.27-0.0067RH \]
    \[ \gamma_{VS,c}=\dfrac{2}{3}\left[1+1.13\exp\left(-0.54V/S\right)\right] \]

    For the compact ACI form, \(\gamma_{add,c}=\) creepUltimateScale. For the detailed ACI form:

    \[ \gamma_{add,c}=\gamma_{sl,c}\gamma_{\psi,c}\gamma_{\alpha,c} \]
    \[ \gamma_{sl,c}=0.82+0.067s_l \]
    \[ \gamma_{\psi,c}=0.88+0.0024\psi \]
    \[ \gamma_{\alpha,c}=\max(1.0,\;0.46+0.09\alpha) \]

    Here, \(V/S\) and \(s_l\) are in inch, \(\psi\) is fine aggregate percentage, and \(\alpha\) is air content percentage.

    In the ACI expression, \(\varepsilon_{sh,u}\) is a positive ultimate shrinkage magnitude. The shrinkage strain stored by Hyfeast is negative for contraction, so the equation carries the leading minus sign.

    \[ \varepsilon^{sh}(t)= \begin{cases} 0 & (t<t_s) \\ -\dfrac{t-t_s}{f+(t-t_s)}\varepsilon_{sh,u} & (t\ge t_s) \end{cases} \]
    \[ \varepsilon_{sh,u}=780\times10^{-6}\gamma_{RH,s}\gamma_{VS,s}\gamma_{add,s} \]
    \[ \gamma_{RH,s}= \begin{cases} 1.4-0.01RH & (RH\le 80) \\ 3.0-0.03RH & (RH>80) \end{cases} \]
    \[ \gamma_{VS,s}=\max\left(0.2,\;1.2\exp(-0.12V/S)\right) \]

    For the compact ACI form, \(\gamma_{add,s}=\) shrinkageUltimateScale. For the detailed ACI form:

    \[ \gamma_{add,s}=\gamma_{mc}\gamma_{sl,s}\gamma_{\psi,s}\gamma_{cc,s}\gamma_{\alpha,s} \]
    \[ \gamma_{sl,s}=0.89+0.041s_l \]
    \[ \gamma_{\psi,s}= \begin{cases} 0.30+0.014\psi & (\psi\le 50) \\ 0.90+0.002\psi & (\psi>50) \end{cases} \]
    \[ \gamma_{cc,s}=0.75+0.00036c_c \]
    \[ \gamma_{\alpha,s}=0.95+0.008\alpha \]

    Here, \(c_c\) is cement content in \(\mathrm{lb/yd^3}\). For Steam curing, \(\gamma_{mc}=1.0\). For Moist curing, \(\gamma_{mc}\) is 1.20, 1.10, 1.00, 0.93, 0.86, and 0.75 at moistCuringDuration values of 1, 3, 7, 14, 28, and 90 days, respectively; intermediate values are linearly interpolated.

    Keyword line
    • TYPE=type: type of function
      • MultiLinear: Multi-linear function
      • TimeSignal: Time signal. Multi-linear function with fixed step size. Supports both file source lines and tools/db/timeSignal DB source lines
      • ResponseSpectrum: Response spectrum function generated from a TimeSignal, KDS17, or KDS41 source
      • String: function by mathematical expression
      • ParabolaCEnv: section-analysis parabola concrete compressive envelope

    First data line
    • dtime: Time step or auto (required). auto is allowed only when at least one DB source line is provided, and it is resolved from the DB record dtime. When multiple DB records are listed, all DB record dtime values shall match after conversion to the reference UnitSystem.

    Second data line and subsequent data lines
    • file: File to be read (required). A text file with values separated by commas, spaces, etc., or an npy file.
    • nseries: Number of time series in the file (optional, default 1). For npy files, the number of columns must be the same.
    • scale: Scale factor (optional, default 1).
    • skipRows: Number of rows to skip at the beginning of the file (optional, default 0). Ignored for npy files.

    The TimeSignal function, suitable for representing time histories, can be understood as a multi-linear function with fixed interval x values. File source line data is read with values separated by whitespace (colon, space, tab, newline). Each file consists of nseries time series data. It reads ntime entries for each of the nseries data. If the file has fewer data entries, the missing values are filled with zeros. At time 0, the value is assumed to be 0, and the first value given in the data corresponds to the value at time dt. The final value corresponds to the value at time ntime*dt.

- If the keyword line has no `UnitSystem` and a global UnitSystem exists, file source lines are interpreted in the global UnitSystem. DB source lines are read in the record UnitSystem, then converted into the global/function UnitSystem before being stored.
- If the keyword line has no `UnitSystem` and all source lines are DB lines, the function metadata is stored with the first DB record UnitSystem, and the remaining DB source lines are converted into that UnitSystem.
- If the keyword line has no `UnitSystem`, no global UnitSystem exists, and file and DB source lines are mixed, the input is rejected because there is no reference UnitSystem.
- It is not an input error for the keyword `UnitSystem` and DB record UnitSystem to differ. Multiple DB record UnitSystems and quantities may also differ, but their dtime shall match after conversion.
- If source lines have different quantities, the TimeSignal definition is still valid. Signal Analysis and preview features may restrict operations that require a single physical quantity.

    Define the stress-strain compressive envelope for cross-sectional design as specified by EC2 and KDS.

    *Function, Type=ParabolaCEnv, UnitSystem=unitSystem, Name=name
  fck, n, eco, ecu[, alpha]

*Function, Type=ParabolaCEnv, Name=name
  KDS-2026-C<fck>|EC2-2004-C<fck>[, alpha][, ToDirectForm]
    First data line
    • fck: design compressive strength, (required)
    • n: shape factor (required)
    • eco: peak strain (optional, 0.002)
    • ecu: ultimate strain (optional, always set to max(eco, ecu) )
    • alpha: reduction factor multiplied by fck (optional, default 1.0)
    • KDS-2026-C<fck> or EC2-2004-C<fck>: Concrete DB item accepted by ParabolaCEnv. It can be used instead of the numeric dataline when keyword UnitSystem is omitted and a global UnitSystem is defined.     • ToDirectForm: Optional output option for DB item datalines. It must be the last token.     The curve given as

    \[ f_c= \begin{cases} \alpha f_{ck}\left[1-\left(1-\dfrac{\epsilon_c}{\epsilon_{co}}\right)^n\right] & (\epsilon_c\le\epsilon_{co}) \\ \alpha f_{ck} & (\epsilon_{co}<\epsilon_c\le\epsilon_{cu}) \end{cases} \]

    Hyfeast returns zero for \(\epsilon_c > \epsilon_{cu}\) and does not append a tail branch.

    ParabolaCEnv does not use Ec or Eci. The curve is a section-design parabola-rectangle relation, and the peak stress is \(\alpha f_{ck}\).

    For DB input, the item strength is used as fck and alpha controls the design reduction. The DB item supplies the following section-design shape parameters, with fck in MPa:

    KDS-2026:

    \[ n= \begin{cases} 2.0 & (f_{ck} \le 40) \\ 1.2 + 1.5\left((100-f_{ck})/60\right)^4 & (40 < f_{ck} \le 90) \end{cases} \]
    \[ \varepsilon_{co}= \begin{cases} 0.002 & (f_{ck} \le 40) \\ 0.002 + 0.0001(f_{ck}-40)/10 & (40 < f_{ck} \le 90) \end{cases} \]
    \[ \varepsilon_{cu}= \begin{cases} 0.0033 & (f_{ck} \le 40) \\ 0.0033 - 0.0001(f_{ck}-40)/10 & (40 < f_{ck} \le 90) \end{cases} \]

    EC2-2004:

    \[ n= \begin{cases} 2.0 & (f_{ck} \le 50) \\ 1.4 + 23.4\left((90-f_{ck})/100\right)^4 & (50 < f_{ck} \le 90) \end{cases} \]
    \[ \varepsilon_{co}= \begin{cases} 0.002 & (f_{ck} \le 50) \\ \left(2.0 + 0.085(f_{ck}-50)^{0.53}\right)/1000 & (50 < f_{ck} \le 90) \end{cases} \]
    \[ \varepsilon_{cu}= \begin{cases} 0.0035 & (f_{ck} \le 50) \\ \left(2.6 + 35\left((90-f_{ck})/100\right)^4\right)/1000 & (50 < f_{ck} \le 90) \end{cases} \]

    For KDS strength-design section checks, use \(\alpha=0.85\). For KDS limit-state design, use \(\alpha=0.85\phi_c\); \(\phi_c=0.65\) for ultimate load combinations and \(\phi_c=1.0\) for extreme-event, service, or fatigue load combinations. For EC2, use \(\alpha=\alpha_{cc}/\gamma_C\); \(\alpha_{cc}\) is a national parameter, typically between 0.8 and 1.0, and \(\gamma_C\) is 1.5 for persistent/transient situations or 1.2 for accidental situations.

    Define the compressive envelope of concrete based on the Mander, Priestley, and Park model.

    *Function, Type=MPPCEnv, Name=name
  fco, Ec, eco, ecu, fcc, esp[, EciCurve]

*Function, Type=MPPCEnv, Name=name
  KDS-2026-C<fck>|ACI318-2025-C<fck>|EC2-2004-C<fck>[, EciCurve][, ToDirectForm]
    First data line
    • fco: unconfined compressive strength (required)
    • Ec: unconfined secant modulus to 0.4*fco (required)
    • eco: strain at peak strength of unconfined concrete (optional, default 0.002)
    • ecu: ultimate strain (optional, default 2*eco)
    • fcc: confined compressive strength. (optional, default fco)
    • esp: spalling strain (optional, default ecu). A straight spalling branch from ecu to esp is used only when esp is greater than ecu; Hyfeast returns zero beyond esp.
    • EciCurve: Optional curve-shape flag. If omitted, the curve is linear from the origin to 0.4*fco or 0.4*fcc with the derived secant slope; if specified, the Mander-Priestley-Park curve is used from the origin.
    • KDS-2026-C<fck>, ACI318-2025-C<fck>, or EC2-2004-C<fck>: Concrete DB item. It can be used instead of the numeric dataline when keyword UnitSystem is omitted and a global UnitSystem is defined. DB input assumes unconfined concrete. ACI fills fco=f'c, eco=0.002, and ecu=0.003; KDS/EC2 fill fco=fcm, eco=standard value, and ecu=standard value. All standards use the DB-derived secant modulus for Ec, set fcc=fco, and set esp=ecu.
    • ToDirectForm: Optional output option for DB item datalines. It must be the last token. When specified, saved/formatted output writes the resolved numeric dataline in the current global UnitSystem. If that unit system is the same as the global UnitSystem, no local UnitSystem is printed on the keyword line. If omitted, the DB item dataline is preserved.

    The Mander-Priestley-Park model can define both the confined and unconfined concrete model.

    For the unconfined input values, Hyfeast interprets Ec as the secant modulus to 0.4*fco:

    \[ E_{sec,0}=\frac{f_{co}}{\epsilon_{co}}, \qquad \epsilon_{0.4,0}=\frac{0.4 f_{co}}{E_c}, \qquad x_{0.4,0}=\frac{\epsilon_{0.4,0}}{\epsilon_{co}} =0.4\frac{E_{sec,0}}{E_c} \]

    The Mander-Priestley-Park stress ratio is

    \[ \frac{f_c}{f_{cc}}= \frac{x r}{r-1+x^r}, \qquad r=\frac{E_{ci}}{E_{ci}-E_{sec}} \]

    Hyfeast solves the unconfined equation below for \(r_0\), then derives the internal initial tangent:

    \[ 0.4=\frac{x_{0.4,0} r_0}{r_0-1+x_{0.4,0}^{r_0}}, \qquad E_{ci}=\frac{r_0}{r_0-1}E_{sec,0} \]

    The direct input must satisfy \(E_c \ge E_{sec,0}\). If fcc differs from fco, the same \(E_{ci}\) is used for the confined curve. Hyfeast computes

    \[ \epsilon_{cc}=\epsilon_{co}\left(1+5\left(\frac{f_{cc}}{f_{co}}-1\right)\right), \qquad E_{sec,c}=\frac{f_{cc}}{\epsilon_{cc}}, \qquad r_c=\frac{E_{ci}}{E_{ci}-E_{sec,c}} \]

    and solves \(0.4=x_{0.4,c}r_c/(r_c-1+x_{0.4,c}^{r_c})\). The transition strain used by the default linearized branch is then

    \[ \epsilon_{0.4,c}=x_{0.4,c}\epsilon_{cc}, \qquad E_{c,\mathrm{linear}}=\frac{0.4f_{cc}}{\epsilon_{0.4,c}} \]

    When EciCurve is omitted, the curve is linear from the origin to this current 0.4-strength point. When EciCurve is specified, the Mander-Priestley-Park curve uses the derived \(E_{ci}\) from the origin.

    8.1.10 *Function, Type=MaekawaTEnv

    Maekawa concrete tensile envelope

    *Function, Type=MaekawaTEnv, UnitSystem=unitSystem, Name=coverTension
  Ec, ft[, c]

*Function, Type=MaekawaTEnv, Name=coverTension
  KDS-2026-C<fck>|ACI318-2025-C<fck>|EC2-2004-C<fck>[, c][, ToDirectForm]
    First data line
    • Ec: secant elastic modulus (required for direct numeric input)
    • ft: tensile strength (required for direct numeric input)
    • c: parameter for Maekawa model (optional, default 0.4)
    • KDS-2026-C<fck>, ACI318-2025-C<fck>, or EC2-2004-C<fck>: Concrete DB item. It fills direct numeric Ec with the DB-derived secant modulus when keyword UnitSystem is omitted and a global UnitSystem is defined. It fills ft with \(7.5\sqrt{f'_c}\) for ACI items and \(f_{ctm}\) for KDS/EC2 items.
    • ToDirectForm: Optional output option for DB item datalines. It must be the last token. When specified, saved/formatted output writes the resolved numeric dataline in the current global UnitSystem. If that unit system is the same as the global UnitSystem, no local UnitSystem is printed on the keyword line. If omitted, the DB item dataline is preserved.

    Maekawa et al. (2002) proposed the following tension softening curve for both normal concrete and reinforced concrete considering tensile hardening, using the same equation:

    \[ \sigma = f_t \left(\frac{\epsilon_{tu}} {\epsilon_t} \right)^c \]

    Here, \(c\) is the factor that determines the shape of the curve. For normal concrete, it should be determined by the following equation based on fracture energy and the characteristic length of the element:

    \[ \int \sigma_t d \epsilon_t = \int f_t \left(\frac{\epsilon_{tu}} {\epsilon_t} \right)^c d \epsilon_t = \frac {G_F}{l_r} \]

    In reinforced concrete, parameter analysis suggests a value of 0.4 for deformed bars and 0.2 for welded wire mesh. Figure 8.2-6 shows a representative result.

    • User: Uses existing functions as the user-defined time-dependent function set. The named-group form accepts one or more of Aging, Creep, and Shrinkage; omitted groups use neutral defaults.
    • Aging=fcAge, ftAge, EcAge: Function names for the compressive-strength, tensile-strength, and elastic-modulus age factors. The three functions must be specified together. They are evaluated with \(x=t\). If omitted, the three age factors are 1.
    • Creep=creepDuration, creepLoadAge: Function names for the creep duration factor and creep loading-age factor. creepDuration is evaluated with \(x=t-\tau\), and creepLoadAge is evaluated with \(x=\tau\). The two functions must be specified together. If omitted, the creep contribution is 0.
    • Shrinkage=shrinkage: Function name for the free shrinkage strain. It is evaluated with \(x=t\). For the User input function value, + means shrinkage and - means expansion; the sign is reversed when the value is used in the material. If omitted, the shrinkage contribution is 0.
    • EC2-2004-C<fck>: EC2-2004 concrete time-dependent function. <fck> is in MPa. cementClass is S, N, or R.
    • KDS-2026-C<fck>: KDS-2026 concrete time-dependent function. <fck> is in MPa. cementType is Type1, Type2, Type3, or Type5; curingType is Moist or Steam.
    • ACI209-1992-C<fc>: ACI 209R-92 concrete time-dependent function. <fc> is \(f'_c\) in psi. cementType is TypeI or TypeIII; curingType is Moist or Steam.
    • RH: Relative humidity in percent.
    • h0: EC2/KDS notional member size in mm.
    • V/S: ACI 209 volume-to-surface ratio in inch. It is used directly in the ACI 209 correction equations.
    • ts: Concrete age, in days, at the beginning of drying shrinkage.
    • creepUltimateScale, shrinkageUltimateScale: Optional ACI 209 additional scale factors. When these two tokens are omitted, both factors are 1.0.
    • moistCuringDuration, slump, fineAggregatePercent, cementContent, airContent: Detailed ACI 209 correction parameters. moistCuringDuration is in days, slump is in inch, fineAggregatePercent and airContent are in percent, and cementContent is in \(\mathrm{lb/yd^3}\). slump and cementContent use fixed units and are not converted from the global unit system.

    ConcreteTime stores the six function series and evaluates EC2/KDS/ACI formulas according to the concrete DB common rules and standard-specific concrete DB descriptions above. It also provides an internal default first retardation time for material-side Kelvin-chain fitting. Built-in EC2/KDS ConcreteTime functions provide 1 day, while built-in ACI 209 and User ConcreteTime functions provide 5 days. If a different first retardation time is needed, specify lambda1 in the material LongTerm, Concrete dataline that uses this function.

    In both standard EC2/KDS/ACI forms and the User form, the time variables \(t\), \(\tau\), \(t-\tau\), and \(t_s\) are evaluated in days, regardless of the time unit specified by *Environment, Type=UnitSystem. A Function referenced by the User form must not define keyword-line UnitSystem=.... This section lists only the input syntax and examples.
