    2.9 hfStudio Remote Control Postprocessing

    Use these commands after analysis results are available and you want to switch steps, frames, contours, vectors, scales, or overlay displays.

    get queries return JSON and do not append a scriptTail. Set-type commands append canonical post-* ... tails to Remote Control History and *.ipc.txt.

    Most definition commands remain preprocessing-only, but postprocessing mode still keeps a few GUI-matched exception paths that can modify the current HDB: environment-info set, nset, elset, step Post ..., step-delete-from ..., and history PostHistory ....

    2.9.1 post-plot

    hfStudio --remote [--target <id>] post-plot <contour|diagram|vector|sensor|deformed> <on|off>
hfStudio --remote [--target <id>] post-plot plot <x-tag> <y-tag> [--id <cN>]
hfStudio --remote [--target <id>] post-plot series list
hfStudio --remote [--target <id>] post-plot series details <tag>
hfStudio --remote [--target <id>] post-plot series add <tag>...
hfStudio --remote [--target <id>] post-plot series remove <tag>
hfStudio --remote [--target <id>] post-plot series clear
hfStudio --remote [--target <id>] post-plot series expr <expression> --var <name=tag> [--var <name=tag> ...]
hfStudio --remote [--target <id>] post-plot curve list [--id <cN>]
hfStudio --remote [--target <id>] post-plot curve add <x-tag> <y-tag> [--id <cN>]
hfStudio --remote [--target <id>] post-plot curve show <x-tag> <y-tag> <on|off> [--id <cN>]
hfStudio --remote [--target <id>] post-plot curve remove <x-tag> <y-tag>
hfStudio --remote [--target <id>] post-plot curve clear
hfStudio --remote [--target <id>] post-plot view show
hfStudio --remote [--target <id>] post-plot export <file> [--id <cN>]
hfStudio --remote [--target <id>] post-plot copy [--id <cN>]
    • Controls postprocessing plot toggles in the active view.
    • Available only in postprocessing mode.
    • deformed on fails when the current result step does not contain displacement output D.
    • plot registers one postprocessing series in the shared PostPlot data model, shows it in the target PostPlot composition, and refreshes open PostPlot views.
    • series commands manage the left Series candidate list stored in the shared PostPlot data model. Index is implicit and is not added with series add.
    • series expr creates a MathExpression-derived source tag. Map variables with --var <name=tag>, for example --var A=R1:LF; all operands must belong to the same source group and have the same point count.
    • curve commands manage the right Curves list. curve add is the canonical form of plot, curve show changes the checkbox/visibility state for one composition, and curve remove/curve clear remove shared registered curves.
    • view show opens a floating PostPlot display window, matching the editor's Show Plot button.
    • <x-tag> and <y-tag> use the same source keys as the XY Plot Editor. Examples include header:history-name.H, (index):history-name.H, result field tags such as N:0:53:D.Z.R, and result frame-axis tags such as R1:STime, R1:RTime, and R1:LF.
    • R1:RTime values follow the TUnit of the Step that owns the result step. The XY Plot Editor and plot axes show the unit as in RTime [day], while command source keys keep the R1:RTime form. export and copy use the converted numeric values in that unit.
    • export <file> writes the currently visible PostPlot series from the target composition to a CSV file.
    • copy copies the same CSV content to the clipboard. When replayed from script-save, it updates the clipboard again.
    • --id <cN> selects the target floating PostPlot display view and its visible-series composition. It does not choose a separate PostPlot data cache; the cache is shared. If no PostPlot view is open, post-plot runs against the default composition.
    • script-save does not record the display-view --id. Replayed PostPlot data commands apply to the active PostPlot composition if one is open, otherwise the default composition.
    • plot and curve add return JSON with series, added, seriesCount, xPointCount, yPointCount, and plotted.
    • series list, series details, curve list, and view show return JSON and do not require CSV export.
    • export and copy return JSON with seriesCount and rowCount.

    2.9.2 post-step

    hfStudio --remote [--target <id>] post-step <step-name>
hfStudio --remote [--target <id>] post-step get
    • post-step <step-name> selects the named result step and moves to frame 1 of that step.
    • post-step get returns the current step and frame state as JSON.
    • Available only in postprocessing mode.
    • <step-name> must match an existing result-step name exactly.
    • The single token get is reserved as a query keyword for this command.

    2.9.3 post-frame

    hfStudio --remote [--target <id>] post-frame <frame-index>
hfStudio --remote [--target <id>] post-frame get
    • post-frame <frame-index> selects a frame in the current result step.
    • post-frame get returns the current step and frame state as JSON.
    • Available only in postprocessing mode.
    • <frame-index> is 1-based and must be within the current step frame count.

    2.9.4 post-scalar

    hfStudio --remote [--target <id>] post-scalar <field> [<average-threshold>]
hfStudio --remote [--target <id>] post-scalar get
    • Selects the scalar field for the active result step.
    • get returns the current scalar field state as JSON.
    • Available only in postprocessing mode.
    • <field> must be a valid scalar field name for the current step and frame.
    • [<average-threshold>] is optional and must be an integer between 0 and 100.
    • <average-threshold> controls whether extrapolated element scalar values are averaged at shared element nodes. 0 disables averaging, while 1..100 averages values in the same averaging group only when they satisfy:
    \[ \max(v_i)-\min(v_i) \le \frac{\mathrm{threshold}}{100} \left(\max(v_\mathrm{region})-\min(v_\mathrm{region})\right) \]
    • Averaging groups are formed within the same section, and \(v_\mathrm{region}\) is the scalar value range of that section group. Continuum elements average by shared node. Shell elements keep bottom/top values separate and average only values with the same shell element coordinate system. Beam elements average only values with the same section/material point index and beam element coordinate system.

    2.9.5 post-vector

    hfStudio --remote [--target <id>] post-vector <field>
hfStudio --remote [--target <id>] post-vector get
    • Selects the vector or tensor field for the active result step.
    • get returns the current vector field state as JSON.
    • Available only in postprocessing mode.
    • <field> must be a valid vector or tensor field name for the current step and frame.

    2.9.6 post-contour

    hfStudio --remote [--target <id>] post-contour auto-range <on|off>
hfStudio --remote [--target <id>] post-contour auto-range get
hfStudio --remote [--target <id>] post-contour range <min> <max>
hfStudio --remote [--target <id>] post-contour range get
hfStudio --remote [--target <id>] post-contour bands <n>
hfStudio --remote [--target <id>] post-contour bands get
hfStudio --remote [--target <id>] post-contour mode <uniform|custom>
hfStudio --remote [--target <id>] post-contour mode get
hfStudio --remote [--target <id>] post-contour levels <v1,v2,...>
hfStudio --remote [--target <id>] post-contour levels get
hfStudio --remote [--target <id>] post-contour overlay <text>
hfStudio --remote [--target <id>] post-contour overlay get
hfStudio --remote [--target <id>] post-contour overlay-color <r,g,b[,a]>
hfStudio --remote [--target <id>] post-contour overlay-color get
    • Controls contour settings in the active postprocessing view.
    • Available only in postprocessing mode.
    • auto-range, range, and bands set operations are rejected while custom contour mode is active.
    • mode custom initializes custom boundary levels from the current uniform range and band state when needed.
    • levels set requires between 2 and 31 strictly increasing boundary values.
    • overlay-color uses integer 0..255 channel values.
    • get returns the full contour state as JSON, plus action-specific aliases such as enabled, min, max, text, or color.

    2.9.7 post-scale

    hfStudio --remote [--target <id>] post-scale deformed auto <on|off>
hfStudio --remote [--target <id>] post-scale deformed auto get
hfStudio --remote [--target <id>] post-scale deformed value <scale>
hfStudio --remote [--target <id>] post-scale deformed value get
hfStudio --remote [--target <id>] post-scale diagram auto <on|off>
hfStudio --remote [--target <id>] post-scale diagram auto get
hfStudio --remote [--target <id>] post-scale diagram value <scale>
hfStudio --remote [--target <id>] post-scale diagram value get
hfStudio --remote [--target <id>] post-scale vector auto <on|off>
hfStudio --remote [--target <id>] post-scale vector auto get
hfStudio --remote [--target <id>] post-scale vector value <scale>
hfStudio --remote [--target <id>] post-scale vector value get
hfStudio --remote [--target <id>] post-scale sensor auto <on|off>
hfStudio --remote [--target <id>] post-scale sensor auto get
hfStudio --remote [--target <id>] post-scale sensor <e|d|v|a> <scale>
hfStudio --remote [--target <id>] post-scale sensor <e|d|v|a> get
    • Controls deformed, diagram, vector, and sensor scale factors in the active postprocessing view.
    • Available only in postprocessing mode.
    • Explicit value or e|d|v|a inputs disable the corresponding auto-scale mode first.
    • get returns the full scale state as JSON, plus query-specific aliases such as enabled or value.

    2.9.8 post-display

    hfStudio --remote [--target <id>] post-display <information|scalarbar|min-max-tag> <on|off>
    • Toggles postprocessing overlay and display items in the active view.
    • Available only in postprocessing mode.
    • information: upper-left information text
    • scalarbar: scalar bar widget
    • min-max-tag: min and max caption tags

    2.9.9 post-animation-time-history

    hfStudio --remote [--target <id>] post-animation-time-history <on|off>
    • Matches Postprocessing > Play > Time History Ani.
    • Available only in postprocessing mode.
    • Fails if scale-factor animation is currently active.

    2.9.10 post-animation-scale-factor

    hfStudio --remote [--target <id>] post-animation-scale-factor <on|off>
    • Matches Postprocessing > Play > Scale Factor Ani.
    • Available only in postprocessing mode.
    • Fails if time-history animation is currently active.

    2.9.11 post-animation-loop

    hfStudio --remote [--target <id>] post-animation-loop <on|off>
    • Matches Postprocessing > Play > Loop.
    • Available only in postprocessing mode.
    • Controls whether the current animation repeats automatically.

    2.9.12 post-animation-record

    hfStudio --remote [--target <id>] post-animation-record <on|off> [<file>]
    • Matches Postprocessing > Play > Record.
    • Available only in postprocessing mode.
    • on requires a writable output file path with .avi or .mp4 extension.
    • off clears the current animation record target.
    • Can be changed only while no animation is active.

    Example:

    hfStudio --remote post-step "LC1-DeadLoad"
hfStudio --remote post-frame 7
hfStudio --remote post-scalar "S.Mises" 85
hfStudio --remote post-contour mode get
hfStudio --remote post-plot plot "(index):result-history.H" "D.X@2:result-history.H"
hfStudio --remote post-plot plot "R1:STime" "R1:LF"
hfStudio --remote post-plot series expr "A-B" --var "A=R1:STime" --var "B=R1:RTime"
hfStudio --remote post-plot series list
hfStudio --remote post-plot export "tmp/postplot-result.csv"
hfStudio --remote post-plot view show
hfStudio --remote post-plot copy
hfStudio --remote post-animation-record on "D:/work/result.avi"
