    2.2 Window and File

    The hf2DStudio File menu and File toolbar create section models, open and save them, import DXF geometry, edit options, and close the program.

    For automation of the same actions, see Remote Control Window and File.

    2.2.1 Menu layout

    • New: start a new empty section model
    • Open: open an existing .hf2d file
    • Import: import a DXF drawing as the current section's Geometry
    • Save: save to the current file
    • Save As: save to a different path
    • Open Folder in File Explorer: open the directory of the current file in the OS file explorer
    • Option: open the settings dialog
    • Recent Files: list of recently opened files (up to 5)
    • Undo / Redo: step backward/forward through the model-history stack
    • Close: quit the program

    The File toolbar exposes New, Open, Import, Save, Option, Undo, and Redo.

    2.2.2 New

    Start with an empty section model.

    If unsaved changes exist, the same save-confirmation flow as GUI File > New runs.

    • Yes: save the current section first. If there is no save path yet, the Save As dialog opens.
    • No: discard unsaved changes and create a new empty section.
    • Cancel: keep the current section open and abort the action.

    Remote Control can skip this confirmation with --discard-unsaved.

    If the current Untitled model only contains the startup UnitSystem choice, hf2DStudio discards it without asking.

    Same action via Remote Control: new.

    2.2.3 Open

    Open the specified .hf2d section file.

    • If unsaved changes exist and the current file already has a path, hf2DStudio auto-saves first.
    • If unsaved changes exist and the current file has no path, Open fails because there is no place to auto-save, except for an Untitled model whose only user change is the startup UnitSystem choice.

    Same action via Remote Control: open.

    2.2.4 Import (DXF Geometry)

    Import supported DXF entities into the active section's Geometry.

    • Supported entities: LINE, LWPOLYLINE, POLYLINE, ARC, CIRCLE, ELLIPSE, SPLINE. Uses the same reader path as the hfStudio DXF importer and converts the resulting Construction Guide primitives into Line, Arc, Bezier, and Spline curves.
    • DXF z coordinates are dropped; only (x, y) becomes the hf2DStudio Geometry coordinate.
    • DXF unit scaling is applied only when both the DXF $INSUNITS and the active section/global unit are valid; otherwise coordinates are taken without scaling.
    • Import fails if the active section already has a mesh. Remove the mesh first via Operation > Delete Mesh.

    Same action via Remote Control: import-dxf-geometry.

    2.2.5 Save / Save As

    • Save: save to the current file path. If there is no path, the Save As dialog opens automatically.
    • Save As: pick a new path; that path is used and becomes the current file path.

    Remote Control collapses both into one command — save.

    2.2.6 Open Folder in File Explorer

    Open the directory of the current file in the OS file explorer. Useful for checking the result .xlsx file or other side outputs.

    2.2.7 Option

    Open the settings dialog. Individual options are documented inside the dialog.

    2.2.8 Recent Files

    Up to five recently opened files appear in the menu and can be opened directly. They follow the same unsaved-change handling as Open.

    2.2.9 Undo / Redo

    Apply the in-memory model-history stack of the session.

    • Disabled when no previous/next snapshot is available.
    • Triggered from the menu or toolbar buttons.
    • Rebuilds state from the stack rather than re-parsing input text, so it works across Geometry, Definition, and Operation actions.

    2.2.10 Close

    Quit the program.

    • If unsaved changes exist and the current file has a path, hf2DStudio auto-saves first.
    • If unsaved changes exist and the file has no path, Close fails, except for an Untitled model whose only user change is the startup UnitSystem choice.
    • Remote Control can quit immediately without auto-save using --discard-unsaved — quit.
