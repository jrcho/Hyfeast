    3 Plugin Interface

    3.1 Functions to export

    A plugin DLL must export the following two functions under their C names.

    Function Role
    hf_umat_v1 Computes one material point. The argument list is the same as the Abaqus UMAT (Section 3.3).
    hf_umat_abi_version Takes no arguments and returns the integer 1 (HF_UMAT_ABI_VERSION). Hyfeast calls it once when loading the DLL and stops with an error before the analysis if the value differs.

    If a different function name (symbol) is given on the first dataline of *Material, that function is called instead of hf_umat_v1. Its argument list must be the same.

    3.2 Differences from the Abaqus UMAT

    Item Abaqus UMAT hf_umat_v1
    Function name Depends on the compiler (UMAT, umat_, ...) Fixed as hf_umat_v1; Fortran uses bind(C, name="hf_umat_v1")
    CMNAME CHARACTER*80 with a hidden length argument 81-byte char array (name of at most 80 characters, NUL, zero padding); no hidden argument

    Other argument names, order, meaning and component order are the same as in Abaqus. An existing Abaqus UMAT can be used without changing its source when it is built with the kit bridge, which covers these two differences (Chapter 4).

    3.3 Arguments

    All arguments are passed by reference (pointer) and are non-null. Matrices are column-major; in C, DDSDDE(i,j) is ddsdde[(i-1) + (j-1)*ntens].

    # Argument Type In/Out Size Meaning and Hyfeast v1 value
    1 STRESS double in/out NTENS Stress at start of increment → at end of increment
    2 STATEV double in/out NSTATV State variables at start → at end of increment; 0 in the first increment
    3 DDSDDE double out NTENS×NTENS Tangent \(\partial\Delta\sigma/\partial\Delta\varepsilon\); zeroed before the call
    4 SSE double in/out 1 Specific elastic strain energy; stored by Hyfeast and passed back in the next increment (not written)
    5 SPD double in/out 1 Specific plastic dissipation; stored like SSE
    6 SCD double in/out 1 Specific creep dissipation; stored like SSE
    7 RPL double out 1 Not used
    8 DDSDDT double out NTENS Not used
    9 DRPLDE double out NTENS Not used
    10 DRPLDT double out 1 Not used
    11 STRAN double in NTENS Total strain at start of increment
    12 DSTRAN double in NTENS Strain increment (total strain increment including thermal strain)
    13 TIME double in 2 TIME(1) step time, TIME(2) total time at start of increment
    14 DTIME double in 1 Time increment (Section 3.5)
    15 TEMP double in 1 Temperature at start of increment (temperature change accumulated since the start of the analysis)
    16 DTEMP double in 1 Temperature increment
    17 PREDEF double in 1 0
    18 DPRED double in 1 0
    19 CMNAME char in 81 Material name (Section 3.2)
    20 NDI int32 in 1 Number of direct components (Section 3.4)
    21 NSHR int32 in 1 Number of shear components
    22 NTENS int32 in 1 Total number of components
    23 NSTATV int32 in 1 NState value
    24 PROPS double in NPROPS Material properties
    25 NPROPS int32 in 1 Number of properties
    26 COORDS double in 3 0
    27 DROT double in 3×3 Identity
    28 PNEWDT double in/out 1 \(10^{30}\) before the call; a value below 1 requests a smaller increment (Section 3.6)
    29 CELENT double in 1 Element characteristic length (Section 3.5)
    30 DFGRD0 double in 3×3 Identity
    31 DFGRD1 double in 3×3 Identity
    32 NOEL int32 in 1 0
    33 NPT int32 in 1 0
    34 LAYER int32 in 1 0
    35 KSPT int32 in 1 0
    36 JSTEP int32 in 4 0
    37 KINC int32 in 1 0
    • Integers are 4 bytes (int32_t, Fortran integer(c_int)), the same as the default INTEGER of Abaqus on Windows x64.
    • Writing to input arguments has no effect on Hyfeast; Hyfeast passes buffers filled anew for every call.
    • The function returns no value. Failure is reported by PNEWDT < 1.

    3.4 Components by condition

    Hyfeast calls the plugin with the following dimensions depending on the element condition. Shear strains are engineering shear strains (\(\gamma_{12}=2\varepsilon_{12}\)).

    Condition Elements NDI NSHR NTENS Component order
    3D C3D4, C3D6, C3D8, C3D8I, C3D8PMDL, CS6, CS8 3 3 6 11, 22, 33, 12, 13, 23
    Shell S3, S3F, S4, S4F 3 3 6 11, 22, 33, 12, 13, 23
    Plane strain, axisymmetric CPE3, CPE4, CAX3, CAX4, ... 3 1 4 11, 22, 33, 12
    Plane stress CPS3, CPS4, ... 2 1 3 11, 22, 12
    • Plane strain: DSTRAN(3)=0 is passed. The returned STRESS(3) is used for the S33 output, and the 33 row and column of DDSDDE are not used.
    • Plane stress: The plugin must enforce \(\sigma_{33}=0\) and return the reduced 3×3 DDSDDE. The 33 component of the strain output is 0.
    • Shell: The plugin is called in 3D. Hyfeast corrects the \(\varepsilon_{33}\) increment by Newton iteration until \(\sigma_{33}=0\), calling the plugin again from the start-of-increment state in each iteration. After convergence the 33 component is condensed out of the tangent. The transverse shear (13, 23) stiffness returned by the plugin is used as is. A 3D UMAT can therefore be used for shells without extra input, while shell-only Abaqus UMATs that handle only NTENS=3 cannot be used. The iteration is limited to 20; without convergence the increment is reduced.
    • Axisymmetric: The 33 component is the hoop direction.

    3.5 Time, temperature and characteristic length

    Argument Quasi-static and dynamic Static
    TIME(1) Step time at start of increment Step time (load factor) at start of increment
    TIME(2) Total time at start of increment Real time up to the previous step + TIME(1)
    DTIME Time increment Step time increment
    • The time unit is the analysis time unit of the step (TUnit).
    • TEMP is the temperature change accumulated since the start of the analysis and starts from 0. If an absolute temperature is needed, put the reference temperature in PROPS.
    • DSTRAN is the total strain increment. Thermal expansion is handled by the plugin through TEMP and DTEMP.
    CELENT Elements
    \(\sqrt[3]{V}\) 3D solids (per integration point for C3D4), continuum shells (CS6, CS8)
    \(\sqrt{A}\) 2D solids, shells (S3, S3F, S4, S4F)

    Calls that are not analysis increments receive the following values.

    Call TIME DTIME CELENT
    *TestMaterial 0, 0 0 1
    Directional field computation of CS6, CS8 0, 0 1 1

    3.6 Call rules

    • State: During equilibrium iterations every call starts from the last converged state (STRESS, STATEV, STRAN, TEMP, energies), and only the results of an accepted increment are committed. The plugin only has to update the input state by DSTRAN.
    • Tangent symmetry: With Unsymm=No (default) the tangent is symmetrized as \((C+C^T)/2\). With Unsymm=Yes it is used as is and the unsymmetric stiffness matrix is solved.
    • Increment reduction: If PNEWDT is returned smaller than 1, the current increment is rejected and solved again with an increment reduced by the ratio chosen by the Hyfeast time controller. The returned ratio itself is not used. Values larger than 1 are ignored.
    • Non-finite values: NaN or infinity in STRESS, DDSDDE, STATEV or the energies is treated as failure and the increment is reduced.
    • Concurrent calls: Several integration points are computed at the same time (OpenMP). The plugin must be reentrant and must not use writable global or static variables. Fortran is built with /recursive so that local arrays are on the stack (build_umat.cmd sets it). Specify Thread=No for existing UMATs that share values between calls through COMMON, SAVE and the like (Section 2.3).
    • Output: In the result file S is STRESS, E is the accumulated total strain and MTEMP is the accumulated temperature change. STATEV is not written.
