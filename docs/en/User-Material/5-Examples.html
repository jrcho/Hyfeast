    5 Examples

    This chapter walks through two cases, an elastic plugin written in C and a von Mises plasticity UMAT written for Abaqus and built from its original source, and compares the results with the built-in materials. The input syntax is in Chapter 2, the arguments and call rules in Chapter 3, and building in Chapter 4.

    The example distribution folder in this chapter is D:\Apps\Hyfeast-v1.0.0. Replace paths with your actual extraction location and version name.

    • Example folder: D:\Apps\Hyfeast-v1.0.0\Examples\UMAT
    • Development kit folder: D:\Apps\Hyfeast-v1.0.0\Examples\UMAT\UserMaterial (Section 1.3)
    File in the example folder Content
    build.bat Builds the two example plugins into this folder
    run.bat Analyzes the three models with the plugin and with the built-in material
    01-elastic-cantilever.inp C elastic plugin, cantilever
    02-plastic-cyclic.inp von Mises UMAT, single element under cyclic loading
    03-plastic-cantilever.inp von Mises UMAT, cantilever pushed well past first yield

    5.1 Building the plugins

    A plugin is a DLL that exports the function hf_umat_v1, whose argument list is the same as the Abaqus UMAT. C plugins are built with the Visual Studio C++ compiler; Fortran plugins and Abaqus UMATs are built with Intel Fortran (ifx).

    Running build.bat in the example folder builds the two plugins into the example folder. Double-click build.bat in Explorer, or type the following in a command window.

    cd /d "D:\Apps\Hyfeast-v1.0.0\Examples\UMAT"
build.bat

    build.bat finds Visual Studio and Intel Fortran automatically and runs the following two commands. Typed by hand they are (the C build in the x64 developer command prompt for your installed Visual Studio or Build Tools). The required build tools and Fortran compiler compatibility conditions are described in Section 4.1.

    cd /d "D:\Apps\Hyfeast-v1.0.0\Examples\UMAT"
cl /nologo /O2 /LD /I"D:\Apps\Hyfeast-v1.0.0\Examples\UMAT\UserMaterial\include" "D:\Apps\Hyfeast-v1.0.0\Examples\UMAT\UserMaterial\examples\NativeElasticC\hfUmatElasticC.c" /Fe"hfUmatElasticC.dll"
"D:\Apps\Hyfeast-v1.0.0\Examples\UMAT\UserMaterial\build_umat.cmd" abaqus umat_vonmises.dll "D:\Apps\Hyfeast-v1.0.0\Examples\UMAT\UserMaterial\examples\AbaqusPlasticUMAT\umat_vonmises.for"

    When they finish, hfUmatElasticC.dll and umat_vonmises.dll are in the example folder.

    The first command builds the C source into a DLL. The source includes the public header hfUserMaterialAPI.h and exports hf_umat_v1 and hf_umat_abi_version.

    In the second command, build_umat.cmd abaqus adds the Hyfeast bridge (hfAbaqusUmatBridge.f90) and ABA_PARAM.INC to the Abaqus UMAT source and builds the DLL. umat_vonmises.for is a SUBROUTINE UMAT exactly as used in Abaqus; nothing was changed for Hyfeast. To write a new material in Native Fortran, follow Section 4.3.

    To analyze, run HyfeastCmd.bat in the distribution folder. When a command window opens with Bin added to the executable search path, type the following. It analyzes the three models with the plugin and with the built-in material and writes the results (*.csv, *.hdb, *.log) to the example folder.

    cd /d "D:\Apps\Hyfeast-v1.0.0\Examples\UMAT"
run.bat

    run.bat uses the command hfAnalyzer; see 3.1 Running hfAnalyzer for details of the execution environment.

    5.2 C elastic plugin

    The body of the C plugin does what an Abaqus UMAT does: it fills DDSDDE and updates STRESS. Arrays are indexed from 0 and DDSDDE(i,j) is ddsdde[(i-1) + (j-1)*ntens].

    void hf_umat_v1(double* stress, double* statev, double* ddsdde, /* ... Abaqus UMAT arguments ... */)
{
  const int n = *ntens;
  const double E = props[0], nu = props[1];
  /* fill ddsdde[i + j*n] for NDI = 3 or 2, then */
  for (i = 0; i < n; i++)
    for (j = 0; j < n; j++) stress[i] += ddsdde[i + j * n] * dstran[j];
}

    01-elastic-cantilever.inp pushes the tip of a 2000×400×100 mm cantilever down by 5 mm. The material is defined as follows.

    *Material, Type=User, Name=umatC
 hfUmatElasticC.dll, NProps=2
 200000., 0.3

    The first dataline gives the DLL path. A relative path is searched from the folder of the input file. NProps=2 is an optional item that checks the number of PROPS values. The lines from the second one are passed to the plugin as PROPS. As with other materials, the section refers to the material by name in *Section, Type=Solid.

    hfAnalyzer 01-elastic-cantilever.inp -p "<M>=umatC"
hfAnalyzer 01-elastic-cantilever.inp -p "<M>=iso"

    <M>=iso analyzes the same model with the built-in IsoElasticity of the same properties. The tip reaction is \(2.0365\times10^{5}\) N in both results.

    5.3 Abaqus UMAT: cyclic loading

    umat_vonmises.for is a von Mises plasticity model with linear isotropic hardening. It updates the stress by radial return and returns the consistent tangent.

    PROPS Meaning STATEV Meaning
    1 \(E\) 1 Equivalent plastic strain
    2 \(\nu\)
    3 Initial yield stress \(\sigma_{y0}\)
    4 Hardening modulus \(H\) 
    *Material, Type=User, Name=umatVM
 umat_vonmises.dll, NState=1, NProps=4
 200000., 0.3, 250., 2000.

    NState is the number of STATEV used by the UMAT and corresponds to Abaqus *DEPVAR. The built-in reference is vonMises with the same law (yield stress 250, \(H=2000\), \(\theta=1\) isotropic hardening).

    02-plastic-cyclic.inp applies \(\varepsilon_{11}\) = 0 → 0.005 → −0.005 → 0 to one 1 mm cube C3D8 element. The stresses of the two materials are equal in every increment.

    \(\varepsilon_{11}\) Stage \(\sigma_{11}\) (UMAT) [MPa] \(\sigma_{11}\) (vonMises) [MPa]
    0.0015 Just after first yield 250.50 250.50
    0.005 Maximum tension 257.43 257.43
    0.002 Reyield after load reversal −258.27 −258.27
    −0.005 Maximum compression −272.13 −272.13
    0 After second reversal 276.64 276.64

    5.4 Abaqus UMAT: plastic cantilever

    03-plastic-cantilever.inp pushes the tip of the cantilever of Section 5.2 down to 50 mm with automatic increments. The reaction is linear up to a tip displacement of 9.75 mm; after that the integration points near the fixed end yield and the stiffness drops.

    Tip displacement [mm] Reaction (UMAT) [N] Reaction (vonMises) [N]
    2.5 \(1.0183\times10^{5}\) \(1.0183\times10^{5}\)
    9.75 \(3.9713\times10^{5}\) \(3.9713\times10^{5}\)
    19.75 \(5.8732\times10^{5}\) \(5.8732\times10^{5}\)
    32.25 \(6.5045\times10^{5}\) \(6.5045\times10^{5}\)
    50 \(6.9987\times10^{5}\) \(6.9987\times10^{5}\)

    Both analyses finish in 22 increments with 69 equilibrium iterations, which shows that the tangent returned by the UMAT converges like the built-in material.

    As with other materials, the results can be viewed in hfStudio as S and E contours. STATEV is not written to the result file.

    5.5 Material-point check

    Before element analyses, check the material-point response with *TestMaterial. The command runs while the input is read and writes the results to a CSV file (16.3 *TestMaterial).

    *TestMaterial, Mat=umatVM, File=umatVM-G.csv
 Type=G, Field=DSDE,E,S
 0.005, -0.0015, -0.0015, 0, 0, 0, N=10
 -0.005, 0.0015, 0.0015, 0, 0, 0, N=20

    Type=G is the 3D condition, and each line gives the target values of the six strain components and the number of subdivisions N to reach them. PE, AX and PS check other conditions. Separate the items of a dataline with commas. In this command the plugin receives TIME and DTIME as 0 and CELENT as 1, so models that depend on time or element size are checked with element analyses.

    5.6 Using your own UMAT

    • Check it at a material point first. Compare S, E and DSDE from *TestMaterial with a built-in material or a hand calculation (Section 5.5).
    • Match NState and NProps to the Abaqus input. The count of *DEPVAR goes to NState, and n of *USER MATERIAL, CONSTANTS=n goes to NProps.
    • Give units in the model unit system. PROPS are not converted.
    • Specify Thread=No for a UMAT with global state. A UMAT that shares values through COMMON or SAVE mixes them up when several integration points are computed at the same time (Section 2.3).
    • Specify Unsymm=Yes for an unsymmetric tangent. Otherwise it is symmetrized as \((C+C^T)/2\).
    • Return PNEWDT smaller than 1 to reduce the increment. Hyfeast rejects the current increment and solves it again with a smaller one.
    • Check the supported elements. 3D solids, shells (S3, S3F, S4, S4F), continuum shells (CS6, CS8) and 2D solids are supported. Shells use a 3D UMAT as is. Beams, trusses, springs, composite plates and interface elements are not supported.
    • An absolute DLL path is safer. When the model is saved as an HDB in another folder and run, the base of a relative path becomes the HDB folder.
