    V.19 Concrete Damage Plasticity

    Compare single-C3D8 tension, compression and shear responses with prescribed material curves and an equivalent material model, then check equivalent opening/fracture-energy inputs and characteristic-length effects. Units are N, mm and MPa. Experimental comparisons are presented in C.1 Plain Concrete Notched Beam, C.2 RC Beam Model Comparison and C.3 Earij U2.

    V.19.1 Uniaxial Tension and Compression

    Apply axial displacement to one 100×100×100 mm C3D8 cube with free lateral faces. Use \(E=29188.63\) MPa and \(\nu=0.18\). Load to 0.2 mm in tension and 1 mm in compression. Material curves are defined against the tensile and compressive plastic internal variables \(\kappa_t\) and \(\kappa_c\).

    Table V.19.1 Uniaxial Material Curve Checks

    Input Prescribed curve and comparison criterion Final stress
    tension-PP.inp Perfect plasticity at 2 MPa in tension 2.0000 MPa
    tension-Hard.inp Hardening from 2 to 4 MPa up to \(\kappa_t=0.002\) 3.8675 MPa
    tension-Soft.inp Softening from 2 to 0.1 MPa up to \(\kappa_t=0.001\) 0.1000 MPa
    tension-Damage.inp Same tensile softening with damage up to \(d_t=0.6\) 0.1000 MPa
    compression-PP.inp Perfect plasticity at 20 MPa in compression −20.0000 MPa
    compression-CompSoft.inp 30 MPa at \(\kappa_c=0.001\), then 5 MPa at 0.006 −5.0000 MPa

    All six analyses completed in 104 increments. Plastic-range stresses agree with the prescribed curves within 0.002 MPa, and normal stresses on the free lateral faces remain below 0.001 MPa.

    Figure V.19.1 Uniaxial Tension and Compression against the Prescribed Curves

    • tension-PP.inp
    • tension-Hard.inp
    • tension-Soft.inp
    • tension-Damage.inp
    • compression-PP.inp
    • compression-CompSoft.inp

    V.19.2 Equivalent Material Models in Pure Shear

    For a C3D8 of the same size, fix the bottom face in \(x\) and impose 1 mm of \(x\) displacement on the top face. Fix every node in \(y\) and \(z\) to obtain proportional pure shear. Use \(E=200000\) MPa and \(\nu=0.2\).

    Compare CDP with equal tensile and compressive strengths, zero pressure dependence and zero dilation against the corresponding Drucker–Prager model. The perfectly plastic pair has an initial equivalent strength of 400 MPa; the hardening pair corresponds to a DP hardening modulus of 1000 MPa. Along this proportional shear path, the CDP internal variables and DP equivalent plastic strain satisfy \(\kappa_t=\kappa_c=\sqrt{3}\,\bar\varepsilon^p/4\).

    Table V.19.2 Equivalent Pure-Shear Results

    Input pair Final shear stress Difference between models
    shear-J2PP.inp · shear-DP.inp 230.94 MPa Zero at CSV precision
    shear-J2Hard.inp · shear-DPHard.inp 233.34 MPa Zero at CSV precision

    All four analyses completed in 104 increments. This result establishes equivalence along the specified proportional pure-shear path.

    Figure V.19.2 CDP and Drucker–Prager Responses in Proportional Pure Shear

    Input File
    • shear-J2PP.inp
    • shear-DP.inp
    • shear-J2Hard.inp
    • shear-DPHard.inp

    V.19.3 Equivalent Opening and Fracture-Energy Inputs

    Specify the same tensile strength and damage curves using Displacement and GFI in a 100 mm cube. The initial tensile strength is 2 MPa and \(G_f=0.1\) N/mm; the characteristic opening of the linear softening curve is \(w_f=2G_f/f_{t0}=0.1\) mm. Both inputs use the same damage curve, reaching 0.6 at an opening of 0.1 mm.

    Both analyses completed in 104 increments to the target displacement of 0.08 mm. The final tensile stress is 0.42942 MPa, and the displacement, reaction, stress and internal-variable CSVs are identical. This checks equivalence between the two input modes.

    Input File
    • tension-Open.inp
    • tension-Energy.inp

    V.19.4 Characteristic Length and Mesh Shape

    Use a 3 mm bar with a 1×1 mm cross-section. Apply a weak CDP material to the central element layer and an elastic material with the same elastic modulus elsewhere. Pull the right end to 0.12 mm. The weak layer uses GFI, 2, 0.1. Sum the nodal reactions on the loaded face, and integrate the accepted-increment reaction–displacement curve using the trapezoidal rule for external work.

    Table V.19.3 GFI Results for Three Mesh Shapes

    Input Total/weak elements Weak-element dimensions Peak reaction External work
    bar-h1.inp 3/1 1×1×1 mm 2.15052 N 0.10620 N·mm
    bar-h05.inp 6/1 0.5×1×1 mm 2.15664 N 0.06780 N·mm
    bar-cube-h05.inp 24/4 0.5×0.5×0.5 mm 2.16437 N 0.10624 N·mm

    The current C3D8 characteristic length is \(\ell=\sqrt[3]{V}\). Refining cubic elements from 1 mm to 0.5 mm changes external work by approximately 0.035%. Refinement only along the loading direction produces different responses because the axial element width and characteristic length differ.

    External work includes changes in elastic energy and the GFI 1% residual-strength range, so it is not the same fracture-energy quantity as the input \(G_f\). Interpret these results within the scope of this uniaxial mesh-shape comparison.

    Figure V.19.3 Equivalent Opening Inputs and GFI Response for Three Mesh Shapes

    Input File
    • bar-h1.inp
    • bar-h05.inp
    • bar-cube-h05.inp

    V.19.5 Monotonic Cantilever Loading

    Use the C3D8 cantilever geometry from V.5: length 2000 mm, depth 400 mm, width 100 mm, and a 20×4×1 mesh. Fix the left face and connect the vertical displacement of the right face to a central loading node through a RigidLink. Use the PP, Hard, Soft and Damage materials from V.19.1.

    Load PP and Hard to a tip displacement of 5 mm. For Soft and Damage, use an arc-length analysis with a 30 kN reference tip load to trace post-peak softening. Plot the curves in accepted-increment order.

    Table V.19.4 Monotonic CDP Cantilever Results

    Input Comparison Final tip displacement Peak load
    cant-PP.inp Perfectly plastic concrete 5.0000 mm 7.7080 kN
    cant-Hard.inp Tensile hardening 5.0000 mm 9.7624 kN
    cant-Soft-arc.inp Tensile softening without damage 5.1199 mm 4.6762 kN
    cant-Damage-arc.inp Tensile softening with damage 5.1188 mm 4.7167 kN

    All four inputs completed. Soft and Damage each use 1200 increments and show a short tip-displacement reversal during the descending load path. In the registered-input CSVs, the reversal ranges are 1.1146→1.1124 mm for Soft and 1.1323→1.1300 mm for Damage. TM-03 describes the analysis methods.

    This test compares CDP material responses and softening equilibrium paths in the same structure.

    V.19.6 Cyclic Cantilever Loading

    Apply the tip-displacement history \(0\rightarrow+1.10\rightarrow0\rightarrow+1.10\rightarrow-1.10\rightarrow+1.10\rightarrow0\) mm to the Soft and Damage versions of the same cantilever. The total time is 8.8 s, the uniform time increment is 0.005 s, and each loading segment also changes displacement by 0.005 mm per increment.

    Both inputs completed in 1760 increments with a final tip displacement of zero. Compare unloading, reloading, large reversals, stiffness and residual responses with and without damage in the load–displacement curves. Both materials use the same tensile softening curve, allowing their model responses to be compared.

    Inputs and Execution

    The 21 inputs and common material files are directly under Examples/V.19 Concrete Damage Plasticity/. Uniaxial, shear, input-equivalence and cantilever cases include materials.inp; bar cases include gfi-materials.inp. Reference CSVs are stored in Result/, as in other Verification examples. The input lists above match the V.19 entries in verification.def.

    In a command prompt with hfAnalyzer on the executable search path, change to the V.19 folder and run one input or the complete batch.

    hfAnalyzer tension-Open.inp
run.bat

    Outputs are created beside the inputs and do not overwrite reference CSVs in Result/. From the repository root, python verify.py verification.def runs all registered Verification cases and compares each output with its reference.
