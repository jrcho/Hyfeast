    V.6.2 Total and Relative Motion in Earthquake

    In seismic analysis, depending on the input ground motion, the formulation can be expressed in terms of relative motion or absolute motion. The following is the governing equation for seismic input formulated in absolute motion.

    \[ \mathbf{M} \ddot{\mathbf{u}} + \mathbf{C} \dot{\mathbf{u}} + \mathbf{K} \mathbf{u} = \mathbf{0} \tag{V.6.1} \]

    If the ground motion is assumed to be the product of a direction vector and a time-dependent motion, the total motion can be expressed as the sum of the relative motion and the ground motion.

    \[ \mathbf{u}(t) = \mathbf{u}_{r}(t) + \mathbf{r} u_{g}(t) \tag{V.6.2} \]

    Here, the direction vector \(\mathbf{r}\) represents the direction of the ground motion. Rearranging the governing equation in terms of relative motion yields the following.

    \[ \mathbf{M} \ddot{\mathbf{u}}_{r} + \mathbf{C} \dot{\mathbf{u}}_{r} + \mathbf{K} \mathbf{u}_{r} = -\mathbf{M} \mathbf{r} \ddot{u}_{g}(t) - \mathbf{C} \mathbf{r} \dot{u}_{g}(t) - \mathbf{K} \mathbf{r} u_{g}(t) \tag{V.6.3} \]

    In the above, \(\mathbf{K r} = \mathbf{0}\) is satisfied, which corresponds to rigid body motion. However, for the mass matrix, \(\mathbf{M r} \neq \mathbf{0}\). For the damping matrix, when it is composed of local dampers, \(\mathbf{C r} = \mathbf{0}\) is satisfied. When Rayleigh damping is applied, \(\mathbf{C} = \alpha\mathbf{M} + \beta\mathbf{K}\), so for mass-proportional damping, \(\mathbf{C r} \neq \mathbf{0}\). In general, the governing equation for relative motion considers only \(-\mathbf{M r} \ddot{u}_{g}(t)\) as follows.

    \[ \mathbf{M} \ddot{\mathbf{u}}_{r} + \mathbf{C} \dot{\mathbf{u}}_{r} + \mathbf{K} \mathbf{u}_{r} = -\mathbf{M} \mathbf{r} \ddot{u}_{g}(t) \tag{V.6.4} \]

    This is equivalent to the governing equation for absolute motion when mass-proportional damping is not present.

    The figure illustrates an example of a single-degree-of-freedom (SDOF) system. In this example, the differences in results according to the formulation were examined for an SDOF system. The input ground motions considered were both baseline-corrected and non–baseline-corrected earthquake records.

    Figure V.6.3 SDF system with ground input

    When using the baseline-corrected Loma Prieta earthquake record (RSN765_LOMAP_G01090), it was confirmed that there is no difference in the response values between the two formulations. Similarly, when applying the non–baseline-corrected El Centro earthquake record (Caltech version), the response values were found to be identical when comparing relative displacements. However, in cases where the input ground motions differ by location, applying non–baseline-corrected earthquake records may cause problems.

    In the input examples, *Load, TYPE=Earthquake applies \(-\mathbf{M r} \ddot{u}_{g}(t)\) on the right-hand side of the relative motion formulation as an external load. In contrast, *Load, TYPE=Displacement applies the displacement history directly to the nodes, thereby using the absolute motion formulation. When using *Load, TYPE=Displacement, acceleration, velocity, and displacement histories are required. If only one of these histories is available, the others can be generated using the numerical integration and differentiation tools built into Hyfeast. The example verifies all of these cases.

    V.6.4 Five Story Building

    The time-history and response-spectrum analyses of the five-story building presented in AK Chopra (2009) are compared. The floor weight is 100 kips, the interstory spring stiffness is 31.54 kips/in, and the ground motion input is the El Centro (1940) earthquake record provided in AK Chopra (2009).

    fivestory.inp performs the time-history analysis with the direct integration method and with modal analysis. The direct step applies 5% Rayleigh damping to the full matrices, while the modal steps use 5% modal damping. Results are also shown for the cases where only the first mode or only the second mode is retained. fivestory_rs_verify.inp uses the same five-story model and the same 15 s window of the elcentro_chopra.dat record, generates a 5%-damped response spectrum from that time history, and performs ResponseSpectrum analyses with SRSS and CQC modal combination.

    Since the given system has only five degrees of freedom, the five-mode modal time-history result is expected to closely follow the direct result. Figure V.6.10 keeps the original Direct and Modal time-history comparison. The response-spectrum result is an envelope response without sign or occurrence time, so it is compared only by the peak absolute roof displacement table instead of being plotted with the time histories.

    V.6.5 Initial Velocity

    Mass-spring models verify that *InitialCondition, Type=Velocity assigns the starting velocities of a direct time-integration step.

    Initial velocity of a single-degree-of-freedom system. A system with mass \(m=1\) and stiffness \(k=4\pi^2\) receives an initial velocity \(v_0=1\ \mathrm{m/s}\). The undamped Newmark solution is compared with \(u=v_0\sin(\omega t)/\omega\), and the HHT solution with Rayleigh damping ratio \(\zeta=0.05\) with \(u=v_0e^{-\zeta\omega t}\sin(\omega_dt)/\omega_d\). The time increment is \(\Delta t=0.01\ \mathrm{s}\).

    Partial reset in a two-degree-of-freedom chain. In an HHT chain of two mass-spring degrees of freedom, the first step starts from \(v_2=1\ \mathrm{m/s}\), and the second step continues through Prev= and resets only \(v_3=-0.5\ \mathrm{m/s}\). In the initial frame of the second step, the displacements, the accelerations, and the untouched velocity \(v_2\) must equal the end values of the first step.
