    3.1 Running hfAnalyzer

    hfAnalyzer is the finite element CLI solver of Hyfeast. It reads a .inp input file or an HDB-family file, runs the analysis, and produces the run log (.log), the reconstructed input (.chk), text output (.prn), and the result database (.hdb). What each file contains is described in Files and Results.

    3.1.1 Basic runs

    hfAnalyzer frame.inp            # run the analysis
hfAnalyzer frame.inp -s         # silent (no screen echo)
hfAnalyzer -h                   # help
hfAnalyzer                      # no arguments: interactive mode

    If the input is a .hdb, .bin.hdb, or .text.hdb file, the input snapshot embedded in it is extracted and re-analyzed; the source is not overwritten and the result is written as name.rerun.hdb.

    3.1.2 Options

    Option Meaning
    -p "..." Parameter substitution in the input file (section 3.1.3)
    -o name Output HDB name without extension. May be combined with a parameter expression
    -f Text\|Binary\|HDF5 Generated HDB format. Default is HDF5 for .inp input, or the source family format for HDB input
    -r Re-analyze an HDB-family input and replace the source only after success. Cannot be combined with -o or -k
    -s Silent mode (screen echo off)
    -n ncpu Number of processors to use
    -k Check the input only, without analysis
    -V Show the version

    3.1.3 Parameter substitution

    Placeholders written as <name> in the input file are replaced at run time.

    hfAnalyzer example.inp -p "<E>=20E9, <BaseN>=1000"

    With *Parameter sets defined in the top-level input file, a set can be picked by name, and individual values can be overridden.

    hfAnalyzer example.inp -p "Concrete"
hfAnalyzer example.inp -p "Concrete:<E>=30E9"

    Putting a parameter value into the output name separates the result files per case.

    hfAnalyzer input.inp -p "<S>=100" -o "input-<S>"   # result: input-100.hdb

    The *Parameter syntax is described in Modelling Convenience.

    3.1.4 HDB utilities

    Subcommands that operate on HDB-family files without running an analysis.

    hfAnalyzer hdb extract mymodel.hdb myinput.inp    # extract the embedded input as .inp
hfAnalyzer hdb convert mymodel.hdb Text           # convert the format (Text|Binary|HDF5)
hfAnalyzer hdb remove-step mymodel.hdb step2      # remove result steps from step2 onward

    3.1.5 Opening a CLI shell

    Ways to open a shell where hfAnalyzer is on the PATH.

    • Development tree: run cmdQt6.bat (or cmdQt5.bat) in the repository root. It adds the build output folder and dependency paths to the PATH.
    • Distribution: run setpath.bat in the distribution root. It adds its own Bin folder to the PATH.
    • Analysis > Open Hyfeast CLI Here in hfStudio: opens a separate cmd.exe window in the current file's folder. The current model is not saved or exported automatically, so prepare the input to analyze from the saved file.
