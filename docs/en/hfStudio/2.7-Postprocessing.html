    2.7 Postprocessing

    This page covers stepping through results once the analysis is done — moving between steps and frames, controlling contour/vector/diagram/sensor/deformed display, and driving animation.

    For automation, see Remote Control Postprocessing.

    Postprocessing commands work only in postprocessing mode. post-* get queries return JSON and do not record a history tail. Setter commands record the same canonical post-* ... tail into Remote Control History and *.ipc.txt.

    2.7.1 Plot toggles

    Automation: post-plot <type> <on|off>.

    • Contour: RC value contour
    • Diagram: diagram
    • Vector: vector
    • Sensor Plot: sensor
    • Deformed: deformed

    Deformed on fails when the current result step has no displacement output D.

    2.7.2 Step and frame navigation

    • Step pick (Step combobox) — RC: post-step <step-name>. Also moves to frame 1.
    • Query current step and frame: RC: post-step get, post-frame get.
    • Frame pick: RC: post-frame <index> (1-based).

    The Postprocessing menu's Play submenu has frame-navigation buttons:

    • Follow Step Model: toggle: change the model shape with the step
    • First: first frame of the current step
    • Previous: previous frame
    • Next: next frame
    • Last: last frame

    In automation, jump directly with post-frame <index> instead of stepping.

    2.7.3 Scalar (Contour Field)

    • Pick scalar field: RC: post-scalar <field> [<avg-threshold>]
    • Query current scalar: RC: post-scalar get

    <field> must be a valid scalar field name for the current step and frame. [<avg-threshold>] is optional and accepts an integer in 0..100.

    The GUI Averaging Threshold(%) controls whether extrapolated element scalar values are averaged at shared element nodes. 0 disables averaging, while 1..100 averages values in the same averaging group only when they satisfy:

    \[ \max(v_i)-\min(v_i) \le \frac{\mathrm{threshold}}{100} \left(\max(v_\mathrm{region})-\min(v_\mathrm{region})\right) \]

    Averaging groups are formed within the same section, and \(v_\mathrm{region}\) is the scalar value range of that section group. Continuum elements average by shared node. Shell elements keep bottom/top values separate and average only values with the same shell element coordinate system. Beam elements average only values with the same section/material point index and beam element coordinate system.

    2.7.4 Vector / Tensor

    • Pick vector or tensor field: RC: post-vector <field>
    • Query current vector: RC: post-vector get

    2.7.5 Contour settings

    Controls range, mode, levels, and overlay of the contour. Automation lives in the post-contour command family:

    • Auto-range toggle: post-contour auto-range <on|off>
    • Range value: post-contour range <min> <max>
    • Band count: post-contour bands <n>
    • Mode: post-contour mode <uniform|custom>
    • Custom levels: post-contour levels <v1,v2,...> (strictly increasing, 2..31 values)
    • Overlay text: post-contour overlay <text>
    • Overlay color: post-contour overlay-color <r,g,b[,a]> (0..255)

    The auto-range, range, and bands setters are rejected in custom mode. Switching to mode custom initializes custom levels from the current uniform range and band state if needed.

    2.7.6 Scale factor

    Controls deformed shape, diagram, vector, and sensor scales. Automation: post-scale.

    • Deformed (auto on/off): post-scale deformed auto <on|off>
    • Deformed (explicit value): post-scale deformed value <scale>
    • Diagram: post-scale diagram auto, post-scale diagram value
    • Vector: post-scale vector auto, post-scale vector value
    • Sensor: post-scale sensor auto, post-scale sensor <e|d|v|a> <scale>

    Passing an explicit value or e|d|v|a automatically turns the matching auto-scale off first.

    2.7.7 Overlay and display

    Automation: post-display <item> <on|off>.

    • Information (top-left info text) — RC <item> information
    • Scalar bar: scalarbar
    • Min/Max tag (captions) — min-max-tag

    2.7.8 Play (animation)

    Animation controls live under the Postprocessing menu's Play submenu and on the toolbar.

    • Time History Ani: step through frames. RC: post-animation-time-history <on|off>.
    • Scale Factor Ani: step through scale values. RC: post-animation-scale-factor <on|off>.
    • Loop: toggle automatic looping. RC: post-animation-loop <on|off>.
    • Record: record animation to .avi/.mp4. RC: post-animation-record <on|off> [<file>].

    Animation rules:

    • Time History and Scale Factor cannot run at the same time (turning one on while the other is active is rejected).
    • Record on requires a writable output path with a .avi or .mp4 extension.
    • The record target can be changed only while no animation is running.

    2.7.9 PostPlot

    In postprocessing mode, use the XY Plot tool button in the command panel, or XY Plot in the Postprocessing menu/toolbar, to open the modeless XY Plot Editor. The Postprocessing panel does not show a separate curve list; the editor owns the flow for creating series candidates, registering curves, controlling visible curves, and opening plot windows. Chart is postprocessing-only; preprocessing preview and signal-analysis tools stay in the Function widget.

    The XY Plot Editor has Series candidates and Add Series from tabs on the left, and a Curves list on the right. Use History/Result/Path tabs to create series candidates, and use f(x)... to create a derived series candidate by applying pointwise operations to selected series. Use tooltips or Details to inspect the source description. The History (index) column is not registered as a candidate; automatic Index can be used as an X series. Operand length mismatch in a derived series is treated as an error during curve registration or export.

    Result RTime series values follow the TUnit of the Step that owns the result step. Candidate names and plot axes show the unit beside the field, for example RTime [day], while the stable source key remains R1:RTime.

    The PostPlot view is modeless and separate from the central RenderView, Node Table, and Element Table workspace. The PostPlot data model owns one shared series library and PostPlot data cache, while each PostPlot view keeps its own visible-series composition.

    Show Plot opens a new PostPlot view and a new composition. The new window starts by copying the active PostPlot view's visible composition, but later show/hide changes and added series are independent per window. The XY Plot Editor can register, remove, or show/hide series even before any PostPlot view exists; in that case it edits the default composition. Each PostPlot view can be activated or closed by its cN view id.

    Automation: register a series in the shared series library and show it in the target composition with post-plot plot .... A PostPlot view is optional for data registration; use view add post-plot when a visible display window is needed. The target composition's visible PostPlot data can be written to CSV with post-plot export ... or copied to the clipboard with post-plot copy. post-plot plot computes series data on demand and does not persist a PostPlot cache in the HDB.
