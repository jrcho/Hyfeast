    3.1 hfAnalyzer 실행

    hfAnalyzer는 Hyfeast의 유한요소 CLI solver이다. 텍스트 입력 파일 .inp를 읽어 해석을 수행하고, 실행 로그·텍스트 출력·hfStudio에서 열 수 있는 결과 데이터베이스를 만든다.

    3.1.1 언제 쓰는가

    hfAnalyzer는 solver 실행 자체가 작업의 중심일 때 쓴다.

    • .inp 파일을 직접 작성하거나 검토할 때
    • 반복 가능한 batch 실행이 필요할 때
    • 검증이나 자동화를 위해 solver 중심 workflow가 필요할 때
    • command reference를 기준으로 입력을 통제하고 싶을 때

    처음 GUI 중심 사용자라면 hfStudio Help나 Tutorial Overview를 먼저 보는 편이 좋다. 정확한 command 문법은 Command Reference에서 본다.

    3.1.2 기본 실행

    입력 파일을 바로 넘겨 실행한다.

    hfAnalyzer frame.inp

    옵션 목록이 필요하면 -h를 쓴다.

    hfAnalyzer -h

    입력 파일과 옵션을 interactive하게 넣고 싶다면 인자 없이 시작한다.

    hfAnalyzer

    3.1.3 파라미터와 출력 이름

    명령행에서는 -p 옵션으로 파라미터 치환을 줄 수 있다.

    hfAnalyzer example.inp -p "<E>=20E9, <BaseN>=1000"

    최상위 입력 파일에 *Parameter를 정의해 두면 이름만 골라 실행할 수 있다.

    hfAnalyzer example.inp -p "Concrete"
hfAnalyzer example.inp -p "Steel"
hfAnalyzer example.inp -p "Concrete:<E>=30E9"

    기본 출력 이름을 바꾸고 싶으면 -o를 쓴다.

    hfAnalyzer example.inp -o output
hfAnalyzer example.inp -o "output-<PARAMETER>" -p "WT"

    3.1.4 실행 전후 점검

    실행 전에는 모델 정의, 의도한 step과 load, 입력 파일 revision을 확인한다. 실행 후에는 정상 종료 여부, warning/error, 기대한 출력 파일 생성을 먼저 본다.

    문제가 생기면 다음 파일을 순서대로 확인한다.

    • .log
    • .chk
    • .prn
    • 가장 최근의 모델링 변경
    • 관련 command 정의

    큰 모델이 작동하지 않을 때는 한두 element / 한 step 수준의 작은 재현 모델로 줄이면 원인을 더 빨리 찾을 수 있다. 출력 파일 종류와 역할은 Files and Results에서 본다.
