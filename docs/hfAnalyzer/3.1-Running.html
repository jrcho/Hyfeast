    3.1 hfAnalyzer 실행

    hfAnalyzer는 Hyfeast의 유한요소 CLI solver다. .inp 입력 파일 또는 .hdb 계열 파일을 읽어 해석하고, 실행 로그(.log), 재구성 입력(.chk), 텍스트 출력(.prn), 결과 데이터베이스(.hdb)를 만든다. 파일 종류별 내용은 Files and Results에 있다.

    3.1.1 기본 실행

    hfAnalyzer frame.inp            # 해석 실행
hfAnalyzer frame.inp -s         # 화면 출력 없이 (silent)
hfAnalyzer -h                   # 도움말
hfAnalyzer                      # 인자 없이 실행하면 대화형 모드

    입력이 .hdb, .bin.hdb, .text.hdb이면 파일에 내장된 입력 스냅샷을 꺼내 재해석하고, 원본을 덮어쓰지 않고 이름.rerun.hdb를 만든다.

    3.1.2 옵션

    옵션 내용
    -p "..." 입력 파일의 파라미터 치환 (아래 3.1.3)
    -o name 출력 HDB 이름 지정 (확장자 제외). 파라미터 표현식과 조합 가능
    -f Text\|Binary\|HDF5 생성할 HDB 형식. .inp 입력의 기본은 HDF5, HDB 입력은 원본 형식 유지
    -r HDB 계열 입력을 재해석한 뒤 성공 시 원본을 교체. -o, -k와 함께 쓸 수 없음
    -s silent 모드 (화면 echo 끔)
    -n ncpu 사용할 프로세서 수
    -k 해석 없이 입력 검사만 수행
    -V 버전 표시

    3.1.3 파라미터 치환

    입력 파일 안의 <이름> 자리표를 실행 시점에 값으로 바꾼다.

    hfAnalyzer example.inp -p "<E>=20E9, <BaseN>=1000"

    최상위 입력 파일에 *Parameter 세트를 정의해 두면 세트 이름으로 고르거나, 일부 값만 덮어쓸 수 있다.

    hfAnalyzer example.inp -p "Concrete"
hfAnalyzer example.inp -p "Concrete:<E>=30E9"

    파라미터 값을 출력 이름에 넣으면 케이스별 결과 파일이 나뉜다.

    hfAnalyzer input.inp -p "<S>=100" -o "input-<S>"   # 결과: input-100.hdb

    *Parameter 문법은 Modelling Convenience에서 본다.

    3.1.4 HDB 유틸리티

    해석 없이 HDB 계열 파일을 다루는 부속 명령이다.

    hfAnalyzer hdb extract mymodel.hdb myinput.inp    # 내장 입력을 .inp로 추출
hfAnalyzer hdb convert mymodel.hdb Text           # 형식 변환 (Text|Binary|HDF5)
hfAnalyzer hdb remove-step mymodel.hdb step2      # step2부터 끝까지 result step 제거

    3.1.5 CLI 셸 열기

    hfAnalyzer를 PATH에서 찾을 수 있는 셸을 여는 방법이다.

    • 개발 트리: 저장소 루트의 cmdQt6.bat(또는 cmdQt5.bat) 실행. 빌드 출력 폴더와 의존성 경로를 PATH에 추가한다.
    • 배포판: 배포 루트의 setpath.bat 실행. 자기 위치 기준 Bin 폴더를 PATH에 추가한다.
    • hfStudio의 Analysis > Open Hyfeast CLI Here: 현재 작업 파일 폴더에서 별도 cmd.exe 창을 연다. 현재 모델을 자동 저장·export하지 않으므로, 해석할 입력은 저장된 파일 기준으로 준비한다.
