    2.3 View and Display

    화면을 만들고, 카메라를 맞추고, 렌더링 표현을 바꾸고, label과 측정 도구를 켜는 작업을 정리한다.

    같은 동작을 자동화하려면 Remote Control View와 Remote Control Display를 본다.

    Render View는 모델과 결과를 보는 중앙 작업 영역이다. Display 메뉴와 Display toolbar는 이 view의 표현 방식, 표시 항목, 카메라 방향, 측정 도구를 바꾼다.

    2.3.1 Central View와 Render View

    화면 가운데(central)에는 한 번에 여러 view가 tab 또는 split으로 떠 있을 수 있다.

    • Render View: 모델과 결과를 3D로 보는 영역. id: r0, r1, …
    • Node Table: node 데이터 표. id: n0, …
    • Element Table: element 데이터 표. id: e0, …

    두 가지 핵심 개념:

    • currentView: 지금 포커스를 가진 central view. table일 수도 있다.
    • activeRenderView: display, camera, visibility 명령이 기본으로 적용되는 render view. currentView가 render가 아니어도 마지막 active render는 따로 유지된다.

    추가, 활성화, 닫기는 GUI의 tab/split UI로 직접 한다. 자동화는 Remote Control view 명령군을 쓴다.

    마지막으로 남은 render view는 닫을 수 없다.

    Postprocessing PostPlot view는 floating modeless window로 열리며 cN id로 관리된다. XY Plot Editor의 Show Plot 또는 Remote Control view add post-plot으로 생성한다.

    2.3.2 View 메뉴 — Dock과 Toolbar 가시성

    상단 View 메뉴는 dock widget과 toolbar 표시 여부를 토글한다. 카메라 작업과는 별개이다.

    Dock widget 토글:

    • Output Window
    • Model Tree
    • Command
    • Selection Widget
    • Chart
    • Digital Twin Widget

    Toolbar 토글:

    • File
    • Display
    • Selection
    • Postprocessing
    • Analysis

    각 toolbar의 우클릭 popup에서도 같은 토글에 접근할 수 있다.

    2.3.3 Display 메뉴

    2.3.3.1 Representation 하위 메뉴

    대상 render view의 표현 방식을 정한다.

    • Wireframe: 선분 표현. RC: representation wireframe
    • Surface: 표면 표현. RC: representation surface
    • Transparency: 투명 표시 토글. RC: transparency
    • Shrink: element shrink 토글. RC: element-shrink
    • Section View: section-view clipping 토글. RC: section-view

    Section View가 켜지면 Shell/CompositePlate 단면의 structural layer stack을 두께 방향으로 표시한다. NSLayer가 있으면 structural top side 바깥의 별도 non-structural layer로 표시하며, stress/strain contour 대상에는 포함하지 않는다. Section View가 꺼져 있으면 structural body만 표시한다.

    Remote Control은 surface, wireframe, both 세 값을 한 명령으로 처리한다.

    2.3.3.2 Parallel Projection

    Display 메뉴의 단독 토글. perspective ↔ parallel projection 사이를 전환한다.

    같은 동작은 Remote Control parallel-projection.

    2.3.3.3 Shading Color 하위 메뉴

    • Shading by Element Type: RC 값 element-type
    • Shading by Section: RC 값 section

    자동화: shading-color <none|element-type|section>.

    2.3.3.4 Display Control 하위 메뉴

    각 항목은 preprocessing과 postprocessing 모두에서 동작한다. 토글 명령: display-control <item> <on|off>.

    • Origin Axes: RC <item> origin-axes
    • Corner Axes: corner-axes
    • Grid: grid
    • Auto Grid Spacing: 별도 명령: grid-spacing set auto
    • Dimension Box: dimension-box
    • Node: node
    • Node Label: node-label
    • Element Label: element-label
    • ECS: ecs
    • Sensor Label: sensor-label

    2.3.3.5 View Direction 하위 메뉴

    대상 render view의 카메라 방향을 빠르게 바꾼다.

    • View Reset: 기본 fit 상태로. RC: camera fit
    • Area Zoom: 화면에 그린 영역으로 확대 (interactive only)
    • Iso Z/Y/X: isometric. RC: camera view iso-z|iso-y|iso-x
    • +X / −X / +Y / −Y / +Z / −Z: 축에 정면. RC: camera view +x|-x|+y|-y|+z|-z
    • Rotate ±X/Y/Z: 현재 카메라를 회전. RC: camera rotate ±X|±Y|±Z
    • Set User View ½/3: 현재 카메라를 사용자 view 슬롯에 저장 (interactive only)
    • Unset User View ½/3: 사용자 view 슬롯 지우기 (interactive only)
    • User View ½/3: 저장한 사용자 view로 이동 (interactive only)

    위치, 초점, 회전을 정확히 지정하려면 Remote Control camera set --position ... --focal-point ... --view-up ....

    2.3.3.6 Tool 하위 메뉴

    render view에서 측정 도구를 배치한다.

    • Distance Tool: 두 점 사이 거리를 측정
    • Angle Tool: 세 점(p1, center, p2) 사이 각도를 측정
    • Clear Tools: 현재 render view의 tool widget 제거

    자동화 동작:

    • 좌표 없이 호출하면 GUI에서 점을 찍는 interactive 모드로 들어간다.
    • 좌표를 넘기면 완성된 tool을 바로 만든다 — Remote Control tool distance <p1> <p2>, tool angle <p1> <center> <p2>.
    • 다른 tool 배치가 진행 중이거나 view가 deformed 상태이면 거부된다.
    • Clear Tools는 지울 tool이 있을 때만 활성화된다.

    2.3.4 Grid Spacing

    Display 메뉴 또는 Display toolbar의 Auto Grid Spacing 액션은 현재 work-plane view에 맞춰 spacing을 자동 조정한다.

    • spacing 값만 바뀌고, grid 표시 on/off 상태는 바꾸지 않는다.
    • grid가 꺼져 있거나 oblique view 각도 때문에 work-plane grid가 숨겨진 경우에는 동작하지 않는다.
    • 자동화 시 history에는 해석된 숫자가 아니라 semantic tail grid-spacing set auto가 기록된다.

    수치를 직접 지정하거나 현재 값을 조회하려면 Remote Control grid-spacing.

    2.3.5 다른 render view에 적용

    Remote Control 명령에 --view-id <rN>을 붙이면 currentView나 activeRenderView를 바꾸지 않고 다른 render view에 display, camera, visibility를 적용한다. GUI에서는 해당 render view를 활성화한 뒤 작업하는 흐름이 기본이다.

    2.3.6 마우스로 화면 조작

    render view는 어느 작업 모드에서든(절점 picking 중에도) 마우스로 카메라를 조작할 수 있다. 모드를 따로 전환할 필요가 없다.

    동작 입력
    줌 휠 또는 Shift + 가운데 버튼 드래그
    팬 Ctrl + 가운데 버튼 드래그
    회전 가운데 버튼 드래그
    • 트랙패드: 트랙패드는 가운데 버튼이 없으니 **Alt + 왼쪽 버튼**을 가운데 버튼 대신 쓴다(Alt를 누른 채 한 손가락으로 끌기 = 회전, +Ctrl = 팬, +Shift = 줌). 줌은 두 손가락 스크롤로도 된다.
    • Alt 없이 누른 왼쪽 버튼은 선택/picking 전용이며 화면을 회전시키지 않는다.
    • 휠이 없는 입력(펜 태블릿 등)은 Shift + 가운데 버튼 또는 툴바 Zoom to Box/Fit으로 줌한다.
