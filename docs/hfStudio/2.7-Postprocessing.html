    2.7 Postprocessing

    해석 결과가 준비된 뒤 step과 frame을 이동하고, contour/vector/diagram/sensor/deformed 표시를 제어하고, animation을 다루는 작업을 정리한다.

    자동화: Remote Control Postprocessing.

    후처리 명령은 후처리 모드에서만 동작한다. post-* get 조회는 JSON을 반환하고 history에 tail을 기록하지 않는다. 설정형 명령은 같은 canonical post-* ... tail을 history와 *.ipc.txt에 기록한다.

    2.7.1 Plot 토글

    자동화: post-plot <type> <on|off>.

    • Contour: RC 값 contour
    • Diagram: diagram
    • Vector: vector
    • Sensor Plot: sensor
    • Deformed: deformed

    Deformed on은 현재 result step에 변위 출력 D가 없으면 실패한다.

    2.7.2 Step과 Frame 이동

    • Step 선택 (Step combobox) — RC: post-step <step-name>. frame은 1로 이동.
    • 현재 step과 frame 조회: RC: post-step get, post-frame get.
    • Frame 직접 지정: RC: post-frame <index> (1-based).

    Postprocessing 메뉴의 Play 하위 frame navigation:

    • Follow Step Model: step 변경 시 모델 형상도 따라 바뀌도록 토글
    • First: 현재 step의 첫 frame
    • Previous: 이전 frame
    • Next: 다음 frame
    • Last: 마지막 frame

    자동화에서는 위 buttons 대신 post-frame <index>로 직접 이동한다.

    2.7.3 Scalar (Contour Field)

    • Scalar field 선택: RC: post-scalar <field> [<avg-threshold>]
    • 현재 scalar 상태 조회: RC: post-scalar get

    GUI에서는 Field 영역을 펼친 뒤 scalar, vector/tensor, averaging 값을 고르고 Field 영역 하단의 **Apply Field**로 적용한다. Contour range, scale factor, PostPlot visibility 같은 다른 후처리 조작은 각 control에서 즉시 반영된다.

    <field>는 현재 step과 frame에서 유효한 scalar field 이름이어야 한다. [<avg-threshold>]는 선택 사항이며 0..100 정수.

    GUI의 Averaging Threshold(%) 는 element scalar 값을 element node로 외삽한 뒤 공유 절점에서 평균할지 결정한다. 0은 평균을 끄고, 1..100은 같은 평균 그룹의 값이 아래 조건을 만족할 때만 평균한다.

    \[ \max(v_i)-\min(v_i) \le \frac{\mathrm{threshold}}{100} \left(\max(v_\mathrm{region})-\min(v_\mathrm{region})\right) \]

    평균 그룹은 같은 section 안에서 구성되며, \(v_\mathrm{region}\)은 그 section 그룹의 scalar 값 범위이다. 연속체 요소는 공유 절점별로 평균한다. 쉘 요소는 bottom/top을 분리하고 shell element coordinate system이 같은 값끼리만 평균한다. 보 요소는 section/material point index와 beam element coordinate system이 같은 값끼리만 평균한다.

    2.7.4 Vector / Tensor

    • Vector 또는 tensor field 선택: RC: post-vector <field>
    • 현재 vector 상태 조회: RC: post-vector get

    2.7.5 Contour 설정

    contour의 range, mode, level, overlay를 제어한다. 자동화는 post-contour 명령군:

    • Auto-range 토글: post-contour auto-range <on|off>
    • Range 값: post-contour range <min> <max>
    • Band 개수: post-contour bands <n>
    • 모드: post-contour mode <uniform|custom>
    • Custom level: post-contour levels <v1,v2,...> (엄격히 증가, 2..31개)
    • Overlay 텍스트: post-contour overlay <text>
    • Overlay 색: post-contour overlay-color <r,g,b[,a]> (0..255)

    auto-range, range, bands 설정은 custom mode에서 거부된다. mode custom 전환은 필요하면 현재 uniform range/band 상태로 custom level을 초기화한다.

    2.7.6 Scale Factor

    deformed shape, diagram, vector, sensor scale을 제어한다. 자동화: post-scale.

    • Deformed (auto on/off): post-scale deformed auto <on|off>
    • Deformed (값 직접): post-scale deformed value <scale>
    • Diagram: post-scale diagram auto, post-scale diagram value
    • Vector: post-scale vector auto, post-scale vector value
    • Sensor: post-scale sensor auto, post-scale sensor <e|d|v|a> <scale>

    명시적 value 또는 e|d|v|a 입력은 대응되는 auto-scale을 먼저 끈다.

    2.7.7 Overlay와 Display

    자동화: post-display <item> <on|off>.

    • Information (좌상단 정보 텍스트) — RC <item> information
    • Scalar bar: scalarbar
    • Min/Max tag (caption) — min-max-tag

    2.7.8 Play (Animation)

    Postprocessing 메뉴 Play 하위 메뉴 또는 toolbar의 animation 컨트롤.

    • Time History Ani: frame을 따라 진행하는 animation. RC: post-animation-time-history <on|off>.
    • Scale Factor Ani: scale을 따라 진행하는 animation. RC: post-animation-scale-factor <on|off>.
    • Loop: animation 자동 반복 토글. RC: post-animation-loop <on|off>.
    • Record: animation을 .avi/.mp4로 녹화. RC: post-animation-record <on|off> [<file>].

    Animation 규칙:

    • Time History와 Scale Factor 두 모드는 동시에 켤 수 없다 (한쪽이 켜져 있으면 다른쪽은 거부됨).
    • Record on은 .avi 또는 .mp4 확장자를 가진 쓰기 가능한 출력 경로가 필요하다.
    • Animation이 실행 중이 아닐 때만 Record 대상을 변경할 수 있다.

    2.7.9 PostPlot

    Postprocessing 모드에서는 command panel 아래의 XY Plot tool button이나 Postprocessing menu/toolbar의 **XY Plot**으로 별도 nonmodal **XY Plot Editor**를 연다. Postprocessing panel은 PostPlot curve 목록을 직접 표시하지 않고, series 후보 작성, curve 등록/표시 제어, plot 창 열기를 XY Plot Editor에 모은다. PostPlot은 후처리 전용이며, preprocessing의 미리보기와 signal analysis는 Function widget에 둔다.

    XY Plot Editor는 왼쪽 Series 후보와 Add Series from 탭, 오른쪽 Curves 목록으로 구성된다. History/Result/Path 탭에서 series 후보를 만들고, f(x)... 로 선택한 series에 점별 연산을 적용한 파생 series 후보를 만들 수 있다. 자세한 source 설명은 tooltip 또는 Details**에서 확인한다. History의 (index) column은 후보로 등록하지 않고, X series로 자동 **Index 축을 사용할 수 있다. 파생 series operand 길이가 다르면 curve 등록이나 export에서 오류로 처리한다. Series 후보가 기존 curve에서 쓰이고 있으면 먼저 해당 curve를 삭제해야 series를 삭제할 수 있다.

    Result의 RTime series 값은 해당 result step을 소유한 Step의 TUnit을 따르며, 후보명과 plot 축에는 RTime [day]처럼 단위를 함께 표시한다. 내부 source key는 단위 표시에 관계없이 R1:RTime 형식을 유지한다.

    PostPlot view는 중앙 RenderView, Node Table, Element Table 작업 영역과 분리된 modeless window이다. PostPlot data model은 series library와 PostPlot data cache를 단 하나만 소유하고, 각 PostPlot view는 자기 visible-curve composition만 따로 가진다. **Show Plot**은 새 PostPlot view와 새 composition을 연다. 새 창은 현재 active PostPlot view의 visible composition을 초기값으로 복사하지만, 이후 show/hide와 추가 curve는 창별로 독립된다. PostPlot view를 열기 전에도 XY Plot Editor에서 series 후보와 curve를 만들 수 있으며, 이 경우 default composition을 편집한다. 각 창은 cN view id로 activate 또는 close할 수 있다.

    자동화에서는 post-plot plot ...으로 shared series library에 series를 등록하고 대상 composition에 표시한다. 데이터 등록에는 PostPlot view가 필수가 아니며, 화면 표시 창이 필요할 때 view add post-plot을 사용한다. 대상 composition의 visible PostPlot data는 post-plot export ... 또는 post-plot copy로 CSV에 저장하거나 clipboard로 복사할 수 있다. post-plot plot은 series 데이터를 필요할 때 계산하고 HDB 안에 PostPlot cache를 저장하지 않는다.
