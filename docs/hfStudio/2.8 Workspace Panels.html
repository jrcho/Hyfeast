    2.8 Workspace Panels

    hfStudio에서 메뉴와 툴바는 명령을 시작하는 입구이고, 작업의 상태 확인, 입력, 결과 검토는 workspace panel에서 이루어진다. 이 장은 메뉴별 항목을 반복하지 않고, 각 화면 영역이 맡는 역할을 정리한다.

    2.8.1 Main Window Map

    • Top menu / toolbar strip: File, Display, Selection, Preprocessing, Analysis, Postprocessing, View 명령의 진입점.
    • Model Tree: 모델 객체 구조와 per-view visibility 상태.
    • Central views: Render View, Node Table, Element Table, Chart를 tab 또는 split으로 배치하는 작업 영역.
    • Command / Selection dock: 오른쪽 dock에 놓이는 명령 입력 패널과 선택 제어 패널.
    • Output Window: import, check, analysis, Remote Control 메시지를 확인하는 로그 영역.

    2.8.2 Top Menu와 Toolbar Strip

    메뉴와 툴바는 대부분 같은 기능을 제공한다. 메뉴는 명령 전체 목록과 세부 분류를 보여 주고, 툴바는 자주 쓰는 명령을 빠르게 실행하는 진입점이다. 툴바 표시 여부는 View 메뉴에서 켜고 끌 수 있다.

    2.8.3 Model Tree

    Model Tree는 현재 모델의 객체를 종류별로 묶어 보여 준다. 체크박스는 모델 데이터를 삭제하거나 수정하지 않고, 현재 render view에서 해당 객체의 visibility만 바꾼다. 많은 항목을 한 번에 보이거나 숨겨야 하면 먼저 selection을 만들고 Select 메뉴의 Show/Hide 명령을 사용한다.

    2.8.4 Render View

    Render View는 모델 형상, 표시 항목, 해석 결과를 3D로 확인하는 중앙 view이다. Display 메뉴와 Display toolbar의 representation, projection, shading, label, grid, camera, measurement tool 명령은 기본적으로 active render view에 적용된다.

    2.8.5 Command Panel

    Command Panel은 정의와 편집 명령의 실제 입력 영역이다. Preprocessing 메뉴에서 Environment, Coordinate System, Node, Element, Material, Section, Function, Step, History, Model 같은 항목을 선택하면 오른쪽 dock에 해당 위젯이 열린다.

    Apply 또는 Apply & Close를 누르면 GUI 입력은 canonical Remote Control tail로 변환되어 history와 *.ipc.txt에 기록된다. 따라서 수동 작업을 자동화해야 할 때는 이 기록을 기준으로 Remote Control 명령을 재사용할 수 있다.

    2.8.6 Selection Dock

    Selection Dock은 Command Panel과 같은 오른쪽 dock 영역을 공유한다. 이 패널은 selection kind, selection mode, picking mode, Show/Hide, reset 작업을 모아 둔다. selection은 다음 edit/delete/assign 명령의 대상 집합이며, visibility는 render view에 보이는 상태만 바꾸는 별도 개념이다.

    2.8.7 Output Window

    Output Window는 실행 결과를 확인하는 아래쪽 로그 영역이다. 모델 import 경고, check-model 결과, analysis 실행 메시지, Remote Batch와 Remote History 상태를 여기서 확인한다. 실패 원인을 추적할 때는 먼저 Output tab의 마지막 메시지를 확인한다.

    2.8.8 Node Table과 Element Table

    Node Table과 Element Table은 중앙 view에 열리는 표 형식 작업 화면이다. Node 메뉴와 Element 메뉴의 create, update, delete 계열 명령과 같은 모델 데이터를 다룬다. table에서 수행한 편집도 같은 Remote Control 규칙과 history 기록 방식을 따른다.

    2.8.9 Chart View

    Chart View는 해석 결과나 signal analysis 결과를 그래프로 확인하는 중앙 view이다. Render View처럼 tab 또는 split으로 배치할 수 있으며, 여러 view를 띄운 상태에서는 currentView와 activeRenderView가 다를 수 있다.
